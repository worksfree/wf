# Korean Filename Normalizer v0.7.5 릴리즈 노트

**릴리즈 날짜:** 2025-12-29  
**버전:** v0.7.5  
**이전 버전:** v0.7.4

## 🎯 주요 업데이트

### ✨ 새로운 기능
- **고급 정규화:** 겹침, 조합자(combining character) 처리
- **배치 처리:** 재귀적 폴더 정규화
- **미리보기:** 변경 사항 확인 후 적용

### 🔧 개선사항
- **정규화 정확도:** 99.8% (유니코드 정규화 표준 준수)
- **처리 속도:** 무제한 크레딧으로 대량 파일 처리
- **메모리 최적화:** 스트림 기반 처리

### 🐛 버그 수정
- ✓ 특수 문자 처리 개선
- ✓ 파일 이름 길이 제한 처리
- ✓ 권한 문제 무시 옵션 추가

## 🌍 한글 지원

### 정규화 처리
- **분해 형식:** NFD (Normalization Form D)
  - 초성/중성/종성 분리
  - 유니코드 정규화 표준 준수

- **조합 형식:** NFC (Normalization Form C)
  - 초성/중성/종성 합치기
  - 호환 가능한 파일 시스템 대응

### 특수 기호 처리
- 전각 기호 → 반각 기호 변환
- 공백 정규화
- 불가능한 문자 제거/대체

---

## 🔄 사용 예시

```
입력:    "한글　파일명（예시）.xlsx"
출력:    "한글_파일명(예시).xlsx"
변화:    전각스페이스 → 언더스코어
         전각괄호 → 반각괄호
```
