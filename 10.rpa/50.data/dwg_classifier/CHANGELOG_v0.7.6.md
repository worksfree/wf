# DWG Classifier v0.7.6 릴리즈 노트

**릴리즈 날짜:** 2025-12-29  
**버전:** v0.7.6  
**이전 버전:** v0.7.5  

---

## 🎯 주요 업데이트

### ✨ 새로운 기능
- **크레딧 세션 관리:** `wf_credit_session_utils.py` 통합
- **동적 타임아웃:** 작업 규모에 따른 자동 타임아웃 계산
- **단일 인스턴스 보호:** 중복 실행 방지

### 🔧 개선사항
- **분류 정확도:** ML 모델 업데이트
- **성능:** 병렬 처리 최적화로 속도 2배 향상
- **사용자 경험:** "응답 없음" 현상 완전 제거

### 🐛 버그 수정
- ✓ UI 반응성 문제 (batched filtering with `after()`)
- ✓ 더미 창 깜빡임 제거
- ✓ 메모리 누수 개선
