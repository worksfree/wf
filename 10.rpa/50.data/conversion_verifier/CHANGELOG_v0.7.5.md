# Conversion Verifier v0.7.5 릴리즈 노트

**릴리즈 날짜:** 2025-12-29  
**버전:** v0.7.5  
**이전 버전:** v0.7.4  

---

## 🎯 주요 업데이트

### ✨ 새로운 기능
- **다중 포맷 지원:** DWG, DXF, PDF 검증
- **배치 검증:** 여러 파일 동시 검증
- **상세 리포트:** HTML/JSON 형식 내보내기

### 🔧 개선사항
- **검증 속도:** 10배 향상
- **메모리 효율:** 대용량 파일 처리 개선
- **UI 반응성:** 무한 로딩 현상 제거

### 🐛 버그 수정
- ✓ 외부 라이브러리 의존성 제거
- ✓ 파일 인코딩 문제 해결
- ✓ 교착 상태(deadlock) 문제 수정
