## 시작하기

### 시스템 요구사항
- **OS**: Windows 10/11 (64bit)
- **해상도**: FHD (1920x1080) 권장
- **메모리**: 8GB RAM 이상
- **디스크**: 500MB 이상 여유 공간

### 설치 방법
1. 설치 파일(`WorksFree_RPA_Installer.exe`)을 다운로드합니다.
2. 설치 파일을 실행하고 안내에 따라 설치를 진행합니다.
3. 설치 완료 후 바탕화면 아이콘을 더블클릭하여 앱을 실행합니다.

### 크레딧 시스템
- **체험판**: 설치 시 자동으로 체험 크레딧이 제공됩니다.
- **정식 등록**: 앱 내 "등록" 버튼을 클릭하여 정식 라이선스를 구매할 수 있습니다.
- **크레딧 소진**: 파일 처리 시 크레딧이 차감되며, 크레딧이 부족하면 작업이 중단됩니다.

## 1. BOM 엑셀 파일 저장하기

### 1.1 앱 실행

**📸 캡처 필요**: `be_01_app_launch.png`  
- 바탕화면의 "BOM 엑셀 저장" 아이콘을 더블클릭합니다.
- 앱이 실행되면 메인 화면이 표시됩니다.

![BOM 앱 시작 화면](images/be_01_app_launch.png)

> ⚠️ **강조 필요**: "BOM 엑셀 저장" 아이콘을 적색 경계선으로 표시

---

### 1.2 폴더 선택

어셈블리 파일(.asm)이 있는 폴더를 선택합니다.

**📸 캡처 필요**: `be_02_folder_select.png`  
1. **"폴더 선택"** 버튼을 클릭합니다.
2. 폴더 선택 대화상자가 열립니다.
3. 어셈블리 파일이 있는 폴더를 선택하고 **"폴더 선택"** 버튼을 클릭합니다.

![폴더 선택](images/be_02_folder_select.png)

> ⚠️ **강조 필요**: "폴더 선택" 버튼을 적색 경계선으로 표시

**선택된 폴더 확인**:
- 폴더 경로가 입력란에 표시됩니다.
- 하단 상태 표시줄에 스캔된 파일 개수가 표시됩니다 (예: `45/45`).

---

### 1.3 폴더 스캔

폴더 선택 후 자동으로 스캔이 시작됩니다.

**📸 캡처 필요**: `be_03_scan_progress.png`  
- **진행률 바**: 스캔 진행 상황을 표시합니다.
- **파일 개수**: 스캔된 어셈블리 파일 개수를 표시합니다 (예: `45/45`).
- **크레딧 표시**: 남은 크레딧과 사용 가능 작업 횟수를 표시합니다.

![폴더 스캔](images/be_03_scan_progress.png)

> ⚠️ **강조 필요**: 진행률 바와 파일 개수 영역을 적색 경계선으로 표시

---

### 1.4 BOM 저장 시작

스캔이 완료되면 BOM 엑셀 파일 저장을 시작할 수 있습니다.

**📸 캡처 필요**: `be_04_start_export.png`  
1. **"저장시작"** 버튼을 클릭합니다.
2. SolidWorks가 백그라운드에서 자동으로 실행됩니다.
3. 진행률 바가 실시간으로 업데이트됩니다.

![BOM 저장 시작](images/be_04_start_export.png)

> ⚠️ **강조 필요**: "저장시작" 버튼을 적색 경계선으로 표시

**진행 중**:
- **스피너 애니메이션**: 작업 진행 중임을 표시합니다 (`●`가 회전).
- **진행률 바**: 처리된 파일 비율을 표시합니다.
- **파일 카운터**: `12/45` 형식으로 현재 처리 중인 파일을 표시합니다.

---

### 1.5 작업 완료

모든 파일 처리가 완료되면 완료 메시지가 표시됩니다.

**📸 캡처 필요**: `be_05_complete.png`  
- **완료 메시지**: "BOM 저장이 완료되었습니다!" 메시지 박스가 표시됩니다.
- **출력 파일**: 선택한 폴더에 각 어셈블리별 BOM 엑셀 파일(`.xlsx`)이 생성됩니다.

![작업 완료](images/be_05_complete.png)

**출력 파일 확인**:
```
선택한_폴더/
├── Assembly1.asm
├── Assembly1_BOM.xlsx  ← 생성된 파일
├── Assembly2.asm
├── Assembly2_BOM.xlsx  ← 생성된 파일
└── ...
```

## FAQ & 문제 해결

### Q1. 앱이 실행되지 않아요.
**A**: 다음 사항을 확인하세요:
- Windows 10/11 64bit인지 확인
- 바이러스 백신 예외 등록 (WorksFree 폴더)
- 관리자 권한으로 실행 시도

### Q2. "크레딧이 부족합니다" 메시지가 나와요.
**A**: 
- 체험판 크레딧이 모두 소진되었습니다.
- **"등록"** 버튼을 클릭하여 정식 라이선스를 구매하세요.
- 또는 **"업데이트"** 버튼을 클릭하여 크레딧을 동기화하세요.

### Q3. SolidWorks/AutoCAD가 응답하지 않아요.
**A**:
- 작업 중 다른 프로그램을 실행하지 마세요.
- 대용량 파일의 경우 시간이 오래 걸릴 수 있습니다.
- 작업 중 강제 종료하지 마세요 (크레딧이 차감될 수 있습니다).

### Q4. 분류되지 않은 파일이 있어요. (DWG 분류)
**A**:
- 엑셀 파일에 해당 도번이 없는 경우 **"미분류"** 폴더로 이동됩니다.
- 엑셀 파일의 도번 컬럼과 DWG 파일명이 일치하는지 확인하세요.

### Q5. 엑셀 파일이 생성되지 않아요. (BOM 저장)
**A**:
- 어셈블리 파일(.asm)이 정상인지 확인하세요.
- SolidWorks에서 수동으로 열리는지 테스트하세요.
- 파일 경로에 한글이나 특수문자가 있는지 확인하세요.

## 관리자 기능

### 관리자 모드 진입

**📸 캡처 필요**: `admin_01_toggle.png`  
1. 앱 실행 후 **"진행률:"** 레이블을 클릭합니다.
2. 비밀번호 입력 창이 표시됩니다.
3. 관리자 비밀번호를 입력하고 **"확인"** 버튼을 클릭합니다.

![관리자 모드](images/admin_01_toggle.png)

> ⚠️ **강조 필요**: "진행률:" 레이블을 적색 경계선으로 표시

### 실시간 로그 확인

**📸 캡처 필요**: `admin_02_log_frame.png`  
- 관리자 모드에 진입하면 창 하단에 **실시간 로그** 영역이 표시됩니다.
- 앱의 모든 작업 로그를 실시간으로 확인할 수 있습니다.
- **"자동 스크롤"** 체크박스를 활성화하면 최신 로그가 자동으로 표시됩니다.

![실시간 로그](images/admin_02_log_frame.png)

### 테스트 데이터 생성 (DWG 분류만 해당)

**📸 캡처 필요**: `admin_03_test_data.png`  
- DWG 분류 앱의 관리자 모드에서만 사용 가능합니다.
- **"테스트 데이터 생성"** 버튼을 클릭하면 샘플 DWG 파일과 엑셀 파일이 생성됩니다.
- **"테스트 데이터 삭제"** 버튼으로 테스트 데이터를 삭제할 수 있습니다.

![테스트 데이터](images/admin_03_test_data.png)
