## 📚 학습 내용

### 1. PyInstaller 번들 환경 차이
- **`sys.frozen`**: 번들 환경 여부 판단
- **`sys._MEIPASS`**: 번들 임시 디렉토리 경로
- **파일 복사 vs 직접 참조**: 번들에서는 직접 참조가 더 안정적

### 2. PowerShell 스크립트 모범 사례
```powershell
# 검증 결과를 배열로 저장
$script:PassedChecks = @()
$script:FailedChecks = @()

# Exit Code로 성공/실패 전달
if ($FailedChecks.Count -gt 0) { exit 1 } else { exit 0 }

# 상위 스크립트에서 Exit Code 확인
if ($LASTEXITCODE -ne 0) { 
    Write-Host "검증 실패" -ForegroundColor Red
}
```

### 3. JSON 설정 파일 인코딩
- **UTF-8 without BOM** 필수
- PowerShell: `-Encoding UTF8`
- Python: `encoding='utf-8'`

### 4. 구글 시트 연동 필수 요소
```json
{
  "google_sheets": {
    "sheet_id_prod": "실제 시트 ID",

    "scope": [
      "https://spreadsheets.google.com/feeds",
      "https://www.googleapis.com/auth/drive"
    ]

}
```

- **Scope**: 2개 이상 (spreadsheets, drive)
