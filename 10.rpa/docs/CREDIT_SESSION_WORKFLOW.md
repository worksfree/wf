# BOM Exporter 크레딧 세션 관리 워크플로우

## 📌 개요

BOM Exporter는 **세션 기반 크레딧 관리**를 통해 크레딧 부족 시에도 작업을 안전하게 중단하고 재개할 수 있습니다.

동일 폴더에서 **크레딧이 부족한 상태로 작업을 시작하고 중단**한 후, **다음 실행 시 동일 폴더를 지정**하면 어떻게 처리되는지 모든 시나리오를 정리합니다.

---

## 🔑 핵심 개념

### 1. 세션 식별자
- **폴더 경로**: 작업 폴더 경로 자체가 세션 ID 역할
- **상태 파일**: `{폴더}/wf_pending_list.txt` - 크레딧 부족으로 중단된 미완료 파일 목록

### 2. 크레딧 차감 시점
```python
# automation.py Line 2045
credit_result = self.credit_manager.deduct_credits_by_policy(
    file_count=1, 
    description=f"BOM 추출: {os.path.basename(sldprt_file)}"
)
```
- **시점**: 파일 처리 **성공 직후** (BOM 엑셀 생성 완료 시)
- **단위**: 파일당 credit_per_work (기본 100 크레딧)

### 3. 크레딧 부족 감지
```python
# automation.py Line 2019
if not credit_result["success"]:
    self.credit_shortage_stop = True
```
- 파일 처리 성공 후 크레딧 차감 시도
- 차감 실패 → `credit_shortage_stop = True` 설정
- 남은 파일 목록을 `wf_pending_list.txt`에 저장
