# DWG Batch Print v1.0.0 릴리즈 노트

**릴리즈 날짜:** 2025-12-29  
**버전:** v1.0.0 (신규 앱)  
**이전 버전:** -

---

## 🎯 주요 기능

### ✨ 신규 기능
- **일괄 인쇄:** 여러 DWG 파일을 한 번에 인쇄
- **크레딧 기반 제어:** 각 작업당 크레딧 소비
- **정책 관리:** 관리자 정책에 따른 제한
- **로그 기록:** 모든 인쇄 작업 자동 기록

### 🔧 주요 개선사항
- **빠른 인쇄:** 병렬 처리로 대량 파일 처리
- **오류 복구:** 실패한 파일 자동 재시도
- **사용자 피드백:** 실시간 진행률 표시

---

## 📊 기술 사양

| 항목 | 값 |
|------|-----|
| 개발 언어 | Python 3.13 |
| GUI 프레임워크 | Tkinter |
| CAD 연동 | pyautogui + LibreCAD 라이브러리 |
| 최소 요구사항 | Windows 10 21H2+ |
| 메모리 | 2GB RAM |
| 디스크 | 120MB |
| 실행 파일 크기 | ~110MB (onedir) |
