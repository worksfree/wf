# Bom Exporter v0.8.1 릴리즈 노트

**릴리즈 날짜:** 2025-12-29  
**버전:** v0.8.1  
**이전 버전:** v0.8.0  

---

## 🎯 주요 업데이트

### ✨ 새로운 기능
- **크레딧 시스템 통합:** 파일당 크레딧 사용량 추적
- **정책 기반 제한:** 사용자 정책에 따른 자동 제한
- **글로벌 설정:** `wf_global_settings.json`으로 중앙화된 관리

### 🔧 개선사항
- **UI 반응성:** 더미 창 깜빡임 제거
- **메모리 관리:** 대용량 파일 처리 최적화
- **에러 처리:** 사용자 친화적 오류 메시지

### 🐛 버그 수정
- ✓ frozen 모드 경로 불일치
- ✓ 설정 파일 로딩 오류
- ✓ 동시성 문제 해결

| 항목 | 값 |
|------|-----|
| 개발 언어 | Python 3.13 |
| GUI 프레임워크 | Tkinter |
| 패키징 | PyInstaller |

- 사용자 홈 `~/.wf_rpa/bom_exporter/` 경로 기반으로 통합
- 모든 설정 파일 숨김 처리
- JSON 기반 설정 확대

### 테스트
- 13개 통합 테스트 추가 (모두 통과)
- 크레딧 시스템 검증 완료
