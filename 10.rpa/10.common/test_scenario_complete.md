# 🧪 BOM2Excel 크레딧 관리 시스템 완전 테스트 시나리오

## 📋 **테스트 개요**
**목적**: BOM2Excel 앱에서 체험판 → 구매 → 수동 동기화 전체 플로우 검증

**예상 결과**: 깨끗한 상태에서 시작

**확인 사항**:

## 💳 **Phase 2: 체험판 크레딧 사용 테스트**

### **Step 2-1: 소량 크레딧 사용**
1. 테스트 폴더 선택 (5개 정도의 .slddrw 파일)
2. "BOM 엑셀 저장" 버튼 클릭
3. BOM 추출 실행

**예상 결과**:
- [ ] 크레딧 차감: 2000 → 1995 (5개 파일)
- [ ] 크레딧 표시 업데이트 (파란색 유지)
- [ ] BOM 파일 정상 생성

### **Step 2-2: 대량 크레딧 사용 시뮬레이션**
```python
# 테스트용 크레딧 차감 스크립트
from wf_creditmanager import CreditManager
cm = CreditManager('bom2excel', 'test_user@worksfree.com')

# 1900개 크레딧 추가 차감
for i in range(380):  # 5 * 380 = 1900
    result = cm.deduct_credits(5)
    print(f"차감 {i+1}: {result['remaining_trial']}")
```

**예상 결과**:
- [ ] 체험판 크레딧: 1995 → 95
- [ ] 크레딧 표시: "크레딧: 95" (주황색)

### **Step 2-3: 크레딧 부족 경고 테스트**
1. 100개 이상 파일이 있는 폴더 선택
2. BOM 추출 시도

**예상 결과**:
- [ ] 크레딧 부족 경고 메시지 표시
- [ ] "현재 남은 크레딧: 95, BOM 추출을 계속 진행하시겠습니까?" 확인 창

## 💰 **Phase 4: 크레딧 구매 및 수동 동기화**

```python

    'payment_id': 'PAY_TEST_001',
    'amount': 50000,
    'currency': 'KRW'
})
```

**예상 결과**:
- [ ] 구매 크레딧 1000개 추가 완료

### **Step 4-2: UI에서 수동 동기화**
1. "크레딧 업데이트" 버튼 클릭
2. 동기화 진행 확인

**예상 결과**:
- [ ] 버튼 텍스트 변경: "크레딧 업데이트" → "동기화 중..."

- [ ] 크레딧 표시 업데이트: "크레딧: 1500" (파란색)

### **Step 4-3: 구매 크레딧으로 BOM 추출**

2. BOM 추출 실행

**예상 결과**:

- [ ] 정상적인 BOM 추출
