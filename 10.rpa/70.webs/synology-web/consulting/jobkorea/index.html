📌 주의사항
• 첫 실행 시 브라우저 창이 열리고 로그인 화면이 나옵니다 — 수동으로 로그인하면 세션이 저장됩니다
• 이후 실행부터는 저장된 세션을 재사용하여 자동 로그인됩니다
• HEADLESS=true로 설정하면 브라우저 창 없이 백그라운드 실행 가능합니다
• 중복 발송 방지: Supabase의 발송 이력을 기반으로 이미 제안한 후보자는 자동 제외됩니다
• 잡코리아 UI 변경 시 선택자(selector) 수정이 필요할 수 있습니다
