# 개인 자산 통합 · 연금/배당 세후 시뮬레이터 — 개발 요구사항 명세서 (v2)

> 용도: VS Code + Claude Code 구현용 스펙. 이 문서를 그대로 붙여 넣고 구현을 지시한다.
> 기준 시점: 2026년 (세법·건보료 기준은 §7, §8). 본 문서는 **무엇을 만들지**를 정의하며, 코드(DDL·함수)는 포함하지 않는다.
> 사용 형태: 개인용 폐회로(내 화면→나) 웹앱, Synology NAS 배포.

---

## 1. 프로젝트 개요

### 1.1 목적
여러 증권 계좌에 흩어진 주식·ETF 보유 내역을 한곳에 통합하여 평가손익·수익률을 보여주고, **월배당 상품을 연금으로 전환·수령할 때의 세전/세후 금액과 건강보험료 영향**을 시뮬레이션한다.

### 1.2 설계 원칙 (구현 시 반드시 준수)
1. **폐회로**: 시세는 인증된 본인에게만 표출. 외부 공개 대시보드 금지. NAS reverse proxy + 인증 게이트.
2. **보유는 입력값, 시세는 피드, 세금은 계산**: 증권사 계좌 API로 잔고를 자동 동기화하지 않는다(라이선스·멀티브로커 복잡도 회피). 보유 내역은 사용자가 입력.
3. **계좌 유형(account wrapper)이 모든 과세·건보료 분기의 축**: 동일 종목이라도 일반/연금/ISA에 따라 결과가 전부 달라진다.
4. **세법·건보료 수치는 설정 테이블로 분리**: 세율·한도·점수당 금액을 하드코딩하지 말 것. 연도별 config로 로드해 매년 갱신만으로 대응.
5. **모든 금액은 원(KRW) 정수 기준.**

## 3. 데이터 모델 (엔티티·필드 명세)

> Claude Code는 아래 명세를 바탕으로 Supabase 스키마와 TypeScript 타입을 생성한다.

### 3.1 엔티티 관계
```
HouseholdMember(가구원) 1─N Account 1─N Holding N─1 Instrument 1─N Dividend/Quote
Account(연금계좌) 1─N PensionFundingSource (재원 구성)
HouseholdMember 1─N RealEstate / LeaseDeposit / FinancialAsset / Liability
Config: TaxConfig, InsuranceConfig (연도별)
SimulationScenario (입력/결과 저장)
```

### 3.2 핵심 열거값
- **AccountType**: `TAXABLE`(일반 위탁), `PENSION_SAVING`(연금저축), `IRP`(개인형 퇴직연금), `DC`(확정기여형), `DB`(확정급여형), `ISA`
- **InstrumentKind**: `STOCK`, `ETF`
- **EtfTaxType**: `DOMESTIC_EQUITY`(국내주식형), `BOND_OTHER`(채권·기타형), `OVERSEAS`(해외형)
- **PensionFundingKind**: 아래 §5 참조

### 3.3 엔티티별 필드
**HouseholdMember (가구원)** — 부부 분산·동반탈락 시뮬레이션용
| 필드 | 타입 | 설명 |
|---|---|---|
| name | text | 이름 |
| role | enum | SELF / SPOUSE / DEPENDENT |
| birthDate | date | 연금소득세 나이별 세율 판정 |
| isEmployeeInsured | bool | 직장가입자 여부(피부양자 부양자) |

**Account (계좌)**: ownerId(FK), name, broker(표시용), type(AccountType)

**Instrument (종목 마스터)**: code(6자리 PK), name, kind, market, isMonthlyDividend, distributionCycle(MONTHLY/QUARTERLY/ANNUAL), etfTaxType

**Holding (보유)**: accountId(FK), instrumentCode(FK), quantity, avgBuyPrice(평단, 제비용 포함), feesIncluded(bool), extraFees(제비용 별도 입력 시), acquiredAt

**DividendHistory**: instrumentCode(FK), payDate, amountPerShare(1주당 세전 분배금)

**QuoteSnapshot**: instrumentCode(FK), price, asOf, source(NAVER/YFINANCE), delayedMinutes

**PortfolioSnapshot**: ownerId(FK), asOf(date), totalValue, totalCost, cumulativeDividend — 추세 그래프용

**PensionFundingSource (퇴직연금 재원 구성)** — §5의 과세 분기 핵심
| 필드 | 타입 | 설명 |
|---|---|---|
| accountId | FK | 연금계좌 |
| kind | enum | PensionFundingKind |
| amount | bigint | 해당 재원 잔액(원) |
| deferredRetirementTax | bigint? | 이연퇴직소득세(분류과세 계산용) |

**RealEstate (부동산)**: ownerId(FK), label, isResidence(1세대1주택 거주), propertyTaxBase(재산세 과세표준 — 건보 산정 기준), marketValue(참고)

**LeaseDeposit (전월세 보증금, 임차)**: ownerId(FK), isJeonse(전세/월세), deposit(보증금), monthlyRent(월세)
- ※ 지역가입자 부과 시에만 30% 환산 반영. 피부양자 재산판정엔 미반영.

**FinancialAsset (금융자산)**: ownerId(FK), label, amount(평가액), expectedAnnualIncome(연 예상 이자·배당)
- ※ **건보 재산점수 미포함**. 발생 소득(이자·배당)만 소득으로 반영.

**Liability (부채)**: ownerId(FK), label, balance, isResidenceLoan(실거주 주택 대출), reportedToNhis(공단 통보 여부)
- ※ **건보 재산에서 원칙적으로 차감 안 됨**. 자산현황·순자산 표시용. 단 실거주 주택 구입·임차 대출은 공단 통보 시 재산 제외 가능.

**TaxConfig / InsuranceConfig**: §7, §8의 수치를 연도별로 보관(year를 키로).

**SimulationScenario**: ownerId, name, params(JSON), result(JSON)

## 4. 계좌 유형별 과세·건보료 매트릭스 (구현 핵심)
| 계좌 유형 | 분배금(배당) 과세 | 매매차익 | 인출/수령 시 | 피부양자 소득 합산 |
|---|---|---|---|---|
| 일반 위탁 | 배당소득 15.4% 원천(연 2천만원 초과분 종합과세) | 국내주식·국내주식형 ETF 비과세 / 해외·기타 ETF 배당소득·양도세 | 해당 없음 | 금융소득으로 합산(연 1천만원 초과 시 전액) |
| 연금저축 | 계좌 내 비과세(과세이연) | 과세이연 | 연금수령 시 연금소득세(§7.1) | **합산 제외(사적연금)** |
| IRP | 계좌 내 비과세(과세이연) | 과세이연 | 연금소득세 + 퇴직재원은 분류과세(§7.2) | **합산 제외(사적연금)** |
| ISA | 순이익 200만원(서민형 400만원) 비과세, 초과분 9.9% 분리과세 | 손익통산 | 만기 후 연금계좌 전환 시 추가 세액공제 | ISA 내 발생 소득 건보 산정 제외 |

## 5. 퇴직연금 재원 구분 (직접용어 / 전문용어 병행)

연금계좌 적립금은 자금 원천(재원)에 따라 과세가 갈린다. `PensionFundingKind`로 모델링한다.

| 직접적인 용어 | 전문용어 | enum 값 | 연금 수령 시 과세 |
|---|---|---|---|
| 회사납입분(퇴직금) | 이연퇴직소득 / 사용자부담금 | `DEFERRED_RETIREMENT` | 퇴직소득세 연계, 30~40% 감면된 연금소득세 → **분류과세**, 1,500만원 한도 무관 |
| 본인납입분(세액공제 받은) | 세액공제 받은 가입자부담금 | `DEDUCTED_CONTRIB` | 연금소득세 3.3~5.5% → **분리/종합과세**, 1,500만원 한도 적용 |
| 본인납입분(세액공제 안 받은) | 과세제외 가입자부담금 | `NONDEDUCTED_CONTRIB` | 인출 시 **비과세(원금)**, 한도에서 제외 |
| 불어난 수익 | 적립금 운용수익 | `INVESTMENT_GAIN` | 연금소득세 → 1,500만원 한도 적용 |

**법정 인출순서**(엔진이 따라야 함): ① 과세제외 납입금 → ② 이연퇴직소득(회사 퇴직금) → ③ 세액공제 받은 납입금 + 운용수익.

제도 유형 참고: DB형(확정급여형, Defined Benefit) / DC형(확정기여형, Defined Contribution) / IRP(개인형 퇴직연금). DC·IRP의 부담금은 사용자부담금(회사)과 가입자부담금(본인)으로 나뉜다.

## 6. 기능 요구사항 (Functional Requirements)

- **FR-1 종목 조회·등록**: 종목코드/명으로 검색해 Instrument 등록, 월배당 여부·분배주기·ETF 과세유형 설정(자동 추정 + 수동 보정).
- **FR-2 보유·평단 입력**: 계좌별 종목·수량·평단 입력. 제비용 별도 입력 시 평단 자동 반영.
- **FR-3 월배당률(두 지표 동시)**: ① 시가 배당률 = 연환산 분배금 ÷ 현재가, ② **평단 대비 배당률(YoC)** = 연환산 분배금 ÷ 평단. 월 단위 표시도 제공(예: 평단 10,000원·월 분배 100원 → 월 1.0%, 연 12.0%).
- **FR-4 수익률**: 평가손익 = (현재가−평단)×수량, 누적수익률 = (평가손익+누적분배금)÷매입원가. 자본수익/인컴 분리 표기.
- **FR-5 계좌 통합 뷰**: 여러 계좌 합산 총평가액·총수익률. 계좌유형별·명의자별 필터.
- **FR-6 연금 전환 시뮬레이션(월배당 유지)**: 입력=대상 종목/계좌, 가정 분배율 슬라이더(연 10~12%), 개시 나이, 수령 방식. 계좌가 연금계좌면 재원별 과세, 일반계좌면 배당소득. 출력=연도별 세전→세금→건보료→세후.
- **FR-7 과세 시뮬레이션 엔진**: §7 규칙으로 분리/분류/종합 자동 판정 + 선택지 비교. 1,500만원 cliff 시각화(근접 경고 + 초과 시 두 선택지 세액 비교). 각 판정의 **근거 문구**를 출력해 설명 패널에 표시.
- **FR-8 건보료·피부양자 시뮬레이션**: §8 규칙으로 자격 유지/탈락 판정, 탈락 시 지역보험료 추정, 부부 동반탈락·명의 분산 효과 비교.
- **FR-9 세전/세후 비교 리포트**: 동일 시나리오를 (a)세전 (b)세금 차감 (c)건보료 포함으로 비교. 같은 종목을 일반 vs 연금 vs ISA에 담았을 때를 한 화면에서 비교.
- **FR-10 재산·부채 입력**: 부동산 과표, 전월세 보증금, 금융자산, 부채 입력(건보 산정 + 순자산 현황).

## 7. 과세 규칙 명세 (2026 — TaxConfig로 분리)

### 7.1 사적연금(연금저축·IRP) 연금소득세
판정 대상 = **세액공제 받은 납입분 + 운용수익**의 연 수령액(비과세 원금·이연퇴직소득·공적연금 제외).
- **연 1,500만원 이하**: 저율 분리과세(연금소득세) 또는 종합과세 중 유리한 쪽 선택.
  - 나이별 세율(지방세 포함, 확정기간형): 55~69세 **5.5%**, 70~79세 **4.4%**, 80세+ **3.3%** (종신형: 80세 미만 4.4%, 80세+ 3.3%)
- **연 1,500만원 초과**: 종합과세(6.6~49.5% 누진) 또는 **전액 16.5% 분리과세** 중 유리한 쪽 선택(소득세법 제64조의4). 엔진은 두 세액을 모두 계산해 비교.
- **한도에서 제외되는 재원**: 세액공제 안 받은 원금, 이연퇴직소득(§7.2), 공적연금.
- 종합과세 선택 시: 연금소득공제(350만~900만원), 인적공제(기본 150만원, 70세+ 경로우대 100만원) 반영.

### 7.2 분류과세 — 이연퇴직소득(회사납입분/퇴직금)
연금수령 시 산출 퇴직소득세의 **30% 감면**(연금 실수령 10년 이하), **40% 감면**(10년 초과)된 연금소득세로 분류과세. 종합과세·1,500만원 한도와 무관.

### 7.3 배당소득(일반계좌 월배당 ETF/주식)
- 금융소득(이자+배당) 연 **2,000만원 이하**: 15.4% 원천징수로 종결(분리과세).
- **2,000만원 초과**: 초과분을 다른 종합소득과 합산(비교과세).
- (옵션) 2026 고배당 분리과세 특례: 일정 요건 배당에 과표 구간별 15.4/22/27.5/33% — 일반 ETF엔 기본 규칙. 토글로 둔다.

### 7.4 ETF 과세 구분
국내주식형: 매매차익 비과세·분배금=배당소득. 채권·기타·해외형: 매매차익도 배당소득(보유기간 과세) 또는 양도세 → `etfTaxType`으로 분기.

## 8. 건강보험료·피부양자·재산 규칙 명세 (2026 — InsuranceConfig로 분리)

### 8.1 기본 수치
- 건보료율 **7.19%**. 부과는 약 2년 시차(예: 2026년 부과 = 2024년 소득 기준) — 시차 안내 문구 표시.
- 재산 점수당 금액·장기요양보험료율은 매년 고시 → config 값 확인 후 입력.

### 8.2 피부양자 자격 — 소득 요건
- 연 합산소득 **2,000만원 초과 시 박탈**(지역가입자 전환).
- 합산 항목: 근로 + 사업 + 금융(이자·배당) + 공적연금 + 기타.
  - 공적연금 **100% 반영**.
  - 금융소득 연 **1,000만원 초과 시 초과분이 아니라 전액** 합산(999만원→0, 1,001만원→전액).
  - **사적연금(연금저축·IRP·연금보험) 제외.** ← 핵심 절세 포인트.
  - ISA 내 발생 소득 제외.

### 8.3 피부양자 자격 — 재산 요건
- 본인 소유 부동산 재산세 과표 **9억원 초과 → 박탈**.
- 과표 **5.4억~9억원 + 연소득 1,000만원 초과 → 박탈**.
- 전월세 보증금(임차)은 피부양자 재산판정에 **미반영**(소유 부동산만).

### 8.4 부부 동반탈락
부부 중 한 명이 소득 기준 초과로 탈락하면 배우자도 함께 탈락. 명의 분산 시뮬레이션에 반영.

### 8.5 지역가입자 보험료 (탈락 시 추정)
- 소득보험료 + 재산보험료(점수×점수당 금액).
- 소득보험료: 사적연금 제외, **공적연금 50% 반영**(피부양자 판정과 반영률 다름).
- 재산점수 기준액 = 부동산 과표 + 전월세 보증금 **30% 환산** − 기본공제(**1억**, 2024.2~).
  - 월세 환산: (월세보증금 + 월세/0.025) × 30%.
  - **부채 미차감**(예외: 실거주 주택 대출 공단 통보 시 제외). **금융자산 잔액 자체 미포함**(소득만 반영).
- 정밀 재산점수는 국민건강보험법 시행령 별표4 구간표로 산정(1차 버전은 근사 + "공단 모의계산 권장" 안내).
- 임의계속가입(최대 36개월, 직장 보험료 수준 유지) 안내.

## 9. 시뮬레이션 시나리오 & 출력

### 9.1 대표 시나리오 (요청 반영)
"월배당 10~12% ETF 보유 → 연금 전환 후 월배당 유지 수령":
1. 입력: 보유액, 가정 분배율(연 10/11/12% 슬라이더), 계좌 유형, 개시 나이, 다른 소득·재산.
2. 연도별 산출: 세전 수령액 → 과세 구분 자동 판정(분리/분류/종합) 및 선택지 비교 → 세금 → 건보료(피부양자 유지/탈락→지역보험료) → **세후 실수령액 + 실효부담률**.
3. 비교 축: 계좌유형(일반 vs 연금 vs ISA), 1,500만원 한도 내 vs 초과, 부부 분산 vs 단독.

### 9.2 출력 화면
- 통합 대시보드: 총자산·총수익률·종목별 수익률·월배당 캘린더·순자산(자산−부채).
- 배당률 패널: 시가배당률 / 평단 대비 배당률(YoC).
- 연금 시뮬 패널: 연도별 세전→세금→건보료→세후 폭포(waterfall) 그래프 + 표.
- "왜 이 과세인가" 설명 패널: 어느 한도/기준을 넘었는지 근거 문구 표시.

## 10. 비기능 요구사항
- **시세 수집**: `getQuote(code)` 인터페이스로 추상화, 구현 2종(네이버·yfinance), 폴백 체인(네이버→yfinance), 마지막 정상값 캐싱(stale-while-error), 실패 시 알림(텔레그램/메일), 5분 폴링·장 마감 후 중단.
- **보안·폐회로**: 인증 게이트 필수, 비로그인 화면 시세 미표출, App Key 서버 환경변수, 외부 노출 시 noindex.
- **설정 분리**: 세율·한도·건보료 수치는 config 테이블에서 로드, 연도 선택 가능.
