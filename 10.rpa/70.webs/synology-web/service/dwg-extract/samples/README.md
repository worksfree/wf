# DWG 샘플 파일 — 대기 중 (사용자가 직접 복사 필요)

이 폴더는 비어 있다. UI/JS는 이미 완성돼서 아래 3개 파일이 여기 놓이는 즉시 동작한다
(Auto Mode 분류기가 실제 회사 도면 파일 복사를 차단해서 사용자가 직접 복사해야 함).

```
D:\test_data\셈플\초기\DWD-2524-0330-07.DWG  →  sample_singlepart.DWG    (단품, BOM 없음)
D:\test_data\셈플\초기\DWD-2524-0340-00.DWG  →  sample_assembly_bom.DWG  (조립도, BOM 24행)
D:\test_data\셈플\초기\DWD-2524-0000-00.DWG  →  sample_top_assembly.DWG (최상위 조립도, BOM 1행)
```

## ⚠️ 임시 조치임을 기록해둔다

이 3개는 (주)엠디텍의 실제 도면이다(표제란에 회사명·담당자 실명 포함). 공개 라이선스로
재배포 가능한 CAD 조립도(BOM까지 채워진) 대체 자료를 찾아봤으나 없었다(제목블록 *템플릿*
라이브러리는 많지만, 완성된 조립도+BOM을 명확한 재배포 라이선스로 제공하는 곳은 못 찾음).
사용자가 "안 되면 임시로 실제 파일 사용"을 명시적으로 승인해서 이 방식으로 구현했다
(2026-07-25).

허브가 여러 테넌트(타 고객사)가 함께 쓰는 플랫폼이라, 다른 회사 로그인 사용자도 이 파일을
내려받을 수 있다는 점은 남아있는 리스크다. 재검토 옵션:
- 표제란 텍스트(회사명·담당자명)만 더미 값으로 치환한 도면으로 교체
- 사내 CAD팀에 완전히 가상의 샘플 조립도 제작 요청
- 진짜 공개 라이선스 CAD 데이터가 새로 나오면 교체
