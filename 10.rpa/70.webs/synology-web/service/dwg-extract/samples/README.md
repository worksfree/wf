# DWG 샘플 파일

6개 실제 도면 + 그 중 3개의 정답 BOM 엑셀(Ground Truth)이 놓여있다.

```
sample_singlepart1.DWG       단품 도면 1 (BOM 없음)
sample_singlepart2.DWG       단품 도면 2 (BOM 없음 — 홀 가공 치수표를 BOM으로
                              오인하는 실제 버그를 이 파일로 발견·수정함, 2026-07-25)
sample_assembly_bom1.DWG     조립도 1 (BOM 24행) + sample_assembly_bom1.xlsx(정답)
sample_assembly_bom2.DWG     조립도 2 (BOM 31행) + sample_assembly_bom2.xlsx(정답)
sample_assembly_bom3.DWG     조립도 3 (BOM 14행) + sample_assembly_bom3.xlsx(정답)
sample_top_assembly.DWG      최상위 조립도 (BOM 1행)
```

.xlsx 파일은 웹 갤러리에 노출되지 않는다(업로드 테스트용 .DWG만 카드로 제공) —
회귀 테스트 시 `dwg_extract.py`의 추출 결과를 이 엑셀 내용과 대조하는 정답지로만 쓴다.

## 이 파일들로 발견·수정한 실제 버그 (2026-07-25)

- **열 오배정**: 일부 행이 특정 열(MATERIAL 등)의 셀 자체가 없어서(빈 문자열
  placeholder조차 없음), 순서대로 배정하던 로직이 뒤 열 값을 앞으로 밀어 넣는
  버그를 `sample_assembly_bom2`로 발견 — 열별 기준 X좌표(완전한 행들의 중앙값)에
  최근접 매칭하는 방식으로 수정.
- **BOM 오판정**: 홀/가공 치수표(헤더: 태그·크기·수량)가 진짜 BOM보다 커서
  잘못 선택되는 버그를 `sample_singlepart2`로 발견 — BOM 특이 어휘(제조사·재질·
  표면처리·열처리 등) 검증 단계 추가로 수정.

수정 후 재검증: `sample_assembly_bom1`(24/24 정확), `bom2`(31/31, 정답 불일치 2건은
줄바꿈 표기 차이·DWG 원본에 없고 엑셀에만 있는 값으로 코드 버그 아님), `bom3`(14/14
정확), `singlepart1/2`(정상적으로 BOM 없음 판정), `top_assembly`(1/1 정확).

## ⚠️ 임시 조치임을 기록해둔다

이 파일들은 (주)엠디텍의 실제 도면이다(표제란에 회사명·담당자 실명 포함). 공개
라이선스로 재배포 가능한 CAD 조립도(BOM까지 채워진) 대체 자료를 찾아봤으나 없었다
(제목블록 *템플릿* 라이브러리는 많지만, 완성된 조립도+BOM을 명확한 재배포 라이선스로
제공하는 곳은 못 찾음). 사용자가 "안 되면 임시로 실제 파일 사용"을 명시적으로
승인해서 이 방식으로 구현했다(2026-07-25).

허브가 여러 테넌트(타 고객사)가 함께 쓰는 플랫폼이라, 다른 회사 로그인 사용자도 이
파일을 내려받을 수 있다는 점은 남아있는 리스크다. 재검토 옵션:
- 표제란 텍스트(회사명·담당자명)만 더미 값으로 치환한 도면으로 교체
- 사내 CAD팀에 완전히 가상의 샘플 조립도 제작 요청
- 진짜 공개 라이선스 CAD 데이터가 새로 나오면 교체
