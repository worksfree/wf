⚙ 초기 설정 필요

❌ NAS PHP API 응답 없음 /admin/api/upload.php

원인 후보:

  • Web Station에서 PHP 패키지가 중지됐거나 버전이 바뀜
  • 가상 호스트 설정에 PHP 프로세서가 연결 안 됨
  • 최신 배포 시 admin/api/upload.php가 NAS에 전송 안 됨
  • NAS 재부팅 후 /volume1/web/nas_uploads/ 디렉터리 없어짐

조치:

ssh admin@nas "mkdir -p /volume1/web/nas_uploads && chown http:http /volume1/web/nas_uploads"

DSM → 패키지 센터 → Web Station → PHP 버전 확인 / 가상 호스트 PHP 연결 확인

❌ Supabase storage_files 테이블 접근 실패

  • 테이블에 RLS가 활성화됐지만 SELECT 정책이 없음
  • 테이블이 삭제됐거나 folder / backend 컬럼이 없음

조치 — Supabase SQL Editor에서 실행:

ALTER TABLE public.storage_files ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "storage_admin" ON public.storage_files; CREATE POLICY "storage_admin" ON public.storage_files FOR ALL USING (auth.uid() IS NOT NULL) WITH CHECK (auth.uid() IS NOT NULL); ALTER TABLE public.storage_files ADD COLUMN IF NOT EXISTS backend text DEFAULT 'nas';

❌ Supabase Storage 버킷 wf-assets 접근 불가

버킷은 존재하지만 업로드 정책이 없습니다. Supabase SQL Editor에서 실행:

CREATE POLICY "wf_assets_auth" ON storage.objects FOR ALL TO authenticated USING (bucket_id = 'wf-assets') WITH CHECK (bucket_id = 'wf-assets');
