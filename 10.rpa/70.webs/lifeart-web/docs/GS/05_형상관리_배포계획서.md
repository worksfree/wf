## 1. 버전 체계
- 표기: `MAJOR.MINOR.PATCH.BUILD` (푸터 노출, deploy.ps1 이 자동 증가)
- 증가 규칙: pre-test 배포=BUILD↑ / test 배포=PATCH↑(BUILD 리셋) / production 배포=MINOR↑(PATCH·BUILD 리셋)
- 캐시버스팅: 배포 사본의 /assets 참조에 `?v=버전` 자동 부여

## 3. 본 형상(v2-redesign-gs)에 포함된 변경
1. **콘텐츠 대개편**: 사업계획서(IR) 메시지 반영(26년·700건+·한화오션 독점·특허·AI 4축), 납품 실사진 15장(albums/) 도입, 갤러리 '기업·기관 납품' 신설
2. **액자 상품 강화**: 실사진 3종(frames/), 라인별 소개, AI 포토북 티저 이미지
3. **UX 결함 수정 3건**(06 결함보고서): 비로그인 헤더 버튼 미표시, 모바일 가로 스크롤, 관리자 로컬 400 오류
4. **히어로 개선**: 즉시 시작(DB 대기 제거)·켄번즈 줌 체감 개선·줌 풀림 아티팩트 제거
5. **성능 최적화**: 참조 이미지 전수 500KB 이하 (총 ~45MB→~3MB)
6. **품질 산출물**: GS 문서 세트(docs/GS 01~06), 자동화 시험 스위트(tests/gs-cert.spec.js)

## 4. 배포 절차 (deploy.ps1)
```powershell
cd 10.rpa/70.webs/lifeart-web
.\deploy.ps1 -Target 1              # ① pre-test 검수 배포
.\deploy.ps1 -Target 2 -Stage N     # ② test(고객사 공개, 단계 N=1~5)
.\deploy.ps1 -Target 3              # ③ production (yes 확인 필요)
```
- 배포 시 자동 수행: NAS 현재본 백업(최근 5개 보관) → 스테이징 사본 생성(worker/supabase/tests/docs 제외)
  → 헤더·푸터 인라인 주입 → SEO 태그 주입 → SPA 스크립트 주입 → 버전·캐시버스팅 치환 → tar+SSH 전송 → 검증
- **배포 전 게이트**: `tests/gs-cert.spec.js` 25건 전건 PASS + 자산검사 404 0건 확인

## 5. 배포 계획 (본 형상)
