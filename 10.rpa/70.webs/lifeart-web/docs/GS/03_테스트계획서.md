- **포함**: 정적 페이지 39종 전체, 히어로 슬라이드쇼, 갤러리(필터·라이트박스), 헤더 인증 UI(비로그인),
  폼 렌더링(로그인·가입·문의·견적), 반응형(모바일/태블릿/데스크톱), 접근성 표본 검사,
  자산 무결성(내부 링크·이미지 404), 성능 기초 지표, 기본 보안 점검.
- **제외(별도 시험)**: 결제 E2E(tests/payment.spec.js — 토스 테스트 키 필요),
  회원 가입/로그인 실계정 E2E 및 관리자 콘솔 CRUD(tests/smoke.spec.js — 공유 DB에 쓰기 발생),
  소셜 로그인(OAuth 공급자 설정 의존), 크로스 브라우저 실기기(Safari/모바일 실기기 — 수동 항목).

## 5. 합격 기준
- 자동화 시험: **전 케이스 PASS** (FAIL 발생 시 결함 수정 후 재시험, 결함보고서 06 문서에 기록)
- 자산 검사: 내부 참조 404 **0건**
- 접근성 표본: img alt 누락 0, lang/title/h1/skip-nav 충족
- 성능: 메인 DOMContentLoaded < 3초(로컬), 배포 이미지 개별 ≤ 400KB
- 보안: 소스 내 service_role 등 비밀키 노출 0건
