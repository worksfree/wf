# LifeArt 웹서비스 제품 설명서

| 항목 | 내용 |
|---|---|
| 문서 번호 | LA-GS-PRD-001 |
| 제품명 | LifeArt 웹서비스 (lifeart-web) |
| 버전 | v0.8.6.7 기반 배포 후보 형상 (2026-07-19) |
| 공급자 | WorksFree (개발) / LifeArt · 대표 문영식 (서비스 주체) |

## 1. 제품 개요
LifeArt는 26년 포토·앨범 도메인 전문성을 보유한 프리미엄 포토 서비스 브랜드의 공식 웹서비스다.
포토북(AI, 예정) · 삽입식 기념앨범 · VIP 앨범 · 액자 4대 상품군의 소개·갤러리·상담/견적·주문·결제와
회원(가입/로그인/마이페이지), 관리자 콘솔(O&M)을 제공한다.

## 2. 주요 기능
| 구분 | 기능 |
|---|---|
| 소개 | 브랜드 스토리, CEO 인사말, 오시는 길, 보도자료(DB 연동) |
| 상품 | 4대 상품 소개, 액자 사이즈별 정찰가, 납품 사례 실사진 |
| 갤러리 | 카테고리 필터(기업·기관 납품/VIP/행사/상품컷) + 라이트박스 |
| 제작과정 | 상품별 제작 프로세스 안내 |
| 비즈니스 | 웨딩·여행/골프·키오스크 제휴 안내, 제휴 문의 폼(DB 저장) |
| 고객지원 | 공지사항·FAQ·1:1 문의·견적 문의 (DB 연동) |
| 회원 | 이메일 가입/로그인(Supabase Auth), 소셜 로그인(단계 공개), 마이페이지(주문·문의 내역) |
| 주문·결제 | 액자 주문, 토스페이먼츠 결제(서버 검증 Worker) |
| 관리자 | 매출 대시보드, 주문·문의·공지·FAQ·보도자료·회원·히어로 슬라이드 관리 |

## 3. 운영 환경
| 구분 | 내용 |
|---|---|
| 클라이언트 | 데스크톱/모바일 브라우저 (Chrome·Edge 최신, 반응형 375px~) |
| 웹 서버 | Synology NAS(정적 호스팅) + Cloudflare Tunnel/CDN |
| 백엔드 | Supabase (PostgreSQL + Auth + RLS, 멀티테넌트 tenant_id 격리) |
| 결제 검증 | Cloudflare Worker (lifeart-toss-verify, service_role 서버 사이드 전용) |
| 배포 표면 | pre-test(검수) → test(고객사 공개) → production(www.lifeart.ai.kr) |

## 4. 아키텍처 특성
- 정적 HTML + 공통 파트셜(header/footer) — 배포 시 인라인 주입으로 FOUC 제거, ?v= 캐시버스팅
- 단계 공개(RELEASE_STAGE 1~5)로 메뉴·기능을 점진 오픈 (배포 사본만 치환, 소스 불변)
- 공유 Supabase 멀티테넌트: tenant_id(UUID) + RLS 로 데이터 격리, 결제 확정은 Worker(service_role)만 수행
- 접근성: KWCAG 대응(스킵 링크, 라벨 자동 연결, 표 scope, 탭 ARIA, 모션 감소 대응)

## 5. 제약 사항
- AI 포토북은 Coming Soon (사업계획 반영 소개만 제공)
- 소셜 로그인은 stage 2 이상에서 공개, OAuth redirect 허용목록 운영자 설정 필요
- 결제는 토스 테스트 키 상태 — 실 운영 전환 시 라이브 키 교체 필요
