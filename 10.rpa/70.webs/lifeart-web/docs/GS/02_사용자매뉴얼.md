# LifeArt 웹서비스 사용자 매뉴얼

| 항목 | 내용 |
|---|---|
| 문서 번호 | LA-GS-MAN-001 |
| 대상 | 일반 사용자(고객) / 관리자(운영자) |
| 버전 | 2026-07-19 배포 후보 형상 기준 |

## 1부. 일반 사용자

### 1.1 시작하기
- 주소: https://www.lifeart.ai.kr (검수: pre-test-lifeart.lifeart.ai.kr)
- 첫 화면: 히어로 슬라이드(대표 납품 사례) → 4대 상품 → 실적 지표 → AI 기술 소개 → 상담 유도
- 상단 메뉴: LifeArt 소개 · 상품 · 제작과정 · 비즈니스 · 고객지원 / 우측: 카탈로그 · 회원가입 · 로그인

### 1.2 회원 가입 / 로그인
1. 우측 상단 **회원가입** → 이름·연락처·이메일·비밀번호 입력 → 가입
2. (이메일 인증 사용 시) 수신된 인증 메일 확인 후 **로그인**
3. 로그인 후 우측 상단이 **마이페이지 · 로그아웃** 으로 바뀐다
- 주의: WorksFree 등 다른 서비스에서 쓰는 이메일은 LifeArt 가입에 사용할 수 없다(안내 문구 표시)

### 1.3 상품 탐색·견적
- **상품 → 전체 상품 보기**: 4대 상품 카드. 액자는 시리즈별(슬림 크리스탈/티크목/삼각소 다크) 정찰가 표 제공
- **갤러리**: 상단 필터로 기업·기관 납품 / VIP·기업앨범 / 행사·기념 / 상품컷 분류. 이미지 클릭 시 확대(라이트박스)
- **견적 문의**: 고객지원 → 견적 문의 폼 작성 → 접수 (마이페이지에서 처리 상태 확인)

### 1.4 액자 주문·결제
1. 상품 → 액자 → **주문하기**
2. 시리즈·사이즈·수량 선택, 배송 정보 입력
3. 토스페이먼츠 결제 → 완료 화면에서 주문번호 확인 (실패 시 실패 화면 안내)
4. 마이페이지 → 주문 내역에서 배송 상태 확인

### 1.5 마이페이지
- 로그인 필요(비로그인 접근 시 로그인 안내 표시)
- 탭: 주문 내역 / 문의 내역 / 프로필(이름·연락처 수정)

## 2부. 관리자(운영자)

### 2.1 접속
- /admin/ 접속 → LifeArt 관리자 계정으로 로그인해야 콘솔 표시
- 비관리자·타 테넌트 계정은 차단 안내 표시

### 2.2 기능
| 탭 | 기능 |
|---|---|
| 대시보드 | 매출 요약(결제 완료 기준), 최근 주문 |
| 주문 | 주문 목록, 배송 상태 변경(준비→발송→완료) |
| 문의 | 1:1/견적/제휴 문의 목록, 상태 변경·답변 등록 |
| 공지 | 공지 등록·수정·삭제, 고정(📌) |
| FAQ | 자주 묻는 질문 등록·정렬 |
| 보도자료 | 게시일·매체·링크 관리, 공개 여부 |
| 회원 | 회원 목록 조회 |
| 히어로 | 첫 화면 슬라이드 이미지 URL·순서·활성 관리 |

### 2.3 첫 화면 슬라이드 교체
1. 관리자 → 히어로 탭 → 이미지 URL 등록(권장 1600px 폭, 500KB 이하)
2. 활성 체크 + 정렬 순서 지정 → 저장
3. 메인 화면은 기본 슬라이드로 즉시 시작하고, 등록 슬라이드가 로드되는 대로 교체 표시된다

## 3부. 문제 해결(FAQ)
| 증상 | 조치 |
|---|---|
| 로그인 버튼이 안 보임 | 새로고침(Ctrl+F5). 지속 시 캐시 삭제 |
| 결제 후 완료 화면이 안 뜸 | 마이페이지 주문 내역 확인 — 서버 검증은 Worker 가 별도 수행하므로 이중 결제되지 않음 |
| 공지/보도자료가 비어 있음 | 등록된 게시물이 없는 상태 — 관리자 콘솔에서 등록 |
| 다른 서비스 이메일로 가입 불가 안내 | LifeArt 전용 이메일로 가입 (멀티테넌트 계정 보호 정책) |
