# 도로명주소 API 키 발급 가이드 (영수증 주소 자동 검증용)

2026-07-24, 실제 영수증 촬영 테스트에서 "효원로"가 "요원로"로, 유사하게 "팔달구"류 행정구역명도
오인식될 수 있음을 확인 — 행정안전부 도로명주소 검색API로 OCR이 뽑아낸 주소를 공식 주소 DB와
대조해 자동 보정하는 기능을 `workers/ocr-service/index.js`에 추가했다(`searchJuso`/`correctAddress`).
이 기능을 켜려면 API 키(`JUSO_API_KEY`) 발급이 필요하다.

**AI-Hub와 달리 이건 신청 즉시 승인된다** — 사용목적 심사나 대기 없음. 5분이면 끝난다.

## 1. 발급 (5분)

1. https://business.juso.go.kr 접속 → 회원가입
2. **오픈API 신청** 메뉴 → API 종류: **검색API**(팝업API 아님, 서버에서 직접 호출하는 용도) 선택
3. 사용할 도메인/URL 입력 — 이 워커가 배포된 도메인(`ocr-service.worksfree.workers.dev` 또는 커스텀 도메인이 있다면 그 값)을 입력. 승인키는 이 URL/IP 기준으로 발급되므로 정확히 입력할 것
4. 신청 즉시 승인키(confmKey) 발급됨 — 별도 대기 없음

## 2. 워커에 시크릿 등록

발급받은 키를 채팅에 붙여넣지 말고, 아래 명령으로 직접 등록해 주세요(터미널에만 입력되고 저장소나 대화 로그에 남지 않음).

```powershell
cd D:\drive_files\10.worksfree\10.rpa\70.webs\synology-web\workers\ocr-service
wrangler secret put JUSO_API_KEY
# 프롬프트가 뜨면 발급받은 승인키를 붙여넣고 Enter
```

## 3. 확인

키를 등록하지 않아도 영수증 처리 자체는 그대로 동작한다(주소 보정 기능만 조용히 꺼짐 —
`correctAddress()`가 `env.JUSO_API_KEY` 없으면 원문 주소를 그대로 반환). 키 등록 후 영수증(CSV/엑셀
출력)을 하나 처리해보면 주소 필드 아래에 다음 중 하나가 표시된다:

- ✓ 주소 자동 보정됨 — OCR 결과와 공식 주소가 달라서 자동으로 고쳤음
- ✓ 공식 주소와 일치 확인됨 — OCR 결과가 애초에 맞았음(검증만 통과)
- ⚠ 추정 보정 — 원래 주소 그대로는 못 찾아서 상위 행정구역(시/도·시/군/구)만으로 재검색해 찾은 결과. 정확도가 상대적으로 낮으니 한 번 더 확인 권장
- 주소 자동 검증 실패 — API 키 미등록이거나 호출 실패. 원본 인식 그대로 표시

## 참고 — 보정 알고리즘

사용자가 제안한 방식 그대로 구현: 전체 주소로 검색 → 결과가 없으면 뒤(가장 세부적인 단어, 보통
번지·도로명)부터 한 단어씩 줄여가며 재검색 → 처음 결과가 나온 단계에서 채택. 단어를 줄여야
찾은 경우("낮은 신뢰도")는 UI에 별도로 표시해, 잘못된 지역으로 자신 있게 잘못 보정하는 걸
방지한다(신뢰도 표시 없이 조용히 틀린 주소로 바꾸는 게 OCR 원본 오류보다 더 나쁠 수 있어서).
