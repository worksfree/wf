# 🚀 삼성생명 법인영업(GFC) 자동 인재검색 시스템

## 🎯 개요
- **24주 MECE 사이클**: 연 2사이클 자동 운영
- **매주 금요일 11시**: 자동 검색 + 제안 + 리포트
- **헤드리스 크롬**: 백그라운드 완전 자동화
- **이메일 리포트**: 주간 결과 + 차트 자동 발송

## 📊 핵심 기능

| 문제     | 원인     | 해결               |
| ------ | ------ | ---------------- |
| 로그인 실패 | 2단계 인증 | 앱 비밀번호 사용        |
| 검색 0명  | 키워드 문제 | 필터 완화            |
| 이메일 실패 | 비밀번호   | Gmail 앱 비밀번호 재발급 |
| 셀렉터 에러 | UI 변경  | CSS 셀렉터 업데이트     |
