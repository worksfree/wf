# 제36회 경영지도사 생산관리 - 문제 1

## 수요예측 - 단순지수평활법과 계절지수

### 문제 요약
최근 6년간 제품 수요 데이터를 바탕으로:
- (1) 단순지수평활법으로 5~7년 수요 예측 (α=0.7)
- (2) 6년의 분기별 수요로 계절지수 계산
- (3) 7년의 분기별 예측수요 계산

---

## 📋 1. 수요예측 기법의 이해

### (1) 단순지수평활법 (Simple Exponential Smoothing)

#### 개념
```
Ft+1 = α × At + (1 - α) × Ft
     = Ft + α × (At - Ft)
```

**의미**
- Ft+1: t+1기의 예측값
- At: t기의 실제값
- Ft: t기의 예측값
- α: 평활상수 (0 < α < 1)

#### 특징
- **최근 데이터에 가중치 부여**: α가 클수록 최근 실제값 반영도 높음
- **추세나 계절성 미반영**: 단순한 수평 패턴에 적합
- **계산 간단**: 이전 예측값과 실제값만 필요
- **α 선택이 중요**: 0.1~0.3 (안정), 0.7~0.9 (반응적)

### (2) 계절지수 (Seasonal Index)

#### 개념
```
계절지수 = 해당 기간 실제값 / 평균값
```

**승법 모형 (Multiplicative Model)**
```
수요 = 기본 수요 × 계절지수
```

#### 특징
- **계절적 패턴 정량화**: 각 기간의 상대적 수요 수준
- **계절지수 합계**: 승법모형에서 = 기간 수
- **예측 조정**: 기본 예측치에 계절지수 곱하여 조정

## 🧮 2. 문제 (1) 풀이: 단순지수평활법

### 주어진 데이터

| 년(t) | 1년 | 2년 | 3년 | 4년 | 5년 | 6년 | 7년 |
|------|-----|-----|-----|-----|-----|-----|-----|
| 실제수요(At) | 1,028 | 1,002 | 1,063 | 1,037 | 1,041 | 1,040 | - |
| 예측수요(Ft) | 1,018 | 1,025 | 1,009 | 1,047 | ? | ? | ? |

**조건**: α = 0.7

### 계산 과정

#### F5 (5년 예측수요) 계산
```
F5 = α × A4 + (1 - α) × F4
   = 0.7 × 1,037 + 0.3 × 1,047
   = 725.9 + 314.1
   = 1,040.0
   ≈ 1,040개
```

**검증**
```
F5 = F4 + α × (A4 - F4)
   = 1,047 + 0.7 × (1,037 - 1,047)
   = 1,047 + 0.7 × (-10)
   = 1,047 - 7
   = 1,040개 ✓
```

#### F6 (6년 예측수요) 계산
```
F6 = α × A5 + (1 - α) × F5
   = 0.7 × 1,041 + 0.3 × 1,040
   = 728.7 + 312.0
   = 1,040.7
   ≈ 1,041개
```

#### F7 (7년 예측수요) 계산
```
F7 = α × A6 + (1 - α) × F6
   = 0.7 × 1,040 + 0.3 × 1,041
   = 728.0 + 312.3
   = 1,040.3
   ≈ 1,040개
```

### 결과 요약

| 년(t) | 실제수요(At) | 예측수요(Ft) | 오차(At-Ft) |
|------|------------|------------|-----------|
| 5년 | 1,041 | **1,040** | +1 |
| 6년 | 1,040 | **1,041** | -1 |
| 7년 | - | **1,040** | - |

## 📊 3. 문제 (2) 풀이: 계절지수 계산

### 주어진 데이터

| 분기 | 1분기 | 2분기 | 3분기 | 4분기 | 합계 |
|------|------|------|------|------|------|
| 6년 실제수요(A6) | 182 | 340 | 280 | 238 | 1,040 |

### 계산 과정

#### 1단계: 분기별 평균 수요 계산
```
분기당 평균 수요 = 연간 수요 / 4
                = 1,040 / 4
                = 260개
```

#### 2단계: 분기별 계절지수 계산

**1분기 계절지수**
```
SI1 = 1분기 수요 / 평균 수요
    = 182 / 260
    = 0.7000
```

**2분기 계절지수**
```
SI2 = 2분기 수요 / 평균 수요
    = 340 / 260
    = 1.3077
    ≈ 1.308
```

**3분기 계절지수**
```
SI3 = 3분기 수요 / 평균 수요
    = 280 / 260
    = 1.0769
    ≈ 1.077
```

**4분기 계절지수**
```
SI4 = 4분기 수요 / 평균 수요
    = 238 / 260
    = 0.9154
    ≈ 0.915
```

### 결과 및 검증

| 분기 | 실제수요 | 평균수요 | 계절지수 |
|------|---------|---------|---------|
| 1분기 | 182 | 260 | **0.700** |
| 2분기 | 340 | 260 | **1.308** |
| 3분기 | 280 | 260 | **1.077** |
| 4분기 | 238 | 260 | **0.915** |
| **합계** | 1,040 | 1,040 | **4.000** ✓ |

**검증**: 계절지수의 합 = 0.700 + 1.308 + 1.077 + 0.915 = 4.000 ✓

## 🎯 4. 문제 (3) 풀이: 분기별 예측수요

### 주어진 데이터
- 7년 예측수요(F7) = 1,040개
- 분기별 계절지수: 1분기(0.700), 2분기(1.308), 3분기(1.077), 4분기(0.915)

### 계산 과정

#### 분기당 기본 예측
```
분기당 기본 예측 = F7 / 4
                = 1,040 / 4
                = 260개
```

#### 분기별 예측수요 계산 (승법 모형)

**1분기 예측수요**
```
F7,Q1 = 분기 기본 예측 × 1분기 계절지수
      = 260 × 0.700
      = 182.0
      = 182개
```

**2분기 예측수요**
```
F7,Q2 = 260 × 1.308
      = 340.08
      ≈ 340개
```

**3분기 예측수요**
```
F7,Q3 = 260 × 1.077
      = 280.02
      ≈ 280개
```

**4분기 예측수요**
```
F7,Q4 = 260 × 0.915
      = 237.9
      ≈ 238개
```

### 결과 요약

| 분기 | 계절지수 | 기본예측 | 분기별 예측수요 |
|------|---------|---------|---------------|
| 1분기 | 0.700 | 260 | **182개** |
| 2분기 | 1.308 | 260 | **340개** |
| 3분기 | 1.077 | 260 | **280개** |
| 4분기 | 0.915 | 260 | **238개** |
| **합계** | 4.000 | 1,040 | **1,040개** ✓ |

**검증**: 182 + 340 + 280 + 238 = 1,040 ✓

## 📈 5. 종합 분석

### (1) 연간 수요 패턴 분석

```
연도별 실제수요 추이:
1년: 1,028 → 2년: 1,002 (-2.5%)
2년: 1,002 → 3년: 1,063 (+6.1%)
3년: 1,063 → 4년: 1,037 (-2.4%)
4년: 1,037 → 5년: 1,041 (+0.4%)
5년: 1,041 → 6년: 1,040 (-0.1%)
```

**특징**
- 평균 수요: 약 1,035개
- 변동 범위: 1,002 ~ 1,063 (약 ±3%)
- 추세: 큰 상승/하락 없이 안정적
- 패턴: **수평적 (Horizontal)** 수요 패턴

### (2) 계절적 패턴 분석

```
계절지수 비교:
2분기 (1.308) > 3분기 (1.077) > 4분기 (0.915) > 1분기 (0.700)
```

**해석**
- **2분기 (성수기)**: 평균 대비 +30.8% (최고 수요)
- **3분기 (성수기)**: 평균 대비 +7.7%
- **4분기 (평수기)**: 평균 대비 -8.5%
- **1분기 (비수기)**: 평균 대비 -30.0% (최저 수요)

**계절 변동 폭**
```
최대 변동 = (최고지수 - 최저지수) / 최저지수
         = (1.308 - 0.700) / 0.700
         = 86.9%
```

### (3) α=0.7의 의미

```
F(t+1) = 0.7 × A(t) + 0.3 × F(t)
```

**특성**
- **높은 반응성**: 최근 실제값에 70% 가중치
- **낮은 안정성**: 과거 예측값에 30% 가중치만 부여
- **적용 상황**: 수요 변동이 크거나 빠른 대응 필요 시

**본 문제에서**
- 실제 수요가 비교적 안정적 (변동계수 작음)
- α=0.7은 다소 높은 설정
- α=0.3~0.5 정도가 더 적합할 수 있음

## 💡 6. 경영 의사결정 시사점

### (1) 재고 관리 전략

#### 연간 계획
```
7년 예상 수요: 1,040개
안전재고 고려: 1,040 × 1.1 = 1,144개 (10% 여유)
```

#### 분기별 재고 계획

| 분기 | 예측수요 | 안전재고(10%) | 목표 재고 |
|------|---------|--------------|----------|
| 1분기 | 182 | 18 | 200 |
| 2분기 | 340 | 34 | 374 |
| 3분기 | 280 | 28 | 308 |
| 4분기 | 238 | 24 | 262 |

**전략**
- 1분기 말: 2분기 성수기 대비 재고 증량
- 2분기: 최대 재고 확보 (340개)
- 4분기 말: 재고 최소화하여 1분기 진입

### (2) 생산 계획

#### 균등 생산 vs 추종 생산

**균등 생산 전략**
```
분기당 균등 생산: 1,040 / 4 = 260개

재고 변동:
1분기 말: 260 - 182 = 78 (재고 증가)
2분기 말: 78 + 260 - 340 = -2 (재고 부족!)
→ 균등 생산은 부적합
```

**추종 생산 전략**
```
분기별 실제 예측량 생산:
1분기: 182개
2분기: 340개
3분기: 280개
4분기: 238개
→ 재고 최소화, 생산 변동성 증가
```

**절충 전략 (권장)**
```
기본 생산: 260개/분기
2분기 추가 생산: +80개
→ 생산 평준화 + 재고 최적화
```

### (3) 마케팅 전략

#### 비수기(1분기) 수요 확대
```
목표: 1분기 수요 182개 → 220개 (20% 증가)
수단:
- 프로모션 (할인, 사은품)
- 신제품 출시
- 대체 수요 창출
```

#### 성수기(2분기) 대응
```
대비책:

```

### (4) 수요예측 정확도 향상

#### 예측 오차 분석
```
MAPE (평균절대백분율오차) 계산:
|A5-F5|/A5 = |1,041-1,040|/1,041 = 0.10%
|A6-F6|/A6 = |1,040-1,041|/1,040 = 0.10%

## 🔍 7. 심화 학습

### (1) 다른 평활상수의 영향

| α | 특성 | 적용 상황 |
|---|------|----------|
| 0.1~0.3 | 안정적, 변동 완화 | 안정적 수요, 장기 계획 |
| 0.4~0.6 | 균형적 | 일반적 상황 |
| 0.7~0.9 | 반응적, 민감 | 변동 큰 수요, 단기 대응 |

**α=0.3으로 재계산 시**
```
F5 = 0.3 × 1,037 + 0.7 × 1,047
   = 311.1 + 732.9 = 1,044개

차이: 1,044 - 1,040 = 4개
→ α가 낮을수록 변화에 덜 민감
```

### (2) 계절조정 예측법

**Winters의 지수평활법**
```
L(t) = α × (A(t) / S(t-s)) + (1-α) × L(t-1)  (수준)
S(t) = β × (A(t) / L(t)) + (1-β) × S(t-s)    (계절성)
F(t+k) = L(t) × S(t+k-s)                      (예측)
```

**본 문제 적용**
- 연간 수준: 약 1,040개 (안정적)
- 계절성: 4개 분기 패턴 명확
- 향후 예측: 수준 × 계절지수

### (3) 예측 구간

**점 예측의 한계**
```
F7 = 1,040개 (단일 값)
→ 불확실성 미반영
```

**구간 예측 (권장)**
```
표준편차(σ) 추정: √Σ(At-Ft)²/n
예측 구간: F7 ± 1.96σ (95% 신뢰구간)

예: 1,040 ± 30개
→ 1,010 ~ 1,070개 범위
```

4. **반올림 표시**: 계산값 → 최종값 구분

```

# 제36회 경영지도사 생산관리 - 문제 2

## 프로세스 관리 - 자원이용률과 산출물

### 문제 요약
A 레스토랑의 주문 충족 프로세스 분석:
- (1) 각 작업활동별 자원이용률 계산
- (2) 작업활동 3의 이용률을 100% 이하로 낮추기 위한 셰프 수
- (3) 자원 증가 시 산출물 증가량
- (4) Little's Law를 이용한 재공품재고 계산

---

## 📋 1. 프로세스 관리 기본 개념

### (1) 자원이용률 (Resource Utilization)

#### 정의
```
자원이용률 = 도착률 × 활동시간 / 자원의 수
          = (주문도착률 × 평균소요시간) / 자원수
```

**의미**
- 자원이 실제로 사용되는 비율 (0~1 또는 0~100%)
- 100% 초과 시: 병목 발생, 대기열 무한 증가
- 100%: 임계 상태
- 100% 미만: 정상 운영

### (2) 병목 (Bottleneck)

```
병목 = 가용능력이 가장 낮은 자원
     = 이용률이 가장 높은 자원
```

**특성**
- 전체 프로세스의 산출률 결정
- 병목 개선 → 전체 산출률 증가
- 비병목 개선 → 산출률 불변 (낭비)

### (3) 프로세스 산출률 (Throughput Rate)

```
산출률 = min(도착률, 가용능력)
가용능력 = 자원수 / 활동시간
```

### (4) Little's Law

```
재공품재고(WIP) = 산출률(R) × 흐름시간(T)
I = R × T
```

**조건**: 안정 상태 (steady state)

## 🧮 2. 문제 (1) 풀이: 자원이용률 계산

### 주어진 데이터

| 작업활동 | 업무 | 도착률 (R) | 소요시간 (분) | 자원수 (c) |
|---------|------|-----------|-------------|----------|
| 1 | 주문 확인 | 20/시간 | 1 | 1 셰프 |
| 2 | 식자재 선택 및 주 요리 | 20/시간 | 6 | 1 셰프 |
| 3 | 사이드 요리 | 20/시간 | 12 | 1 셰프 |
| 4 | 오븐 작업 | 20/시간 | 10 | 2 오븐 |
| 5 | 세팅 작업 | 20/시간 | 3 | 1 셰프 |

### 계산 과정

#### 작업활동 1: 주문 확인

```
도착률 = 20주문/시간 = 20/60 = 0.333 주문/분
소요시간 = 1분
자원수 = 1

이용률 = (0.333 × 1) / 1
      = 0.333
      = 33.33%
```

**답**: 33.33%

#### 작업활동 2: 식자재 선택 및 주 요리

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 6분
자원수 = 1

이용률 = (0.333 × 6) / 1
      = 2.0
      = 200.00%
```

**답**: 200.00%

#### 작업활동 3: 사이드 요리

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 12분
자원수 = 1

이용률 = (0.333 × 12) / 1
      = 4.0
      = 400.00%
```

**답**: 400.00%

#### 작업활동 4: 오븐 작업

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 10분
자원수 = 2

이용률 = (0.333 × 10) / 2
      = 3.333 / 2
      = 1.667
      = 166.67%
```

**답**: 166.67%

#### 작업활동 5: 세팅 작업

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 3분
자원수 = 1

이용률 = (0.333 × 3) / 1
      = 1.0
      = 100.00%
```

**답**: 100.00%

### 결과 요약

| 작업활동 | 업무 | 이용률 | 상태 |
|---------|------|--------|------|
| 1 | 주문 확인 | **33.33%** | 정상 |
| 2 | 주 요리 | **200.00%** | 과부하 ⚠️ |
| 3 | 사이드 요리 | **400.00%** | **병목** 🔴 |
| 4 | 오븐 작업 | **166.67%** | 과부하 ⚠️ |
| 5 | 세팅 작업 | **100.00%** | 임계 |

**병목 공정**: 작업활동 3 (이용률 400%, 가장 높음)

## 📊 3. 문제 (2) 풀이: 필요 셰프 수

### 문제
작업활동 3의 이용률을 100% 이하로 낮추기 위한 최소 셰프 수는?

### 계산

#### 이용률 공식 변형
```
이용률 = (도착률 × 소요시간) / 자원수 ≤ 100%
자원수 ≥ 도착률 × 소요시간
```

#### 필요 자원수 계산
```
자원수 ≥ (20/60) × 12
       ≥ 0.333 × 12
       ≥ 4.0
```

**답**: 최소 **4명의 셰프** 필요

### 검증
```
4명 투입 시 이용률:
= (20/60 × 12) / 4
= 4.0 / 4
= 1.0
= 100% ✓

3명 투입 시 이용률:
= (20/60 × 12) / 3
= 4.0 / 3
= 133.33% ✗ (여전히 100% 초과)
```

## 🎯 4. 문제 (3) 풀이: 산출물 증가 분석

### 시나리오
- 작업활동 3: 1명 → 3명 셰프
- 작업활동 4: 2대 → 4대 오븐

### 1단계: 현재 프로세스 산출률

#### 각 활동별 가용능력

```
가용능력 = 자원수 / 소요시간 (주문/분)
        = 자원수 / 소요시간 × 60 (주문/시간)
```

**작업활동 1**
```
가용능력 = 1셰프 / 1분 = 1주문/분 = 60주문/시간
```

**작업활동 2**
```
가용능력 = 1셰프 / 6분 = 0.167주문/분 = 10주문/시간
```

**작업활동 3**
```
가용능력 = 1셰프 / 12분 = 0.083주문/분 = 5주문/시간 ← 최소 (병목)
```

**작업활동 4**
```
가용능력 = 2오븐 / 10분 = 0.2주문/분 = 12주문/시간
```

**작업활동 5**
```
가용능력 = 1셰프 / 3분 = 0.333주문/분 = 20주문/시간
```

#### 현재 프로세스 산출률
```
현재 산출률 = min(60, 10, 5, 12, 20)
          = 5주문/시간
```

### 2단계: 개선 후 프로세스 산출률

#### 변경된 가용능력

**작업활동 3** (1명 → 3명)
```
새 가용능력 = 3셰프 / 12분
           = 0.25주문/분
           = 15주문/시간
```

**작업활동 4** (2대 → 4대)
```
새 가용능력 = 4오븐 / 10분
           = 0.4주문/분
           = 24주문/시간
```

#### 새로운 프로세스 산출률
```
새 산출률 = min(60, 10, 15, 24, 20)
         = 10주문/시간
```

**새로운 병목**: 작업활동 2 (주 요리, 10주문/시간)

### 3단계: 산출물 증가량 계산

```
증가량 = 새 산출률 - 현재 산출률
      = 10 - 5
      = 5주문/시간
```

**증가율**
```
증가율 = (증가량 / 현재 산출률) × 100%
      = (5 / 5) × 100%
      = 100%
```

**답**: 산출물이 **5주문/시간 증가** (100% 증가)

### 결과 비교표

| 구분 | 현재 | 개선 후 | 변화 |
|------|------|---------|------|
| **작업 3 자원** | 1명 | 3명 | +2명 |
| **작업 3 능력** | 5/시간 | 15/시간 | +10/시간 |
| **작업 4 자원** | 2대 | 4대 | +2대 |
| **작업 4 능력** | 12/시간 | 24/시간 | +12/시간 |
| **병목** | 작업 3 | 작업 2 | 변경 |
| **프로세스 산출률** | 5/시간 | 10/시간 | **+5/시간** |

## 💡 5. 문제 (4) 풀이: 재공품재고

### 주어진 조건
- 평균 산출물(throughput): 12주문/시간
- 평균 프로세스 처리시간(flow time): 10분

### Little's Law 적용

```
WIP = R × T
```

**여기서**
- WIP: 재공품재고 (Work In Process)
- R: 산출률 (Throughput Rate)
- T: 흐름시간 (Flow Time)

### 단위 통일

#### 방법 1: 시간 단위로 통일
```
R = 12주문/시간
T = 10분 = 10/60시간 = 1/6시간

WIP = 12 × (1/6)
    = 2주문
```

#### 방법 2: 분 단위로 통일
```
R = 12주문/시간 = 12/60 = 0.2주문/분
T = 10분

WIP = 0.2 × 10
    = 2주문
```

**답**: 평균 재공품재고 = **2주문**

### 의미 해석

```
재공품재고 = 2주문

의미:
- 평균적으로 2개의 주문이 프로세스 내에서 처리 중
- 주문 1: 조리 중
- 주문 2: 대기 또는 다른 단계 처리 중
```

작업 3: 400% (과부하 300%) ← 최악

**문제**

```
1순위: 최대 병목 (작업 3, 400%)

3순위: 3차 병목 (작업 4, 167%)

```
투입: +1명 셰프

비용 대비 효과: 중간 ⭐⭐

투입: +2대 오븐

### (3) 최적 자원 배치 전략

#### 단계적 개선 방안

**1단계: 병목 해소**
```
작업 3: 1명 → 4명 (+3명)
목표: 이용률 100% 이하

결과:
- 프로세스 산출률: 5 → 10주문/시간
- 새 병목: 작업 2
```

**2단계: 차순위 병목 개선**
```
작업 2: 1명 → 2명 (+1명)
목표: 이용률 100% 이하

가용능력 = 2/6분 = 20주문/시간
새 이용률 = (10 × 6) / 2 = 300% → 여전히 높음
→ 3명 필요: (10 × 6) / 3 = 200%
→ 4명 필요: (10 × 6) / 4 = 150%
→ 5명 필요: (10 × 6) / 5 = 120%
→ 6명 필요: (10 × 6) / 6 = 100% ✓

결과:
- 프로세스 산출률: 10 → 20주문/시간
- 새 병목: 작업 5
```

**3단계: 균형 조정**
```
작업 5: 1명 → 필요 인원
도착률 20/시간 시:
필요 자원 = (20 × 3) / 60 = 1명 (현재 충분)

20주문/시간 시:
필요 자원 = (20/60 × 3) = 1명 (현재 충분)

→ 추가 인력 불필요
```

**결과**

### (4) 수요-공급 균형

#### 도착률과 산출률 비교

```
현재 상황:
도착률: 20주문/시간
산출률:  5주문/시간
→ 공급 부족: 15주문/시간 (75%)

개선 후 (문제 3):
도착률: 20주문/시간
산출률: 10주문/시간
→ 공급 부족: 10주문/시간 (50%)

완전 개선 시:
도착률: 20주문/시간
산출률: 20주문/시간
→ 균형 달성 ✓
```

### (5) 대기 시간 분석

#### 현재 (산출률 5주문/시간)

```
도착률 > 산출률 → 불안정
대기열 지속 증가
→ 고객 불만, 주문 취소 발생
```

#### Little's Law로 추정

```
만약 안정 상태 가정:
산출률 = 5주문/시간
흐름시간 = 평가 필요

실제 도착: 20주문/시간
처리: 5주문/시간
→ 15주문/시간 처리 불가
→ 대기 시간 무한 증가 경향
```

### (6) 재공품재고 관리

#### Little's Law 활용

```
목표 WIP: 2주문 (문제 4)
산출률: 12주문/시간
→ 흐름시간 = WIP/R = 2/12시간 = 10분 ✓

적정 WIP 관리:
- WIP 과다: 혼잡, 품질 저하
- WIP 부족: 자원 유휴
- 적정 수준: 2~3주문 (본 사례)
```

## 🔍 7. 프로세스 개선 기법

### (1) 병목 관리 (TOC: Theory of Constraints)

#### 5단계 집중 개선

```
1. 제약 식별: 작업 3 (400% 이용률)
2. 제약 활용: 작업 3 유휴 시간 최소화
3. 제약에 동조: 다른 작업을 작업 3에 맞춤
4. 제약 완화: 자원 증가 (1→4명)
5. 반복: 새 제약(작업 2) 개선
```

### (2) 프로세스 재설계

#### 병렬 처리
```
현재: 순차 처리
개선: 일부 작업 병렬화

예:
작업 2(주 요리) ─┐
                 ├─→ 작업 5(세팅)
작업 3(사이드) ──┘

효과: 전체 시간 단축
```

#### 작업 재분배
```
작업 3(12분) 분할:
→ 작업 3a(6분) + 작업 3b(6분)
→ 2명이 각각 담당
→ 이용률 200%로 감소 (여전히 높지만 개선)
```

### (3) 유연성 확보

#### 다기능 인력
```
셰프 교차 훈련:
- 주 요리 + 사이드 요리 가능
- 피크 시간대 유연한 배치
- 이용률 균등화
```

#### 동적 자원 배분
```
시간대별 수요 변동 대응:
- 점심 피크: 작업 3에 인력 집중
- 한가한 시간: 작업 1, 5로 인력 이동
```

### (4) 재공품재고
```
WIP = 2주문
```

## 🎯 9. 답안 작성 팁

### 계산 체계
```
1. 공식 명시
2. 단위 통일 (분 또는 시간)
3. 중간 계산 표기
4. 최종 답 강조
```

### 시간 관리
```
문제 2 (30점) 권장 시간: 25~30분

배분:
(1) 이용률 5개: 12분
(2) 최소 자원: 5분
(3) 산출물 분석: 10분
(4) Little's Law: 3분
검토: 5분
```

### 실수 방지
```
✓ 시간 단위 일치 (분 ↔ 시간)
✓ 자원수 분모 위치 확인
✓ 병목은 최고 이용률
✓ Little's Law 단위 통일
✓ 소수점 자리수 (둘째자리)
```

### 경영 해석 포인트
```
✓ 병목이 전체 성능 결정
✓ 비병목 개선은 효과 없음
✓ 균형잡힌 자원 배치 중요
✓ 이용률 80~90% 목표 적정
✓ 100% 초과는 대기 발생
```

# 제36회 경영지도사 생산관리 - 문제 3

## 아웃소싱의 장점

### 문제 요약
아웃소싱의 장점을 세 가지 측면에서 설명:
- (1) 재무원가 측면 (2가지)
- (2) 개선 측면 (2가지)
- (3) 조직 측면 (2가지)

---

## 📋 1. 아웃소싱의 기본 개념

### (1) 아웃소싱(Outsourcing) 정의

```
아웃소싱 = 외부 자원 활용(Out + Resourcing)
```

**의미**
- 기업 내부 활동과 의사결정 책임의 일부를 외부 공급자에게 이전
- Make or Buy 의사결정에서 Buy 선택
- 핵심역량 집중을 위한 전략적 선택

### (2) 아웃소싱의 범위

#### 전통적 아웃소싱
```
- 청소, 경비, 급식
- 물류, 운송
- IT 인프라 관리
```

#### 전략적 아웃소싱
```
- 제조 생산 (OEM, ODM)
- 연구개발 (R&D)
- 인사관리 (채용, 교육)
- 재무/회계
- 고객서비스
```

### (3) 아웃소싱 vs 인소싱

| 구분 | 아웃소싱 | 인소싱 |
|------|---------|--------|
| **수행 주체** | 외부 전문업체 | 내부 조직 |
| **장점** | 비용절감, 전문성 | 통제력, 보안 |
| **단점** | 통제 어려움 | 고정비 부담 |
| **적합 업무** | 비핵심, 표준화 | 핵심, 차별화 |

---

## 💰 2. (1) 재무원가 측면의 장점

### 장점 1: 고정비의 변동비화

#### 개념
```
아웃소싱 전: 고정비 (인건비, 설비 감가상각)
아웃소싱 후: 변동비 (사용량 기반 지급)
```

#### 구체적 설명

**고정비 부담 감소**
```
내부 수행 시:
- 전담 인력 인건비: 연간 고정 지출
- 설비/장비 투자: 초기 대규모 자본
- 유지보수 비용: 지속적 발생

아웃소싱 시:
- 사용량 기반 지급: 필요한 만큼만
- 초기 투자 불필요: 즉시 활용
- 수요 변동 대응: 유연한 비용 조정
```

**경영 효과**
```
✓ 손익분기점(BEP) 하락
✓ 영업 레버리지 감소
✓ 재무 안정성 향상
✓ 현금흐름 개선
```

#### 실무 사례
```
물류 아웃소싱:
- 자체 운영: 차량 구매(5억), 운전기사(10명), 창고(임대)
  → 연간 고정비 10억원
- 아웃소싱: 배송 건당 5,000원
  → 사용량에 비례, 수요 감소 시 비용 자동 감소
```

### 장점 2: 총원가(TCO) 절감

#### 개념
```
TCO (Total Cost of Ownership) = 총소유비용
= 직접비 + 간접비 + 기회비용
```

#### 구체적 설명

**규모의 경제 혜택**
```
전문업체:
- 대량 구매로 원가 절감
- 여러 고객 대상으로 자원 공유
- 효율적 프로세스 보유

예시:
- IT 아웃소싱 업체: 수백 개 기업 대상
  → 인력 1명이 여러 고객 담당
  → 개별 기업보다 낮은 단가 제공 가능
```

**숨은 비용 절감**
```
내부 수행 시 발생 비용:
- 채용/교육 비용
- 관리 감독 비용
- 실패/오류 비용
- 기술 업데이트 비용

아웃소싱 시:
- 전문업체가 부담
- 성과 기반 계약 가능
- SLA(서비스수준협약)로 품질 보장
```

**경영 효과**
```
✓ 운영 효율성 향상
✓ 간접비 절감
✓ 예산 예측 가능성 증대
✓ 자본 효율성 개선
```

#### 실무 사례
```
급식 서비스 아웃소싱:
- 자체 운영 총비용: 200만원/월
  · 식재료비: 100만원
  · 조리사 인건비: 80만원
  · 시설/설비 상각: 15만원
  · 관리감독 비용: 5만원

- 아웃소싱 비용: 140만원/월
  · 1인당 4,000원 × 350명
  → 총 30% 비용 절감
```

## 🔧 3. (2) 개선 측면의 장점

### 장점 1: 전문 기술과 역량 확보

#### 개념
```
외부 전문업체의 노하우와 기술 즉시 활용
= 학습 시간 단축 + 실패 위험 감소
```

#### 구체적 설명

**전문성의 이점**
```
전문업체 특성:
- 해당 분야 집중 투자
- 최신 기술/방법론 보유
- 풍부한 경험과 노하우
- 우수 인력 확보

기업의 혜택:
- 즉시 활용 가능
- 품질 수준 향상
- 기술 리스크 감소
- 빠른 문제 해결
```

**지속적 개선**
```
전문업체 동기:
- 경쟁력 유지 위해 지속 개선
- 다수 고객 경험 축적
- 모범 사례(Best Practice) 공유

예시:
- IT 보안 아웃소싱
  → 최신 보안 위협 대응
  → 24/7 모니터링
  → 전문가 즉시 투입
```

**경영 효과**
```
✓ 서비스 품질 향상
✓ 기술 격차 해소
✓ 혁신 속도 가속
✓ 실패 비용 감소
```

#### 실무 사례
```
금융사 콜센터 아웃소싱:
- 전문 콜센터 업체
  · 10년 이상 경험
  · 고객 응대 매뉴얼 체계화
  · 상담사 전문 교육 프로그램
  · 음성인식, AI 챗봇 등 최신 기술

- 효과
  · 고객 만족도: 65% → 85%
  · 평균 처리 시간: 5분 → 3분
  · 초기 해결률: 60% → 80%
```

### 장점 2: 유연성과 확장성 확보

#### 개념
```
시장 변화와 수요 변동에 신속하게 대응
= 규모 조정의 용이성
```

#### 구체적 설명

**수요 변동 대응**
```
확장(Scale-up):
- 성수기: 자원 즉시 증가
- 신규 시장: 빠른 진입
- 프로젝트: 한시적 증원

축소(Scale-down):
- 비수기: 비용 자동 감소
- 사업 철수: 빠른 정리
- 구조조정: 부담 최소화
```

**기술 변화 대응**
```
기술 업데이트:
- 신기술 도입: 공급자가 투자
- 노후 시스템: 즉시 교체 가능
- 플랫폼 전환: 공급자 책임

내부 수행 시:
- 신기술 도입: 대규모 재투자 필요
- 전환 비용: 매몰비용 발생
- 저항: 조직 내부 반발
```

**경영 효과**
```
✓ 시장 변화 신속 대응
✓ 사업 확장 용이
✓ 리스크 분산
✓ 전략 수정 유연성
```

#### 실무 사례
```
제조업 생산 아웃소싱:
- 상황: 계절 상품 (겨울 의류)
  · 성수기(9~12월): 월 10만 벌
  · 비수기(3~8월): 월 2만 벌

- 자체 생산 시:
  · 설비: 10만 벌 기준 투자
  · 비수기: 80% 유휴 (낭비)

- 아웃소싱 시:
  · 성수기: 여러 협력사 활용
  · 비수기: 최소 업체만 활용
  → 탄력적 생산 가능
```

## 👥 4. (3) 조직 측면의 장점

### 장점 1: 핵심역량 집중

#### 개념
```
핵심역량(Core Competence):
= 기업의 경쟁우위 원천이 되는 고유 능력

전략: 핵심은 내부, 비핵심은 외부
```

#### 구체적 설명

**자원의 선택과 집중**
```
제한된 자원:
- 경영진 시간과 관심
- 인력과 예산
- 투자 여력

핵심역량 집중 시:
- 차별화 요소 강화
- 경쟁력 향상
- 시장 지위 공고화
```

**전략적 우선순위**
```
핵심 활동:
- 제품 개발
- 브랜드 관리
- 고객 관계
→ 내부 역량 집중

지원 활동:
- 총무, 경리
- IT 인프라
- 물류
→ 아웃소싱
```

**경영 효과**
```
✓ 전략적 집중력 향상
✓ 자원 배분 최적화
✓ 경쟁우위 강화
✓ 조직 명료성 증대
```

#### 실무 사례
```
애플(Apple):
- 핵심역량: 디자인, 소프트웨어, 브랜드
  → 내부 집중 투자

- 비핵심: 제조 생산
  → 폭스콘 등 외부 위탁

- 결과:
  · 혁신에 집중
  · 제품 차별화 극대화
  · 프리미엄 브랜드 구축
```

### 장점 2: 조직 슬림화와 관리 부담 경감

#### 개념
```
아웃소싱 → 조직 규모 축소 → 관리 효율성 증대
```

#### 구체적 설명

**조직 복잡성 감소**
```
내부 수행 시:
- 부서 증가: 의사결정 지연
- 계층 증가: 관료화
- 조정 비용: 부서 간 갈등

아웃소싱 시:
- 조직 단순화
- 의사결정 신속화
- 계약 관계로 명확화
```

**인사 관리 부담 경감**
```
인사 관리 부담:
- 채용: 시간과 비용
- 교육: 지속적 투자
- 평가/보상: 관리 노력
- 노사 관계: 갈등 관리
- 이직: 숙련도 손실

아웃소싱 시:
- 공급업체가 관리
- 계약으로 성과 관리
- 인력 문제 최소화
```

**경영 효과**
```
✓ 관리 효율성 향상
✓ 의사결정 속도 증가
✓ 조직 민첩성 확보
✓ 갈등 관리 부담 감소
```

#### 실무 사례
```
대기업 IT 부서:
- 아웃소싱 전:
  · IT 인력: 200명
  · 관리자: 20명
  · 관리 계층: 4단계
  · 의사결정: 평균 2주

- 아웃소싱 후:
  · 핵심 IT 인력: 50명 (전략/기획)
  · 외부 관리: 계약 담당 5명
  · 관리 계층: 2단계
  · 의사결정: 평균 3일

- 효과:
  · 조직 75% 축소
  · 의사결정 80% 단축
  · 운영비 40% 절감
```

**추가 장점: 변화 관리 용이성**

```
구조조정 시:
- 내부 인력: 해고 어려움, 사회적 이슈
- 외부 계약: 계약 종료/축소 가능

사업 다각화 시:
- 신규 인력 채용: 시간 소요
- 외부 활용: 즉시 투입
```

## 💡 6. 경영 의사결정 시사점

### (1) 전략적 아웃소싱 접근

```
단계별 아웃소싱 전략:

1단계: 명확한 비핵심 (청소, 경비)
2단계: 지원 기능 (급식, 차량)
3단계: 전문 기능 (IT, 물류)
4단계: 생산 기능 (제조, 조립)
5단계: 전략 기능 (일부 R&D)
```

### (2) 아웃소싱 성공 요인

```
✓ 명확한 목표 설정
✓ 적합한 공급자 선정
✓ 상세한 계약 (SLA 포함)

# 제36회 경영지도사 생산관리 - 문제 4

## 경제적 주문량(EOQ) 모형

### 문제 요약
- (1) EOQ 계산 및 주문간격 산출
  - 연간 수요(D): 3,000개
  - 1회 주문비용(S): 1,000,000원
  - 단위당 연간재고유지비용(H): 6,000원
- (2) 파라미터 변화 시 EOQ 민감도 분석

---

## 📋 1. EOQ 모형의 기본 개념

### (1) EOQ (Economic Order Quantity)

#### 정의
```
경제적 주문량 = 총 재고비용을 최소화하는 1회 주문량
```

**의미**
- 주문비용과 재고유지비용의 균형점
- 연간 총비용(Total Cost)을 최소화
- 외부 구매 시 적용 (cf. EPQ는 자체 생산)

### (2) EOQ 모형의 가정

```
1. 수요율: 일정하고 확정적
2. 리드타임: 일정하고 알려짐
3. 입고: 즉시 전량 입고 (일시 입고)
4. 재고 부족: 허용 안 됨
5. 품목: 독립적 (상호 영향 없음)
6. 비용: 일정 (가격 할인 없음)
```

### (3) 비용 구조

#### 총 재고비용 구성
```
TC (Total Cost) = 주문비용 + 재고유지비용

주문비용 = (D/Q) × S
재고유지비용 = (Q/2) × H

여기서:
D: 연간 수요량
Q: 1회 주문량
S: 1회 주문비용 (Setup cost)
H: 단위당 연간재고유지비용 (Holding cost)
```

---

## 🧮 2. 문제 (1) 풀이: EOQ 계산

### 주어진 데이터
```
D (연간 수요량) = 3,000개
S (1회 주문비용) = 1,000,000원
H (단위당 연간재고유지비용) = 6,000원
```

### 1단계: EOQ 공식

```
EOQ = Q* = √[(2 × D × S) / H]
```

**공식 유도** (참고)
```
TC = (D/Q) × S + (Q/2) × H

dTC/dQ = 0 에서 최소점:
-D×S/Q² + H/2 = 0
D×S/Q² = H/2
Q² = 2×D×S/H
Q* = √(2DS/H)
```

### 2단계: EOQ 계산 과정

```
Q* = √[(2 × D × S) / H]
   = √[(2 × 3,000 × 1,000,000) / 6,000]
```

**분자 계산**
```
2 × D × S = 2 × 3,000 × 1,000,000
          = 6,000,000,000
```

**분수 계산**
```
(2 × D × S) / H = 6,000,000,000 / 6,000
                = 1,000,000
```

**제곱근 계산**
```
Q* = √1,000,000
   = 1,000개
```

**답**: EOQ = **1,000개**

### 3단계: 주문간격 계산

#### 연간 주문 횟수
```
N (연간 주문 횟수) = D / Q*
                   = 3,000 / 1,000
                   = 3회
```

#### 주문간격 (개월)
```
주문간격 = 12개월 / N
        = 12개월 / 3회
        = 4개월
```

**답**: 주문간격 = **4개월**

**의미**: 4개월마다 1,000개씩 주문

### 4단계: 검증 (최적 조건 확인)

#### EOQ에서 주문비용 = 재고유지비용

**주문비용**
```
연간 주문비용 = (D/Q*) × S
             = (3,000/1,000) × 1,000,000
             = 3 × 1,000,000
             = 3,000,000원
```

**재고유지비용**
```
평균 재고 = Q*/2 = 1,000/2 = 500개

연간 재고유지비용 = (Q*/2) × H
                 = 500 × 6,000
                 = 3,000,000원
```

**검증**
```
주문비용 = 재고유지비용
3,000,000원 = 3,000,000원 ✓

→ 최적 조건 충족
```

#### 연간 총비용
```
TC = 주문비용 + 재고유지비용
   = 3,000,000 + 3,000,000
   = 6,000,000원
```

## 📊 3. 문제 (2) 풀이: 민감도 분석

### EOQ 공식 재확인
```
Q* = √(2DS/H)
```

### 파라미터별 영향 분석

#### (1) 연간 수요량(D) 감소 → EOQ 변화?

**수학적 분석**
```
Q* ∝ √D  (D와 제곱근 비례)

D 감소 → √D 감소 → Q* 감소
```

**구체적 예시**
```
현재: D = 3,000 → Q* = 1,000

D를 50% 감소 (3,000 → 1,500):
Q*_new = √[(2 × 1,500 × 1,000,000) / 6,000]
       = √(500,000)
       = 707개

감소율: (1,000 - 707) / 1,000 = 29.3%
→ D가 50% 감소 시 Q*는 29.3% 감소
→ √0.5 = 0.707 (약 29.3% 감소)
```

**답**: **감소**

**경영 시사점**
- 수요 감소 시 주문량도 감소해야 함
- 단, 비례적 감소 아님 (제곱근 관계)
- 수요 1/4 감소 시 주문량 1/2 감소

#### (2) 1회 주문비용(S) 감소 → EOQ 변화?

**수학적 분석**
```
Q* ∝ √S  (S와 제곱근 비례)

S 감소 → √S 감소 → Q* 감소
```

**구체적 예시**
```
현재: S = 1,000,000 → Q* = 1,000

S를 36% 감소 (1,000,000 → 640,000):
Q*_new = √[(2 × 3,000 × 640,000) / 6,000]
       = √(640,000)
       = 800개

감소율: (1,000 - 800) / 1,000 = 20%
→ S가 36% 감소 시 Q*는 20% 감소
```

**답**: **감소**

**경영 시사점**
- 주문비용 절감 → 소량 다빈도 주문 가능
- EDI, 자동 발주 시스템 → S 감소 → Q* 감소
- JIT (Just-In-Time) 전략의 기반

#### (3) 단위당 연간재고유지비용(H) 증가 → EOQ 변화?

**수학적 분석**
```
Q* ∝ 1/√H  (H와 반비례의 제곱근)

H 증가 → √H 증가 → 1/√H 감소 → Q* 감소
```

**구체적 예시**
```
현재: H = 6,000 → Q* = 1,000

H를 44% 증가 (6,000 → 8,640):
Q*_new = √[(2 × 3,000 × 1,000,000) / 8,640]
       = √(694,444)
       = 833개

감소율: (1,000 - 833) / 1,000 = 16.7%
→ H가 44% 증가 시 Q*는 16.7% 감소
```

**답**: **감소**

**경영 시사점**
- 재고유지비용 증가 → 재고 최소화 전략
- 금리 상승, 창고료 인상 → 소량 주문 유리
- 부패성/계절성 제품 → H 높음 → Q* 작아짐

---

## 📈 4. 민감도 분석 종합

### (1) 파라미터별 영향 요약

| 파라미터 | 변화 방향 | EOQ 변화 | 관계 | 민감도 |
|---------|---------|---------|------|--------|
| **D (수요량)** | 감소 | **감소** | √D | 중간 |
| **S (주문비용)** | 감소 | **감소** | √S | 중간 |
| **H (재고유지비용)** | 증가 | **감소** | 1/√H | 중간 |

**공통점**: 모두 제곱근 관계 → 완만한 변화

### (2) 제곱근 관계의 의미

```
Q* = k × √(파라미터)

특징:
- 파라미터 4배 증가 → Q* 2배 증가
- 파라미터 1/4 감소 → Q* 1/2 감소
- 완충 효과(Cushioning effect)
```

**경영적 의미**
```
✓ 파라미터 추정 오차에 덜 민감
✓ 실무적으로 강건한(Robust) 모형
✓ 정확한 데이터 없어도 적용 가능
```

### (3) 시나리오 분석

#### 시나리오 1: 경기 침체
```
상황: D 30% 감소, H 20% 증가 (자금 부담)

D_new = 3,000 × 0.7 = 2,100
H_new = 6,000 × 1.2 = 7,200

Q*_new = √[(2 × 2,100 × 1,000,000) / 7,200]
       = √(583,333)
       = 764개

변화: 1,000 → 764 (23.6% 감소)
주문간격: 4개월 → 5.1개월
→ 주문 빈도 감소, 재고 감소
```

#### 시나리오 2: 프로세스 혁신
```
상황: S 60% 감소 (EDI 도입)

S_new = 1,000,000 × 0.4 = 400,000

Q*_new = √[(2 × 3,000 × 400,000) / 6,000]
       = √(400,000)
       = 632개

변화: 1,000 → 632 (36.8% 감소)
주문간격: 4개월 → 2.5개월
→ 소량 다빈도 주문 가능 (JIT 방향)
```

## 💡 5. 경영 의사결정 시사점

### (1) EOQ 활용 전략

#### 재고 정책 수립
```
기본 원칙:
- 1회 주문량: 1,000개
- 주문 시점: 4개월마다
- 평균 재고: 500개
- 최대 재고: 1,000개 (입고 직후)
- 최소 재고: 0개 (주문 직전)
```

#### 안전재고 추가 고려
```
EOQ는 확정적 수요 가정
→ 실제는 수요 변동 존재

안전재고 = Z × σ × √LT
(Z: 서비스수준, σ: 수요 표준편차, LT: 리드타임)

예: 안전재고 100개 추가
→ 재주문점 = LT 동안 수요 + 100개
```

### (2) 비용 절감 방안

#### 주문비용(S) 절감
```
방법:
✓ EDI/자동발주 시스템
✓ 거래선 통합
✓ 장기 계약
✓ 온라인 주문 플랫폼

효과:
S 감소 → Q* 감소 → 소량 다빈도
→ 재고 감소 → 재고유지비용 절감
```

#### 재고유지비용(H) 절감
```
방법:
✓ 창고 효율화
✓ 재고 회전율 향상
✓ 보험료 협상
✓ 재고 손실 감소

효과:
H 감소 → Q* 증가 → 대량 저빈도
→ 주문비용 절감
```

### (3) 파라미터 최적화

#### 균형점 찾기
```
목표: TC (총비용) 최소화

현재 TC = 6,000,000원

만약 S를 50% 절감 (500,000원):
Q*_new = √[(2 × 3,000 × 500,000) / 6,000]
       = 707개
TC_new = 2 × 주문비용 (또는 재고유지비용)
       = 2 × [(3,000/707) × 500,000]
       = 2 × 2,121,320
       = 4,242,640원

절감액: 6,000,000 - 4,242,640 = 1,757,360원 (29.3%)
```

### (4) 수요 변동 대응

#### 수요 증가 시
```
D 증가 → Q* 증가 필요

예: D가 3,000 → 4,800 (60% 증가)
Q*_new = √[(2 × 4,800 × 1,000,000) / 6,000]
       = √(1,600,000)
       = 1,265개 (26.5% 증가)

주문간격 = 12 / (4,800/1,265) = 3.2개월
→ 주문 빈도 증가 필요
```

## 🔍 6. EOQ 모형의 확장

### (1) 수량 할인 EOQ

```
상황: 대량 구매 시 단가 할인

예:
Q < 1,000: 단가 10,000원
Q ≥ 1,000: 단가 9,500원 (5% 할인)

분석:
- 기본 EOQ: 1,000개
- 할인 적용 시: 총비용 재계산 필요
  TC = 구매비용 + 주문비용 + 재고유지비용
```

### (2) 계획적 품절 허용 EOQ

```
상황: 품절 허용 시 품절 비용 발생

공식:
Q* = √[(2DS/H) × {(H + B) / B}]

B: 단위당 품절비용
→ B가 클수록 Q*는 일반 EOQ에 근접
```

### (3) 유한 보충률 모형 (EPQ)

```
생산 속도 > 수요 속도일 때

EPQ = √[(2DS/H) × {p / (p-d)}]

p: 생산율
d: 수요율
→ EOQ의 확장형 (40회 문제 2 참고)
```

## 📊 7. 실무 적용 가이드

### (1) EOQ 적용 체크리스트

```
✓ 수요 패턴: 비교적 안정적인가?
✓ 리드타임: 일정하고 예측 가능한가?
✓ 주문비용: 파악 가능한가?
✓ 재고유지비용: 산정 가능한가?
✓ 품목 특성: 독립 수요 품목인가?
```

### (2) 파라미터 추정 방법

#### 주문비용(S) 산정
```
포함 항목:
- 발주 업무 인건비
- 통신비 (전화, 팩스, 이메일)
- 검수 비용
- 시스템 처리 비용

예: 발주 1건당 평균 소요 시간 2시간
    시간당 인건비 25,000원
    기타 비용 10,000원
    → S = 50,000 + 10,000 = 60,000원
```

#### 재고유지비용(H) 산정
```
포함 항목:
- 자본비용 (기회비용): 단가 × 연이자율
- 창고 보관비: 단가 × 보관료율
- 보험료: 단가 × 보험료율
- 노후화/파손: 단가 × 손실율

예: 단가 10,000원, 연이자 5%, 기타 15%
    → H = 10,000 × (0.05 + 0.15) = 2,000원
```

### (3) 모니터링 및 조정

```
정기 검토 (분기별):
✓ 실제 수요 vs 예상 수요
✓ 파라미터 변화 (S, H)
✓ EOQ 재계산
✓ 정책 조정

이상 신호:
- 재고 회전율 급변
- 빈번한 품절
- 과다 재고 누적
→ EOQ 재검토 필요
```

---

## 📝 8. 최종 답안 정리

### (1) EOQ 및 주문간격

**경제적 주문량(EOQ)**
```
Q* = √[(2 × D × S) / H]
   = √[(2 × 3,000 × 1,000,000) / 6,000]
   = √1,000,000
   = 1,000개
```

**주문간격**
```
연간 주문 횟수 = D / Q* = 3,000 / 1,000 = 3회
주문간격 = 12개월 / 3회 = 4개월
```

**답**: EOQ = **1,000개**, 주문간격 = **4개월**

### (2) 파라미터 변화에 따른 EOQ 변화

| 파라미터 | 변화 | EOQ 변화 |
|---------|------|---------|
| 연간 수요량(D) | 감소 | **감소** |
| 1회 주문비용(S) | 감소 | **감소** |
| 단위당 연간재고유지비용(H) | 증가 | **감소** |

## 📋 1. 생산능력의 기본 개념

```
확장 필요 상황:

## 💡 2. 생산능력 확장 시 유의사항

### 유의사항 1: 수요예측의 정확성 확보

#### (1) 핵심 내용

**수요예측의 중요성**
```
생산능력 = 수요 충족을 위한 투자
→ 수요예측 오류 = 투자 실패
```

**과잉 투자 위험**
```
수요 과대 예측 시:
- 유휴 설비 발생
- 고정비 부담 증가
- 자본 회수 지연
- 재무 건전성 악화
```

**과소 투자 위험**
```
수요 과소 예측 시:
- 시장 기회 상실
- 경쟁사에 시장 점유율 양보
- 고객 이탈
- 추가 증설 비용 발생
```

#### (2) 구체적 유의사항

**다각도 수요 분석**
```
✓ 과거 추세 분석
  - 시계열 분석
  - 성장률 패턴 파악
  - 계절성 고려

✓ 시장 조사
  - 고객 니즈 변화
  - 시장 규모 전망
  - 경쟁 환경 분석

✓ 거시경제 요인
  - GDP 성장률
  - 인구 변화
  - 산업 트렌드

✓ 제품 수명주기
  - 도입기, 성장기, 성숙기, 쇠퇴기
  - 기술 변화 속도
  - 대체재 출현 가능성
```

**시나리오 분석**
```
다중 시나리오 수립:

낙관적 시나리오 (P=30%)
- 수요 연평균 15% 성장
- 필요 능력: 150%

기준 시나리오 (P=50%)
- 수요 연평균 8% 성장
- 필요 능력: 120%

비관적 시나리오 (P=20%)
- 수요 연평균 3% 성장
- 필요 능력: 105%

→ 기대값 계산 및 위험 평가
```

**단계적 검증**
```
1단계: 초기 시장 테스트
2단계: 시범 생산
3단계: 본격 확장
→ 각 단계에서 수요 재검증
```

#### (3) 실무 사례

```
사례: 반도체 업체 A사
- 2020년: 수요 급증 예측 → 대규모 증설
- 2022년: 수요 급감 → 가동률 50%
- 결과: 3조원 투자 회수 난항

교훈: 단기 호황을 장기 추세로 오판
     → 보수적 증설 + 단계적 확장 필요
```

### 유의사항 2: 적절한 확장 시기 및 규모 결정

#### (1) 핵심 내용

**타이밍의 중요성**
```
너무 빠른 확장:
- 수요 미달 → 유휴 설비
- 자금 회수 지연

너무 늦은 확장:
- 기회 상실
- 리드타임으로 시장 대응 실패
```

**규모의 딜레마**
```
대규모 확장:
- 장점: 규모의 경제, 단가 절감
- 단점: 리스크 집중, 유연성 부족

소규모 확장:
- 장점: 리스크 분산, 유연성
- 단점: 규모의 불경제, 높은 단가
```

#### (2) 구체적 유의사항

**확장 시기 결정 요소**
```
✓ 현재 가동률
  - 80% 이상: 확장 검토 시작
  - 90% 이상: 확장 필요
  - 95% 이상: 긴급 확장

✓ 수요 증가 추세
  - 지속성: 3년 이상 지속적 증가
  - 안정성: 일시적 급증 vs 구조적 성장
  - 예측 신뢰도: 예측 정확도 평가

✓ 건설 리드타임
  - 공장 건설: 2~3년
  - 설비 도입: 1~2년
  - 시운전 기간: 3~6개월
  → 수요 발생 이전 착수 필요

✓ 경쟁 상황
  - 경쟁사 증설 계획
  - 시장 선점 필요성
  - 과당 경쟁 위험
```

**확장 규모 결정 방법**

**방법 1: 단계적 확장(Incremental)**
```
특징:
- 소규모 능력을 순차적 증설
- 수요 변화에 탄력적 대응

장점:
✓ 리스크 분산
✓ 학습 효과
✓ 유연성 확보

단점:
✗ 규모의 경제 제한
✗ 잦은 증설 비용
✗ 운영 복잡성

적용:
- 수요 불확실성 높음
- 기술 변화 빠름
- 자금 여력 제한
```

**방법 2: 일괄 확장(Lumpy)**
```
특징:
- 대규모 능력을 한 번에 증설
- 장기 수요 예측 기반

장점:
✓ 규모의 경제
✓ 단가 절감
✓ 관리 단순화

단점:
✗ 초기 유휴 설비
✗ 높은 리스크
✗ 유연성 부족

적용:
- 수요 예측 신뢰도 높음
- 규모의 경제 중요
- 자금 여력 충분
```

**방법 3: 선도적 확장(Leading)**
```
전략: 수요보다 앞서 확장

목적:
- 시장 선점
- 경쟁사 진입 억제
- 성장 촉진

위험:
- 초기 과잉 투자
- 수요 미충족 시 손실
```

**방법 4: 추종적 확장(Lagging)**
```
전략: 수요 확인 후 확장

목적:
- 위험 최소화
- 확실한 수요 기반

위험:
- 기회 상실
- 시장점유율 감소
```

#### (3) 실무 사례

```
사례 1: 현대자동차 (단계적 확장)
- 해외 공장: 소규모로 시작
- 수요 확인 후 점진적 증설
- 결과: 리스크 최소화

사례 2: 삼성전자 반도체 (선도적 대규모 확장)
- 시장 예측 기반 대규모 투자
- 경쟁사 진입 장벽 구축
- 결과: 시장 지배력 확보 (단, 높은 리스크)
```

### 유의사항 3: 재무적 타당성 및 투자 회수 계획

#### (1) 핵심 내용

**막대한 자본 투자**
```
생산능력 확장 투자 규모:
- 토지 구입
- 건물 건설
- 설비 구매
- 운전자본
→ 수백억~수조원
```

**투자 회수 기간**
```
장기 투자:
- 회수 기간: 5~10년
- 고정비 부담 지속
- 재무 레버리지 증가
```

#### (2) 구체적 유의사항

**재무 타당성 분석**

**방법 1: NPV (순현재가치)**
```
NPV = Σ(현금유입 / (1+r)^t) - 초기 투자

판단:
NPV > 0: 투자 가치 있음
NPV < 0: 투자 부적절

예시:
초기 투자: 100억원
연간 현금유입: 20억원 (10년)
할인율: 8%

NPV = 20억 × 6.71 - 100억
    = 134.2억 - 100억
    = 34.2억원 > 0 ✓
```

**방법 2: IRR (내부수익률)**
```
IRR = NPV를 0으로 만드는 할인율

판단:
IRR > 자본비용: 투자 가치 있음

예시:
IRR = 15%
자본비용 = 8%
→ 15% > 8% → 투자 적합
```

**방법 3: 회수 기간법**
```
회수 기간 = 초기 투자 / 연간 현금유입

예시:
투자: 100억원
연간 현금유입: 20억원
회수 기간 = 100 / 20 = 5년

판단: 기준 기간(예: 7년) 이내 → 적합
```

**재무 리스크 관리**

```
✓ 자금 조달 계획
  - 자기자본 vs 타인자본 비율
  - 부채비율 적정성
  - 이자 부담 능력
  - 현금흐름 안정성

✓ 손익분기점 분석
  BEP = 고정비 / (단위당 가격 - 단위당 변동비)

  확장 후:
  - 고정비 증가
  - BEP 상승
  - 위험 증가
  → BEP 수요와 예상 수요 비교

✓ 민감도 분석
  주요 변수 변화 시 영향:
  - 수요 ±20%
  - 가격 ±10%
  - 변동비 ±15%
  → 각 시나리오별 수익성 평가

✓ 위험 대비책
  - 유휴 설비 활용 방안 (임대, 다각화)
  - 설비 유연성 (다품종 생산 가능)
  - 단계적 투자로 리스크 분산
```

**운전자본 고려**

```
생산능력 확장 시:
- 원자재 재고 증가
- 재공품 증가
- 완제품 재고 증가
- 매출채권 증가

운전자본 = 유동자산 - 유동부채
→ 추가 운전자본 필요

예시:
능력 2배 확장:
- 설비 투자: 200억원
- 운전자본 증가: 50억원
- 총 필요 자금: 250억원
```

#### (3) 실무 사례

```
사례: 제조업체 B사 확장 프로젝트

투자 계획:
- 공장 부지: 50억원
- 건물: 100억원
- 설비: 150억원
- 운전자본: 50억원
- 총 투자: 350억원

재무 분석:
- 연간 추가 매출: 200억원
- 증분 영업이익: 40억원
- NPV (할인율 10%): 96억원
- IRR: 14.5%
- 회수 기간: 8.75년

의사결정:
- NPV > 0 ✓
- IRR (14.5%) > WACC (10%) ✓
- 회수 기간 10년 이내 ✓
→ 투자 진행 결정

리스크 관리:
- 단계적 투자 (1차 60%, 2차 40%)
- 정부 보조금 활용
- 장기 차입 활용 (금리 고정)
```

## 📊 3. 추가 고려사항

### (1) 기술 및 설비 선택

```
✓ 최신 기술 vs 검증된 기술
  - 최신: 효율성 높으나 불확실성
  - 검증: 안정적이나 경쟁력 제한

✓ 유연성(Flexibility)
  - 다품종 대응 능력
  - 생산량 조절 용이성
  - 향후 업그레이드 가능성

✓ 자동화 수준
  - 인건비 절감
  - 품질 안정성
  - 초기 투자 증가

✓ 환경 규제 대응
  - 친환경 설비
  - 배출 규제 준수
  - ESG 경영 고려
```

### (2) 입지 선정

```
✓ 시장 접근성
  - 고객 근접성
  - 물류 비용

✓ 자원 확보
  - 원자재 조달
  - 인력 수급
  - 인프라

✓ 비용
  - 토지 가격
  - 인건비 수준
  - 세금 혜택

✓ 리스크
  - 정치적 안정성
  - 자연재해
  - 규제 환경
```

### (3) 조직 및 인력

```
✓ 인력 확보 계획
  - 필요 인원 산정
  - 채용 전략
  - 교육 훈련

✓ 조직 재편
  - 관리 체계
  - 보고 라인
  - 권한과 책임

✓ 기존 시설과의 조화
  - 통합 vs 분리 운영
  - 시너지 효과
  - 내부 경쟁 방지
```

## 🎯 5. 최종 답안 정리

### 생산능력 확장 시 유의사항 3가지

#### 1) 수요예측의 정확성 확보

**내용**
- 장기적 생산능력 투자는 수요예측에 기반하므로, 정확한 수요 분석이 필수적이다.
- 과대 예측 시 유휴 설비 발생으로 고정비 부담 증가, 과소 예측 시 시장 기회 상실의 위험이 있다.

**구체적 방안**
- 다각도 수요 분석: 과거 추세, 시장 조사, 거시경제 요인, 제품 수명주기 등 종합 검토
- 시나리오 분석: 낙관/기준/비관 시나리오 수립 및 기대값 계산
- 단계적 검증: 시장 테스트 → 시범 생산 → 본격 확장

#### 2) 적절한 확장 시기 및 규모 결정

**내용**
- 확장 시기가 너무 빠르면 유휴 설비, 너무 늦으면 시장 기회 상실이 발생한다.
- 확장 규모는 대규모(규모의 경제)와 소규모(유연성) 간 균형을 고려해야 한다.

**구체적 방안**
- 시기 결정: 현재 가동률(80% 이상 시 검토), 수요 증가 지속성, 건설 리드타임, 경쟁 상황 고려
- 규모 선택:
  * 단계적 확장: 수요 불확실 시, 리스크 분산
  * 일괄 확장: 수요 확실 시, 규모의 경제
- 전략 선택: 선도적(시장 선점) vs 추종적(위험 최소화)

#### 3) 재무적 타당성 및 투자 회수 계획

**내용**
- 생산능력 확장은 막대한 자본 투자를 수반하므로, 철저한 재무 분석과 회수 계획이 필요하다.
- 투자 회수 기간이 장기(5~10년)이므로, 재무 리스크를 면밀히 관리해야 한다.

**구체적 방안**
- 재무 타당성 분석: NPV, IRR, 회수기간법 등 다각도 평가
- 재무 리스크 관리:
  * 자금 조달 계획: 자기자본/타인자본 비율, 부채비율 적정성
  * 손익분기점 분석: 확장 후 BEP와 예상 수요 비교
  * 민감도 분석: 수요, 가격, 비용 변화 시 영향 평가
- 운전자본 고려: 설비 투자 외 재고, 매출채권 증가분 반영

  생산/공급 분야의 광범위한 정책과 계획
```

**목적**
- 경쟁우위 확보
- 전사 전략과 정합성
- 자원의 효율적 배분

### (2) 생산공급전략의 중요성

✓ 경쟁전략의 실행 수단
✓ 고객 가치 창출의 핵심
✓ 장기적 투자 방향 제시
✓ 조직 역량 구축
```

### (3) 전략적 의사결정 영역

```
구조적 결정 (Structural):
- 생산능력 (규모, 입지)
- 설비와 기술

인프라 결정 (Infrastructural):
- 인적자원 관리
- 품질 관리
- 생산계획 및 통제
- 공급망 관리
```

## 💡 2. (1) 집중화와 상쇄관계의 기본 논리

### 핵심 개념 설명

#### (1) 집중화(Focus)의 논리

**개념**
```
집중화 = 선택과 집중 전략
= 제한된 경쟁차원에 자원을 집중 투입
```

**기본 논리**
```
전제:
- 기업의 자원은 제한적
- 모든 경쟁차원에서 동시 우위 달성 불가능
- 각 경쟁차원은 서로 다른 역량 요구

결론:
→ 특정 경쟁차원에 집중
→ 해당 분야 탁월성(Excellence) 추구
→ 경쟁우위 확보
```

**집중화의 유형**

```
1) 제품 집중
- 제한된 제품군
- 특화된 생산 시스템
- 높은 효율성

2) 시장 집중
- 특정 고객 세그먼트
- 맞춤형 서비스
- 고객 친밀성

3) 공정 집중
- 특정 공정 기술
- 전문화된 역량
- 공정 우수성
```

**사례**
```
사우스웨스트 항공:
- 집중 전략: 저비용
- 포기한 것: 기내식, 좌석 지정, 환승 서비스
- 집중한 것: 운영 효율, 빠른 회전율, 단거리 노선
- 결과: 저비용 항공사 1위
```

#### (2) 상쇄관계(Trade-off)의 논리

**개념**
```
상쇄관계 = 경쟁차원 간 양립 불가능성
= 한 차원 개선 시 다른 차원 희생 불가피
```

**기본 논리**
```
관찰:
- 원가 절감 ↔ 품질 향상 (충돌)
- 유연성 확보 ↔ 효율성 추구 (충돌)
- 납기 단축 ↔ 재고 최소화 (충돌)

원인:
- 제한된 자원 (예산, 인력, 시간)
- 상충하는 요구사항
- 서로 다른 시스템/프로세스 필요

의미:
→ 전략적 선택 불가피
→ 무엇을 포기할 것인가?
→ 명확한 우선순위 설정
```

**상쇄관계가 발생하는 이유**

```
1. 자원 제약
- 예산 한계: 모든 분야 동시 투자 불가
- 시간 제약: 빠름과 완벽함 양립 어려움
- 인력 한계: 다재다능한 인력 부족

2. 시스템 특성
- 대량생산 시스템: 효율적이나 유연성 부족
- 맞춤생산 시스템: 유연하나 비효율적
- 동일 시스템으로 양립 불가

3. 조직 역량
- 원가절감 문화 ↔ 혁신 문화
- 표준화 역량 ↔ 맞춤화 역량
- 한 조직에 양립 어려움
```

**사례**
```
볼보 vs 현대차:
- 볼보: 안전성 집중 (상대적 고가)
- 현대: 가성비 집중 (상대적 안전성 타협)
→ 안전성 ↔ 가격의 상쇄관계
```

#### (3) 집중화와 상쇄관계의 관계

```
상쇄관계 존재
    ↓
모든 차원 동시 우위 불가능
    ↓
전략적 선택 필요
    ↓
특정 차원에 집중
    ↓
집중화 전략
```

**통합 논리**
```
1. 상쇄관계 인정
   - 경쟁차원 간 충돌 존재
   - 동시 달성 불가능 인식

2. 우선순위 결정
   - 시장에서 중요한 차원 파악
   - 자사 역량 고려

3. 집중화 실행
   - 선택한 차원에 자원 집중
   - 다른 차원은 최소 수준 유지

4. 탁월성 추구
   - 선택한 분야 세계 최고 수준 목표
   - 모방 어려운 경쟁우위 구축
```

## 📊 3. (2) 상쇄관계에 있는 경쟁차원 3가지

### 경쟁차원 1: 원가(Cost) vs 품질(Quality)

#### (1) 상쇄관계 설명

**기본 충돌**
```
원가 절감 추구:
- 저가 원자재 사용
- 검사 최소화
- 표준화/단순화
- 인건비 절감

품질 향상 추구:
- 고급 원자재 사용
- 엄격한 검사
- 정밀 공정
- 숙련 인력

→ 동시 추구 시 충돌
```

**구체적 상쇄 사례**

```
원자재:
원가 우선: 저가 재료 → 품질 저하
품질 우선: 고급 재료 → 원가 상승

검사:
원가 우선: 샘플 검사 → 불량 유출 위험
품질 우선: 전수 검사 → 검사 비용 증가

공정:
원가 우선: 고속 생산 → 정밀도 저하
품질 우선: 정밀 가공 → 생산성 하락

인력:
원가 우선: 비숙련 저임금 → 품질 불안정
품질 우선: 고숙련 고임금 → 인건비 상승
```

#### (2) 실무 사례

```
사례 1: 저가 전략 (원가 우선)
- 대표: 중국 제조업체
- 전략: 원가 최소화
- 품질: 기본 수준
- 결과: 가격 경쟁력 확보

사례 2: 프리미엄 전략 (품질 우선)
- 대표: 메르세데스-벤츠
- 전략: 최상급 품질
- 원가: 높은 제조원가 감수
- 결과: 프리미엄 이미지, 고가격
```

#### (3) 관리 포인트

```
의사결정:
- 목표 고객층의 우선순위
- 중저가 시장 vs 프리미엄 시장
- 원가/품질 최적 조합 탐색

예외:
- TQM, Six Sigma 등으로 일부 완화 가능
- 장기적으로 품질 향상이 원가 절감 기여
- 단, 초기 투자와 시간 필요
```

---

### 경쟁차원 2: 유연성(Flexibility) vs 효율성(Efficiency)

#### (1) 상쇄관계 설명

**기본 충돌**
```
유연성 추구:
- 다품종 대응 가능
- 빠른 전환
- 범용 설비
- 다기능 인력

효율성 추구:
- 소품종 대량생산
- 전문화/표준화
- 전용 설비
- 분업화된 인력

→ 시스템 설계 자체가 상충
```

**구체적 상쇄 사례**

```
설비:
유연성: 범용 설비, CNC 등
  - 장점: 다양한 제품 가능
  - 단점: 생산성 낮음, 높은 단가

효율성: 전용 자동화 라인
  - 장점: 고속 대량생산, 낮은 단가
  - 단점: 특정 제품만 가능

인력:
유연성: 다기능 작업자
  - 장점: 업무 전환 가능
  - 단점: 숙련도 분산, 생산성 낮음

효율성: 전문화된 작업자
  - 장점: 높은 숙련도, 빠른 작업
  - 단점: 업무 전환 어려움

재고:
유연성: 다양한 부품 확보
  - 장점: 고객 주문 대응
  - 단점: 재고 비용 증가

효율성: 소품종 집중 재고
  - 장점: 재고 회전율 높음
  - 단점: 고객 대응력 제한
```

#### (2) 실무 사례

```
사례 1: 효율성 집중
- 대표: 맥도날드
- 전략: 표준화된 메뉴, 정해진 프로세스
- 유연성: 제한적 (특별 주문 어려움)
- 효율성: 매우 높음 (빠른 서비스, 저렴한 가격)

사례 2: 유연성 집중
- 대표: 고급 레스토랑
- 전략: 맞춤형 요리, 셰프 재량
- 유연성: 매우 높음 (고객 요구 대응)
- 효율성: 낮음 (긴 조리 시간, 높은 가격)
```

#### (3) 관리 포인트

```
시장 특성 고려:
- 안정적 수요 → 효율성 우선
- 변동적 수요 → 유연성 필요

절충안:
- 모듈화: 표준 모듈 + 맞춤 조합
- 연기 전략(Postponement): 기본 생산 후 후반 맞춤
- 하이브리드 시스템: 핵심은 효율적, 일부 유연
```

### 경쟁차원 3: 납기(Delivery Speed) vs 원가(Cost)

#### (1) 상쇄관계 설명

**기본 충돌**
```
납기 단축:
- 높은 재고 유지
- 여유 생산능력
- 급행 운송
- 초과 근무

원가 절감:
- 재고 최소화
- 가동률 극대화
- 경제적 운송
- 정규 근무

→ 빠름과 저렴함의 충돌
```

**구체적 상쇄 사례**

```
재고:
납기 우선: 완제품 재고 충분히 확보
  - 장점: 즉시 출하 가능
  - 단점: 재고유지비용, 재고 리스크

원가 우선: 재고 최소화, 수주생산
  - 장점: 재고비용 절감
  - 단점: 납기 지연

생산능력:
납기 우선: 여유 능력 유지 (가동률 70%)
  - 장점: 급주문 대응 가능
  - 단점: 유휴 설비 비용

원가 우선: 가동률 극대화 (95%)
  - 장점: 설비 효율 최대
  - 단점: 급주문 대응 불가

운송:
납기 우선: 항공 특송
  - 장점: 익일 배송
  - 단점: 높은 운송비

원가 우선: 해상/육상 운송
  - 장점: 저렴한 운송비
  - 단점: 긴 배송 기간

작업 속도:
납기 우선: 초과근무, 특급작업
  - 장점: 납기 준수
  - 단점: 높은 인건비, 품질 리스크

원가 우선: 정규 작업
  - 장점: 정상 인건비
  - 단점: 표준 리드타임
```

#### (2) 실무 사례

```
사례 1: 납기 우선
- 대표: 쿠팡 로켓배송
- 전략: 지역별 물류센터, 높은 재고
- 원가: 높은 물류/재고 비용 감수
- 결과: 빠른 배송으로 시장 점유율 확대

사례 2: 원가 우선
- 대표: 해외직구 플랫폼
- 전략: 해외 직송, 재고 미보유
- 납기: 2~4주 소요
- 결과: 저렴한 가격으로 가격 민감 고객 확보
```

#### (3) 관리 포인트

```
고객 세분화:
- 긴급 고객: 프리미엄 가격 + 빠른 납기
- 일반 고객: 표준 가격 + 표준 납기

절충 전략:
- 재고 분산: 일부 품목만 재고 보유
- 단계별 서비스: 표준/급행 옵션 제공
- JIT: 재고 없이 빠른 납기 (공급망 협력)
```

## 🔍 4. 기타 상쇄관계 (참고)

### (1) 품질(Quality) vs 유연성(Flexibility)

```
품질 (일관성):
- 표준화된 프로세스
- 엄격한 품질관리
- 변경 최소화

유연성:
- 자주 변경
- 다양한 사양
- 프로세스 변동

→ 품질 안정성 vs 다양성의 충돌
```

### (2) 혁신(Innovation) vs 효율성(Efficiency)

```
혁신:
- 실험과 시행착오
- 자원 여유
- 실패 허용

효율성:
- 검증된 방법
- 낭비 제거
- 실패 최소화

→ 탐험(Exploration) vs 활용(Exploitation)
```

### (3) 대응성(Responsiveness) vs 안정성(Stability)

```
대응성:
- 빠른 의사결정
- 유연한 조직
- 변화 수용

안정성:
- 신중한 검토
- 체계적 절차
- 변화 통제

→ 민첩성 vs 예측가능성
```

## 💡 5. 전략적 시사점

### (1) 명확한 전략적 포지셔닝

```
성공 공식:
1. 목표 시장의 우선순위 파악
2. 핵심 경쟁차원 선택 (1~2개)
3. 해당 차원에 집중 투자
4. 다른 차원은 최소 수준 유지
5. 선택한 분야 탁월성 추구
```

**실패 사례: "Stuck in the Middle"**
```
전략 불명확:
- 원가도 아님
- 품질도 아님
- 유연성도 아님
→ 경쟁우위 없음
→ 시장에서 도태
```

### (2) 일관성 유지

```
전략-시스템-문화 정렬:

원가 리더십 선택 시:
- 시스템: 자동화, 표준화, 대량생산
- 문화: 낭비제거, 효율성, 원가의식
- 인력: 작업 숙련도, 분업
- 보상: 생산성 기준

차별화 선택 시:
- 시스템: 유연성, 품질, 혁신
- 문화: 창의성, 고객만족, 완벽주의
- 인력: 다기능, 전문성
- 보상: 품질, 고객만족도 기준
```

### (3) 상쇄관계 극복 노력

**단기적: 상쇄관계 수용**
```
- 전략적 선택
- 명확한 우선순위
- 포기할 것 결정
```

**장기적: 상쇄관계 완화**
```
방법:
✓ 프로세스 혁신 (TQM, Lean)
✓ 기술 발전 (자동화, AI)
✓ 역량 구축 (학습조직)
✓ 공급망 협력

목표:
- 효율성 + 유연성 (Lean Production)
- 원가 + 품질 (TQM)
- 납기 + 원가 (JIT)

주의:
- 시간과 투자 필요
- 조직 역량 요구
- 모든 상쇄 해소 불가
```

## 📝 6. 최종 답안 정리

### (1) 집중화와 상쇄관계의 기본 논리

**상쇄관계(Trade-off)**
- 경쟁차원(원가, 품질, 납기, 유연성 등) 간에는 양립하기 어려운 상충관계가 존재한다.
- 한 차원을 개선하려면 다른 차원을 희생해야 하는 것이 불가피하다.
- 이는 자원의 제약, 시스템 특성의 차이, 조직 역량의 한계 때문에 발생한다.

**집중화(Focus)**
- 상쇄관계가 존재하므로 모든 경쟁차원에서 동시에 우위를 달성하는 것은 불가능하다.
- 따라서 기업은 제한된 경쟁차원에 자원을 집중 투입하는 전략적 선택이 필요하다.
- 선택한 차원에서 탁월성을 추구하여 경쟁우위를 확보하는 것이 집중화 전략이다.

**기본 논리의 흐름**
```
상쇄관계 존재 → 동시 달성 불가 → 전략적 선택 필요 → 집중화 전략
```

### (2) 상쇄관계에 있는 경쟁차원 3가지

#### 1) 원가(Cost) vs 품질(Quality)

**상쇄관계**
- 원가 절감을 위해 저가 원자재 사용, 검사 최소화, 고속 생산 시 품질이 저하될 수 있다.
- 반대로 품질 향상을 위해 고급 재료, 엄격한 검사, 정밀 공정 적용 시 원가가 상승한다.

**사례**
- 원가 우선: 중국 저가 제조업체 (낮은 품질 감수)
- 품질 우선: 메르세데스-벤츠 (높은 원가 감수)

#### 2) 유연성(Flexibility) vs 효율성(Efficiency)

**상쇄관계**
- 유연성을 위해 범용 설비, 다기능 인력 활용 시 생산 효율성이 떨어진다.
- 효율성을 위해 전용 설비, 전문화된 인력 활용 시 제품 다양성 대응이 어렵다.

**사례**
- 효율성 우선: 맥도날드 (표준화된 메뉴, 빠른 서비스)
- 유연성 우선: 고급 레스토랑 (맞춤형 서비스, 긴 시간)

#### 3) 납기(Delivery Speed) vs 원가(Cost)

**상쇄관계**
- 납기 단축을 위해 높은 재고 유지, 여유 생산능력, 특급 운송 사용 시 원가가 증가한다.
- 원가 절감을 위해 재고 최소화, 가동률 극대화, 경제적 운송 이용 시 납기가 지연된다.

**사례**
- 납기 우선: 쿠팡 로켓배송 (높은 물류비 감수, 빠른 배송)
- 원가 우선: 해외직구 (저렴한 가격, 긴 배송 기간)

## 36회 품질경영 문제 1 예시답안
[문제 바로가기](#36회-품질경영-문제-1)

### 【문제 1 - (1)】 c관리도와 u관리도의 공통점과 차이점 (10점)

#### 1. 공통점

(1) **계수형 관리도**: 두 관리도 모두 계수형 데이터를 다루는 관리도입니다.

(2) **불량 개수 관리**: 부적합품의 개수가 아닌 결함(결점, 흠)의 개수를 관리합니다.

(3) **포아송분포 가정**: 두 관리도 모두 결함 수가 포아송분포를 따른다고 가정합니다.

(4) **공정 안정성 평가**: 공정의 안정성과 품질수준을 평가하는 데 사용됩니다.

#### 2. 차이점

| 구분 | c관리도 | u관리도 |
|---|---|---|
| **시료 크기** | 일정(constant) | 변동 가능(variable) |
| **측정 단위** | 시료당 결함 수 (count) | 단위당 결함 수 (rate) |
| **관리 대상** | 총 결함 수 | 단위당 결함 수 |
| **중심선** | c̄ (평균 결함 수) | ū (평균 단위당 결함 수) |
| **관리한계선** | 고정 | 시료 크기에 따라 변동 |
| **활용 상황** | 일정 면적, 일정 길이의 제품 | 크기가 다른 제품이나 샘플 |

#### 3. 관리도 공식

**c관리도**
- 중심선(CL) = c̄
- 관리상한선(UCL) = c̄ + 3√c̄
- 관리하한선(LCL) = c̄ - 3√c̄ (단, 음수면 0)

**u관리도**
- 중심선(CL) = ū
- 관리상한선(UCL) = ū + 3√(ū/n)
- 관리하한선(LCL) = ū - 3√(ū/n) (단, 음수면 0)
- n: 각 시료의 크기

### 【문제 1 - (2)】 x̄ 관리도의 관리한계선 계산 (10점)

#### 1. 각 샘플군의 평균(x̄ᵢ) 계산

샘플군 1: x̄₁ = (7 + 14 + 3 + 4 + 7) / 5 = 35 / 5 = 7.00

샘플군 2: x̄₂ = (10 + 19 + 9 + 13 + 14) / 5 = 65 / 5 = 13.00

샘플군 3: x̄₃ = (7 + 17 + 2 + 5 + 14) / 5 = 45 / 5 = 9.00

샘플군 4: x̄₄ = (15 + 18 + 16 + 9 + 17) / 5 = 75 / 5 = 15.00

샘플군 5: x̄₅ = (5 + 9 + 4 + 5 + 7) / 5 = 30 / 5 = 6.00

#### 2. 총평균(x̿) 계산

x̿ = (x̄₁ + x̄₂ + x̄₃ + x̄₄ + x̄₅) / 5
x̿ = (7.00 + 13.00 + 9.00 + 15.00 + 6.00) / 5
x̿ = 50.00 / 5 = **10.00**

#### 3. 각 샘플군의 범위(Rᵢ) 계산

R₁ = 14 - 3 = 11
R₂ = 19 - 9 = 10
R₃ = 17 - 2 = 15
R₄ = 18 - 9 = 9
R₅ = 9 - 4 = 5

#### 4. 평균범위(R̄) 계산

R̄ = (R₁ + R₂ + R₃ + R₄ + R₅) / 5
R̄ = (11 + 10 + 15 + 9 + 5) / 5
R̄ = 50 / 5 = **10.00**

#### 5. x̄ 관리도의 관리한계선 계산

샘플 크기 n = 5이므로, A₂ = 0.58

**중심선(CL)** = x̿ = 10.00

**관리상한선(UCL)** = x̿ + A₂ × R̄
= 10.00 + 0.58 × 10.00
= 10.00 + 5.80
= **15.80**

**관리하한선(LCL)** = x̿ - A₂ × R̄
= 10.00 - 0.58 × 10.00
= 10.00 - 5.80
= **4.20**

#### 답안
- **UCL = 15.80**
- **LCL = 4.20**

---

### 【문제 1 - (3)】 R 관리도의 관리한계선 계산 (10점)

#### 1. 평균범위(R̄) 활용

문제 (2)에서 계산한 R̄ = 10.00을 사용합니다.

#### 2. R 관리도의 관리한계선 계산

샘플 크기 n = 5이므로:
- D₄ = 2.12
- D₃ = - (값이 없음, 0으로 간주)

**중심선(CL)** = R̄ = 10.00

**관리상한선(UCL)** = D₄ × R̄
= 2.12 × 10.00
= **21.20**

**관리하한선(LCL)** = D₃ × R̄
= 0 × 10.00
= **0** (또는 설정하지 않음)

#### 답안
- **UCL = 21.20**
- **LCL = 0** (또는 없음)

### 답안 작성 팁

1. **c관리도와 u관리도 비교**: 시료 크기의 일정성 여부가 핵심 차이점입니다. c관리도는 일정한 크기의 시료, u관리도는 변동하는 크기의 시료에 사용됩니다.

2. **계산 과정**: x̄-R 관리도 계산 시 각 단계를 명확히 표시하고, 중간 계산값도 정확히 기재해야 부분점수를 받을 수 있습니다.

3. **소수점 처리**: 문제에서 요구한 대로 소수점 셋째자리에서 반올림하여 둘째자리까지 표기합니다.

4. **계수표 활용**: n값에 따른 A₂, D₃, D₄ 값을 정확히 찾아 적용해야 합니다.

5. **관리하한선 처리**: R 관리도에서 D₃값이 없는 경우(또는 0), LCL은 0 또는 설정하지 않는 것으로 표기합니다.

## 36회 품질경영 문제 2 예시답안
[문제 바로가기](#36회-품질경영-문제-2)

### 【문제 2 - (1)】 모수인자와 변량인자 설명 (4점)

#### 1. 모수인자 (Fixed Factor, 고정인자)

**정의**: 실험자가 의도적으로 선택하고 통제할 수 있는 인자로, 실험에서 다루는 수준(level)이 모집단의 전체를 대표합니다.

**특징**:
- 실험 결과의 추론이 선택된 수준에만 국한됩니다.
- 인자의 수준을 실험자가 의도적으로 선정합니다.
- 특정 조건에서의 효과를 평가하는 것이 목적입니다.

**예시**:
- 특정 기계 3대(A, B, C)의 성능 비교
- 정해진 온도 조건(100℃, 150℃, 200℃)의 효과
- 특정 작업자의 숙련도 비교

#### 2. 변량인자 (Random Factor, 확률인자)

**정의**: 실험에서 다루는 수준이 모집단에서 무작위로 추출된 표본으로 간주되는 인자입니다.

**특징**:
- 실험 결과를 전체 모집단으로 일반화할 수 있습니다.
- 인자의 수준이 무작위로 추출됩니다.
- 변동성(분산)의 크기를 평가하는 것이 목적입니다.

**예시**:
- 공장의 전체 기계 중 무작위로 선택한 3대
- 여러 로트(lot) 중 무작위로 선택한 샘플
- 전체 작업자 중 무작위로 선택한 작업자

#### 3. 두 인자의 비교

| 구분 | 모수인자 | 변량인자 |
|---|---|---|
| 선택 방법 | 의도적 선택 | 무작위 추출 |
| 추론 범위 | 실험 수준에만 국한 | 전체 모집단으로 확대 |
| 관심 대상 | 수준 간 평균 차이 | 변동(분산)의 크기 |
| 분석 목적 | 특정 조건의 효과 | 변동성 평가 |

### 【문제 2 - (2)】 실험계획의 5가지 기본원리 (10점)

#### 1. 반복의 원리 (Replication, 되풀이의 원리)

**정의**: 동일한 조건에서 실험을 여러 번 반복하여 실시하는 것입니다.

**목적 및 효과**:
- 실험오차의 추정이 가능합니다.
- 추정의 정밀도를 향상시킵니다.
- 우연오차의 영향을 감소시킵니다.
- 통계적 검정의 신뢰성을 높입니다.

**주의사항**: 진반복(true replication)이어야 하며, 단순한 측정 반복과는 구별됩니다.

#### 2. 무작위화의 원리 (Randomization)

**정의**: 실험의 순서나 실험단위의 배치를 무작위로 결정하는 것입니다.

**목적 및 효과**:
- 계통오차(systematic error)를 우연오차로 전환합니다.
- 알려지지 않은 교란인자의 영향을 배제합니다.
- 실험의 독립성을 확보합니다.
- 통계적 검정의 타당성을 보장합니다.

**적용 예**:
- 실험 순서의 무작위 배정
- 실험 재료의 무작위 할당
- 측정 순서의 무작위화

#### 3. 국소관리의 원리 (Local Control, 블록화의 원리)

**정의**: 실험단위를 동질적인 그룹(블록)으로 나누어 블록 내에서 실험을 실시하는 것입니다.

**목적 및 효과**:
- 알려진 교란요인의 영향을 제거하거나 감소시킵니다.
- 실험오차를 감소시켜 실험의 정밀도를 향상시킵니다.
- 블록 간 변동을 분리하여 순수한 처리 효과를 평가합니다.

**적용 예**:
- 시간대별 블록 구성
- 원료 로트별 블록 구성
- 작업자별 블록 구성

#### 4. 교락의 원리 (Confounding)

**정의**: 실험의 효율을 높이기 위해 관심이 적은 교호작용을 블록 효과와 의도적으로 혼동시키는 것입니다.

**목적 및 효과**:
- 블록의 크기를 줄여 실험을 효율적으로 실시합니다.
- 중요한 주효과는 보존하면서 덜 중요한 교호작용을 희생합니다.
- 실험 비용과 시간을 절감합니다.

**주의사항**: 중요한 효과가 교락되지 않도록 주의해야 합니다.

#### 5. 직교성의 원리 (Orthogonality)

**정의**: 인자 간의 효과를 독립적으로 추정할 수 있도록 실험을 설계하는 것입니다.

**목적 및 효과**:
- 각 인자의 효과를 서로 독립적으로 추정할 수 있습니다.
- 분산분석이 간단하고 명료해집니다.
- 인자 간 상관관계를 제거합니다.
- 분석의 효율성이 극대화됩니다.

**특징**: 직교배열표를 사용하면 직교성이 보장됩니다.

### 【문제 2 - (3)】 결측치 추정 및 수정항 계산 (8점)

#### 1. 결측치 추정 공식

반복이 없는 이원배치법에서 결측치는 다음 공식으로 추정합니다:

**y = (a × Bᵢ' + b × Aⱼ' - T') / [(a-1)(b-1)]**

여기서:
- a: 인자 A의 수준 수
- b: 인자 B의 수준 수
- Bᵢ': 결측치가 속한 행의 합
- Aⱼ': 결측치가 속한 열의 합
- T': 결측치를 제외한 전체 합

#### 2. 필요한 값 계산

**인자 A(온도)의 수준 수**: a = 4
**인자 B(습도)의 수준 수**: b = 3

**B₂(2행)의 합**: B₂' = 26 + 25 + 31 = 82

**A₃(3열)의 합**: A₃' = 27 + 29 = 56

**전체 합**: T' = 21 + 28 + 27 + 29 + 26 + 25 + 31 + 27 + 30 + 29 + 35
T' = 308

#### 3. 결측치 y 계산

y = (a × B₂' + b × A₃' - T') / [(a-1)(b-1)]
y = (4 × 82 + 3 × 56 - 308) / [(4-1)(3-1)]
y = (328 + 168 - 308) / [(3)(2)]
y = 188 / 6
y = 31.333...
y ≈ **31.33** (소수점 셋째자리에서 반올림)

#### 4. 수정항(CT) 계산

결측치 y = 31.33을 대입한 후 전체 합을 계산합니다.

**총합(T)** = T' + y = 308 + 31.33 = 339.33

**전체 데이터 수(N)** = a × b = 4 × 3 = 12

**수정항(CT)** = T² / N
= (339.33)² / 12
= 115,144.8489 / 12
= 9,595.40407...
≈ **9,595.40** (소수점 셋째자리에서 반올림)

#### 답안
- **결측치 y = 31.33**
- **수정항 CT = 9,595.40**

### 【문제 2 - (4)】 오차항 가정의 4가지 특징 (8점)

모수모형 실험의 데이터 식 xᵢⱼ = μ + aᵢ + bⱼ + eᵢⱼ에서 오차항 eᵢⱼ ~ N(0, σₑ²)의 가정은 다음 4가지 특징을 가집니다:

#### 1. 정규성 (Normality)

**내용**: 오차항 eᵢⱼ는 정규분포를 따릅니다.

**의미**:
- 각 관측값의 오차는 정규분포 N(0, σₑ²)를 따릅니다.
- 이는 F-검정과 t-검정의 이론적 근거가 됩니다.

**검정 방법**:
- 정규확률지(Normal probability plot)
- Shapiro-Wilk 검정
- Anderson-Darling 검정

**위배 시 영향**: 검정 결과의 신뢰성이 저하될 수 있습니다.

#### 2. 독립성 (Independence)

**내용**: 오차항들은 서로 독립적입니다.

**의미**:
- 한 관측값의 오차가 다른 관측값의 오차에 영향을 주지 않습니다.
- Cov(eᵢⱼ, eₖₗ) = 0 (i≠k 또는 j≠l일 때)

**확보 방법**:
- 무작위화(randomization) 원리 적용
- 실험 순서의 무작위 배정
- 독립적인 실험 환경 유지

**위배 시 영향**:
- 자기상관(autocorrelation) 발생
- 검정통계량의 분포가 왜곡됩니다.

#### 3. 등분산성 (Homoscedasticity, 분산의 균일성)

**내용**: 모든 오차항의 분산이 동일합니다.

**의미**:
- Var(eᵢⱼ) = σₑ² (모든 i, j에 대해 동일)
- 처리나 수준에 관계없이 오차의 변동이 일정합니다.

**검정 방법**:
- Bartlett 검정
- Levene 검정
- 잔차도(residual plot) 분석

**위배 시 영향**:
- F-검정의 검정력이 감소합니다.
- 신뢰구간이 부정확해집니다.

**대응 방법**: 변환(transformation) 적용 (로그변환, 제곱근변환 등)

#### 4. 평균이 0 (Zero Mean)

**내용**: 오차항의 기댓값은 0입니다.

**의미**:
- E(eᵢⱼ) = 0
- 계통적 편의(systematic bias)가 없습니다.
- 오차는 양(+)과 음(-)의 방향으로 균형을 이룹니다.

**중요성**:
- 모형의 불편추정량(unbiased estimator) 확보
- 잔차의 합이 0이 되도록 보장
- 모수 추정의 정확성 확보

**확인 방법**: 잔차의 평균이 0에 가까운지 확인

---

### 실험계획 관련 추가 학습사항

#### 분산분석(ANOVA)의 기본 가정

1. 정규성: 각 그룹의 데이터가 정규분포를 따름
2. 독립성: 관측값들이 서로 독립적
3. 등분산성: 모든 그룹의 분산이 동일

이 세 가지 가정이 만족되어야 F-검정이 타당합니다.

#### 이원배치법의 분산분석표 구조

| 요인 | 제곱합(SS) | 자유도(df) | 평균제곱(MS) | F값 |
|---|---|---|---|---|
| 인자 A | SSₐ | a-1 | MSₐ | MSₐ/MSₑ |
| 인자 B | SSᵦ | b-1 | MSᵦ | MSᵦ/MSₑ |
| 오차 | SSₑ | (a-1)(b-1) | MSₑ | - |
| 합계 | SSₜ | ab-1 | - | - |

1. **인자 구분**: 모수인자와 변량인자는 '선택 방법'과 '추론 범위'를 중심으로 대비하여 설명합니다.

## 36회 품질경영 문제 3 예시답안
[문제 바로가기](#36회-품질경영-문제-3)

### 【문제 3 - (1)】 측정시스템의 정확도와 정밀도 (6점)

#### 1. 정확도 (Accuracy)

**정의**: 측정값이 참값(true value) 또는 기준값에 얼마나 가까운가를 나타내는 척도입니다.

**특징**:
- 측정값의 평균과 참값 간의 일치 정도를 의미합니다.
- 계통오차(systematic error)와 관련이 있습니다.
- 편의(bias) 또는 편차로 표현됩니다.

**수식**:
- 정확도 = |측정값의 평균 - 참값|
- 편의(Bias) = 측정값의 평균 - 기준값

**개선 방법**:
- 측정기기의 교정(calibration)
- 측정 방법의 표준화
- 계통오차의 원인 제거
- 기준시료(reference material) 사용

**예시**: 표적의 중심을 맞추는 것에 비유할 수 있습니다. 정확도가 높으면 탄착군의 중심이 과녁의 중심에 가깝습니다.

#### 2. 정밀도 (Precision)

**정의**: 동일한 조건에서 반복 측정했을 때 측정값들이 얼마나 일치하는가를 나타내는 척도입니다.

**특징**:
- 측정값들의 산포도(scatter) 또는 변동성을 의미합니다.
- 우연오차(random error)와 관련이 있습니다.
- 재현성, 반복성으로 평가됩니다.

**수식**:
- 정밀도 = 1 / 표준편차 (또는 분산의 역수)
- 변동계수(CV) = (표준편차 / 평균) × 100%

**개선 방법**:
- 측정 환경의 안정화
- 측정자 훈련 강화
- 측정 절차의 표준화
- 우연오차의 최소화

**예시**: 표적의 탄착군 밀집도에 비유할 수 있습니다. 정밀도가 높으면 탄착군이 좁은 범위에 집중됩니다.

#### 3. 정확도와 정밀도의 관계

| 구분 | 정확도 | 정밀도 |
|---|---|---|
| 의미 | 참값과의 근접성 | 측정값 간 일치성 |
| 관련 오차 | 계통오차 | 우연오차 |
| 평가 지표 | 편의(Bias) | 표준편차, 분산 |
| 목표 | 참값에 가깝게 | 일정하게 |

#### 4. 정확도와 정밀도의 조합 (표적 비유)

```
┌─────────────────┬─────────────────┐
│  정확도: 낮음    │  정확도: 높음    │
│  정밀도: 낮음    │  정밀도: 낮음    │
│                 │                 │
│    ·  ·         │      ·  ·       │
│      ·    ·     │    ·    ·       │
│  ·      +       │        +        │
│    ·            │      ·  ·       │
│                 │                 │
├─────────────────┼─────────────────┤
│  정확도: 낮음    │  정확도: 높음    │
│  정밀도: 높음    │  정밀도: 높음    │
│                 │                 │
│     ····        │        ····     │
│     ····  +     │        +        │
│                 │                 │
│                 │                 │
│                 │                 │
└─────────────────┴─────────────────┘
```

**이상적인 측정시스템**: 정확도와 정밀도가 모두 높아야 합니다.

---

### 【문제 3 - (2)】 게이지 R&R의 반복성과 재현성 (4점)

#### 1. 게이지 R&R 개요

**게이지 R&R (Gage Repeatability & Reproducibility)**:
- 측정시스템의 변동을 정량적으로 평가하는 기법입니다.
- 반복성과 재현성으로 구성됩니다.
- 측정시스템의 신뢰성을 판단하는 핵심 지표입니다.

#### 2. 반복성 (Repeatability)

**정의**: 동일한 측정자가 동일한 측정기기로 동일한 부품을 반복 측정했을 때 나타나는 측정값의 변동입니다.

**특징**:
- Equipment Variation (EV, 기기 변동)이라고도 합니다.
- 측정기기 자체의 변동성을 나타냅니다.
- 기기의 내적 일관성을 평가합니다.

**변동 요인**:
- 측정기기의 정밀도
- 기기의 마모 상태
- 측정 환경의 변화 (온도, 습도 등)
- 측정 방법의 일관성

**평가 방법**:
- 동일 측정자가 같은 부품을 여러 번 반복 측정
- 측정값들의 범위(Range)나 표준편차 계산
- EV = R̄ / d₂ × K₁ (K₁은 계수)

**개선 방안**:
- 측정기기 유지보수 및 교정
- 측정 환경 안정화
- 고정밀 측정기기 도입
- 측정 절차 개선

#### 3. 재현성 (Reproducibility)

**정의**: 서로 다른 측정자가 동일한 측정기기로 동일한 부품을 측정했을 때 나타나는 측정값의 변동입니다.

**특징**:
- Appraiser Variation (AV, 평가자 변동)이라고도 합니다.
- 측정자 간의 차이를 나타냅니다.
- 측정 방법의 표준화 정도를 평가합니다.

**변동 요인**:
- 측정자의 숙련도 차이
- 측정 방법에 대한 이해도 차이
- 측정 절차 준수 정도
- 측정자의 주관적 판단

**평가 방법**:
- 여러 측정자가 같은 부품을 측정
- 측정자 간 평균값의 범위 계산
- AV = (X̄_diff) / d₂ × K₂ (K₂는 계수)

**개선 방안**:
- 측정자 교육 훈련 강화
- 측정 절차의 명확한 표준화
- 측정 방법에 대한 시각적 표준 제시
- 측정자 간 교차 검증

#### 4. 반복성과 재현성의 비교

| 구분 | 반복성 (Repeatability) | 재현성 (Reproducibility) |
|---|---|---|
| **별칭** | Equipment Variation (EV) | Appraiser Variation (AV) |
| **변동 요인** | 측정기기 | 측정자 |
| **측정 조건** | 동일 측정자 | 서로 다른 측정자 |
| **평가 대상** | 기기의 일관성 | 측정자 간 일치성 |
| **주요 원인** | 기기 정밀도, 환경 | 숙련도, 표준화 |

#### 5. 게이지 R&R 종합 평가

**전체 게이지 R&R**:
- GRR = √(EV² + AV²)
- 측정시스템의 총 변동을 나타냅니다.

**판정 기준** (GRR의 공정 변동 대비 비율):
- **10% 미만**: 우수 (acceptable)
- **10~30%**: 조건부 허용 (marginal)
- **30% 이상**: 부적합 (unacceptable), 개선 필요

**측정시스템 분산**:
- 총 관측 변동² = 공정 변동² + 측정시스템 변동²
- 측정시스템 변동² = 반복성² + 재현성²

---

### 측정시스템 분석 추가 학습사항

#### MSA의 5가지 특성

1. **편의(Bias)**: 측정의 정확도
2. **선형성(Linearity)**: 측정 범위 전체에 걸친 편의의 변화
3. **안정성(Stability)**: 시간 경과에 따른 편의의 변화
4. **반복성(Repeatability)**: 동일 조건에서의 변동
5. **재현성(Reproducibility)**: 조건 변화 시 변동

#### 측정시스템의 6가지 변동 원인 (5M1E)

1. **Man (사람)**: 측정자의 숙련도
2. **Machine (기계)**: 측정기기의 성능
3. **Material (재료)**: 측정 대상의 특성
4. **Method (방법)**: 측정 절차
5. **Measurement (측정)**: 측정 환경
6. **Environment (환경)**: 온도, 습도 등

---

### 답안 작성 팁

1. **정확도와 정밀도 구분**: 정확도는 '참값과의 근접성', 정밀도는 '측정값 간 일치성'으로 핵심을 명확히 합니다. 표적 비유를 활용하면 이해가 쉽습니다.

2. **계통오차와 우연오차**: 정확도는 계통오차, 정밀도는 우연오차와 연관됨을 언급하면 깊이 있는 답안이 됩니다.

3. **R&R 개념**: 반복성은 'Equipment(기기)', 재현성은 'Appraiser(평가자)'의 앞 글자를 따서 EV, AV로 기억하면 좋습니다.

4. **실무 적용**: 각 개념의 개선 방안까지 언급하면 실무 적용 능력을 보여줄 수 있습니다.

5. **간결한 표현**: 10점 문제이므로 핵심만 간결하게 작성하되, 정의-특징-예시의 구조를 유지합니다.

## 36회 품질경영 문제 4 예시답안
[문제 바로가기](#36회-품질경영-문제-4)

### 【문제 4 - (1)】 사내실패코스트와 사외실패코스트 (4점)

#### 1. 사내실패코스트 (Internal Failure Cost)

**정의**: 제품이나 서비스가 고객에게 인도되기 전에 사내에서 발견된 결함으로 인해 발생하는 비용입니다.

**발생 시점**: 출하 전, 공장 또는 회사 내부

**주요 항목**:
- **폐기 비용**: 재작업이 불가능한 불량품의 폐기 비용
- **재작업 비용**: 불량품을 양품으로 만들기 위한 추가 작업 비용
- **재검사 비용**: 재작업 후 다시 검사하는 비용
- **공정 정지 비용**: 불량으로 인한 생산라인 중단 비용
- **등급 저하 손실**: 정상가격으로 판매할 수 없어 할인 판매하는 비용
- **재설계 비용**: 설계 결함 발견 시 재설계 비용
- **불량품 처리 비용**: 선별, 분류, 보관 비용

**특징**:
- 고객에게 전달되기 전에 발견되어 외부 영향은 없습니다.
- 조기 발견으로 사외실패코스트보다 비용이 상대적으로 적습니다.
- 예방 및 평가 활동 강화로 감소 가능합니다.

#### 2. 사외실패코스트 (External Failure Cost)

**정의**: 제품이나 서비스가 고객에게 인도된 후에 발견된 결함으로 인해 발생하는 비용입니다.

**발생 시점**: 출하 후, 고객 사용 중

**주요 항목**:
- **품질보증 비용**: 보증기간 내 무상 수리 비용
- **클레임 처리 비용**: 고객 불만 처리 비용
- **제품 회수 비용**: 리콜(recall) 비용
- **반품 처리 비용**: 반품된 제품의 회수 및 처리 비용
- **배상 비용**: 손해배상, 법적 소송 비용
- **신용 손실**: 기업 이미지 실추로 인한 매출 감소
- **시장점유율 상실**: 고객 이탈로 인한 장기적 손실
- **제조물 책임 비용**: PL(Product Liability) 보험료, 소송 비용

**특징**:
- 고객에게 전달된 후 발견되어 기업 이미지에 큰 타격을 줍니다.
- 사내실패코스트보다 훨씬 큰 비용이 발생합니다.
- 신용 손실 등 무형의 손실도 포함되어 정확한 측정이 어렵습니다.
- 가장 큰 품질코스트 항목입니다.

#### 3. 두 코스트의 비교

| 구분 | 사내실패코스트 | 사외실패코스트 |
|---|---|---|
| **발생 시점** | 출하 전 (사내) | 출하 후 (고객) |
| **발견 장소** | 공장, 회사 내부 | 시장, 고객 |
| **비용 크기** | 상대적으로 적음 | 상대적으로 큼 |
| **영향 범위** | 내부에 국한 | 외부로 확산 |
| **무형 손실** | 적음 | 큼 (신용, 이미지) |
| **측정 가능성** | 비교적 용이 | 어려움 |

#### 4. 관리 포인트

**사내실패코스트 감소 방안**:
- 공정 내 검사 강화
- 자동화를 통한 작업 오류 감소
- 통계적 공정관리(SPC) 적용
- 작업자 교육 훈련

**사외실패코스트 감소 방안**:
- 출하 전 철저한 검사
- 고객 불만 사항 신속 대응
- 예방활동 강화 (근본 원인 제거)
- 품질보증 시스템 구축

**중요**: 사외실패코스트가 사내실패코스트보다 5~10배 이상 크므로, 출하 전 완벽한 품질 확보가 필수적입니다.

---

### 【문제 4 - (2)】 평가코스트 (3점)

#### 1. 평가코스트 (Appraisal Cost) 정의

**정의**: 제품이나 서비스가 요구되는 품질수준을 만족하는지 확인하고 평가하기 위해 발생하는 비용입니다.

**목적**:
- 결함이 있는 제품이 고객에게 전달되는 것을 방지
- 품질수준의 적합성 확인
- 불량품의 조기 발견

#### 2. 주요 항목

**검사 관련 비용**:
- **수입검사 비용**: 원자재, 부품 입고 시 검사 비용
- **공정검사 비용**: 생산 공정 중간 검사 비용
- **최종검사 비용**: 완제품 출하 전 검사 비용
- **순회검사 비용**: 현장 순회 점검 비용

**시험 관련 비용**:
- **시험 비용**: 제품 성능, 기능 시험 비용
- **파괴시험 비용**: 신뢰성 시험, 수명 시험 비용
- **환경시험 비용**: 온도, 습도, 진동 시험 비용

**측정 관련 비용**:
- **측정기기 유지 비용**: 게이지, 계측기 교정 비용
- **측정기기 감가상각**: 측정 장비 구입 및 유지 비용
- **검사용 지그/치구 비용**: 검사 도구 제작 비용

**품질평가 비용**:
- **품질감사 비용**: 내부 품질감사 실시 비용
- **공급자 평가 비용**: 협력업체 품질평가 비용
- **외부 인증 비용**: ISO 인증, 제품 인증 비용

**인건비**:
- **검사원 인건비**: 검사 담당자 급여
- **품질관리 요원 인건비**: QC 담당자 급여

#### 3. 특징

**긍정적 측면**:
- 불량품의 조기 발견으로 사외실패코스트 감소
- 품질 수준 유지 및 향상
- 고객 신뢰 확보

**부정적 측면**:
- 검사 활동 자체는 부가가치를 창출하지 않음
- 과도한 검사는 비용 증가의 원인
- 검사 누락 시 불량품 유출 위험

#### 4. 관리 방향

**최적화 방안**:
- 예방코스트 증가로 평가코스트 감소 가능
- 통계적 기법 활용으로 전수검사 대신 샘플링검사
- 자동화 검사 시스템 도입
- 공정 능력 향상으로 검사 횟수 감소

**균형점 찾기**:
- 평가코스트를 무조건 줄이는 것이 아니라 최적점을 찾아야 합니다.
- 과소한 검사는 실패코스트 증가를 초래합니다.

---

### 【문제 4 - (3)】 예방코스트 (3점)

#### 1. 예방코스트 (Prevention Cost) 정의

**정의**: 결함이 발생하지 않도록 사전에 예방하기 위해 투자하는 비용입니다.

**목적**:
- 불량의 근본 원인 제거
- 품질 문제의 사전 예방
- 지속적인 품질 개선
- 안정적인 품질 시스템 구축

**특징**: 가장 효과적인 품질코스트 투자 항목

#### 2. 주요 항목

**품질계획 비용**:
- **품질계획 수립**: 품질목표, 품질전략 수립 비용

### 품질코스트 종합 정리

#### 품질코스트의 4대 분류 (PAF 모델)

1. **예방코스트 (Prevention Cost)**: 결함 예방을 위한 비용
2. **평가코스트 (Appraisal Cost)**: 품질 확인 및 검사 비용
3. **사내실패코스트 (Internal Failure Cost)**: 출하 전 발견된 결함 비용
4. **사외실패코스트 (External Failure Cost)**: 출하 후 발견된 결함 비용

#### 품질코스트의 관계

```
적합 품질코스트 (COQ)     부적합 품질코스트 (COPQ)
├─ 예방코스트              ├─ 사내실패코스트
└─ 평가코스트              └─ 사외실패코스트
```

**총 품질코스트** = 예방코스트 + 평가코스트 + 사내실패코스트 + 사외실패코스트

#### 최적 품질코스트 모델

```
비용
 ↑
 │         총 품질코스트
 │            /＼
 │          /    ＼
 │        /        ＼______ 실패코스트
 │      /                   ＼
 │____/________________________＼_____
 │   예방+평가코스트              ＼
 │                                  ＼
 └────────────────────────────→ 품질수준
                 최적점
```

**최적 품질전략**:
- 예방코스트 증대 → 실패코스트 대폭 감소
- 평가코스트 효율화 → 총 품질코스트 최소화
- 장기적 관점의 예방 활동 강화

#### 품질코스트 관리의 원칙

1. **예방 우선**: 사후 처리보다 사전 예방이 효과적
2. **조기 발견**: 공정 후반보다 초기 발견이 비용 절감
3. **근본 원인 제거**: 증상 치료가 아닌 원인 제거
4. **지속적 개선**: 일회성이 아닌 지속적 투자

### 【문제 5 - (1)】 신뢰도함수와 고장률함수 설명 (6점)

#### 1. 신뢰도함수 R(t) (Reliability Function)

**정의**: 제품이나 시스템이 시간 t까지 정상적으로 작동할 확률을 나타내는 함수입니다.

**수식**:
- R(t) = P(T > t)
- 여기서 T는 고장시간(수명)을 나타내는 확률변수

**특성**:
1. **초기값**: R(0) = 1 (시작 시점에서는 모두 정상)
2. **최종값**: R(∞) = 0 (무한 시간 후에는 모두 고장)
3. **단조감소**: dR(t)/dt ≤ 0 (시간이 지날수록 신뢰도 감소)
4. **범위**: 0 ≤ R(t) ≤ 1

**의미**:
- R(t) = 0.9: 시간 t까지 90%가 정상 작동
- R(t) = 0.5: 시간 t에서 절반이 고장 (평균수명)

**고장분포함수와의 관계**:
- F(t) = P(T ≤ t) = 1 - R(t)
- R(t) = 1 - F(t)
- F(t)는 시간 t까지 고장날 누적확률

**평균수명과의 관계**:
- MTTF (Mean Time To Failure) = ∫₀^∞ R(t)dt
- 신뢰도함수를 적분하면 평균수명

**실무 활용**:
- 보증기간 설정: R(t) ≥ 0.95가 되는 t를 보증기간으로 설정
- 예방보전 계획: R(t)가 일정 수준 이하로 떨어지기 전 교체
- 신뢰성 목표 설정: 특정 시간에서의 목표 신뢰도 설정

#### 2. 고장률함수 h(t) (Hazard Rate Function, Failure Rate Function)

**정의**: 시간 t까지 정상 작동한 제품이 시간 t 직후의 미소시간 동안 고장날 순간고장률을 나타내는 함수입니다.

**수식**:
- h(t) = f(t) / R(t)
- 또는 h(t) = -dR(t)/dt / R(t) = -d[ln R(t)]/dt

**의미**:
- 조건부 고장확률의 순간 비율
- 시간 t까지 생존한 것을 전제로 한 순간 고장률
- 단위: 고장/시간 (예: 고장/시간, 고장/1000시간)

**특성**:
1. **비율**: 0 ≤ h(t) < ∞ (확률이 아니므로 1을 초과 가능)
2. **시간 의존성**: 시간에 따라 증가, 감소, 일정 가능
3. **조건부 확률**: t까지 생존을 전제

**욕조곡선 (Bathtub Curve)**:

```
고장률
h(t)
 ↑
 │＼              ______
 │  ＼          /
 │    ＼______/
 │
 │  초기    우발      마모
 │  고장기  고장기    고장기
 └────────────────────────→ 시간(t)
    DFR     CFR       IFR
```

**3단계 분류**:
1. **초기고장기 (DFR, Decreasing Failure Rate)**:
   - 고장률 감소 구간
   - 설계 결함, 제조 불량, 초기 고장
   - 번인(Burn-in) 테스트로 제거

2. **우발고장기 (CFR, Constant Failure Rate)**:
   - 고장률 일정 구간
   - 우연한 외부 요인에 의한 고장
   - 가장 긴 기간 (정상 사용 기간)
   - 지수분포를 따름: h(t) = λ (상수)

3. **마모고장기 (IFR, Increasing Failure Rate)**:
   - 고장률 증가 구간
   - 물리적 마모, 노화, 피로에 의한 고장
   - 예방보전, 부품 교체 필요

**고장분포별 고장률**:

| 분포 | 고장률 h(t) | 특징 |
|---|---|---|
| 지수분포 | λ (상수) | 우발고장, 기억 없음 |
| 와이블(β<1) | 감소 | 초기고장 |
| 와이블(β=1) | 일정 | 우발고장 (지수분포와 동일) |
| 와이블(β>1) | 증가 | 마모고장 |
| 정규분포 | 증가 | 마모고장 |

**실무 활용**:
- 보전전략 수립: 고장률 패턴에 따른 보전 방법 선택
- 수명 예측: 고장률 증가 추세 분석
- 품질 개선: 초기고장기 단축, 우발고장기 연장
- 교체 시기 결정: 마모고장기 진입 전 교체

#### 3. 신뢰도함수와 고장률함수의 관계

**기본 관계식**:
1. h(t) = f(t) / R(t)
2. h(t) = -dR(t)/dt / R(t)
3. R(t) = exp[-∫₀^t h(u)du]
4. f(t) = h(t) × R(t)

**관계식 유도**:
- 고장밀도함수: f(t) = dF(t)/dt = -dR(t)/dt
- 고장률함수: h(t) = f(t)/R(t) = [-dR(t)/dt]/R(t)
- 적분: ∫₀^t h(u)du = -ln R(t)
- 신뢰도함수: R(t) = exp[-∫₀^t h(u)du]

**주요 함수 간 관계**:

```
f(t) ←──────→ F(t) = 1 - R(t)
 ↓                      ↓
h(t) ←──────────────→ R(t)
```

- f(t): 고장밀도함수 (확률밀도함수)
- F(t): 고장분포함수 (누적분포함수)
- R(t): 신뢰도함수 (생존함수)
- h(t): 고장률함수 (위험률함수)

### 【문제 5 - (2)】 신뢰도함수와 고장률함수 계산 (4점)

주어진 고장밀도함수: **f(t) = λe^(-λt)**

이는 **지수분포**의 확률밀도함수입니다.

#### 1. 신뢰도함수 R(t) 계산

**방법 1: 정의를 이용한 계산**

R(t) = P(T > t) = ∫ₜ^∞ f(u)du

= ∫ₜ^∞ λe^(-λu)du

= λ × [-1/λ × e^(-λu)]ₜ^∞

= λ × [-1/λ × (0 - e^(-λt))]

= λ × [e^(-λt)/λ]

= **e^(-λt)**

**방법 2: 고장분포함수를 이용한 계산**

F(t) = ∫₀^t f(u)du = ∫₀^t λe^(-λu)du

= λ × [-1/λ × e^(-λu)]₀^t

= -e^(-λt) + e^0

= 1 - e^(-λt)

R(t) = 1 - F(t) = 1 - (1 - e^(-λt))

= **e^(-λt)**

#### 답안: **R(t) = e^(-λt)**

#### 2. 고장률함수 h(t) 계산

**방법 1: 정의를 이용한 계산**

h(t) = f(t) / R(t)

= λe^(-λt) / e^(-λt)

= **λ**

**방법 2: 신뢰도함수의 미분을 이용한 계산**

h(t) = -dR(t)/dt / R(t)

dR(t)/dt = d[e^(-λt)]/dt = -λe^(-λt)

h(t) = -(-λe^(-λt)) / e^(-λt)

= λe^(-λt) / e^(-λt)

= **λ**

**방법 3: 적분 관계식을 이용한 검증**

R(t) = exp[-∫₀^t h(u)du]

만약 h(t) = λ라면:

∫₀^t h(u)du = ∫₀^t λdu = λt

R(t) = exp[-λt] = e^(-λt) ✓ (일치)

#### 답안: **h(t) = λ** (상수)

---

### 지수분포의 특성 및 의미

#### 1. 지수분포의 특징

**확률밀도함수**: f(t) = λe^(-λt), t ≥ 0

**신뢰도함수**: R(t) = e^(-λt)

**고장률함수**: h(t) = λ (상수)

**평균수명(MTTF)**:
- MTTF = ∫₀^∞ t·f(t)dt = 1/λ
- 또는 MTTF = ∫₀^∞ R(t)dt = 1/λ

**분산**:
- Var(T) = 1/λ²

**특성**:
- 고장률이 일정 (CFR, Constant Failure Rate)
- 무기억성(Memoryless Property): P(T > s+t | T > s) = P(T > t)
- 우발고장 모델링에 적합

#### 2. 무기억성 (Memoryless Property)

**의미**: 과거의 사용 이력이 미래의 고장에 영향을 주지 않습니다.

**수식**:
- P(T > s+t | T > s) = P(T > t)
- "s 시간까지 작동했다는 조건 하에 추가 t 시간 작동할 확률" = "처음부터 t 시간 작동할 확률"

**증명**:
P(T > s+t | T > s) = P(T > s+t) / P(T > s)
= e^(-λ(s+t)) / e^(-λs)
= e^(-λt)
= P(T > t) ✓

**실무적 의미**:
- 1년 사용한 제품이나 새 제품이나 고장 확률 동일
- 예방보전의 효과가 없음 (우발고장은 예측 불가)
- 고장 시 수리보다 교체가 효과적

#### 3. 신뢰도 계산 예시

**예제**: λ = 0.001 (고장/시간)일 때

| 시간 t | 신뢰도 R(t) = e^(-0.001t) | 의미 |
|---|---|---|
| 0 | 1.000 | 100% 작동 |
| 100 | 0.905 | 90.5% 작동 |
| 693 | 0.500 | 50% 작동 (중위수명) |
| 1000 | 0.368 | 36.8% 작동 (평균수명) |
| 2000 | 0.135 | 13.5% 작동 |

**평균수명**: MTTF = 1/λ = 1/0.001 = 1000 시간

**중위수명**: T₀.₅ = -ln(0.5)/λ = 0.693/λ = 693 시간

#### 4. 실무 응용

**적용 분야**:
- 전자부품의 우발고장
- 기계 부품의 우연 고장
- 사고 발생 모델
- 대기행렬 이론 (고객 도착 시간 간격)

**신뢰성 설계**:
- 병렬 시스템: R_sys = 1 - (1-R₁)(1-R₂)...
- 직렬 시스템: R_sys = R₁ × R₂ × ...
- 지수분포의 직렬: R_sys = e^(-λ₁t) × e^(-λ₂t) = e^(-(λ₁+λ₂)t)

**보전 전략**:
- CFR 구간: 사후보전(CM, Corrective Maintenance)
- 예방보전 효과 없음
- 고장 시 신속한 복구가 중요
- 예비품 확보 필요

---

### 신뢰성 함수 종합 정리

#### 주요 신뢰성 함수 관계도

```
고장밀도함수 f(t) ────미분───→ dF(t)/dt
        │                          │
        │                          │
    h(t)=f(t)/R(t)            적분 ↓
        │                          │
        ↓                          │
고장률함수 h(t) ←──────────── 고장분포함수 F(t)
        │                          │
    적분 │                     1-F(t)
        │                          │
        ↓                          ↓
   -ln R(t)  ←─────────────── 신뢰도함수 R(t)
```

#### 주요 분포의 신뢰성 함수

| 분포 | f(t) | R(t) | h(t) | MTTF |
|---|---|---|---|---|
| 지수 | λe^(-λt) | e^(-λt) | λ | 1/λ |
| 와이블 | (β/η)(t/η)^(β-1)e^(-(t/η)^β) | e^(-(t/η)^β) | (β/η)(t/η)^(β-1) | ηΓ(1+1/β) |
| 정규 | 복잡 | 1-Φ((t-μ)/σ) | f(t)/R(t) | μ |
| 레일리 | (t/α²)e^(-t²/2α²) | e^(-t²/2α²) | t/α² | α√(π/2) |

## 36회 품질경영 문제 6 예시답안
[문제 바로가기](#36회-품질경영-문제-6)

### 문제 분석

이 문제는 **이항분포(Binomial Distribution)**에 관한 문제입니다.

**주어진 조건**:
- 부적합품 비율: p = 0.15 (15%)
- 적합품 비율: q = 1 - p = 0.85 (85%)
- 표본 크기: n = 10개
- 확률변수 X: 10개 중 부적합품의 개수

**이항분포의 조건**:
1. 각 시행은 독립적
2. 각 시행의 성공확률(부적합품 비율)은 일정: p = 0.15
3. 시행 횟수가 고정: n = 10
4. 각 시행은 두 가지 결과만 가능 (부적합/적합)

따라서 X ~ B(n=10, p=0.15)

---

### 【문제 6 - (1)】 3개의 부적합품이 포함될 확률 (4점)

#### 1. 이항분포의 확률질량함수

**일반식**:
P(X = x) = C(n,x) × p^x × q^(n-x)
= C(n,x) × p^x × (1-p)^(n-x)

여기서:
- C(n,x) = nCx = n! / [x!(n-x)!]: 조합
- n: 시행 횟수
- x: 성공(부적합품) 횟수
- p: 성공 확률 (부적합품 비율)
- q: 실패 확률 (적합품 비율)

#### 2. 조합 계산

C(10,3) = 10! / (3! × 7!)

= (10 × 9 × 8) / (3 × 2 × 1)

= 720 / 6

= **120**

#### 3. 확률 계산

P(X = 3) = C(10,3) × (0.15)³ × (0.85)⁷

**각 항 계산**:

(0.15)³ = 0.15 × 0.15 × 0.15
= 0.0225 × 0.15
= 0.003375

(0.85)⁷ 계산:
- 0.85² = 0.7225
- 0.85³ = 0.614125
- 0.85⁴ = 0.52200625
- 0.85⁵ = 0.4437053125
- 0.85⁶ = 0.377149515625
- 0.85⁷ = 0.32057708828125
- 0.85⁷ ≈ 0.320577

**최종 계산**:

P(X = 3) = 120 × 0.003375 × 0.320577

= 120 × 0.001081946...

= 0.129833...

≈ **0.13** (소수점 셋째자리에서 반올림)

#### 답안: **P(X = 3) = 0.13**

---

### 【문제 6 - (2)】 부적합품 수의 기댓값 (3점)

#### 1. 이항분포의 기댓값 공식

**일반식**:
E(X) = n × p

여기서:
- n: 시행 횟수
- p: 성공 확률

#### 2. 기댓값 계산

E(X) = n × p
= 10 × 0.15
= **1.5**

#### 답안: **E(X) = 1.5**

#### 의미
- 제품 10개를 검사할 때 평균적으로 1.5개의 부적합품이 발견됩니다.
- 장기적으로 많은 시행을 반복하면 평균 부적합품 수는 1.5개에 수렴합니다.

---

### 【문제 6 - (3)】 부적합품 수의 분산 (3점)

#### 1. 이항분포의 분산 공식

**일반식**:
Var(X) = n × p × q
= n × p × (1-p)

여기서:
- n: 시행 횟수
- p: 성공 확률
- q: 실패 확률 = 1 - p

#### 2. 분산 계산

Var(X) = n × p × q
= 10 × 0.15 × 0.85
= 10 × 0.1275
= **1.275**

≈ **1.28** (소수점 셋째자리에서 반올림)

#### 답안: **Var(X) = 1.28**

#### 추가 정보

**표준편차**:
σ = √Var(X) = √1.275
≈ 1.129 ≈ 1.13

**의미**:
- 부적합품 수의 변동성을 나타냅니다.
- 평균 1.5개 주변으로 약 1.13개 정도 변동합니다.

---

### 이항분포 추가 학습사항

#### 1. 이항분포의 특성

**적용 조건**:
1. 베르누이 시행: 각 시행은 성공/실패 두 가지 결과만 존재
2. 독립성: 각 시행은 서로 독립
3. 일정한 확률: 각 시행의 성공 확률 p는 동일
4. 고정된 시행 횟수: n이 미리 정해짐

**표기법**:
X ~ B(n, p) 또는 X ~ Bin(n, p)

#### 2. 이항분포의 주요 공식

**확률질량함수**:
P(X = x) = C(n,x) × p^x × (1-p)^(n-x), x = 0, 1, 2, ..., n

**누적분포함수**:
F(x) = P(X ≤ x) = Σᵢ₌₀^x C(n,i) × p^i × (1-p)^(n-i)

**기댓값**:
E(X) = n × p

**분산**:
Var(X) = n × p × (1-p) = n × p × q

**표준편차**:
σ(X) = √[n × p × (1-p)]

**최빈값(Mode)**:
- (n+1)p가 정수가 아닌 경우: ⌊(n+1)p⌋
- (n+1)p가 정수인 경우: (n+1)p와 (n+1)p-1 모두

**왜도(Skewness)**:
γ₁ = (1-2p) / √(npq)
- p < 0.5: 오른쪽 꼬리 (양의 왜도)
- p = 0.5: 대칭
- p > 0.5: 왼쪽 꼬리 (음의 왜도)

#### 3. 이항분포 확률 계산 예시

본 문제의 전체 확률분포:

| x | P(X=x) | 누적확률 F(x) |
|---|---|---|
| 0 | C(10,0)×(0.15)⁰×(0.85)¹⁰ = 0.1969 | 0.1969 |
| 1 | C(10,1)×(0.15)¹×(0.85)⁹ = 0.3474 | 0.5443 |
| 2 | C(10,2)×(0.15)²×(0.85)⁸ = 0.2759 | 0.8202 |
| 3 | C(10,3)×(0.15)³×(0.85)⁷ = 0.1298 | 0.9500 |
| 4 | C(10,4)×(0.15)⁴×(0.85)⁶ = 0.0401 | 0.9901 |
| 5 | C(10,5)×(0.15)⁵×(0.85)⁵ = 0.0085 | 0.9986 |
| 6~10 | 매우 작음 | ≈1.0000 |

**확인**:
- Σ P(X=x) = 1.0000
- E(X) = Σ x·P(X=x) = 1.5
- Var(X) = Σ x²·P(X=x) - [E(X)]² = 1.275

#### 4. 이항분포의 정규근사

**조건**: n이 크고 p가 0.5에 가까울 때 (일반적으로 np ≥ 5, nq ≥ 5)

**근사 공식**:
X ~ B(n, p) ≈ N(μ = np, σ² = npq)

**연속성 수정(Continuity Correction)**:
- P(X = x) ≈ P(x - 0.5 < X < x + 0.5)
- P(X ≤ x) ≈ P(X < x + 0.5)
- P(X ≥ x) ≈ P(X > x - 0.5)

**본 문제의 경우**:
- np = 10 × 0.15 = 1.5 < 5
- nq = 10 × 0.85 = 8.5 ≥ 5
- 조건 미충족으로 정규근사 부적절

#### 5. 이항분포의 포아송 근사

**조건**: n이 크고 p가 작을 때 (일반적으로 n ≥ 20, p ≤ 0.05, np < 5)

**근사 공식**:
X ~ B(n, p) ≈ Poisson(λ = np)

P(X = x) ≈ (λ^x × e^(-λ)) / x!

**본 문제의 경우**:
- n = 10 < 20: 조건 미충족
- p = 0.15 > 0.05: 조건 미충족
- 포아송 근사 부적절

---

### 품질관리에서의 이항분포 응용

#### 1. 샘플링검사 (Sampling Inspection)

**OC곡선 (Operating Characteristic Curve)**:
- 로트 부적합률 p에 대한 합격확률 Pa(p)
- Pa(p) = P(X ≤ c) = Σᵢ₌₀^c C(n,i)×p^i×(1-p)^(n-i)
- n: 샘플 크기, c: 합격판정개수

**예**: n=50, c=2인 샘플링검사
- Pa(0.01) = 0.986 (AQL 통과)
- Pa(0.10) = 0.112 (LTPD 불합격)

#### 2. 계수형 관리도

**np관리도**:
- 중심선 CL = np̄
- UCL = np̄ + 3√(np̄q̄)
- LCL = np̄ - 3√(np̄q̄) (음수면 0)

**p관리도**:
- 중심선 CL = p̄
- UCL = p̄ + 3√[p̄(1-p̄)/n]
- LCL = p̄ - 3√[p̄(1-p̄)/n] (음수면 0)

#### 3. 공정능력 평가

**부적합률 추정**:
- 표본 부적합률: p̂ = X/n
- 신뢰구간: p̂ ± z_(α/2)√[p̂(1-p̂)/n]

**예**: 본 문제에서 3개 부적합 발견 시
- 추정 부적합률: p̂ = 3/10 = 0.30
- 실제 부적합률 p=0.15보다 높게 나타남 (표본 변동)

#### 4. 신뢰성 시험

**이항 신뢰성 시험**:
- n개 제품을 시험하여 x개 고장 관측
- 신뢰도 추정: R̂ = (n-x)/n
- 신뢰구간 설정

**가설검정**:
- H₀: p ≤ p₀ (부적합률이 기준 이하)
- H₁: p > p₀ (부적합률이 기준 초과)
- 검정통계량: X ~ B(n, p₀)

---

### 계산 팁 및 유의사항

#### 1. 조합 계산

**작은 수의 조합**:
C(n,x) = n! / [x!(n-x)!]

**계산 팁**:
- C(n,x) = C(n, n-x) 활용
- C(10,3) = C(10,7) = (10×9×8)/(3×2×1)
- 분자와 분모를 동시에 약분

#### 2. 거듭제곱 계산

**작은 수의 거듭제곱**:
- 0.85⁷을 직접 계산하기보다는
- 계산기 사용 또는 로그 활용

**로그 활용**:
- log(0.85⁷) = 7 × log(0.85)
- 0.85⁷ = 10^(7×log(0.85))

#### 3. 소수점 처리

**문제 요구사항**: 소수점 셋째자리에서 반올림하여 둘째자리까지

**주의사항**:
- 중간 계산은 충분한 유효숫자 유지
- 최종 답안만 반올림
- 0.129833... → 0.13 (올바름)
- 0.129 → 0.13 (중간에 반올림하면 오차 발생 가능)

#### 4. 계산 검증

**확률의 성질 확인**:
- 0 ≤ P(X=x) ≤ 1
- Σ P(X=x) = 1

**기댓값과 분산의 관계**:
- Var(X) = E(X²) - [E(X)]²
- E(X²) = Var(X) + [E(X)]²
- 본 문제: E(X²) = 1.275 + 1.5² = 3.525

---

### 답안 작성 팁

1. **분포 인식**: 문제가 이항분포임을 명시하고 X ~ B(10, 0.15) 표기

2. **공식 제시**: 각 소문제마다 사용할 공식을 먼저 명시

3. **단계별 계산**: 조합, 거듭제곱, 곱셈을 단계별로 명확히 표시

4. **중간 과정**: 부분점수를 위해 중간 계산 과정 상세히 기재

5. **검산**: 시간이 허락하면 계산 결과의 타당성 확인

6. **단위 및 의미**: 답에 대한 간단한 의미 해석 추가 시 가산점 가능

### 관련 개념 확장

#### 베르누이 분포 (Bernoulli Distribution)

**정의**: n=1인 이항분포
- X ~ Bernoulli(p)
- P(X=1) = p, P(X=0) = 1-p
- E(X) = p, Var(X) = p(1-p)

#### 기하분포 (Geometric Distribution)

**정의**: 첫 성공까지의 시행 횟수
- P(X=x) = (1-p)^(x-1) × p
- E(X) = 1/p, Var(X) = (1-p)/p²

#### 음이항분포 (Negative Binomial Distribution)

**정의**: r번째 성공까지의 시행 횟수
- r=1일 때 기하분포와 동일

#### 초기하분포 (Hypergeometric Distribution)

**정의**: 비복원추출에서의 성공 횟수
- 이항분포는 복원추출 또는 N>>n일 때 근사
- P(X=x) = C(K,x)×C(N-K,n-x) / C(N,n)

## 🎯 (1) 전이행렬 (Transition Matrix) (10점)

### 마코프 체인의 개념

```
마코프 체인: 미래 상태가 오직 현재 상태에만 의존하는 확률 과정
전이행렬: 한 상태에서 다른 상태로 전이할 확률을 행렬로 표현
```

### 전이행렬의 구조

전이행렬 P는 다음과 같은 형태를 가집니다:

```
P = [현재 상태에서 → 다음 상태로의 확률]
```

**행(row)**: 현재 상태
**열(column)**: 다음 상태

### 전이행렬 작성

```
상태 순서: 비, 흐림, 맑음
```

|   현재\다음   |   비   |  흐림  |  맑음  |
|--------------|--------|--------|--------|
| **비**       |  0.4   |  0.4   |  0.2   |
| **흐림**     |  0.3   |  0.4   |  0.3   |
| **맑음**     |  0.1   |  0.3   |  0.6   |

### 행렬 표기

```
     ⎡ 0.4  0.4  0.2 ⎤
P =  ⎢ 0.3  0.4  0.3 ⎥
     ⎣ 0.1  0.3  0.6 ⎦
```

또는

```
P = ( 0.4  0.4  0.2 )
    ( 0.3  0.4  0.3 )
    ( 0.1  0.3  0.6 )
```

### 검증

각 행의 합이 1이어야 합니다 (확률의 총합 = 1):

```
1행: 0.4 + 0.4 + 0.2 = 1.0 ✓
2행: 0.3 + 0.4 + 0.3 = 1.0 ✓
3행: 0.1 + 0.3 + 0.6 = 1.0 ✓
```

## ☔ (2) 2시간 후 비 올 확률 (10점)

### 문제 분석

- 현재: 맑음
- 2시간 후: 비?
- 2단계 전이 필요 → P² 사용

### Step 1: 2단계 전이행렬 계산

2시간 후의 확률은 **P² = P × P**

#### P² 계산 과정

**P × P 계산:**

```
     ⎡ 0.4  0.4  0.2 ⎤       ⎡ 0.4  0.4  0.2 ⎤
P² = ⎢ 0.3  0.4  0.3 ⎥   ×   ⎢ 0.3  0.4  0.3 ⎥
     ⎣ 0.1  0.3  0.6 ⎦       ⎣ 0.1  0.3  0.6 ⎦
```

**P²의 (1,1) 원소 (비→비):**
```
0.4×0.4 + 0.4×0.3 + 0.2×0.1 = 0.16 + 0.12 + 0.02 = 0.30
```

**P²의 (1,2) 원소 (비→흐림):**
```
0.4×0.4 + 0.4×0.4 + 0.2×0.3 = 0.16 + 0.16 + 0.06 = 0.38
```

**P²의 (1,3) 원소 (비→맑음):**
```
0.4×0.2 + 0.4×0.3 + 0.2×0.6 = 0.08 + 0.12 + 0.12 = 0.32
```

**P²의 (2,1) 원소 (흐림→비):**
```
0.3×0.4 + 0.4×0.3 + 0.3×0.1 = 0.12 + 0.12 + 0.03 = 0.27
```

**P²의 (2,2) 원소 (흐림→흐림):**
```
0.3×0.4 + 0.4×0.4 + 0.3×0.3 = 0.12 + 0.16 + 0.09 = 0.37
```

**P²의 (2,3) 원소 (흐림→맑음):**
```
0.3×0.2 + 0.4×0.3 + 0.3×0.6 = 0.06 + 0.12 + 0.18 = 0.36
```

**P²의 (3,1) 원소 (맑음→비):**
```
0.1×0.4 + 0.3×0.3 + 0.6×0.1 = 0.04 + 0.09 + 0.06 = 0.19
```

**P²의 (3,2) 원소 (맑음→흐림):**
```
0.1×0.4 + 0.3×0.4 + 0.6×0.3 = 0.04 + 0.12 + 0.18 = 0.34
```

**P²의 (3,3) 원소 (맑음→맑음):**
```
0.1×0.2 + 0.3×0.3 + 0.6×0.6 = 0.02 + 0.09 + 0.36 = 0.47
```

### 2단계 전이행렬

```
      ⎡ 0.30  0.38  0.32 ⎤
P² =  ⎢ 0.27  0.37  0.36 ⎥
      ⎣ 0.19  0.34  0.47 ⎦
```

### Step 2: 맑음 → 비 확률

현재 맑음(상태 3)에서 2시간 후 비(상태 1)가 올 확률은 P²의 (3,1) 원소:

```
P²(3,1) = 0.19
```

### 답

**2시간 후 비가 올 확률 = 0.19 (19%)**

### 해석

```
현재 맑음 → 2시간 후 비: 19%

경로 분석:
1. 맑음 → 비 → 비: 0.1 × 0.4 = 0.04
2. 맑음 → 흐림 → 비: 0.3 × 0.3 = 0.09
3. 맑음 → 맑음 → 비: 0.6 × 0.1 = 0.06
합계: 0.04 + 0.09 + 0.06 = 0.19 ✓
```

## 🌤️ (3) 정상상태 확률 (Steady-State Probability) (10점)

### 정상상태의 개념

```
정상상태(Steady State): 충분한 시간이 지난 후, 확률분포가 더 이상 변하지 않는 상태
몇 주가 지나면 → 정상상태에 도달
초기 상태와 무관하게 일정한 확률분포 유지
```

### 정상상태 조건

정상상태 확률 벡터 π = (π₁, π₂, π₃)는 다음을 만족:

```
πP = π  (정상상태 방정식)
π₁ + π₂ + π₃ = 1  (확률의 합 = 1)
```

여기서 π₁ = 비 올 확률, π₂ = 흐릴 확률, π₃ = 맑을 확률

### 방정식 전개

**πP = π를 성분별로 전개:**

```
(π₁, π₂, π₃) × ⎡ 0.4  0.4  0.2 ⎤ = (π₁, π₂, π₃)
                ⎢ 0.3  0.4  0.3 ⎥
                ⎣ 0.1  0.3  0.6 ⎦
```

**첫 번째 성분:**
```
0.4π₁ + 0.3π₂ + 0.1π₃ = π₁
```

정리하면:
```
-0.6π₁ + 0.3π₂ + 0.1π₃ = 0  ... ①
```

**두 번째 성분:**
```
0.4π₁ + 0.4π₂ + 0.3π₃ = π₂
```

정리하면:
```
0.4π₁ - 0.6π₂ + 0.3π₃ = 0  ... ②
```

**세 번째 성분:**
```
0.2π₁ + 0.3π₂ + 0.6π₃ = π₃
```

정리하면:
```
0.2π₁ + 0.3π₂ - 0.4π₃ = 0  ... ③
```

**확률 조건:**
```
π₁ + π₂ + π₃ = 1  ... ④
```

### 연립방정식 풀이

방정식 ①, ②, ④를 사용 (③는 종속 방정식):

**방정식 ①에서:**
```
-0.6π₁ + 0.3π₂ + 0.1π₃ = 0
양변에 10을 곱하면:
-6π₁ + 3π₂ + π₃ = 0
π₃ = 6π₁ - 3π₂  ... ⑤
```

**방정식 ②에서:**
```
0.4π₁ - 0.6π₂ + 0.3π₃ = 0
양변에 10을 곱하면:
4π₁ - 6π₂ + 3π₃ = 0  ... ⑥
```

**⑤를 ⑥에 대입:**
```
4π₁ - 6π₂ + 3(6π₁ - 3π₂) = 0
4π₁ - 6π₂ + 18π₁ - 9π₂ = 0
22π₁ - 15π₂ = 0
π₂ = (22/15)π₁  ... ⑦
```

**⑦을 ⑤에 대입:**
```
π₃ = 6π₁ - 3(22/15)π₁
π₃ = 6π₁ - (66/15)π₁
π₃ = (90/15)π₁ - (66/15)π₁
π₃ = (24/15)π₁
π₃ = (8/5)π₁  ... ⑧
```

**⑦, ⑧을 ④에 대입:**
```
π₁ + (22/15)π₁ + (8/5)π₁ = 1
π₁ + (22/15)π₁ + (24/15)π₁ = 1
π₁(1 + 22/15 + 24/15) = 1
π₁(15/15 + 22/15 + 24/15) = 1
π₁(61/15) = 1
π₁ = 15/61
```

**π₂ 계산:**
```
π₂ = (22/15) × (15/61) = 22/61
```

**π₃ 계산:**
```
π₃ = (8/5) × (15/61) = (8×15)/(5×61) = 120/305 = 24/61
```

### 검증

```
π₁ + π₂ + π₃ = 15/61 + 22/61 + 24/61 = 61/61 = 1 ✓
```

### 최종 답

**정상상태 확률:**

**분수 표기:**
```
비가 올 확률 = 15/61
```

**소수 표기:**
```
15 ÷ 61 = 0.245901...
소수점 다섯째자리에서 반올림 → 0.2459
```

### 답

```
몇 주 후 아침에 비가 올 확률 = 15/61 또는 0.2459
```

## 🔷 (1) 북서코너법 (Northwest Corner Method) (15점)

### 북서코너법의 원리

```
1. 표의 왼쪽 위(북서쪽) 모서리부터 시작
2. 현재 셀에 가능한 최대량 할당
3. 공급 또는 수요가 소진되면 다음 셀로 이동
4. 모든 공급과 수요가 충족될 때까지 반복
→ 비용은 고려하지 않음 (단순 기계적 방법)
```

### Step 1: 초기 테이블

|   | 가 | 나 | 다 | 공급 |
|---|----|----|-------|------|
| A | 500 | 1,200 | 1,200 | 1,200 |
| B | 1,000 | 250 | 800 | 750 |
| C | 1,200 | 1,000 | 250 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** |

### Step 2: 북서코너법 적용 과정

#### 반복 1: A-가 셀

- 현재 위치: (A, 가)
- A 공급: 1,200개
- 가 수요: 1,500개
- 할당량: min(1,200, 1,500) = **1,200개**

**A-가에 1,200개 할당**

**갱신:**
- A 공급 소진: 1,200 - 1,200 = 0 (A행 제거)
- 가 수요 갱신: 1,500 - 1,200 = 300

#### 반복 2: B-가 셀

- 현재 위치: (B, 가) - A가 소진되어 B로 이동
- B 공급: 750개
- 가 수요: 300개
- 할당량: min(750, 300) = **300개**

**B-가에 300개 할당**

**갱신:**
- B 공급 갱신: 750 - 300 = 450
- 가 수요 소진: 300 - 300 = 0 (가 열 제거)

#### 반복 3: B-나 셀

- 현재 위치: (B, 나) - 가가 소진되어 나로 이동
- B 공급: 450개
- 나 수요: 690개
- 할당량: min(450, 690) = **450개**

**B-나에 450개 할당**

**갱신:**
- B 공급 소진: 450 - 450 = 0 (B행 제거)
- 나 수요 갱신: 690 - 450 = 240

#### 반복 4: C-나 셀

- 현재 위치: (C, 나) - B가 소진되어 C로 이동
- C 공급: 540개
- 나 수요: 240개
- 할당량: min(540, 240) = **240개**

**C-나에 240개 할당**

**갱신:**
- C 공급 갱신: 540 - 240 = 300
- 나 수요 소진: 240 - 240 = 0 (나 열 제거)

#### 반복 5: C-다 셀 (최종)

- 현재 위치: (C, 다) - 유일하게 남은 셀
- C 공급: 300개
- 다 수요: 300개
- 할당량: min(300, 300) = **300개**

**C-다에 300개 할당**

**갱신:**
- C 공급 소진: 300 - 300 = 0
- 다 수요 소진: 300 - 300 = 0

### Step 3: 북서코너법 할당표

|   | 가 | 나 | 다 | 공급 | 소진 |
|---|----|----|-------|------|------|
| A | **1,200**<br>@500 | - | - | 1,200 | 1,200 |
| B | **300**<br>@1,000 | **450**<br>@250 | - | 750 | 750 |
| C | - | **240**<br>@1,000 | **300**<br>@250 | 540 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** | |
| **충족** | 1,500 | 690 | 300 | | **2,490** |

**범례:**
- 굵은 숫자: 할당량(개)
- @숫자: 단위 수송비용(원/개)

### Step 4: 총 수송비용 계산

**할당 경로별 비용:**

| 경로 | 할당량(개) | 단위비용(원/개) | 소계(원) |

```
총 수송비용 = 600,000 + 300,000 + 112,500 + 240,000 + 75,000
           = 1,327,500원
```

```

**수요 제약 확인:**

**기본 가능해 조건:**

## 💰 (2) 최소비용법 (Least Cost Method) (15점)

### 최소비용법의 원리

```
1. 전체 비용표에서 최소 비용 셀을 찾음
2. 해당 셀에 가능한 최대량 할당
3. 공급 또는 수요가 소진되면 해당 행/열 제거
4. 남은 셀 중 최소 비용 셀을 찾아 반복
→ 비용을 고려하여 더 효율적인 초기해 도출
```

### Step 1: 초기 비용표 (재확인)

|   | 가 | 나 | 다 | 공급 |
|---|----|----|-------|------|
| A | **500** | 1,200 | 1,200 | 1,200 |
| B | 1,000 | **250**← | 800 | 750 |
| C | 1,200 | 1,000 | **250**← | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** |

```
최소 비용: B-나 (250원), C-다 (250원) - 동일
```

### Step 2: 최소비용법 적용 과정

#### 반복 1: B-나 또는 C-다

**두 셀 모두 250원으로 동일. B-나를 먼저 선택 (관례적으로 상단/좌측 우선)**

- 셀: B-나 (비용 250원)
- B 공급: 750개
- 나 수요: 690개
- 할당량: min(750, 690) = **690개**

**B-나에 690개 할당**

**갱신:**
- B 공급 갱신: 750 - 690 = 60
- 나 수요 소진: 690 - 690 = 0 (나 열 제거)

**남은 비용표:**

|   | 가 | 다 | 공급 |
|---|----|----|------|
| A | 500 | 1,200 | 1,200 |
| B | 1,000 | 800 | 60 |
| C | 1,200 | **250** ← | 540 |
| **수요** | **1,500** | **300** | |

#### 반복 2: C-다

- 셀: C-다 (비용 250원 - 최소)
- C 공급: 540개
- 다 수요: 300개
- 할당량: min(540, 300) = **300개**

**C-다에 300개 할당**

**갱신:**
- C 공급 갱신: 540 - 300 = 240
- 다 수요 소진: 300 - 300 = 0 (다 열 제거)

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| A | **500** ← | 1,200 |
| B | 1,000 | 60 |
| C | 1,200 | 240 |
| **수요** | **1,500** | |

#### 반복 3: A-가

- 셀: A-가 (비용 500원 - 최소)
- A 공급: 1,200개
- 가 수요: 1,500개
- 할당량: min(1,200, 1,500) = **1,200개**

**A-가에 1,200개 할당**

**갱신:**
- A 공급 소진: 1,200 - 1,200 = 0 (A행 제거)
- 가 수요 갱신: 1,500 - 1,200 = 300

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| B | **1,000** ← | 60 |
| C | 1,200 | 240 |
| **수요** | **300** | |

#### 반복 4: B-가

- 셀: B-가 (비용 1,000원 < 1,200원)
- B 공급: 60개
- 가 수요: 300개
- 할당량: min(60, 300) = **60개**

**B-가에 60개 할당**

**갱신:**
- B 공급 소진: 60 - 60 = 0 (B행 제거)
- 가 수요 갱신: 300 - 60 = 240

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| C | 1,200 | 240 |
| **수요** | **240** | |

#### 반복 5: C-가 (최종)

- 셀: C-가 (유일한 셀)
- C 공급: 240개
- 가 수요: 240개
- 할당량: min(240, 240) = **240개**

**C-가에 240개 할당**

**갱신:**
- C 공급 소진: 240 - 240 = 0
- 가 수요 소진: 240 - 240 = 0

**완료!**

### Step 3: 최소비용법 할당표

|   | 가 | 나 | 다 | 공급 | 소진 |
|---|----|----|-------|------|------|
| A | **1,200**<br>@500 | - | - | 1,200 | 1,200 |
| B | **60**<br>@1,000 | **690**<br>@250 | - | 750 | 750 |
| C | **240**<br>@1,200 | - | **300**<br>@250 | 540 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** | |
| **충족** | 1,500 | 690 | 300 | | **2,490** |

### Step 4: 총 수송비용 계산

**할당 경로별 비용:**

| 경로 | 할당량(개) | 단위비용(원/개) | 소계(원) |
|------|-----------|----------------|----------|
| A → 가 | 1,200 | 500 | 600,000 |
| B → 가 | 60 | 1,000 | 60,000 |
| B → 나 | 690 | 250 | 172,500 |
| C → 가 | 240 | 1,200 | 288,000 |
| C → 다 | 300 | 250 | 75,000 |

**총 비용 계산:**
```
총 수송비용 = 600,000 + 60,000 + 172,500 + 288,000 + 75,000
           = 1,195,500원
```

### 최소비용법 답

```
초기해의 총 수송비용 = 1,195,500원
```

### 검증

**공급 제약 확인:**
- A: 1,200 = 1,200 ✓
- B: 60 + 690 = 750 ✓
- C: 240 + 300 = 540 ✓

**수요 제약 확인:**
- 가: 1,200 + 60 + 240 = 1,500 ✓

- 다: 300 = 300 ✓

**기본 가능해 조건:**
- 필요한 할당 셀 수 = 3 + 3 - 1 = 5 ✓
- 실제 할당 셀 수 = 5개 (A-가, B-가, B-나, C-가, C-다) ✓

# 제36회 경영지도사 경영과학 - 문제 3 답안

## 대기행렬이론 (Queuing Theory)

---

## 📋 문제 상황

### 주어진 정보

**시스템 특성:**
- 서비스 제공자: 1명 (단일 서버)
- 고객 도착률: 시간당 평균 8명
- 서비스 시간: 6분/명

**추가 가정 (M/M/1 대기행렬):**
- 도착 과정: 포아송 분포
- 서비스 시간: 지수 분포
- 서버 수: 1개
- 대기공간: 무한
- 대기규율: FIFO (선입선출)

---

## 🎯 기본 파라미터 계산

### 도착률 (λ)과 서비스율 (μ)

**도착률 (λ):**
```
λ = 시간당 평균 8명
  = 8명/시간
  = 8/60 명/분
  = 2/15 명/분
```

**서비스율 (μ):**
```
서비스 시간 = 6분/명
서비스율 μ = 1/서비스시간
           = 1/6 시간당 명
           = 60/6 명/시간
           = 10명/시간
```

### 이용률 (ρ) 계산

```
ρ = λ/μ
  = 8/10
  = 0.8 (80%)
```

**검증:**
```
ρ < 1 이어야 안정적인 시스템
0.8 < 1 ✓ (시스템 안정)
```

### 해석

```
서버 이용률 = 80%
→ 서버가 80% 시간 동안 바쁨
→ 20% 시간 동안 대기자 없음 (유휴)
```

---

## 📊 (1) 대기 없이 바로 서비스받을 확률 (4점)

### M/M/1 대기행렬 공식

**시스템에 고객이 없을 확률 (P₀):**

```
P₀ = 1 - ρ
   = 1 - λ/μ
```

이것이 곧 대기 없이 바로 서비스받을 확률입니다.

### 계산

```
P₀ = 1 - ρ
   = 1 - 0.8
   = 0.2
```

### 답

```
대기 없이 바로 발급 신청할 확률 = 0.2 (20%)
```

### 해석

```
고객이 도착했을 때:
- 20% 확률로 즉시 서비스 가능
- 80% 확률로 대기 필요

→ 5명 중 1명은 대기 없이 바로 서비스
→ 5명 중 4명은 대기 필요
```

---

## 👥 (2) 평균 대기 인원 (3점)

### M/M/1 대기행렬 공식

**대기열에서 기다리는 평균 고객 수 (Lq):**

```
Lq = ρ²/(1-ρ)
   = (λ/μ)² / (1-λ/μ)
   = λ² / (μ(μ-λ))
```

### 계산

**방법 1: ρ 사용**
```
Lq = ρ²/(1-ρ)
   = (0.8)²/(1-0.8)
   = 0.64/0.2
   = 3.2명
```

**방법 2: λ, μ 직접 사용**
```
Lq = λ²/(μ(μ-λ))
   = 8²/(10(10-8))
   = 64/(10×2)
   = 64/20
   = 3.2명
```

### 소수점 반올림

```
3.2명
→ 소수점 둘째자리에서 반올림
→ 3.2명 (소수점 첫째자리)
```

### 답

```
평균 대기 인원 = 3.2명
```

### 해석

```
언제든지 시험장을 방문하면:
- 평균 3.2명이 번호표 들고 대기 중
- 서비스받는 1명 + 대기 3.2명 = 총 4.2명

→ 평균적으로 자기 앞에 3.2명 대기
```

### 참고: 시스템 내 평균 고객 수 (L)

```
L = Lq + ρ
  = 3.2 + 0.8
  = 4.0명

또는

L = ρ/(1-ρ)
  = 0.8/(1-0.8)
  = 0.8/0.2
  = 4.0명
```

---

## ⏰ (3) 평균 대기 시간 (3점)

### M/M/1 대기행렬 공식

**대기열에서 기다리는 평균 시간 (Wq):**

```
Wq = Lq/λ
   = ρ/(μ(1-ρ))
   = λ/(μ(μ-λ))
```

### 계산

**방법 1: Lq/λ 사용**
```
Wq = Lq/λ
   = 3.2/8
   = 0.4 시간
   = 0.4 × 60 분
   = 24분
```

**방법 2: ρ, μ 사용**
```
Wq = ρ/(μ(1-ρ))
   = 0.8/(10×(1-0.8))
   = 0.8/(10×0.2)
   = 0.8/2
   = 0.4 시간
   = 24분
```

**방법 3: λ, μ 직접 사용**
```
Wq = λ/(μ(μ-λ))
   = 8/(10×(10-8))
   = 8/(10×2)
   = 8/20
   = 0.4 시간
   = 24분
```

### 소수점 반올림

```
24.0분

## ⏰ (2) 활동별 여유시간 (5점)

### 임계경로법(CPM) 계산

#### Step 1: 최조시간 (EST) 계산 (Forward Pass)

**규칙: EST = max(선행활동의 EFT)**

| 활동 | 선행활동 | 소요시간 | EST | EFT |
|------|----------|----------|-----|-----|
| A | - | 15 | 0 | 15 |
| B | A | 10 | 15 | 25 |
| C | B | 30 | 25 | 55 |
| D | A | 13 | 15 | 28 |
| E | D | 20 | 28 | 48 |
| F | C | 13 | 55 | 68 |
| G | E | 22 | 48 | 70 |
| H | F, G | 18 | max(68,70)=70 | 88 |
| I | H | 20 | 88 | 108 |

**계산 과정:**
```
A: EST=0, EFT=0+15=15
B: EST=15 (A완료), EFT=15+10=25
C: EST=25 (B완료), EFT=25+30=55
D: EST=15 (A완료), EFT=15+13=28
E: EST=28 (D완료), EFT=28+20=48
F: EST=55 (C완료), EFT=55+13=68
G: EST=48 (E완료), EFT=48+22=70
H: EST=max(68,70)=70 (F,G 모두 완료), EFT=70+18=88
I: EST=88 (H완료), EFT=88+20=108
```

#### Step 2: 최지시간 (LST) 계산 (Backward Pass)

**규칙: LFT = min(후행활동의 LST), 프로젝트 완료 시간에서 역산**

| 활동 | 소요시간 | LFT | LST |
|------|----------|-----|-----|
| I | 20 | 108 | 88 |
| H | 18 | 88 | 70 |
| G | 22 | 70 | 48 |
| F | 13 | 70 | 57 |
| E | 20 | 48 | 28 |
| D | 13 | 28 | 15 |
| C | 30 | 57 | 27 |
| B | 10 | 27 | 17 |
| A | 15 | min(15,15)=15 | 0 |

**계산 과정:**
```
I: LFT=108 (프로젝트 완료), LST=108-20=88
H: LFT=88 (I의 LST), LST=88-18=70
G: LFT=70 (H의 LST), LST=70-22=48
F: LFT=70 (H의 LST), LST=70-13=57
E: LFT=48 (G의 LST), LST=48-20=28
D: LFT=28 (E의 LST), LST=28-13=15
C: LFT=57 (F의 LST), LST=57-30=27
B: LFT=27 (C의 LST), LST=27-10=17
A: LFT=min(15,15)=15 (B,D의 LST), LST=15-15=0
```

#### Step 3: 여유시간 (Slack Time) 계산

**여유시간 (Total Slack, TS) = LST - EST = LFT - EFT**

| 활동 | EST | LST | EFT | LFT | 여유시간 | 임계 여부 |
|------|-----|-----|-----|-----|----------|----------|

| C | 25 | 27 | 55 | 57 | **2** | |
| D | 15 | 15 | 28 | 28 | **0** | ✓ 임계 |
| E | 28 | 28 | 48 | 48 | **0** | ✓ 임계 |
| F | 55 | 57 | 68 | 70 | **2** | |
| G | 48 | 48 | 70 | 70 | **0** | ✓ 임계 |
| H | 70 | 70 | 88 | 88 | **0** | ✓ 임계 |
| I | 88 | 88 | 108 | 108 | **0** | ✓ 임계 |

**계산 예시:**
```
A: 0 - 0 = 0일
B: 17 - 15 = 2일
C: 27 - 25 = 2일
D: 15 - 15 = 0일
E: 28 - 28 = 0일
F: 57 - 55 = 2일

## 🎯 (1) 손익분기점 판매수량 (5점)

### 손익분기점의 개념

```
손익분기점(Break-Even Point, BEP):
- 총수익 = 총비용이 되는 지점
- 이익도 손실도 없는 지점
- 최소한 달성해야 할 판매량
```

### 손익분기점 공식

**기본 관계식:**
```
총수익(TR) = 판매가격 × 판매수량
          = P × Q

총비용(TC) = 고정비용 + 변동비용
          = FC + VC × Q

손익분기점: TR = TC
```

**BEP 판매수량 공식:**
```
P × Q = FC + VC × Q
P × Q - VC × Q = FC
Q(P - VC) = FC

Q_BEP = FC / (P - VC)
```

여기서 **(P - VC) = 단위당 공헌이익**

### 계산

**주어진 값:**
```
FC = 10,000,000원
P = 25,000원/개
VC = 5,000원/개
```

**단위당 공헌이익:**
```
P - VC = 25,000 - 5,000 = 20,000원/개
```

**손익분기점 수량:**
```
Q_BEP = FC / (P - VC)
      = 10,000,000 / 20,000
      = 500개
```

### 답

```
손익분기점 판매수량 = 500개
```

### 검증

**총수익:**
```
TR = 25,000 × 500 = 12,500,000원
```

**총비용:**
```
TC = 10,000,000 + 5,000 × 500
   = 10,000,000 + 2,500,000
   = 12,500,000원
```

**이익:**
```
π = TR - TC = 12,500,000 - 12,500,000 = 0원 ✓
```

### 해석

```
의미:
- 넥타이 500개 판매 시 손익 0
- 500개 미만 판매 시 손실
- 500개 초과 판매 시 이익

관리:
- 최소 목표: 500개 이상 판매
- 안전마진: 실제 판매량 - 500개
```

## 💰 (2) 변경 시나리오의 최소 판매가격 (5점)

### 변경 사항

**조건 변화:**

1. **고정비용 증가:**
   ```
   기존: 10,000,000원
   증가: +5,000,000원
   새 FC: 15,000,000원
   ```

2. **변동비용 25% 증가:**
   ```
   기존: 5,000원/개
   증가: 5,000 × 1.25 = 6,250원/개
   새 VC: 6,250원/개
   ```

3. **판매수량 확정:**
   ```
   Q = 600개 (마케팅으로 확보)
   ```

4. **목표:**
   ```
   적어도 손해를 보지 않음 (π ≥ 0)
   → 최소 판매가격 P 구하기
   ```

### 공식 유도

**손익 공식:**
```
이익(π) = 총수익 - 총비용
        = P × Q - (FC + VC × Q)
```

**손해를 보지 않는 조건:**
```
π ≥ 0
P × Q - (FC + VC × Q) ≥ 0
P × Q ≥ FC + VC × Q
P ≥ (FC + VC × Q) / Q
P ≥ FC/Q + VC
```

**최소 판매가격:**
```
P_min = FC/Q + VC
      = (고정비용/판매수량) + 단위당 변동비용
```

### 계산

**주어진 값:**
```
FC = 15,000,000원
VC = 6,250원/개
Q = 600개
```

**최소 판매가격 계산:**
```
P_min = FC/Q + VC
      = 15,000,000/600 + 6,250
      = 25,000 + 6,250
      = 31,250원/개
```

### 답

```
최소 판매가격 = 31,250원/개
```

### 검증

**31,250원으로 판매 시:**

```
총수익: TR = 31,250 × 600 = 18,750,000원
총비용: TC = 15,000,000 + 6,250 × 600
          = 15,000,000 + 3,750,000
          = 18,750,000원
이익: π = 18,750,000 - 18,750,000 = 0원 ✓
```

**31,250원 미만으로 판매 시 (예: 31,000원):**

```

총비용: TC = 18,750,000원
이익: π = 18,600,000 - 18,750,000 = -150,000원 (손실) ✗
```

**31,250원 초과로 판매 시 (예: 32,000원):**

```
총수익: TR = 32,000 × 600 = 19,200,000원
총비용: TC = 18,750,000원
이익: π = 19,200,000 - 18,750,000 = +450,000원 (이익) ✓
```

### 해석

```
가격 결정:

- 기존 25,000원 대비 6,250원(25%) 인상 필요

- 고정비용 증가 결정 재검토 필요

    │/  ╱ FC (고정비용 증가)
1,000│ ╱
    │╱________________________________________
    0   200   400   600   800   1000  판매량(개)

BEP = 600개
```

---

## 📝 최종 답안 정리

### (1) 손익분기점 판매수량

**공식:**
```
Q_BEP = FC / (P - VC)
```

**계산:**
```
FC = 10,000,000원
P = 25,000원/개
VC = 5,000원/개

Q_BEP = 10,000,000 / (25,000 - 5,000)
      = 10,000,000 / 20,000
      = 500개
```

**답: 500개**

---

### (2) 최소 판매가격

**공식:**
```
P_min = FC/Q + VC
```

**계산:**
```
FC = 15,000,000원 (500만원 증가)
VC = 6,250원/개 (25% 증가)
Q = 600개

P_min = 15,000,000/600 + 6,250
      = 25,000 + 6,250
      = 31,250원/개
```

**검증:**
```
총수익: 31,250 × 600 = 18,750,000원
총비용: 15,000,000 + 6,250 × 600 = 18,750,000원
이익: 0원 ✓
```

**답: 31,250원/개**

✓ 단위 표기: "개", "원", "원/개" 구분
✓ 계산 과정: 단계별 상세히
✓ 검증: TR = TC 확인
✓ 해석: 경영학적 의미 간략히
✓ 조건 변화: 각 변수의 변화 정확히 파악
```

## 📚 참고: 손익분기점 관련 개념

**공헌이익 (Contribution Margin):**
```
단위당 공헌이익 = P - VC
총공헌이익 = (P - VC) × Q
```

**공헌이익률 (CM Ratio):**
```
CM Ratio = (P - VC) / P × 100%
```

**안전한계 (Margin of Safety):**
```
MOS = 실제 판매량 - BEP 판매량
MOS% = MOS / 실제 판매량 × 100%
```

**목표이익 달성 판매량:**
```
Q_target = (FC + 목표이익) / (P - VC)
```

# 제36회 경영지도사 경영과학 - 문제 6 답안

## 선형계획법의 전제조건 (Linear Programming Assumptions)

---

## 📋 문제 요구사항

선형계획(Linear Programming) 모형 사용의 전제조건이 되는 가정 중 **4가지를 설명**하시오.

---

## 🎯 선형계획법의 4가지 주요 가정

### 1. 선형성 (Linearity)

#### 개념

```
모든 관계식(목적함수 및 제약조건)이 선형(1차식)이어야 함
→ 변수들의 합 또는 차로만 표현
→ 변수의 곱, 제곱, 루트 등 비선형 항 불가
```

#### 상세 설명

**목적함수의 선형성:**
```
허용: z = 3x₁ + 5x₂ + 2x₃
불가: z = x₁² + 5x₂  (제곱항)
불가: z = 3x₁x₂ + 2x₃  (곱셈항)
불가: z = √x₁ + 5x₂  (루트항)
```

**제약조건의 선형성:**
```
허용: 2x₁ + 3x₂ ≤ 100
불가: x₁² + x₂ ≤ 100  (제곱항)
불가: x₁ / x₂ ≤ 5  (나눗셈)
```

#### 경제적 의미

**규모에 대한 수익 불변 (Constant Returns to Scale):**
```
생산량이 2배가 되면 비용/수익도 정확히 2배
→ 규모의 경제나 불경제 없음
```

**예시:**
```
제품 1개 생산 비용: 1,000원
제품 10개 생산 비용: 10,000원 (정확히 10배)
제품 100개 생산 비용: 100,000원 (정확히 100배)

실제: 대량 생산 시 단가 하락 가능 (비선형)
→ LP로 표현 불가
```

#### 위배 시 대안

```
- 비선형계획법 (Nonlinear Programming)
- 정수계획법 (Integer Programming)
- 동적계획법 (Dynamic Programming)
```

---

### 2. 비례성 (Proportionality)

#### 개념

```
각 의사결정 변수의 기여도가 그 변수의 값에 정비례
→ 변수가 2배 증가하면 기여도도 정확히 2배
→ 단위당 기여도 일정 (한계 효용/비용 불변)
```

#### 상세 설명

**목적함수의 비례성:**
```
x₁ = 10일 때 기여도 = 3 × 10 = 30
x₁ = 20일 때 기여도 = 3 × 20 = 60 (정확히 2배)

단위당 기여도(계수) = 3 (일정)
```

**제약조건의 비례성:**
```
자원 소비도 비례적
x₁ = 5일 때 자원 소비 = 2 × 5 = 10
x₁ = 10일 때 자원 소비 = 2 × 10 = 20 (정확히 2배)
```

#### 경제적 의미

**한계 기여도 불변:**
```
첫 번째 제품: 이익 5,000원
두 번째 제품: 이익 5,000원
백 번째 제품: 이익 5,000원

→ 생산량과 무관하게 단위당 이익 동일
```

**실제 위배 사례:**
```
1. 학습 효과: 생산량 증가 → 숙련도 향상 → 단위 비용 감소
2. 피로 효과: 작업량 증가 → 효율 저하 → 단위 시간 증가
3. 가격 할인: 대량 구매 → 단가 하락
4. 체감 효용: 소비량 증가 → 만족도 증가율 감소
```

#### 비례성 vs 선형성

```
선형성: 변수들 간의 관계 (합, 차만 허용)
비례성: 각 변수 내부의 관계 (단위당 기여도 일정)

→ 선형성은 비례성을 포함하는 더 넓은 개념
```

---

### 3. 가법성 (Additivity)

#### 개념

```
여러 활동의 총 기여도 = 각 활동 기여도의 합
→ 활동 간 상호작용 없음
→ 한 변수가 다른 변수에 영향 주지 않음
```

#### 상세 설명

**목적함수의 가법성:**
```
z = 3x₁ + 5x₂

x₁의 기여도: 3x₁
x₂의 기여도: 5x₂
총 기여도: 3x₁ + 5x₂ (단순 합)

→ x₁과 x₂가 서로 독립적
→ x₁이 증가해도 x₂의 단위 기여도(5) 불변
```

**제약조건의 가법성:**
```
2x₁ + 3x₂ ≤ 100

x₁의 자원 소비: 2x₁
x₂의 자원 소비: 3x₂
총 자원 소비: 2x₁ + 3x₂ (단순 합)
```

#### 경제적 의미

**활동 간 독립성:**
```
제품 A 생산 → 제품 B 생산에 영향 없음
제품 B 생산 → 제품 A 생산에 영향 없음

→ 시너지 효과 없음
→ 간섭 효과 없음
```

**실제 위배 사례:**

**1. 시너지 효과 (Synergy):**
```
예: 제품 A와 B를 함께 생산 시 비용 절감
→ TC(A+B) < TC(A) + TC(B)
→ 가법성 위배
```

**2. 대체 효과 (Substitution):**
```
예: 제품 A 판매 증가 → 제품 B 수요 감소
→ 수익 = f(A, B) (교차 효과 있음)
→ 가법성 위배
```

**3. 보완 효과 (Complementarity):**
```
예: 프린터 판매 증가 → 잉크 수요 증가
→ 독립적이지 않음
→ 가법성 위배
```

**4. 공유 자원:**
```
예: A와 B가 같은 설비 사용 시 간섭
→ 동시 생산 시 효율 저하
→ 가법성 위배
```

#### 위배 시 대안

```
- 비선형계획법 (교차항 포함)
- 목표계획법 (다중 목표)
```

---

### 4. 확실성 (Certainty) 또는 결정성 (Deterministic)

#### 개념

```
모든 파라미터(계수, 제약 값 등)가 확실하게 알려져 있음
→ 불확실성 없음
→ 확률적 변동 없음
→ 미래를 정확히 예측 가능
```

#### 상세 설명

**확실한 파라미터:**

**1. 목적함수 계수:**
```
z = 3x₁ + 5x₂
→ 3과 5가 확실히 알려진 값
→ 변동하지 않음
```

**2. 제약조건 계수:**
```
2x₁ + 3x₂ ≤ 100
→ 2, 3, 100이 확실한 값
```

**3. 기술 계수:**
```
자원 소비율, 생산 계수 등이 고정
```

#### 경제적 의미

**결정론적 환경:**
```
- 수요: 정확히 알려짐
- 가격: 변동 없음
- 비용: 확정적
- 자원: 확실한 양
```

**실제 위배 사례:**

**1. 수요 불확실성:**
```
실제: 수요 = 평균 1,000개 ± 200개 (확률 분포)
LP: 수요 = 정확히 1,000개로 가정
```

**2. 가격 변동:**
```
실제: 가격 = 시장 상황에 따라 변동
LP: 가격 = 고정 값으로 가정
```

**3. 자원 가용성:**
```
실제: 설비 고장, 원료 부족 등 발생 가능
LP: 자원이 항상 확실히 공급됨
```

**4. 경쟁 반응:**
```
실제: 경쟁사 반응에 따라 시장 변화
LP: 외부 환경 불변
```

#### 대응 방안

**1. 민감도 분석 (Sensitivity Analysis):**
```
파라미터 변화 시 최적해의 변화 분석
→ "what-if" 분석
```

**2. 시나리오 분석:**
```
낙관/기준/비관 시나리오별 LP 수립
```

**3. 확률 계획법:**
```
- 확률제약계획 (Chance-Constrained Programming)
- 2단계 확률계획 (Two-Stage Stochastic Programming)
```

**4. 재계획:**
```
정기적으로 파라미터 갱신 후 재최적화
→ 동적 환경 대응
```

#### 개념

#### 개념

```

```

#### 예외

```
일부 문제는 음수 허용 (예: 재무 모델)
→ 필요 시 제약 조건 조정
```

## 📝 최종 답안 정리

### 선형계획모형의 4가지 가정

#### 1. 선형성 (Linearity)

```
- 개념: 목적함수와 제약조건이 모두 1차 선형식
- 의미: 변수의 제곱, 곱셈 등 비선형 항 불가
- 예: z = 3x₁ + 5x₂ (허용), z = x₁² (불가)
- 경제적 의미: 규모에 대한 수익 불변
```

#### 2. 비례성 (Proportionality)

```
- 개념: 각 변수의 기여도가 변수 값에 정비례
- 의미: 단위당 기여도 일정 (한계 효용/비용 불변)
- 예: 제품 1개당 이익 5,000원이면, 10개는 정확히 50,000원
- 경제적 의미: 학습효과, 피로효과 등 없음
```

#### 3. 가법성 (Additivity)

```
- 개념: 총 효과 = 각 활동 효과의 단순 합
- 의미: 활동 간 상호작용 없음 (독립적)
- 예: z = 3x₁ + 5x₂ (x₁과 x₂가 서로 영향 없음)
- 경제적 의미: 시너지 효과, 대체 효과 없음
```

#### 4. 확실성 (Certainty)

```
- 개념: 모든 파라미터가 확실하게 알려져 있음
- 의미: 불확실성, 확률적 변동 없음
- 예: 수요, 가격, 비용이 정확히 예측 가능
- 경제적 의미: 미래를 완벽히 예측 가능한 결정론적 환경
- 대응: 민감도 분석, 시나리오 분석으로 보완
```

✓ 경제적 해석: 실무적 의미 언급
✓ 위배 사례: 현실과의 괴리 설명 (선택적)

## 📚 참고: 선형계획법의 한계와 확장

### 한계

```
1. 현실의 많은 문제가 비선형
2. 불확실성 처리 제한적
3. 정수 제약 미반영
4. 다목적 문제 처리 곤란
```

### 확장 기법
