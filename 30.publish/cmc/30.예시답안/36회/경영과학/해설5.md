## 🎯 (1) 손익분기점 판매수량 (5점)

### 손익분기점의 개념

```
손익분기점(Break-Even Point, BEP):
- 총수익 = 총비용이 되는 지점
- 이익도 손실도 없는 지점
- 최소한 달성해야 할 판매량
```

### 손익분기점 공식

**기본 관계식:**
```
총수익(TR) = 판매가격 × 판매수량
          = P × Q

총비용(TC) = 고정비용 + 변동비용
          = FC + VC × Q

손익분기점: TR = TC
```

**BEP 판매수량 공식:**
```
P × Q = FC + VC × Q
P × Q - VC × Q = FC
Q(P - VC) = FC

Q_BEP = FC / (P - VC)
```

여기서 **(P - VC) = 단위당 공헌이익**

### 계산

**주어진 값:**
```
FC = 10,000,000원
P = 25,000원/개
VC = 5,000원/개
```

**단위당 공헌이익:**
```
P - VC = 25,000 - 5,000 = 20,000원/개
```

**손익분기점 수량:**
```
Q_BEP = FC / (P - VC)
      = 10,000,000 / 20,000
      = 500개
```

### 답

```
손익분기점 판매수량 = 500개
```

### 검증

**총수익:**
```
TR = 25,000 × 500 = 12,500,000원
```

**총비용:**
```
TC = 10,000,000 + 5,000 × 500
   = 10,000,000 + 2,500,000
   = 12,500,000원
```

**이익:**
```
π = TR - TC = 12,500,000 - 12,500,000 = 0원 ✓
```

### 해석

```
의미:
- 넥타이 500개 판매 시 손익 0
- 500개 미만 판매 시 손실
- 500개 초과 판매 시 이익

관리:
- 최소 목표: 500개 이상 판매
- 안전마진: 실제 판매량 - 500개
```

## 💰 (2) 변경 시나리오의 최소 판매가격 (5점)

### 변경 사항

**조건 변화:**

1. **고정비용 증가:**
   ```
   기존: 10,000,000원
   증가: +5,000,000원
   새 FC: 15,000,000원
   ```

2. **변동비용 25% 증가:**
   ```
   기존: 5,000원/개
   증가: 5,000 × 1.25 = 6,250원/개
   새 VC: 6,250원/개
   ```

3. **판매수량 확정:**
   ```
   Q = 600개 (마케팅으로 확보)
   ```

4. **목표:**
   ```
   적어도 손해를 보지 않음 (π ≥ 0)
   → 최소 판매가격 P 구하기
   ```

### 공식 유도

**손익 공식:**
```
이익(π) = 총수익 - 총비용
        = P × Q - (FC + VC × Q)
```

**손해를 보지 않는 조건:**
```
π ≥ 0
P × Q - (FC + VC × Q) ≥ 0
P × Q ≥ FC + VC × Q
P ≥ (FC + VC × Q) / Q
P ≥ FC/Q + VC
```

**최소 판매가격:**
```
P_min = FC/Q + VC
      = (고정비용/판매수량) + 단위당 변동비용
```

### 계산

**주어진 값:**
```
FC = 15,000,000원
VC = 6,250원/개
Q = 600개
```

**최소 판매가격 계산:**
```
P_min = FC/Q + VC
      = 15,000,000/600 + 6,250
      = 25,000 + 6,250
      = 31,250원/개
```

### 답

```
최소 판매가격 = 31,250원/개
```

### 검증

**31,250원으로 판매 시:**

```
총수익: TR = 31,250 × 600 = 18,750,000원
총비용: TC = 15,000,000 + 6,250 × 600
          = 15,000,000 + 3,750,000
          = 18,750,000원
이익: π = 18,750,000 - 18,750,000 = 0원 ✓
```

**31,250원 미만으로 판매 시 (예: 31,000원):**

```
총수익: TR = 31,000 × 600 = 18,600,000원
총비용: TC = 18,750,000원
이익: π = 18,600,000 - 18,750,000 = -150,000원 (손실) ✗
```

**31,250원 초과로 판매 시 (예: 32,000원):**

```
총수익: TR = 32,000 × 600 = 19,200,000원
총비용: TC = 18,750,000원
이익: π = 19,200,000 - 18,750,000 = +450,000원 (이익) ✓
```

### 해석

```
가격 결정:
- 최소 31,250원/개에 판매해야 손해 없음
- 기존 25,000원 대비 6,250원(25%) 인상 필요

경영 판단:
- 시장에서 25% 가격 인상 수용 가능한가?
- 가격 인상 시 판매량 600개 유지 가능한가?
- 고정비용 증가 결정 재검토 필요
```

## 💡 경영학적 시사점

### 1. 비용-수량-가격 관계

**공헌이익의 중요성:**
```

→ 고정비용 커버 능력 향상

```

## 📚 참고: 손익분기점 관련 개념

**공헌이익 (Contribution Margin):**
```
단위당 공헌이익 = P - VC
총공헌이익 = (P - VC) × Q
```

**공헌이익률 (CM Ratio):**
```
CM Ratio = (P - VC) / P × 100%
```

**안전한계 (Margin of Safety):**
```
MOS = 실제 판매량 - BEP 판매량
MOS% = MOS / 실제 판매량 × 100%
```

**목표이익 달성 판매량:**
```
Q_target = (FC + 목표이익) / (P - VC)
```
