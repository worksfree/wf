---

## 📋 문제 상황

### 주어진 정보

**물류창고 (공급지):**
- A 창고: 1,200개
- B 창고: 750개
- C 창고: 540개
- **총 공급량: 2,490개**

**수요지역:**
- 가 지역: 1,500개
- 나 지역: 690개
- 다 지역: 300개
- **총 수요량: 2,490개**

```
총 공급량 = 총 수요량 → 균형 수송문제 (Balanced Transportation Problem)
```

### 단위 수송비용표 (원/개)

|   | 가 | 나 | 다 | 공급 |
|---|----|----|-------|------|
| A | 500 | 1,200 | 1,200 | 1,200 |
| B | 1,000 | 250 | 800 | 750 |
| C | 1,200 | 1,000 | 250 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** |

## 🔷 (1) 북서코너법 (Northwest Corner Method) (15점)

### 북서코너법의 원리

```
1. 표의 왼쪽 위(북서쪽) 모서리부터 시작
2. 현재 셀에 가능한 최대량 할당
3. 공급 또는 수요가 소진되면 다음 셀로 이동
4. 모든 공급과 수요가 충족될 때까지 반복
→ 비용은 고려하지 않음 (단순 기계적 방법)
```

### Step 1: 초기 테이블

|   | 가 | 나 | 다 | 공급 |
|---|----|----|-------|------|
| A | 500 | 1,200 | 1,200 | 1,200 |
| B | 1,000 | 250 | 800 | 750 |
| C | 1,200 | 1,000 | 250 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** |

### Step 2: 북서코너법 적용 과정

#### 반복 1: A-가 셀

- 현재 위치: (A, 가)
- A 공급: 1,200개
- 가 수요: 1,500개
- 할당량: min(1,200, 1,500) = **1,200개**

**A-가에 1,200개 할당**

**갱신:**
- A 공급 소진: 1,200 - 1,200 = 0 (A행 제거)
- 가 수요 갱신: 1,500 - 1,200 = 300

#### 반복 2: B-가 셀

- 현재 위치: (B, 가) - A가 소진되어 B로 이동
- B 공급: 750개
- 가 수요: 300개
- 할당량: min(750, 300) = **300개**

**B-가에 300개 할당**

**갱신:**
- B 공급 갱신: 750 - 300 = 450
- 가 수요 소진: 300 - 300 = 0 (가 열 제거)

#### 반복 3: B-나 셀

- 현재 위치: (B, 나) - 가가 소진되어 나로 이동
- B 공급: 450개
- 나 수요: 690개
- 할당량: min(450, 690) = **450개**

**B-나에 450개 할당**

**갱신:**
- B 공급 소진: 450 - 450 = 0 (B행 제거)
- 나 수요 갱신: 690 - 450 = 240

#### 반복 4: C-나 셀

- 현재 위치: (C, 나) - B가 소진되어 C로 이동
- C 공급: 540개
- 나 수요: 240개
- 할당량: min(540, 240) = **240개**

**C-나에 240개 할당**

**갱신:**
- C 공급 갱신: 540 - 240 = 300
- 나 수요 소진: 240 - 240 = 0 (나 열 제거)

#### 반복 5: C-다 셀 (최종)

- 현재 위치: (C, 다) - 유일하게 남은 셀
- C 공급: 300개
- 다 수요: 300개
- 할당량: min(300, 300) = **300개**

**C-다에 300개 할당**

**갱신:**
- C 공급 소진: 300 - 300 = 0
- 다 수요 소진: 300 - 300 = 0

### Step 3: 북서코너법 할당표

|   | 가 | 나 | 다 | 공급 | 소진 |
|---|----|----|-------|------|------|
| A | **1,200**<br>@500 | - | - | 1,200 | 1,200 |
| B | **300**<br>@1,000 | **450**<br>@250 | - | 750 | 750 |
| C | - | **240**<br>@1,000 | **300**<br>@250 | 540 | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** | |
| **충족** | 1,500 | 690 | 300 | | **2,490** |

**범례:**
- 굵은 숫자: 할당량(개)
- @숫자: 단위 수송비용(원/개)

### Step 4: 총 수송비용 계산

**할당 경로별 비용:**

| 경로 | 할당량(개) | 단위비용(원/개) | 소계(원) |
|------|-----------|----------------|----------|
| A → 가 | 1,200 | 500 | 600,000 |
| B → 가 | 300 | 1,000 | 300,000 |
| B → 나 | 450 | 250 | 112,500 |
| C → 나 | 240 | 1,000 | 240,000 |
| C → 다 | 300 | 250 | 75,000 |

**총 비용 계산:**
```
총 수송비용 = 600,000 + 300,000 + 112,500 + 240,000 + 75,000
           = 1,327,500원
```

### 북서코너법 답

```
초기해의 총 수송비용 = 1,327,500원
```

### 검증

**공급 제약 확인:**
- A: 1,200 = 1,200 ✓
- B: 300 + 450 = 750 ✓
- C: 240 + 300 = 540 ✓

**수요 제약 확인:**
- 가: 1,200 + 300 = 1,500 ✓
- 나: 450 + 240 = 690 ✓
- 다: 300 = 300 ✓

**기본 가능해 조건:**
- m (공급지 수) = 3
- n (수요지 수) = 3
- 필요한 할당 셀 수 = m + n - 1 = 3 + 3 - 1 = 5 ✓
- 실제 할당 셀 수 = 5개 (A-가, B-가, B-나, C-나, C-다) ✓

## 💰 (2) 최소비용법 (Least Cost Method) (15점)

### 최소비용법의 원리

```
1. 전체 비용표에서 최소 비용 셀을 찾음
2. 해당 셀에 가능한 최대량 할당
3. 공급 또는 수요가 소진되면 해당 행/열 제거
4. 남은 셀 중 최소 비용 셀을 찾아 반복
→ 비용을 고려하여 더 효율적인 초기해 도출
```

### Step 1: 초기 비용표 (재확인)

|   | 가 | 나 | 다 | 공급 |
|---|----|----|-------|------|
| A | **500** | 1,200 | 1,200 | 1,200 |
| B | 1,000 | **250**← | 800 | 750 |
| C | 1,200 | 1,000 | **250**← | 540 |
| **수요** | **1,500** | **690** | **300** | **2,490** |

```
최소 비용: B-나 (250원), C-다 (250원) - 동일
```

### Step 2: 최소비용법 적용 과정

#### 반복 1: B-나 또는 C-다

**두 셀 모두 250원으로 동일. B-나를 먼저 선택 (관례적으로 상단/좌측 우선)**

- 셀: B-나 (비용 250원)
- B 공급: 750개
- 나 수요: 690개
- 할당량: min(750, 690) = **690개**

**B-나에 690개 할당**

**갱신:**
- B 공급 갱신: 750 - 690 = 60
- 나 수요 소진: 690 - 690 = 0 (나 열 제거)

**남은 비용표:**

|   | 가 | 다 | 공급 |
|---|----|----|------|
| A | 500 | 1,200 | 1,200 |
| B | 1,000 | 800 | 60 |
| C | 1,200 | **250** ← | 540 |
| **수요** | **1,500** | **300** | |

#### 반복 2: C-다

- 셀: C-다 (비용 250원 - 최소)
- C 공급: 540개
- 다 수요: 300개
- 할당량: min(540, 300) = **300개**

**C-다에 300개 할당**

**갱신:**
- C 공급 갱신: 540 - 300 = 240
- 다 수요 소진: 300 - 300 = 0 (다 열 제거)

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| A | **500** ← | 1,200 |
| B | 1,000 | 60 |
| C | 1,200 | 240 |
| **수요** | **1,500** | |

#### 반복 3: A-가

- 셀: A-가 (비용 500원 - 최소)
- A 공급: 1,200개
- 가 수요: 1,500개
- 할당량: min(1,200, 1,500) = **1,200개**

**A-가에 1,200개 할당**

**갱신:**
- A 공급 소진: 1,200 - 1,200 = 0 (A행 제거)
- 가 수요 갱신: 1,500 - 1,200 = 300

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| B | **1,000** ← | 60 |
| C | 1,200 | 240 |
| **수요** | **300** | |

#### 반복 4: B-가

- 셀: B-가 (비용 1,000원 < 1,200원)
- B 공급: 60개
- 가 수요: 300개
- 할당량: min(60, 300) = **60개**

**B-가에 60개 할당**

**갱신:**
- B 공급 소진: 60 - 60 = 0 (B행 제거)
- 가 수요 갱신: 300 - 60 = 240

**남은 비용표:**

|   | 가 | 공급 |
|---|----|------|
| C | 1,200 | 240 |
| **수요** | **240** | |

#### 반복 5: C-가 (최종)

- 셀: C-가 (유일한 셀)
- C 공급: 240개
- 가 수요: 240개
- 할당량: min(240, 240) = **240개**

**C-가에 240개 할당**

**갱신:**
- C 공급 소진: 240 - 240 = 0
- 가 수요 소진: 240 - 240 = 0

**완료!**

### 최소비용법 답

```

### 검증

**공급 제약 확인:**

✓ 할당표 작성: 각 단계별 할당량과 비용 명시
✓ 계산 과정: 반복 단계마다 공급/수요 갱신 표시
✓ 총 비용: 각 경로별 비용 분해하여 계산
✓ 검증: 공급/수요 제약, 기본 가능해 조건 확인
✓ 비교: 두 방법의 차이와 효율성 분석
✓ 단위: "원" 또는 "개" 명시
```

---

*이 답안은 제36회 경영지도사 경영과학 기출문제의 예시답안입니다.*
