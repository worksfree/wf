# 제36회 경영지도사 경영과학 - 문제 6 답안

## 선형계획법의 전제조건 (Linear Programming Assumptions)

---

## 📋 문제 요구사항

선형계획(Linear Programming) 모형 사용의 전제조건이 되는 가정 중 **4가지를 설명**하시오.

---

## 🎯 선형계획법의 4가지 주요 가정

### 1. 선형성 (Linearity)

#### 개념

```
모든 관계식(목적함수 및 제약조건)이 선형(1차식)이어야 함
→ 변수들의 합 또는 차로만 표현
→ 변수의 곱, 제곱, 루트 등 비선형 항 불가
```

#### 상세 설명

**목적함수의 선형성:**
```
허용: z = 3x₁ + 5x₂ + 2x₃
불가: z = x₁² + 5x₂  (제곱항)
불가: z = 3x₁x₂ + 2x₃  (곱셈항)
불가: z = √x₁ + 5x₂  (루트항)
```

**제약조건의 선형성:**
```
허용: 2x₁ + 3x₂ ≤ 100
불가: x₁² + x₂ ≤ 100  (제곱항)
불가: x₁ / x₂ ≤ 5  (나눗셈)
```

#### 경제적 의미

**규모에 대한 수익 불변 (Constant Returns to Scale):**
```
생산량이 2배가 되면 비용/수익도 정확히 2배
→ 규모의 경제나 불경제 없음
```

**예시:**
```
제품 1개 생산 비용: 1,000원
제품 10개 생산 비용: 10,000원 (정확히 10배)
제품 100개 생산 비용: 100,000원 (정확히 100배)

실제: 대량 생산 시 단가 하락 가능 (비선형)
→ LP로 표현 불가
```

#### 위배 시 대안

```
- 비선형계획법 (Nonlinear Programming)
- 정수계획법 (Integer Programming)
- 동적계획법 (Dynamic Programming)
```

---

### 2. 비례성 (Proportionality)

#### 개념

```
각 의사결정 변수의 기여도가 그 변수의 값에 정비례
→ 변수가 2배 증가하면 기여도도 정확히 2배
→ 단위당 기여도 일정 (한계 효용/비용 불변)
```

#### 상세 설명

**목적함수의 비례성:**
```
x₁ = 10일 때 기여도 = 3 × 10 = 30
x₁ = 20일 때 기여도 = 3 × 20 = 60 (정확히 2배)

단위당 기여도(계수) = 3 (일정)
```

**제약조건의 비례성:**
```
자원 소비도 비례적
x₁ = 5일 때 자원 소비 = 2 × 5 = 10
x₁ = 10일 때 자원 소비 = 2 × 10 = 20 (정확히 2배)
```

#### 경제적 의미

**한계 기여도 불변:**
```
첫 번째 제품: 이익 5,000원
두 번째 제품: 이익 5,000원
백 번째 제품: 이익 5,000원

→ 생산량과 무관하게 단위당 이익 동일
```

**실제 위배 사례:**
```
1. 학습 효과: 생산량 증가 → 숙련도 향상 → 단위 비용 감소
2. 피로 효과: 작업량 증가 → 효율 저하 → 단위 시간 증가
3. 가격 할인: 대량 구매 → 단가 하락
4. 체감 효용: 소비량 증가 → 만족도 증가율 감소
```

#### 비례성 vs 선형성

```
선형성: 변수들 간의 관계 (합, 차만 허용)
비례성: 각 변수 내부의 관계 (단위당 기여도 일정)

→ 선형성은 비례성을 포함하는 더 넓은 개념
```

---

### 3. 가법성 (Additivity)

#### 개념

```
여러 활동의 총 기여도 = 각 활동 기여도의 합
→ 활동 간 상호작용 없음
→ 한 변수가 다른 변수에 영향 주지 않음
```

#### 상세 설명

**목적함수의 가법성:**
```
z = 3x₁ + 5x₂

x₁의 기여도: 3x₁
x₂의 기여도: 5x₂
총 기여도: 3x₁ + 5x₂ (단순 합)

→ x₁과 x₂가 서로 독립적
→ x₁이 증가해도 x₂의 단위 기여도(5) 불변
```

**제약조건의 가법성:**
```
2x₁ + 3x₂ ≤ 100

x₁의 자원 소비: 2x₁
x₂의 자원 소비: 3x₂
총 자원 소비: 2x₁ + 3x₂ (단순 합)
```

#### 경제적 의미

**활동 간 독립성:**
```
제품 A 생산 → 제품 B 생산에 영향 없음
제품 B 생산 → 제품 A 생산에 영향 없음

→ 시너지 효과 없음
→ 간섭 효과 없음
```

**실제 위배 사례:**

**1. 시너지 효과 (Synergy):**
```
예: 제품 A와 B를 함께 생산 시 비용 절감
→ TC(A+B) < TC(A) + TC(B)
→ 가법성 위배
```

**2. 대체 효과 (Substitution):**
```
예: 제품 A 판매 증가 → 제품 B 수요 감소
→ 수익 = f(A, B) (교차 효과 있음)
→ 가법성 위배
```

**3. 보완 효과 (Complementarity):**
```
예: 프린터 판매 증가 → 잉크 수요 증가
→ 독립적이지 않음
→ 가법성 위배
```

**4. 공유 자원:**
```
예: A와 B가 같은 설비 사용 시 간섭
→ 동시 생산 시 효율 저하
→ 가법성 위배
```

#### 위배 시 대안

```
- 비선형계획법 (교차항 포함)
- 목표계획법 (다중 목표)
```

### 4. 확실성 (Certainty) 또는 결정성 (Deterministic)

#### 개념

```
모든 파라미터(계수, 제약 값 등)가 확실하게 알려져 있음
→ 불확실성 없음
→ 확률적 변동 없음
→ 미래를 정확히 예측 가능
```

#### 상세 설명

**확실한 파라미터:**

**1. 목적함수 계수:**
```
z = 3x₁ + 5x₂
→ 3과 5가 확실히 알려진 값
→ 변동하지 않음
```

**2. 제약조건 계수:**
```
2x₁ + 3x₂ ≤ 100
→ 2, 3, 100이 확실한 값
```

**3. 기술 계수:**
```
자원 소비율, 생산 계수 등이 고정
```

#### 경제적 의미

**결정론적 환경:**
```
- 수요: 정확히 알려짐
- 가격: 변동 없음
- 비용: 확정적
- 자원: 확실한 양
```

**실제 위배 사례:**

**1. 수요 불확실성:**
```
실제: 수요 = 평균 1,000개 ± 200개 (확률 분포)
LP: 수요 = 정확히 1,000개로 가정
```

**2. 가격 변동:**
```
실제: 가격 = 시장 상황에 따라 변동
LP: 가격 = 고정 값으로 가정
```

**3. 자원 가용성:**
```
실제: 설비 고장, 원료 부족 등 발생 가능
LP: 자원이 항상 확실히 공급됨
```

**4. 경쟁 반응:**
```
실제: 경쟁사 반응에 따라 시장 변화
LP: 외부 환경 불변
```

#### 대응 방안

**1. 민감도 분석 (Sensitivity Analysis):**
```
파라미터 변화 시 최적해의 변화 분석
→ "what-if" 분석
```

**2. 시나리오 분석:**
```
낙관/기준/비관 시나리오별 LP 수립
```

**3. 확률 계획법:**
```
- 확률제약계획 (Chance-Constrained Programming)
- 2단계 확률계획 (Two-Stage Stochastic Programming)
```

**4. 재계획:**
```
정기적으로 파라미터 갱신 후 재최적화
→ 동적 환경 대응
```

## 📊 추가 가정 (참고)

### 5. 분할가능성 (Divisibility)

#### 개념

```
의사결정 변수가 연속적 (소수점 값 허용)
→ x = 5.7, x = 10.3 등 가능
→ 정수 제약 없음
```

#### 위배 시

```
예: 자동차, 직원 수 등은 정수여야 함
→ 정수계획법 (Integer Programming) 사용
```

### 6. 비음조건 (Non-negativity)

#### 개념

```
모든 의사결정 변수 ≥ 0
→ 음수 생산량, 음수 배정 등 불가능
```

#### 예외

```
일부 문제는 음수 허용 (예: 재무 모델)
→ 필요 시 제약 조건 조정
```

## 💡 선형계획법 적용 시 검토사항

### 적용 전 체크리스트

```
□ 선형성: 모든 관계식이 1차식인가?
□ 비례성: 단위당 기여도가 일정한가?
□ 가법성: 활동 간 독립적인가?
□ 확실성: 파라미터가 확실히 알려졌는가?
□ 분할성: 소수점 해가 의미 있는가?
□ 비음성: 변수가 0 이상인가?
```

### 가정 위배 시 대안

| 위배 가정 | 문제 유형 | 대안 기법 |
|---------|---------|---------|
| 선형성 | 비선형 관계 | 비선형계획법 (NLP) |
| 비례성 | 규모의 경제 | 동적계획법 (DP) |
| 가법성 | 시너지 효과 | 목표계획법 (GP) |
| 확실성 | 불확실성 | 확률계획법 (SP) |
| 분할성 | 정수 제약 | 정수계획법 (IP) |
| 다중 목표 | 상충 목표 | 다목적계획법 (MOP) |

## 🎯 실무 적용 예시

### 적합한 사례

**1. 배합 문제 (Blending):**
```
사료 배합, 석유 정제 등
→ 선형 관계 성립
→ LP 적합
```

**2. 수송 문제 (Transportation):**
```
공장-창고 간 배송 계획
→ 단위당 수송비 일정
→ LP 적합
```

**3. 생산 계획:**
```
단기 생산 계획 (제품 믹스)
→ 자원 제약 명확
→ LP 적합
```

### 부적합한 사례

**1. 신제품 개발:**
```
수요 불확실
가격 미정
→ 확실성 위배
```

**2. 대규모 투자:**
```
규모의 경제 존재
고정비 존재
→ 선형성 위배
```

**3. 마케팅 믹스:**
```
광고 효과 체감
시너지 효과 존재
→ 비례성, 가법성 위배
```

## 📝 최종 답안 정리

### 선형계획모형의 4가지 가정

#### 1. 선형성 (Linearity)

```
- 개념: 목적함수와 제약조건이 모두 1차 선형식
- 의미: 변수의 제곱, 곱셈 등 비선형 항 불가
- 예: z = 3x₁ + 5x₂ (허용), z = x₁² (불가)
- 경제적 의미: 규모에 대한 수익 불변
```

#### 2. 비례성 (Proportionality)

```
- 개념: 각 변수의 기여도가 변수 값에 정비례
- 의미: 단위당 기여도 일정 (한계 효용/비용 불변)
- 예: 제품 1개당 이익 5,000원이면, 10개는 정확히 50,000원
- 경제적 의미: 학습효과, 피로효과 등 없음
```

#### 3. 가법성 (Additivity)

```
- 개념: 총 효과 = 각 활동 효과의 단순 합
- 의미: 활동 간 상호작용 없음 (독립적)
- 예: z = 3x₁ + 5x₂ (x₁과 x₂가 서로 영향 없음)
- 경제적 의미: 시너지 효과, 대체 효과 없음
```

#### 4. 확실성 (Certainty)

```
- 개념: 모든 파라미터가 확실하게 알려져 있음
- 의미: 불확실성, 확률적 변동 없음
- 예: 수요, 가격, 비용이 정확히 예측 가능
- 경제적 의미: 미래를 완벽히 예측 가능한 결정론적 환경
- 대응: 민감도 분석, 시나리오 분석으로 보완
```

```
✓ 4가지 명확히: 선형성, 비례성, 가법성, 확실성

✓ 경제적 해석: 실무적 의미 언급

✓ 분량 배분: 각 가정당 비슷한 분량
```

## 📚 참고: 선형계획법의 한계와 확장

### 한계

```
1. 현실의 많은 문제가 비선형
2. 불확실성 처리 제한적
3. 정수 제약 미반영
4. 다목적 문제 처리 곤란
```

### 확장 기법

```
1. 정수계획법 (IP): 정수 제약
2. 비선형계획법 (NLP): 비선형 관계
3. 확률계획법 (SP): 불확실성
4. 목표계획법 (GP): 다중 목표
5. 동적계획법 (DP): 다단계 의사결정
```

### 보완 방법

```
1. 선형 근사: 비선형을 구간별 선형으로 근사
2. 민감도 분석: 파라미터 변화 영향 분석
3. 시나리오 분석: 여러 상황 대비
4. 재최적화: 정기적 모델 갱신
```
