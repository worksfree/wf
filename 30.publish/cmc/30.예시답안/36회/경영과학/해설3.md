# 제36회 경영지도사 경영과학 - 문제 3 답안

## 대기행렬이론 (Queuing Theory)

---

## 📋 문제 상황

### 주어진 정보

**시스템 특성:**
- 서비스 제공자: 1명 (단일 서버)
- 고객 도착률: 시간당 평균 8명
- 서비스 시간: 6분/명

**추가 가정 (M/M/1 대기행렬):**
- 도착 과정: 포아송 분포
- 서비스 시간: 지수 분포
- 서버 수: 1개
- 대기공간: 무한
- 대기규율: FIFO (선입선출)

---

## 🎯 기본 파라미터 계산

### 도착률 (λ)과 서비스율 (μ)

**도착률 (λ):**
```
λ = 시간당 평균 8명
  = 8명/시간
  = 8/60 명/분
  = 2/15 명/분
```

**서비스율 (μ):**
```
서비스 시간 = 6분/명
서비스율 μ = 1/서비스시간
           = 1/6 시간당 명
           = 60/6 명/시간
           = 10명/시간
```

### 이용률 (ρ) 계산

```
ρ = λ/μ
  = 8/10
  = 0.8 (80%)
```

**검증:**
```
ρ < 1 이어야 안정적인 시스템
0.8 < 1 ✓ (시스템 안정)
```

### 해석

```
서버 이용률 = 80%
→ 서버가 80% 시간 동안 바쁨
→ 20% 시간 동안 대기자 없음 (유휴)
```

---

## 📊 (1) 대기 없이 바로 서비스받을 확률 (4점)

### M/M/1 대기행렬 공식

**시스템에 고객이 없을 확률 (P₀):**

```
P₀ = 1 - ρ
   = 1 - λ/μ
```

이것이 곧 대기 없이 바로 서비스받을 확률입니다.

### 계산

```
P₀ = 1 - ρ
   = 1 - 0.8
   = 0.2
```

### 답

```
대기 없이 바로 발급 신청할 확률 = 0.2 (20%)
```

### 해석

```
고객이 도착했을 때:
- 20% 확률로 즉시 서비스 가능
- 80% 확률로 대기 필요

→ 5명 중 1명은 대기 없이 바로 서비스
→ 5명 중 4명은 대기 필요
```

---

## 👥 (2) 평균 대기 인원 (3점)

### M/M/1 대기행렬 공식

**대기열에서 기다리는 평균 고객 수 (Lq):**

```
Lq = ρ²/(1-ρ)
   = (λ/μ)² / (1-λ/μ)
   = λ² / (μ(μ-λ))
```

### 계산

**방법 1: ρ 사용**
```
Lq = ρ²/(1-ρ)
   = (0.8)²/(1-0.8)
   = 0.64/0.2
   = 3.2명
```

**방법 2: λ, μ 직접 사용**
```
Lq = λ²/(μ(μ-λ))
   = 8²/(10(10-8))
   = 64/(10×2)
   = 64/20
   = 3.2명
```

### 소수점 반올림

```
3.2명
→ 소수점 둘째자리에서 반올림
→ 3.2명 (소수점 첫째자리)
```

### 답

```
평균 대기 인원 = 3.2명
```

### 해석

```
언제든지 시험장을 방문하면:
- 평균 3.2명이 번호표 들고 대기 중
- 서비스받는 1명 + 대기 3.2명 = 총 4.2명

→ 평균적으로 자기 앞에 3.2명 대기
```

### 참고: 시스템 내 평균 고객 수 (L)

```
L = Lq + ρ
  = 3.2 + 0.8
  = 4.0명

또는

L = ρ/(1-ρ)
  = 0.8/(1-0.8)
  = 0.8/0.2
  = 4.0명
```

## ⏰ (3) 평균 대기 시간 (3점)

### M/M/1 대기행렬 공식

**대기열에서 기다리는 평균 시간 (Wq):**

```
Wq = Lq/λ
   = ρ/(μ(1-ρ))
   = λ/(μ(μ-λ))
```

### 계산

**방법 1: Lq/λ 사용**
```
Wq = Lq/λ
   = 3.2/8
   = 0.4 시간
   = 0.4 × 60 분
   = 24분
```

**방법 2: ρ, μ 사용**
```
Wq = ρ/(μ(1-ρ))
   = 0.8/(10×(1-0.8))
   = 0.8/(10×0.2)
   = 0.8/2
   = 0.4 시간
   = 24분
```

**방법 3: λ, μ 직접 사용**
```
Wq = λ/(μ(μ-λ))
   = 8/(10×(10-8))
   = 8/(10×2)
   = 8/20
   = 0.4 시간
   = 24분
```

### 소수점 반올림

```
24.0분
→ 소수점 둘째자리에서 반올림
→ 24.0분 (소수점 첫째자리)
```

### 답

```
평균 대기 시간 = 24.0분 (또는 0.4시간)
```

### 해석

```
번호표를 뽑고 대기하는 시간:
- 평균 24분 대기
- 서비스 시간(6분) 포함 시 총 30분

→ 시험장 방문 시 평균 30분 소요
```

### 참고: 시스템 내 평균 체류 시간 (W)

```
W = Wq + 1/μ
  = 24 + 6
  = 30분

또는

W = L/λ
  = 4.0/8
  = 0.5 시간
  = 30분

또는

W = 1/(μ-λ)
  = 1/(10-8)
  = 1/2 시간
  = 30분
```

## 📊 대기행렬 주요 공식 정리

### M/M/1 시스템 공식 요약

| 지표 | 기호 | 공식 | 본 문제 값 |
|------|------|------|-----------|
| 도착률 | λ | 8명/시간 | 8 |
| 서비스율 | μ | 10명/시간 | 10 |
| 이용률 | ρ | λ/μ | 0.8 |
| 시스템 유휴 확률 | P₀ | 1-ρ | 0.2 |
| 대기 인원 | Lq | ρ²/(1-ρ) | 3.2명 |
| 시스템 내 인원 | L | ρ/(1-ρ) | 4.0명 |
| 대기 시간 | Wq | ρ/(μ(1-ρ)) | 24분 |
| 체류 시간 | W | 1/(μ-λ) | 30분 |

### Little의 법칙 검증

```
L = λW
4.0 = 8 × 0.5 ✓

Lq = λWq
3.2 = 8 × 0.4 ✓
```

## 💡 경영학적 시사점

### 1. 현재 시스템 분석

**강점:**
```
- 시스템이 안정적 (ρ = 0.8 < 1)
- 서비스 제공 가능
```

**약점:**
```
- 평균 대기 시간 24분 (긴 편)
- 평균 대기 인원 3.2명
- 서버 이용률 80% (높음)
```

### 2. 서비스 개선 방안

#### 방안 1: 서비스 시간 단축

**목표: 서비스 시간 6분 → 5분**

```
새로운 μ = 60/5 = 12명/시간
새로운 ρ = 8/12 = 0.667

Lq = (0.667)²/(1-0.667) = 0.444/0.333 = 1.33명
Wq = 1.33/8 = 0.167시간 = 10분

개선 효과:
- 대기 인원: 3.2명 → 1.33명 (58% 감소)
- 대기 시간: 24분 → 10분 (58% 감소)
```

#### 방안 2: 서버 추가 (2명 체제)

**M/M/2 시스템으로 전환**

```
복잡한 계산 필요하지만, 대략:
- 대기 시간 90% 이상 감소 예상
- 비용 증가 고려 필요
```

#### 방안 3: 예약 시스템 도입

```
- 도착률 평준화
- 대기 시간 예측 가능
- 고객 만족도 향상
```

### 3. 비용-편익 분석

**현재 시스템 유지 비용:**
```
- 고객 대기 비용: 3.2명 × 24분
- 고객 불만족도
- 기회비용
```

**개선 시 편익:**
```
- 대기 시간 감소
- 고객 만족도 향상
- 처리량 증대
```

**추가 투자 대비 효과:**
```
서비스 시간 20% 단축 시:
→ 대기 시간 58% 감소
→ 투자 효율성 검토 필요
```
