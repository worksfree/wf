# 제36회 경영지도사 경영과학 - 문제 1 답안

## 마코프 체인 (Markov Chain)

---

## 📋 문제 상황

### 주어진 정보

날씨의 변화는 한 시간 전의 기상 상황에만 의존 (마코프 특성)

**전이확률:**

**비가 올 때** 한 시간 후:
- 비 → 비: 0.4
- 비 → 흐림: 0.4
- 비 → 맑음: 0.2

**흐릴 때** 한 시간 후:
- 흐림 → 비: 0.3
- 흐림 → 흐림: 0.4
- 흐림 → 맑음: 0.3

**맑을 때** 한 시간 후:
- 맑음 → 비: 0.1
- 맑음 → 흐림: 0.3
- 맑음 → 맑음: 0.6

## 🎯 (1) 전이행렬 (Transition Matrix) (10점)

### 마코프 체인의 개념

```
마코프 체인: 미래 상태가 오직 현재 상태에만 의존하는 확률 과정
전이행렬: 한 상태에서 다른 상태로 전이할 확률을 행렬로 표현
```

### 전이행렬의 구조

전이행렬 P는 다음과 같은 형태를 가집니다:

```
P = [현재 상태에서 → 다음 상태로의 확률]
```

**행(row)**: 현재 상태
**열(column)**: 다음 상태

### 전이행렬 작성

```
상태 순서: 비, 흐림, 맑음
```

|   현재\다음   |   비   |  흐림  |  맑음  |
|--------------|--------|--------|--------|
| **비**       |  0.4   |  0.4   |  0.2   |
| **흐림**     |  0.3   |  0.4   |  0.3   |
| **맑음**     |  0.1   |  0.3   |  0.6   |

### 행렬 표기

```
     ⎡ 0.4  0.4  0.2 ⎤
P =  ⎢ 0.3  0.4  0.3 ⎥
     ⎣ 0.1  0.3  0.6 ⎦
```

또는

```
P = ( 0.4  0.4  0.2 )
    ( 0.3  0.4  0.3 )
    ( 0.1  0.3  0.6 )
```

### 검증

각 행의 합이 1이어야 합니다 (확률의 총합 = 1):

```
1행: 0.4 + 0.4 + 0.2 = 1.0 ✓
2행: 0.3 + 0.4 + 0.3 = 1.0 ✓
3행: 0.1 + 0.3 + 0.6 = 1.0 ✓
```

## ☔ (2) 2시간 후 비 올 확률 (10점)

### 문제 분석

- 현재: 맑음
- 2시간 후: 비?
- 2단계 전이 필요 → P² 사용

### Step 1: 2단계 전이행렬 계산

2시간 후의 확률은 **P² = P × P**

#### P² 계산 과정

**P × P 계산:**

```
     ⎡ 0.4  0.4  0.2 ⎤       ⎡ 0.4  0.4  0.2 ⎤
P² = ⎢ 0.3  0.4  0.3 ⎥   ×   ⎢ 0.3  0.4  0.3 ⎥
     ⎣ 0.1  0.3  0.6 ⎦       ⎣ 0.1  0.3  0.6 ⎦
```

**P²의 (1,1) 원소 (비→비):**
```
0.4×0.4 + 0.4×0.3 + 0.2×0.1 = 0.16 + 0.12 + 0.02 = 0.30
```

**P²의 (1,2) 원소 (비→흐림):**
```
0.4×0.4 + 0.4×0.4 + 0.2×0.3 = 0.16 + 0.16 + 0.06 = 0.38
```

**P²의 (1,3) 원소 (비→맑음):**
```
0.4×0.2 + 0.4×0.3 + 0.2×0.6 = 0.08 + 0.12 + 0.12 = 0.32
```

**P²의 (2,1) 원소 (흐림→비):**
```
0.3×0.4 + 0.4×0.3 + 0.3×0.1 = 0.12 + 0.12 + 0.03 = 0.27
```

**P²의 (2,2) 원소 (흐림→흐림):**
```
0.3×0.4 + 0.4×0.4 + 0.3×0.3 = 0.12 + 0.16 + 0.09 = 0.37
```

**P²의 (2,3) 원소 (흐림→맑음):**
```
0.3×0.2 + 0.4×0.3 + 0.3×0.6 = 0.06 + 0.12 + 0.18 = 0.36
```

**P²의 (3,1) 원소 (맑음→비):**
```
0.1×0.4 + 0.3×0.3 + 0.6×0.1 = 0.04 + 0.09 + 0.06 = 0.19
```

**P²의 (3,2) 원소 (맑음→흐림):**
```
0.1×0.4 + 0.3×0.4 + 0.6×0.3 = 0.04 + 0.12 + 0.18 = 0.34
```

**P²의 (3,3) 원소 (맑음→맑음):**
```
0.1×0.2 + 0.3×0.3 + 0.6×0.6 = 0.02 + 0.09 + 0.36 = 0.47
```

### 2단계 전이행렬

```
      ⎡ 0.30  0.38  0.32 ⎤
P² =  ⎢ 0.27  0.37  0.36 ⎥
      ⎣ 0.19  0.34  0.47 ⎦
```

### Step 2: 맑음 → 비 확률

현재 맑음(상태 3)에서 2시간 후 비(상태 1)가 올 확률은 P²의 (3,1) 원소:

```
P²(3,1) = 0.19
```

### 답

**2시간 후 비가 올 확률 = 0.19 (19%)**

### 해석

```
현재 맑음 → 2시간 후 비: 19%

경로 분석:
1. 맑음 → 비 → 비: 0.1 × 0.4 = 0.04
2. 맑음 → 흐림 → 비: 0.3 × 0.3 = 0.09
3. 맑음 → 맑음 → 비: 0.6 × 0.1 = 0.06
합계: 0.04 + 0.09 + 0.06 = 0.19 ✓
```

## 🌤️ (3) 정상상태 확률 (Steady-State Probability) (10점)

### 정상상태의 개념

```
정상상태(Steady State): 충분한 시간이 지난 후, 확률분포가 더 이상 변하지 않는 상태
몇 주가 지나면 → 정상상태에 도달
초기 상태와 무관하게 일정한 확률분포 유지
```

### 정상상태 조건

정상상태 확률 벡터 π = (π₁, π₂, π₃)는 다음을 만족:

```
πP = π  (정상상태 방정식)
π₁ + π₂ + π₃ = 1  (확률의 합 = 1)
```

여기서 π₁ = 비 올 확률, π₂ = 흐릴 확률, π₃ = 맑을 확률

### 방정식 전개

**πP = π를 성분별로 전개:**

```
(π₁, π₂, π₃) × ⎡ 0.4  0.4  0.2 ⎤ = (π₁, π₂, π₃)
                ⎢ 0.3  0.4  0.3 ⎥
                ⎣ 0.1  0.3  0.6 ⎦
```

**첫 번째 성분:**
```
0.4π₁ + 0.3π₂ + 0.1π₃ = π₁
```

정리하면:
```
-0.6π₁ + 0.3π₂ + 0.1π₃ = 0  ... ①
```

**두 번째 성분:**
```
0.4π₁ + 0.4π₂ + 0.3π₃ = π₂
```

정리하면:
```
0.4π₁ - 0.6π₂ + 0.3π₃ = 0  ... ②
```

**세 번째 성분:**
```
0.2π₁ + 0.3π₂ + 0.6π₃ = π₃
```

정리하면:
```
0.2π₁ + 0.3π₂ - 0.4π₃ = 0  ... ③
```

**확률 조건:**
```
π₁ + π₂ + π₃ = 1  ... ④
```

### 연립방정식 풀이

방정식 ①, ②, ④를 사용 (③는 종속 방정식):

**방정식 ①에서:**
```
-0.6π₁ + 0.3π₂ + 0.1π₃ = 0
양변에 10을 곱하면:
-6π₁ + 3π₂ + π₃ = 0
π₃ = 6π₁ - 3π₂  ... ⑤
```

**방정식 ②에서:**
```
0.4π₁ - 0.6π₂ + 0.3π₃ = 0
양변에 10을 곱하면:
4π₁ - 6π₂ + 3π₃ = 0  ... ⑥
```

**⑤를 ⑥에 대입:**
```
4π₁ - 6π₂ + 3(6π₁ - 3π₂) = 0
4π₁ - 6π₂ + 18π₁ - 9π₂ = 0
22π₁ - 15π₂ = 0
π₂ = (22/15)π₁  ... ⑦
```

**⑦을 ⑤에 대입:**
```
π₃ = 6π₁ - 3(22/15)π₁
π₃ = 6π₁ - (66/15)π₁
π₃ = (90/15)π₁ - (66/15)π₁
π₃ = (24/15)π₁
π₃ = (8/5)π₁  ... ⑧
```

**⑦, ⑧을 ④에 대입:**
```
π₁ + (22/15)π₁ + (8/5)π₁ = 1
π₁ + (22/15)π₁ + (24/15)π₁ = 1
π₁(1 + 22/15 + 24/15) = 1
π₁(15/15 + 22/15 + 24/15) = 1
π₁(61/15) = 1
π₁ = 15/61
```

**π₂ 계산:**
```
π₂ = (22/15) × (15/61) = 22/61
```

**π₃ 계산:**
```
π₃ = (8/5) × (15/61) = (8×15)/(5×61) = 120/305 = 24/61
```

### 검증

```
π₁ + π₂ + π₃ = 15/61 + 22/61 + 24/61 = 61/61 = 1 ✓
```

### 최종 답

**정상상태 확률:**

**분수 표기:**
```
비가 올 확률 = 15/61
```

**소수 표기:**
```
15 ÷ 61 = 0.245901...
소수점 다섯째자리에서 반올림 → 0.2459
```

### 답

```
몇 주 후 아침에 비가 올 확률 = 15/61 또는 0.2459
```

## 💡 경영학적 시사점

### 1. 의사결정 활용

**단기 예측 (2시간):**
- 현재 날씨에 크게 영향받음
- 맑음 → 비: 19% (낮음)
- 단기 외출 계획 시 유용

**장기 예측 (몇 주):**
- 초기 상태 무관
- 비: 24.59%, 흐림: 36.07%, 맑음: 39.34%
- 장기 재고 계획, 인력 배치 등에 활용

### 2. 비즈니스 응용

**우산 판매점:**
```
장기 재고 비율:
- 비 대비: 25%
- 흐림 대비: 36%
- 맑음 대비: 39%
```

**야외 행사 기획:**
```
단기 (2시간 후):
- 현재 맑음 → 비 확률 19% (진행 가능)
장기 계획:
- 비 올 확률 약 25% 고려
```

### 3. 마코프 체인의 특징

**무기억성(Memoryless Property):**
```
과거 날씨 무관, 현재만 중요
→ 어제 비가 왔든 안 왔든, 현재 비면 동일한 전이확률
```

**정상상태의 존재:**
```
충분한 시간 후 안정된 확률분포
→ 장기 예측 가능
```

**분석 가능성:**
```
행렬 연산으로 n단계 후 예측 가능
→ 정량적 의사결정 지원
```
