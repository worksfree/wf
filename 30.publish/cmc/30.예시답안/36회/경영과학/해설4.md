## 🎯 (1) 최소 소요시간 (프로젝트 완료시간) (5점)

### Step 1: 네트워크 다이어그램 작성

#### AON (Activity-On-Node) 방식

```
시작(0)
   │
   A(15)
   ├─────────────┐
   │             │
   B(10)        D(13)
   │             │
   C(30)        E(20)
   │             │
   F(13)        G(22)
   └──────┬──────┘
          │
         H(18)
          │
         I(20)
          │
        종료
```

### Step 2: 모든 경로 파악

**경로 1: A → B → C → F → H → I**
```
15 + 10 + 30 + 13 + 18 + 20 = 106일
```

**경로 2: A → D → E → G → H → I**
```
15 + 13 + 20 + 22 + 18 + 20 = 108일
```

### Step 3: 임계경로 및 최소 소요시간

**두 경로 비교:**
```
경로 1 (A-B-C-F-H-I): 106일
경로 2 (A-D-E-G-H-I): 108일 ← 최장 경로
```

**임계경로 (Critical Path):**
```
A → D → E → G → H → I (108일)
```

### 답

```
최소 소요시간 = 108일
```

### 해석

```
스포츠카 완성까지 최소 108일 소요
→ 이보다 빨리 완성 불가능
→ A-D-E-G-H-I 경로가 전체 일정 결정
```

## ⏰ (2) 활동별 여유시간 (5점)

### 임계경로법(CPM) 계산

#### Step 1: 최조시간 (EST) 계산 (Forward Pass)

**규칙: EST = max(선행활동의 EFT)**

| 활동 | 선행활동 | 소요시간 | EST | EFT |
|------|----------|----------|-----|-----|
| A | - | 15 | 0 | 15 |
| B | A | 10 | 15 | 25 |
| C | B | 30 | 25 | 55 |
| D | A | 13 | 15 | 28 |
| E | D | 20 | 28 | 48 |
| F | C | 13 | 55 | 68 |
| G | E | 22 | 48 | 70 |
| H | F, G | 18 | max(68,70)=70 | 88 |
| I | H | 20 | 88 | 108 |

**계산 과정:**
```
A: EST=0, EFT=0+15=15
B: EST=15 (A완료), EFT=15+10=25
C: EST=25 (B완료), EFT=25+30=55
D: EST=15 (A완료), EFT=15+13=28
E: EST=28 (D완료), EFT=28+20=48
F: EST=55 (C완료), EFT=55+13=68
G: EST=48 (E완료), EFT=48+22=70
H: EST=max(68,70)=70 (F,G 모두 완료), EFT=70+18=88
I: EST=88 (H완료), EFT=88+20=108
```

#### Step 2: 최지시간 (LST) 계산 (Backward Pass)

**규칙: LFT = min(후행활동의 LST), 프로젝트 완료 시간에서 역산**

| 활동 | 소요시간 | LFT | LST |
|------|----------|-----|-----|
| I | 20 | 108 | 88 |
| H | 18 | 88 | 70 |
| G | 22 | 70 | 48 |
| F | 13 | 70 | 57 |
| E | 20 | 48 | 28 |
| D | 13 | 28 | 15 |
| C | 30 | 57 | 27 |
| B | 10 | 27 | 17 |
| A | 15 | min(15,15)=15 | 0 |

**계산 과정:**
```
I: LFT=108 (프로젝트 완료), LST=108-20=88
H: LFT=88 (I의 LST), LST=88-18=70
G: LFT=70 (H의 LST), LST=70-22=48
F: LFT=70 (H의 LST), LST=70-13=57
E: LFT=48 (G의 LST), LST=48-20=28
D: LFT=28 (E의 LST), LST=28-13=15
C: LFT=57 (F의 LST), LST=57-30=27
B: LFT=27 (C의 LST), LST=27-10=17
A: LFT=min(15,15)=15 (B,D의 LST), LST=15-15=0
```

#### Step 3: 여유시간 (Slack Time) 계산

**여유시간 (Total Slack, TS) = LST - EST = LFT - EFT**

| 활동 | EST | LST | EFT | LFT | 여유시간 | 임계 여부 |
|------|-----|-----|-----|-----|----------|----------|
| A | 0 | 0 | 15 | 15 | **0** | ✓ 임계 |
| B | 15 | 17 | 25 | 27 | **2** | |
| C | 25 | 27 | 55 | 57 | **2** | |
| D | 15 | 15 | 28 | 28 | **0** | ✓ 임계 |
| E | 28 | 28 | 48 | 48 | **0** | ✓ 임계 |
| F | 55 | 57 | 68 | 70 | **2** | |
| G | 48 | 48 | 70 | 70 | **0** | ✓ 임계 |
| H | 70 | 70 | 88 | 88 | **0** | ✓ 임계 |
| I | 88 | 88 | 108 | 108 | **0** | ✓ 임계 |

**계산 예시:**
```
A: 0 - 0 = 0일
B: 17 - 15 = 2일
C: 27 - 25 = 2일
D: 15 - 15 = 0일
E: 28 - 28 = 0일
F: 57 - 55 = 2일
G: 48 - 48 = 0일
H: 70 - 70 = 0일
I: 88 - 88 = 0일
```

### 답

**여유시간이 있는 활동:**

| 활동 | 여유시간 |
|------|---------|
| B | 2일 |
| C | 2일 |
| F | 2일 |

또는 문장으로:

```
활동 B: 2일
활동 C: 2일
활동 F: 2일
```

### 해석

```
임계활동 (여유시간 0):
- A, D, E, G, H, I
- 이들은 지연되면 프로젝트 전체가 지연됨
- 집중 관리 필요

비임계활동 (여유시간 있음):
- B, C, F (각 2일 여유)
- 2일까지 지연되어도 프로젝트 완료 시간에 영향 없음
- 자원 재배치 가능
```

## 📊 상세 분석

### 임계경로 분석

**임계경로: A → D → E → G → H → I (108일)**

```
A(15) → D(13) → E(20) → G(22) → H(18) → I(20) = 108일
```

**특징:**
- 6개 활동으로 구성
- 전체 활동 9개 중 67%가 임계활동
- 어느 하나라도 지연되면 전체 지연

### 비임계경로 분석

**비임계경로: A → B → C → F → H → I (106일)**

```
A(15) → B(10) → C(30) → F(13) → H(18) → I(20) = 106일

여유: 108 - 106 = 2일
```

**각 활동별 여유시간:**
```
B: 2일 (경로 여유와 동일)
C: 2일 (경로 여유와 동일)
F: 2일 (경로 여유와 동일)
```

**주의사항:**
```
B, C, F는 경로 여유를 공유
→ 세 활동의 지연이 합계 2일을 초과하면 안 됨
→ 예: B가 2일 지연되면 C, F는 지연 불가
```

## 💡 경영학적 시사점

### 1. 프로젝트 관리 전략

**임계활동 관리 (A, D, E, G, H, I):**
```
우선순위: 최고
전략:
- 충분한 자원 배분
- 진행 상황 밀착 감시
- 위험 요소 사전 제거
- 예비 계획 수립

→ 이들 중 하나라도 지연되면 전체 프로젝트 지연
```

**비임계활동 관리 (B, C, F):**
```
우선순위: 중간
전략:
- 2일 범위 내 일정 조정 가능
- 자원을 임계활동으로 재배치 가능
- 비용 절감 기회 모색

→ 여유 활용하되, 합계 2일 초과 주의
```

### 2. 프로젝트 단축 전략

**목표: 프로젝트 기간 108일 → 100일로 단축**

**단축 방법:**
```
임계경로의 활동 소요시간 단축 필요
→ 비임계활동 단축은 전체 기간에 무의미
```

**단축 우선순위 (비용-효과 고려):**
```
1. G (22일): 가장 긴 임계활동, 단축 효과 큼
2. E (20일): 두 번째로 긴 활동
3. H (18일): 병합점으로 양 경로 영향
4. A (15일): 초기 활동, 전체 영향 큼
```

**시나리오 분석:**

**시나리오 1: G를 8일 단축 (22→14일)**
```
새 프로젝트 기간: 108 - 8 = 100일
효과: 목표 달성
주의: 경로1(B-C-F)도 단축 필요 (현재 106일)
→ 추가 4일 단축 필요
```

**시나리오 2: 균형 단축**
```
G: 4일 단축 (22→18일)
E: 2일 단축 (20→18일)
D: 2일 단축 (13→11일)
→ 총 8일 단축, 100일 달성
```

### 3. 자원 배분 최적화

**현재 자원 배분:**
```
임계활동 (A,D,E,G,H,I): 우선 배분
비임계활동 (B,C,F): 여유 자원 활용
```

**자원 재배치 전략:**
```
시나리오: B, C, F에서 자원 일부를 임계활동으로 이동

예시:
- C (30일)에서 자원 10% 감소 → G로 이전
- C 소요시간 33일로 증가 (여유 2일 소진)
- G 소요시간 20일로 감소
- 전체 기간: 106일로 단축
```

## 📚 참고: CPM vs PERT

**CPM (Critical Path Method):**
```
- 결정론적 (소요시간 확정)
- 본 문제에 적용
- 단일 시간 추정
```

**PERT (Program Evaluation and Review Technique):**
```
- 확률론적 (소요시간 불확실)
- 3점 추정 (낙관/가능/비관)
- 기대시간 = (낙관 + 4×가능 + 비관)/6
```
