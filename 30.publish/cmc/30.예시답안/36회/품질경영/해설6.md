## 36회 품질경영 문제 6 예시답안
[문제 바로가기](#36회-품질경영-문제-6)

### 문제 분석

이 문제는 **이항분포(Binomial Distribution)**에 관한 문제입니다.

**주어진 조건**:
- 부적합품 비율: p = 0.15 (15%)
- 적합품 비율: q = 1 - p = 0.85 (85%)
- 표본 크기: n = 10개
- 확률변수 X: 10개 중 부적합품의 개수

**이항분포의 조건**:
1. 각 시행은 독립적
2. 각 시행의 성공확률(부적합품 비율)은 일정: p = 0.15
3. 시행 횟수가 고정: n = 10
4. 각 시행은 두 가지 결과만 가능 (부적합/적합)

따라서 X ~ B(n=10, p=0.15)

---

### 【문제 6 - (1)】 3개의 부적합품이 포함될 확률 (4점)

#### 1. 이항분포의 확률질량함수

**일반식**:
P(X = x) = C(n,x) × p^x × q^(n-x)
= C(n,x) × p^x × (1-p)^(n-x)

여기서:
- C(n,x) = nCx = n! / [x!(n-x)!]: 조합
- n: 시행 횟수
- x: 성공(부적합품) 횟수
- p: 성공 확률 (부적합품 비율)
- q: 실패 확률 (적합품 비율)

#### 2. 조합 계산

C(10,3) = 10! / (3! × 7!)

= (10 × 9 × 8) / (3 × 2 × 1)

= 720 / 6

= **120**

#### 3. 확률 계산

P(X = 3) = C(10,3) × (0.15)³ × (0.85)⁷

**각 항 계산**:

(0.15)³ = 0.15 × 0.15 × 0.15
= 0.0225 × 0.15
= 0.003375

(0.85)⁷ 계산:
- 0.85² = 0.7225
- 0.85³ = 0.614125
- 0.85⁴ = 0.52200625
- 0.85⁵ = 0.4437053125
- 0.85⁶ = 0.377149515625
- 0.85⁷ = 0.32057708828125
- 0.85⁷ ≈ 0.320577

**최종 계산**:

P(X = 3) = 120 × 0.003375 × 0.320577

= 120 × 0.001081946...

= 0.129833...

≈ **0.13** (소수점 셋째자리에서 반올림)

#### 답안: **P(X = 3) = 0.13**

---

### 【문제 6 - (2)】 부적합품 수의 기댓값 (3점)

#### 1. 이항분포의 기댓값 공식

**일반식**:
E(X) = n × p

여기서:
- n: 시행 횟수
- p: 성공 확률

#### 2. 기댓값 계산

E(X) = n × p
= 10 × 0.15
= **1.5**

#### 답안: **E(X) = 1.5**

#### 의미
- 제품 10개를 검사할 때 평균적으로 1.5개의 부적합품이 발견됩니다.
- 장기적으로 많은 시행을 반복하면 평균 부적합품 수는 1.5개에 수렴합니다.

---

### 【문제 6 - (3)】 부적합품 수의 분산 (3점)

#### 1. 이항분포의 분산 공식

**일반식**:
Var(X) = n × p × q
= n × p × (1-p)

여기서:
- n: 시행 횟수
- p: 성공 확률
- q: 실패 확률 = 1 - p

#### 2. 분산 계산

Var(X) = n × p × q
= 10 × 0.15 × 0.85
= 10 × 0.1275
= **1.275**

≈ **1.28** (소수점 셋째자리에서 반올림)

#### 답안: **Var(X) = 1.28**

#### 추가 정보

**표준편차**:
σ = √Var(X) = √1.275
≈ 1.129 ≈ 1.13

**의미**:
- 부적합품 수의 변동성을 나타냅니다.
- 평균 1.5개 주변으로 약 1.13개 정도 변동합니다.

---

### 이항분포 추가 학습사항

#### 1. 이항분포의 특성

**적용 조건**:
1. 베르누이 시행: 각 시행은 성공/실패 두 가지 결과만 존재
2. 독립성: 각 시행은 서로 독립
3. 일정한 확률: 각 시행의 성공 확률 p는 동일
4. 고정된 시행 횟수: n이 미리 정해짐

**표기법**:
X ~ B(n, p) 또는 X ~ Bin(n, p)

#### 2. 이항분포의 주요 공식

**확률질량함수**:
P(X = x) = C(n,x) × p^x × (1-p)^(n-x), x = 0, 1, 2, ..., n

**누적분포함수**:
F(x) = P(X ≤ x) = Σᵢ₌₀^x C(n,i) × p^i × (1-p)^(n-i)

**기댓값**:
E(X) = n × p

**분산**:
Var(X) = n × p × (1-p) = n × p × q

**표준편차**:
σ(X) = √[n × p × (1-p)]

**최빈값(Mode)**:
- (n+1)p가 정수가 아닌 경우: ⌊(n+1)p⌋
- (n+1)p가 정수인 경우: (n+1)p와 (n+1)p-1 모두

**왜도(Skewness)**:
γ₁ = (1-2p) / √(npq)
- p < 0.5: 오른쪽 꼬리 (양의 왜도)
- p = 0.5: 대칭
- p > 0.5: 왼쪽 꼬리 (음의 왜도)

#### 3. 이항분포 확률 계산 예시

본 문제의 전체 확률분포:

| x | P(X=x) | 누적확률 F(x) |
|---|---|---|
| 0 | C(10,0)×(0.15)⁰×(0.85)¹⁰ = 0.1969 | 0.1969 |
| 1 | C(10,1)×(0.15)¹×(0.85)⁹ = 0.3474 | 0.5443 |
| 2 | C(10,2)×(0.15)²×(0.85)⁸ = 0.2759 | 0.8202 |
| 3 | C(10,3)×(0.15)³×(0.85)⁷ = 0.1298 | 0.9500 |
| 4 | C(10,4)×(0.15)⁴×(0.85)⁶ = 0.0401 | 0.9901 |
| 5 | C(10,5)×(0.15)⁵×(0.85)⁵ = 0.0085 | 0.9986 |
| 6~10 | 매우 작음 | ≈1.0000 |

**확인**:
- Σ P(X=x) = 1.0000
- E(X) = Σ x·P(X=x) = 1.5
- Var(X) = Σ x²·P(X=x) - [E(X)]² = 1.275

#### 4. 이항분포의 정규근사

**조건**: n이 크고 p가 0.5에 가까울 때 (일반적으로 np ≥ 5, nq ≥ 5)

**근사 공식**:
X ~ B(n, p) ≈ N(μ = np, σ² = npq)

**연속성 수정(Continuity Correction)**:
- P(X = x) ≈ P(x - 0.5 < X < x + 0.5)
- P(X ≤ x) ≈ P(X < x + 0.5)
- P(X ≥ x) ≈ P(X > x - 0.5)

**본 문제의 경우**:
- np = 10 × 0.15 = 1.5 < 5
- nq = 10 × 0.85 = 8.5 ≥ 5
- 조건 미충족으로 정규근사 부적절

#### 5. 이항분포의 포아송 근사

**조건**: n이 크고 p가 작을 때 (일반적으로 n ≥ 20, p ≤ 0.05, np < 5)

**근사 공식**:
X ~ B(n, p) ≈ Poisson(λ = np)

P(X = x) ≈ (λ^x × e^(-λ)) / x!

**본 문제의 경우**:
- n = 10 < 20: 조건 미충족
- p = 0.15 > 0.05: 조건 미충족
- 포아송 근사 부적절

### 품질관리에서의 이항분포 응용

#### 1. 샘플링검사 (Sampling Inspection)

**OC곡선 (Operating Characteristic Curve)**:
- 로트 부적합률 p에 대한 합격확률 Pa(p)
- Pa(p) = P(X ≤ c) = Σᵢ₌₀^c C(n,i)×p^i×(1-p)^(n-i)
- n: 샘플 크기, c: 합격판정개수

**예**: n=50, c=2인 샘플링검사
- Pa(0.01) = 0.986 (AQL 통과)
- Pa(0.10) = 0.112 (LTPD 불합격)

#### 2. 계수형 관리도

**np관리도**:
- 중심선 CL = np̄
- UCL = np̄ + 3√(np̄q̄)
- LCL = np̄ - 3√(np̄q̄) (음수면 0)

**p관리도**:
- 중심선 CL = p̄
- UCL = p̄ + 3√[p̄(1-p̄)/n]
- LCL = p̄ - 3√[p̄(1-p̄)/n] (음수면 0)

#### 3. 공정능력 평가

**부적합률 추정**:
- 표본 부적합률: p̂ = X/n
- 신뢰구간: p̂ ± z_(α/2)√[p̂(1-p̂)/n]

**예**: 본 문제에서 3개 부적합 발견 시
- 추정 부적합률: p̂ = 3/10 = 0.30
- 실제 부적합률 p=0.15보다 높게 나타남 (표본 변동)

#### 4. 신뢰성 시험

**이항 신뢰성 시험**:
- n개 제품을 시험하여 x개 고장 관측
- 신뢰도 추정: R̂ = (n-x)/n
- 신뢰구간 설정

**가설검정**:
- H₀: p ≤ p₀ (부적합률이 기준 이하)
- H₁: p > p₀ (부적합률이 기준 초과)
- 검정통계량: X ~ B(n, p₀)

### 계산 팁 및 유의사항

#### 1. 조합 계산

**작은 수의 조합**:
C(n,x) = n! / [x!(n-x)!]

**계산 팁**:
- C(n,x) = C(n, n-x) 활용
- C(10,3) = C(10,7) = (10×9×8)/(3×2×1)
- 분자와 분모를 동시에 약분

#### 2. 거듭제곱 계산

**작은 수의 거듭제곱**:
- 0.85⁷을 직접 계산하기보다는
- 계산기 사용 또는 로그 활용

**로그 활용**:
- log(0.85⁷) = 7 × log(0.85)
- 0.85⁷ = 10^(7×log(0.85))

#### 3. 소수점 처리

**문제 요구사항**: 소수점 셋째자리에서 반올림하여 둘째자리까지

**주의사항**:
- 중간 계산은 충분한 유효숫자 유지
- 최종 답안만 반올림
- 0.129833... → 0.13 (올바름)
- 0.129 → 0.13 (중간에 반올림하면 오차 발생 가능)

#### 4. 계산 검증

**확률의 성질 확인**:
- 0 ≤ P(X=x) ≤ 1
- Σ P(X=x) = 1

**기댓값과 분산의 관계**:
- Var(X) = E(X²) - [E(X)]²
- E(X²) = Var(X) + [E(X)]²
- 본 문제: E(X²) = 1.275 + 1.5² = 3.525

### 관련 개념 확장

#### 베르누이 분포 (Bernoulli Distribution)

**정의**: n=1인 이항분포
- X ~ Bernoulli(p)
- P(X=1) = p, P(X=0) = 1-p
- E(X) = p, Var(X) = p(1-p)

#### 기하분포 (Geometric Distribution)

**정의**: 첫 성공까지의 시행 횟수
- P(X=x) = (1-p)^(x-1) × p
- E(X) = 1/p, Var(X) = (1-p)/p²

#### 음이항분포 (Negative Binomial Distribution)

**정의**: r번째 성공까지의 시행 횟수
- r=1일 때 기하분포와 동일

#### 초기하분포 (Hypergeometric Distribution)

**정의**: 비복원추출에서의 성공 횟수
- 이항분포는 복원추출 또는 N>>n일 때 근사
- P(X=x) = C(K,x)×C(N-K,n-x) / C(N,n)
