### 【문제 2 - (1)】 모수인자와 변량인자 설명 (4점)

#### 1. 모수인자 (Fixed Factor, 고정인자)

**정의**: 실험자가 의도적으로 선택하고 통제할 수 있는 인자로, 실험에서 다루는 수준(level)이 모집단의 전체를 대표합니다.

**특징**:
- 실험 결과의 추론이 선택된 수준에만 국한됩니다.
- 인자의 수준을 실험자가 의도적으로 선정합니다.
- 특정 조건에서의 효과를 평가하는 것이 목적입니다.

**예시**:
- 특정 기계 3대(A, B, C)의 성능 비교
- 정해진 온도 조건(100℃, 150℃, 200℃)의 효과
- 특정 작업자의 숙련도 비교

#### 2. 변량인자 (Random Factor, 확률인자)

**정의**: 실험에서 다루는 수준이 모집단에서 무작위로 추출된 표본으로 간주되는 인자입니다.

**특징**:
- 실험 결과를 전체 모집단으로 일반화할 수 있습니다.
- 인자의 수준이 무작위로 추출됩니다.
- 변동성(분산)의 크기를 평가하는 것이 목적입니다.

**예시**:
- 공장의 전체 기계 중 무작위로 선택한 3대
- 여러 로트(lot) 중 무작위로 선택한 샘플
- 전체 작업자 중 무작위로 선택한 작업자

#### 3. 두 인자의 비교

### 【문제 2 - (2)】 실험계획의 5가지 기본원리 (10점)

#### 1. 반복의 원리 (Replication, 되풀이의 원리)

**정의**: 동일한 조건에서 실험을 여러 번 반복하여 실시하는 것입니다.

**목적 및 효과**:
- 실험오차의 추정이 가능합니다.
- 추정의 정밀도를 향상시킵니다.
- 우연오차의 영향을 감소시킵니다.
- 통계적 검정의 신뢰성을 높입니다.

**주의사항**: 진반복(true replication)이어야 하며, 단순한 측정 반복과는 구별됩니다.

#### 2. 무작위화의 원리 (Randomization)

**정의**: 실험의 순서나 실험단위의 배치를 무작위로 결정하는 것입니다.

**목적 및 효과**:
- 계통오차(systematic error)를 우연오차로 전환합니다.
- 알려지지 않은 교란인자의 영향을 배제합니다.
- 실험의 독립성을 확보합니다.
- 통계적 검정의 타당성을 보장합니다.

**적용 예**:
- 실험 순서의 무작위 배정
- 실험 재료의 무작위 할당
- 측정 순서의 무작위화

#### 3. 국소관리의 원리 (Local Control, 블록화의 원리)

**정의**: 실험단위를 동질적인 그룹(블록)으로 나누어 블록 내에서 실험을 실시하는 것입니다.

**목적 및 효과**:
- 알려진 교란요인의 영향을 제거하거나 감소시킵니다.
- 실험오차를 감소시켜 실험의 정밀도를 향상시킵니다.
- 블록 간 변동을 분리하여 순수한 처리 효과를 평가합니다.

**적용 예**:
- 시간대별 블록 구성
- 원료 로트별 블록 구성
- 작업자별 블록 구성

#### 4. 교락의 원리 (Confounding)

**정의**: 실험의 효율을 높이기 위해 관심이 적은 교호작용을 블록 효과와 의도적으로 혼동시키는 것입니다.

**목적 및 효과**:
- 블록의 크기를 줄여 실험을 효율적으로 실시합니다.
- 중요한 주효과는 보존하면서 덜 중요한 교호작용을 희생합니다.
- 실험 비용과 시간을 절감합니다.

**주의사항**: 중요한 효과가 교락되지 않도록 주의해야 합니다.

#### 5. 직교성의 원리 (Orthogonality)

**정의**: 인자 간의 효과를 독립적으로 추정할 수 있도록 실험을 설계하는 것입니다.

**목적 및 효과**:
- 각 인자의 효과를 서로 독립적으로 추정할 수 있습니다.
- 분산분석이 간단하고 명료해집니다.
- 인자 간 상관관계를 제거합니다.
- 분석의 효율성이 극대화됩니다.

**특징**: 직교배열표를 사용하면 직교성이 보장됩니다.

### 【문제 2 - (3)】 결측치 추정 및 수정항 계산 (8점)

#### 1. 결측치 추정 공식

반복이 없는 이원배치법에서 결측치는 다음 공식으로 추정합니다:

**y = (a × Bᵢ' + b × Aⱼ' - T') / [(a-1)(b-1)]**

여기서:
- a: 인자 A의 수준 수
- b: 인자 B의 수준 수
- Bᵢ': 결측치가 속한 행의 합
- Aⱼ': 결측치가 속한 열의 합
- T': 결측치를 제외한 전체 합

#### 2. 필요한 값 계산

**인자 A(온도)의 수준 수**: a = 4
**인자 B(습도)의 수준 수**: b = 3

**B₂(2행)의 합**: B₂' = 26 + 25 + 31 = 82

**A₃(3열)의 합**: A₃' = 27 + 29 = 56

**전체 합**: T' = 21 + 28 + 27 + 29 + 26 + 25 + 31 + 27 + 30 + 29 + 35
T' = 308

#### 3. 결측치 y 계산

y = (a × B₂' + b × A₃' - T') / [(a-1)(b-1)]
y = (4 × 82 + 3 × 56 - 308) / [(4-1)(3-1)]
y = (328 + 168 - 308) / [(3)(2)]
y = 188 / 6
y = 31.333...
y ≈ **31.33** (소수점 셋째자리에서 반올림)

#### 4. 수정항(CT) 계산

결측치 y = 31.33을 대입한 후 전체 합을 계산합니다.

**총합(T)** = T' + y = 308 + 31.33 = 339.33

**전체 데이터 수(N)** = a × b = 4 × 3 = 12

**수정항(CT)** = T² / N
= (339.33)² / 12
= 115,144.8489 / 12
= 9,595.40407...
≈ **9,595.40** (소수점 셋째자리에서 반올림)

#### 답안
- **결측치 y = 31.33**
- **수정항 CT = 9,595.40**

### 【문제 2 - (4)】 오차항 가정의 4가지 특징 (8점)

모수모형 실험의 데이터 식 xᵢⱼ = μ + aᵢ + bⱼ + eᵢⱼ에서 오차항 eᵢⱼ ~ N(0, σₑ²)의 가정은 다음 4가지 특징을 가집니다:

#### 1. 정규성 (Normality)

**내용**: 오차항 eᵢⱼ는 정규분포를 따릅니다.

**의미**:
- 각 관측값의 오차는 정규분포 N(0, σₑ²)를 따릅니다.
- 이는 F-검정과 t-검정의 이론적 근거가 됩니다.

**검정 방법**:
- 정규확률지(Normal probability plot)
- Shapiro-Wilk 검정
- Anderson-Darling 검정

**위배 시 영향**: 검정 결과의 신뢰성이 저하될 수 있습니다.

#### 2. 독립성 (Independence)

**내용**: 오차항들은 서로 독립적입니다.

**의미**:
- 한 관측값의 오차가 다른 관측값의 오차에 영향을 주지 않습니다.
- Cov(eᵢⱼ, eₖₗ) = 0 (i≠k 또는 j≠l일 때)

**확보 방법**:
- 무작위화(randomization) 원리 적용
- 실험 순서의 무작위 배정
- 독립적인 실험 환경 유지

**위배 시 영향**:
- 자기상관(autocorrelation) 발생
- 검정통계량의 분포가 왜곡됩니다.

#### 3. 등분산성 (Homoscedasticity, 분산의 균일성)

**내용**: 모든 오차항의 분산이 동일합니다.

**의미**:
- Var(eᵢⱼ) = σₑ² (모든 i, j에 대해 동일)
- 처리나 수준에 관계없이 오차의 변동이 일정합니다.

**검정 방법**:
- Bartlett 검정
- Levene 검정
- 잔차도(residual plot) 분석

**위배 시 영향**:
- F-검정의 검정력이 감소합니다.
- 신뢰구간이 부정확해집니다.

**대응 방법**: 변환(transformation) 적용 (로그변환, 제곱근변환 등)

#### 4. 평균이 0 (Zero Mean)

**내용**: 오차항의 기댓값은 0입니다.

**의미**:
- E(eᵢⱼ) = 0
- 계통적 편의(systematic bias)가 없습니다.
- 오차는 양(+)과 음(-)의 방향으로 균형을 이룹니다.

**중요성**:
- 모형의 불편추정량(unbiased estimator) 확보
- 잔차의 합이 0이 되도록 보장
- 모수 추정의 정확성 확보

**확인 방법**: 잔차의 평균이 0에 가까운지 확인

### 실험계획 관련 추가 학습사항

#### 분산분석(ANOVA)의 기본 가정

1. 정규성: 각 그룹의 데이터가 정규분포를 따름
2. 독립성: 관측값들이 서로 독립적
3. 등분산성: 모든 그룹의 분산이 동일

이 세 가지 가정이 만족되어야 F-검정이 타당합니다.

#### 이원배치법의 분산분석표 구조

| 요인 | 제곱합(SS) | 자유도(df) | 평균제곱(MS) | F값 |
|---|---|---|---|---|
| 인자 A | SSₐ | a-1 | MSₐ | MSₐ/MSₑ |
| 인자 B | SSᵦ | b-1 | MSᵦ | MSᵦ/MSₑ |
| 오차 | SSₑ | (a-1)(b-1) | MSₑ | - |
| 합계 | SSₜ | ab-1 | - | - |

### 답안 작성 팁

1. **인자 구분**: 모수인자와 변량인자는 '선택 방법'과 '추론 범위'를 중심으로 대비하여 설명합니다.

2. **기본원리 5가지**: 각 원리의 정의, 목적, 효과를 명확히 기술해야 합니다. 특히 무작위화와 국소관리는 자주 출제되므로 차이점을 정확히 이해해야 합니다.

3. **결측치 계산**: 공식을 정확히 기억하고, 각 항의 의미(Bᵢ', Aⱼ', T')를 이해해야 합니다. 계산 과정을 단계별로 명확히 표시합니다.

4. **오차항 가정**: 정규성, 독립성, 등분산성, 평균 0의 네 가지를 체계적으로 설명하되, 각각의 검정 방법이나 위배 시 영향까지 언급하면 좋습니다.

5. **수식 표기**: 수학 기호와 통계 용어를 정확히 사용하여 전문성을 드러냅니다.
