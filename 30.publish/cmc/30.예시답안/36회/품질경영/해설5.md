## 36회 품질경영 문제 5 예시답안

### 【문제 5 - (1)】 신뢰도함수와 고장률함수 설명 (6점)

#### 1. 신뢰도함수 R(t) (Reliability Function)

**정의**: 제품이나 시스템이 시간 t까지 정상적으로 작동할 확률을 나타내는 함수입니다.

**수식**:
- R(t) = P(T > t)
- 여기서 T는 고장시간(수명)을 나타내는 확률변수

**특성**:
1. **초기값**: R(0) = 1 (시작 시점에서는 모두 정상)
2. **최종값**: R(∞) = 0 (무한 시간 후에는 모두 고장)
3. **단조감소**: dR(t)/dt ≤ 0 (시간이 지날수록 신뢰도 감소)
4. **범위**: 0 ≤ R(t) ≤ 1

**의미**:
- R(t) = 0.9: 시간 t까지 90%가 정상 작동
- R(t) = 0.5: 시간 t에서 절반이 고장 (평균수명)

**고장분포함수와의 관계**:
- F(t) = P(T ≤ t) = 1 - R(t)
- R(t) = 1 - F(t)
- F(t)는 시간 t까지 고장날 누적확률

**평균수명과의 관계**:
- MTTF (Mean Time To Failure) = ∫₀^∞ R(t)dt
- 신뢰도함수를 적분하면 평균수명

**실무 활용**:
- 보증기간 설정: R(t) ≥ 0.95가 되는 t를 보증기간으로 설정
- 예방보전 계획: R(t)가 일정 수준 이하로 떨어지기 전 교체
- 신뢰성 목표 설정: 특정 시간에서의 목표 신뢰도 설정

#### 2. 고장률함수 h(t) (Hazard Rate Function, Failure Rate Function)

**정의**: 시간 t까지 정상 작동한 제품이 시간 t 직후의 미소시간 동안 고장날 순간고장률을 나타내는 함수입니다.

**수식**:
- h(t) = f(t) / R(t)
- 또는 h(t) = -dR(t)/dt / R(t) = -d[ln R(t)]/dt

**의미**:
- 조건부 고장확률의 순간 비율
- 시간 t까지 생존한 것을 전제로 한 순간 고장률
- 단위: 고장/시간 (예: 고장/시간, 고장/1000시간)

**특성**:
1. **비율**: 0 ≤ h(t) < ∞ (확률이 아니므로 1을 초과 가능)
2. **시간 의존성**: 시간에 따라 증가, 감소, 일정 가능
3. **조건부 확률**: t까지 생존을 전제

**욕조곡선 (Bathtub Curve)**:

```
고장률
h(t)
 ↑
 │＼              ______
 │  ＼          /
 │    ＼______/
 │
 │  초기    우발      마모
 │  고장기  고장기    고장기
 └────────────────────────→ 시간(t)
    DFR     CFR       IFR
```

**3단계 분류**:
1. **초기고장기 (DFR, Decreasing Failure Rate)**:
   - 고장률 감소 구간
   - 설계 결함, 제조 불량, 초기 고장
   - 번인(Burn-in) 테스트로 제거

2. **우발고장기 (CFR, Constant Failure Rate)**:
   - 고장률 일정 구간
   - 우연한 외부 요인에 의한 고장
   - 가장 긴 기간 (정상 사용 기간)
   - 지수분포를 따름: h(t) = λ (상수)

3. **마모고장기 (IFR, Increasing Failure Rate)**:
   - 고장률 증가 구간
   - 물리적 마모, 노화, 피로에 의한 고장
   - 예방보전, 부품 교체 필요

**고장분포별 고장률**:

| 분포 | 고장률 h(t) | 특징 |
|---|---|---|
| 지수분포 | λ (상수) | 우발고장, 기억 없음 |
| 와이블(β<1) | 감소 | 초기고장 |
| 와이블(β=1) | 일정 | 우발고장 (지수분포와 동일) |
| 와이블(β>1) | 증가 | 마모고장 |
| 정규분포 | 증가 | 마모고장 |

**실무 활용**:
- 보전전략 수립: 고장률 패턴에 따른 보전 방법 선택
- 수명 예측: 고장률 증가 추세 분석
- 품질 개선: 초기고장기 단축, 우발고장기 연장
- 교체 시기 결정: 마모고장기 진입 전 교체

#### 3. 신뢰도함수와 고장률함수의 관계

**기본 관계식**:
1. h(t) = f(t) / R(t)
2. h(t) = -dR(t)/dt / R(t)
3. R(t) = exp[-∫₀^t h(u)du]
4. f(t) = h(t) × R(t)

**관계식 유도**:
- 고장밀도함수: f(t) = dF(t)/dt = -dR(t)/dt
- 고장률함수: h(t) = f(t)/R(t) = [-dR(t)/dt]/R(t)
- 적분: ∫₀^t h(u)du = -ln R(t)
- 신뢰도함수: R(t) = exp[-∫₀^t h(u)du]

**주요 함수 간 관계**:

```
f(t) ←──────→ F(t) = 1 - R(t)
 ↓                      ↓
h(t) ←──────────────→ R(t)
```

- f(t): 고장밀도함수 (확률밀도함수)
- F(t): 고장분포함수 (누적분포함수)
- R(t): 신뢰도함수 (생존함수)
- h(t): 고장률함수 (위험률함수)

### 【문제 5 - (2)】 신뢰도함수와 고장률함수 계산 (4점)

주어진 고장밀도함수: **f(t) = λe^(-λt)**

이는 **지수분포**의 확률밀도함수입니다.

#### 1. 신뢰도함수 R(t) 계산

**방법 1: 정의를 이용한 계산**

R(t) = P(T > t) = ∫ₜ^∞ f(u)du

= ∫ₜ^∞ λe^(-λu)du

= λ × [-1/λ × e^(-λu)]ₜ^∞

= λ × [-1/λ × (0 - e^(-λt))]

= λ × [e^(-λt)/λ]

= **e^(-λt)**

**방법 2: 고장분포함수를 이용한 계산**

F(t) = ∫₀^t f(u)du = ∫₀^t λe^(-λu)du

= λ × [-1/λ × e^(-λu)]₀^t

= -e^(-λt) + e^0

= 1 - e^(-λt)

R(t) = 1 - F(t) = 1 - (1 - e^(-λt))

= **e^(-λt)**

#### 답안: **R(t) = e^(-λt)**

#### 2. 고장률함수 h(t) 계산

**방법 1: 정의를 이용한 계산**

h(t) = f(t) / R(t)

= λe^(-λt) / e^(-λt)

= **λ**

**방법 2: 신뢰도함수의 미분을 이용한 계산**

h(t) = -dR(t)/dt / R(t)

dR(t)/dt = d[e^(-λt)]/dt = -λe^(-λt)

h(t) = -(-λe^(-λt)) / e^(-λt)

= λe^(-λt) / e^(-λt)

= **λ**

**방법 3: 적분 관계식을 이용한 검증**

R(t) = exp[-∫₀^t h(u)du]

만약 h(t) = λ라면:

∫₀^t h(u)du = ∫₀^t λdu = λt

R(t) = exp[-λt] = e^(-λt) ✓ (일치)

#### 답안: **h(t) = λ** (상수)

### 지수분포의 특성 및 의미

#### 1. 지수분포의 특징

**확률밀도함수**: f(t) = λe^(-λt), t ≥ 0

**신뢰도함수**: R(t) = e^(-λt)

**고장률함수**: h(t) = λ (상수)

**평균수명(MTTF)**:
- MTTF = ∫₀^∞ t·f(t)dt = 1/λ
- 또는 MTTF = ∫₀^∞ R(t)dt = 1/λ

**분산**:
- Var(T) = 1/λ²

**특성**:
- 고장률이 일정 (CFR, Constant Failure Rate)
- 무기억성(Memoryless Property): P(T > s+t | T > s) = P(T > t)
- 우발고장 모델링에 적합

#### 2. 무기억성 (Memoryless Property)

**의미**: 과거의 사용 이력이 미래의 고장에 영향을 주지 않습니다.

**수식**:
- P(T > s+t | T > s) = P(T > t)
- "s 시간까지 작동했다는 조건 하에 추가 t 시간 작동할 확률" = "처음부터 t 시간 작동할 확률"

**증명**:
P(T > s+t | T > s) = P(T > s+t) / P(T > s)
= e^(-λ(s+t)) / e^(-λs)
= e^(-λt)
= P(T > t) ✓

**실무적 의미**:
- 1년 사용한 제품이나 새 제품이나 고장 확률 동일
- 예방보전의 효과가 없음 (우발고장은 예측 불가)
- 고장 시 수리보다 교체가 효과적

#### 3. 신뢰도 계산 예시

**예제**: λ = 0.001 (고장/시간)일 때

| 시간 t | 신뢰도 R(t) = e^(-0.001t) | 의미 |
|---|---|---|
| 0 | 1.000 | 100% 작동 |
| 100 | 0.905 | 90.5% 작동 |
| 693 | 0.500 | 50% 작동 (중위수명) |
| 1000 | 0.368 | 36.8% 작동 (평균수명) |
| 2000 | 0.135 | 13.5% 작동 |

**평균수명**: MTTF = 1/λ = 1/0.001 = 1000 시간

**중위수명**: T₀.₅ = -ln(0.5)/λ = 0.693/λ = 693 시간

#### 4. 실무 응용

**적용 분야**:
- 전자부품의 우발고장
- 기계 부품의 우연 고장
- 사고 발생 모델
- 대기행렬 이론 (고객 도착 시간 간격)

**신뢰성 설계**:
- 병렬 시스템: R_sys = 1 - (1-R₁)(1-R₂)...
- 직렬 시스템: R_sys = R₁ × R₂ × ...
- 지수분포의 직렬: R_sys = e^(-λ₁t) × e^(-λ₂t) = e^(-(λ₁+λ₂)t)

**보전 전략**:
- CFR 구간: 사후보전(CM, Corrective Maintenance)
- 예방보전 효과 없음
- 고장 시 신속한 복구가 중요
- 예비품 확보 필요

### 신뢰성 함수 종합 정리

#### 주요 신뢰성 함수 관계도

```
고장밀도함수 f(t) ────미분───→ dF(t)/dt
        │                          │
        │                          │
    h(t)=f(t)/R(t)            적분 ↓
        │                          │
        ↓                          │
고장률함수 h(t) ←──────────── 고장분포함수 F(t)
        │                          │
    적분 │                     1-F(t)
        │                          │
        ↓                          ↓
   -ln R(t)  ←─────────────── 신뢰도함수 R(t)
```

#### 주요 분포의 신뢰성 함수

| 분포 | f(t) | R(t) | h(t) | MTTF |
|---|---|---|---|---|
| 지수 | λe^(-λt) | e^(-λt) | λ | 1/λ |
| 와이블 | (β/η)(t/η)^(β-1)e^(-(t/η)^β) | e^(-(t/η)^β) | (β/η)(t/η)^(β-1) | ηΓ(1+1/β) |
| 정규 | 복잡 | 1-Φ((t-μ)/σ) | f(t)/R(t) | μ |
| 레일리 | (t/α²)e^(-t²/2α²) | e^(-t²/2α²) | t/α² | α√(π/2) |

### 답안 작성 팁

1. **신뢰도함수 설명**: 정의, 특성(초기값=1, 최종값=0, 단조감소), 의미를 명확히 합니다.

2. **고장률함수 설명**: 조건부 고장확률의 개념과 욕조곡선(초기/우발/마모 고장기)을 언급하면 좋습니다.

3. **함수 간 관계**: h(t) = f(t)/R(t) 관계식을 반드시 제시합니다.

4. **계산 과정**: 적분 계산 과정을 단계별로 명확히 표시하여 부분점수를 확보합니다.

5. **지수분포 특성**: 계산 결과가 지수분포임을 인지하고, 고장률이 상수(λ)라는 의미를 설명하면 가산점이 있을 수 있습니다.

6. **검증**: 계산 결과를 관계식에 대입하여 검증하는 과정을 보여주면 좋습니다.
