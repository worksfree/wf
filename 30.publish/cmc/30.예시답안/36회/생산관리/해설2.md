# 제36회 경영지도사 생산관리 - 문제 2

## 프로세스 관리 - 자원이용률과 산출물

### 문제 요약
A 레스토랑의 주문 충족 프로세스 분석:
- (1) 각 작업활동별 자원이용률 계산
- (2) 작업활동 3의 이용률을 100% 이하로 낮추기 위한 셰프 수
- (3) 자원 증가 시 산출물 증가량
- (4) Little's Law를 이용한 재공품재고 계산

---

## 📋 1. 프로세스 관리 기본 개념

### (1) 자원이용률 (Resource Utilization)

#### 정의
```
자원이용률 = 도착률 × 활동시간 / 자원의 수
          = (주문도착률 × 평균소요시간) / 자원수
```

**의미**
- 자원이 실제로 사용되는 비율 (0~1 또는 0~100%)
- 100% 초과 시: 병목 발생, 대기열 무한 증가
- 100%: 임계 상태
- 100% 미만: 정상 운영

### (2) 병목 (Bottleneck)

```
병목 = 가용능력이 가장 낮은 자원
     = 이용률이 가장 높은 자원
```

**특성**
- 전체 프로세스의 산출률 결정
- 병목 개선 → 전체 산출률 증가
- 비병목 개선 → 산출률 불변 (낭비)

### (3) 프로세스 산출률 (Throughput Rate)

```
산출률 = min(도착률, 가용능력)
가용능력 = 자원수 / 활동시간
```

### (4) Little's Law

```
재공품재고(WIP) = 산출률(R) × 흐름시간(T)
I = R × T
```

**조건**: 안정 상태 (steady state)

## 🧮 2. 문제 (1) 풀이: 자원이용률 계산

### 주어진 데이터

| 작업활동 | 업무 | 도착률 (R) | 소요시간 (분) | 자원수 (c) |
|---------|------|-----------|-------------|----------|
| 1 | 주문 확인 | 20/시간 | 1 | 1 셰프 |
| 2 | 식자재 선택 및 주 요리 | 20/시간 | 6 | 1 셰프 |
| 3 | 사이드 요리 | 20/시간 | 12 | 1 셰프 |
| 4 | 오븐 작업 | 20/시간 | 10 | 2 오븐 |
| 5 | 세팅 작업 | 20/시간 | 3 | 1 셰프 |

### 계산 과정

#### 작업활동 1: 주문 확인

```
도착률 = 20주문/시간 = 20/60 = 0.333 주문/분
소요시간 = 1분
자원수 = 1

이용률 = (0.333 × 1) / 1
      = 0.333
      = 33.33%
```

**답**: 33.33%

#### 작업활동 2: 식자재 선택 및 주 요리

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 6분
자원수 = 1

이용률 = (0.333 × 6) / 1
      = 2.0
      = 200.00%
```

**답**: 200.00%

#### 작업활동 3: 사이드 요리

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 12분
자원수 = 1

이용률 = (0.333 × 12) / 1
      = 4.0
      = 400.00%
```

**답**: 400.00%

#### 작업활동 4: 오븐 작업

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 10분
자원수 = 2

이용률 = (0.333 × 10) / 2
      = 3.333 / 2
      = 1.667
      = 166.67%
```

**답**: 166.67%

#### 작업활동 5: 세팅 작업

```
도착률 = 20/60 = 0.333 주문/분
소요시간 = 3분
자원수 = 1

이용률 = (0.333 × 3) / 1
      = 1.0
      = 100.00%
```

**답**: 100.00%

### 결과 요약

| 작업활동 | 업무 | 이용률 | 상태 |
|---------|------|--------|------|
| 1 | 주문 확인 | **33.33%** | 정상 |
| 2 | 주 요리 | **200.00%** | 과부하 ⚠️ |
| 3 | 사이드 요리 | **400.00%** | **병목** 🔴 |
| 4 | 오븐 작업 | **166.67%** | 과부하 ⚠️ |
| 5 | 세팅 작업 | **100.00%** | 임계 |

**병목 공정**: 작업활동 3 (이용률 400%, 가장 높음)

## 📊 3. 문제 (2) 풀이: 필요 셰프 수

### 문제
작업활동 3의 이용률을 100% 이하로 낮추기 위한 최소 셰프 수는?

### 계산

#### 이용률 공식 변형
```
이용률 = (도착률 × 소요시간) / 자원수 ≤ 100%
자원수 ≥ 도착률 × 소요시간
```

#### 필요 자원수 계산
```
자원수 ≥ (20/60) × 12
       ≥ 0.333 × 12
       ≥ 4.0
```

**답**: 최소 **4명의 셰프** 필요

### 검증
```
4명 투입 시 이용률:
= (20/60 × 12) / 4
= 4.0 / 4
= 1.0
= 100% ✓

3명 투입 시 이용률:
= (20/60 × 12) / 3
= 4.0 / 3
= 133.33% ✗ (여전히 100% 초과)
```

## 🎯 4. 문제 (3) 풀이: 산출물 증가 분석

### 시나리오
- 작업활동 3: 1명 → 3명 셰프
- 작업활동 4: 2대 → 4대 오븐

### 1단계: 현재 프로세스 산출률

#### 각 활동별 가용능력

```
가용능력 = 자원수 / 소요시간 (주문/분)
        = 자원수 / 소요시간 × 60 (주문/시간)
```

**작업활동 1**
```
가용능력 = 1셰프 / 1분 = 1주문/분 = 60주문/시간
```

**작업활동 2**
```
가용능력 = 1셰프 / 6분 = 0.167주문/분 = 10주문/시간
```

**작업활동 3**
```
가용능력 = 1셰프 / 12분 = 0.083주문/분 = 5주문/시간 ← 최소 (병목)
```

**작업활동 4**
```
가용능력 = 2오븐 / 10분 = 0.2주문/분 = 12주문/시간
```

**작업활동 5**
```
가용능력 = 1셰프 / 3분 = 0.333주문/분 = 20주문/시간
```

#### 현재 프로세스 산출률
```
현재 산출률 = min(60, 10, 5, 12, 20)
          = 5주문/시간
```

### 2단계: 개선 후 프로세스 산출률

#### 변경된 가용능력

**작업활동 3** (1명 → 3명)
```
새 가용능력 = 3셰프 / 12분
           = 0.25주문/분
           = 15주문/시간
```

**작업활동 4** (2대 → 4대)
```
새 가용능력 = 4오븐 / 10분
           = 0.4주문/분
           = 24주문/시간
```

#### 새로운 프로세스 산출률
```
새 산출률 = min(60, 10, 15, 24, 20)
         = 10주문/시간
```

**새로운 병목**: 작업활동 2 (주 요리, 10주문/시간)

### 3단계: 산출물 증가량 계산

```
증가량 = 새 산출률 - 현재 산출률
      = 10 - 5
      = 5주문/시간
```

**증가율**
```
증가율 = (증가량 / 현재 산출률) × 100%
      = (5 / 5) × 100%
      = 100%
```

**답**: 산출물이 **5주문/시간 증가** (100% 증가)

### 결과 비교표

| 구분 | 현재 | 개선 후 | 변화 |
|------|------|---------|------|
| **작업 3 자원** | 1명 | 3명 | +2명 |
| **작업 3 능력** | 5/시간 | 15/시간 | +10/시간 |
| **작업 4 자원** | 2대 | 4대 | +2대 |
| **작업 4 능력** | 12/시간 | 24/시간 | +12/시간 |
| **병목** | 작업 3 | 작업 2 | 변경 |
| **프로세스 산출률** | 5/시간 | 10/시간 | **+5/시간** |

## 💡 5. 문제 (4) 풀이: 재공품재고

### 주어진 조건
- 평균 산출물(throughput): 12주문/시간
- 평균 프로세스 처리시간(flow time): 10분

### Little's Law 적용

```
WIP = R × T
```

**여기서**
- WIP: 재공품재고 (Work In Process)
- R: 산출률 (Throughput Rate)
- T: 흐름시간 (Flow Time)

### 단위 통일

#### 방법 1: 시간 단위로 통일
```
R = 12주문/시간
T = 10분 = 10/60시간 = 1/6시간

WIP = 12 × (1/6)
    = 2주문
```

#### 방법 2: 분 단위로 통일
```
R = 12주문/시간 = 12/60 = 0.2주문/분
T = 10분

WIP = 0.2 × 10
    = 2주문
```

**답**: 평균 재공품재고 = **2주문**

### 의미 해석

```
재공품재고 = 2주문

의미:
- 평균적으로 2개의 주문이 프로세스 내에서 처리 중
- 주문 1: 조리 중
- 주문 2: 대기 또는 다른 단계 처리 중
```

## 📈 6. 종합 분석 및 경영 시사점

```
활동별 이용률:

작업 2: 200% (과부하 100%)
작업 3: 400% (과부하 300%) ← 최악
작업 4: 167% (과부하 67%)
```

**문제**
- 작업 1: 자원 낭비 (대부분 유휴)
- 작업 2, 3, 4: 100% 초과 → 대기열 발생, 서비스 지연
- 불균형한 자원 배분

#### 우선순위 결정 원칙
```
1순위: 최대 병목 (작업 3, 400%)
2순위: 차순위 병목 (작업 2, 200%)
3순위: 3차 병목 (작업 4, 167%)
```

```
투입: +3명 셰프
```

```
투입: +1명 셰프
효과: 10 → 12주문/시간 (+20%)
비용 대비 효과: 중간 ⭐⭐
```

**작업 4 개선** (2대 → 4대)
```
투입: +2대 오븐

- 작업 3 미개선 시: 없음
- 작업 3 개선 후: 추가 효과 제공

```

### (3) 최적 자원 배치 전략

#### 단계적 개선 방안

**1단계: 병목 해소**
```
작업 3: 1명 → 4명 (+3명)
목표: 이용률 100% 이하

결과:
- 프로세스 산출률: 5 → 10주문/시간
- 새 병목: 작업 2
```

**2단계: 차순위 병목 개선**
```
작업 2: 1명 → 2명 (+1명)
목표: 이용률 100% 이하

가용능력 = 2/6분 = 20주문/시간
새 이용률 = (10 × 6) / 2 = 300% → 여전히 높음
→ 3명 필요: (10 × 6) / 3 = 200%
→ 4명 필요: (10 × 6) / 4 = 150%
→ 5명 필요: (10 × 6) / 5 = 120%
→ 6명 필요: (10 × 6) / 6 = 100% ✓

결과:
- 프로세스 산출률: 10 → 20주문/시간
- 새 병목: 작업 5
```

**3단계: 균형 조정**
```
작업 5: 1명 → 필요 인원
도착률 20/시간 시:
필요 자원 = (20 × 3) / 60 = 1명 (현재 충분)

20주문/시간 시:
필요 자원 = (20/60 × 3) = 1명 (현재 충분)

→ 추가 인력 불필요
```

**결과**

### (4) 수요-공급 균형

#### 도착률과 산출률 비교

```
현재 상황:
도착률: 20주문/시간
산출률:  5주문/시간
→ 공급 부족: 15주문/시간 (75%)

개선 후 (문제 3):
도착률: 20주문/시간
산출률: 10주문/시간
→ 공급 부족: 10주문/시간 (50%)

완전 개선 시:
도착률: 20주문/시간
산출률: 20주문/시간
→ 균형 달성 ✓
```

### (5) 대기 시간 분석

#### 현재 (산출률 5주문/시간)

```
도착률 > 산출률 → 불안정
대기열 지속 증가
→ 고객 불만, 주문 취소 발생
```

#### Little's Law로 추정

```
만약 안정 상태 가정:
산출률 = 5주문/시간
흐름시간 = 평가 필요

실제 도착: 20주문/시간
처리: 5주문/시간
→ 15주문/시간 처리 불가
→ 대기 시간 무한 증가 경향
```

### (6) 재공품재고 관리

#### Little's Law 활용

```
목표 WIP: 2주문 (문제 4)
산출률: 12주문/시간
→ 흐름시간 = WIP/R = 2/12시간 = 10분 ✓

적정 WIP 관리:
- WIP 과다: 혼잡, 품질 저하
- WIP 부족: 자원 유휴
- 적정 수준: 2~3주문 (본 사례)
```

## 🔍 7. 프로세스 개선 기법

### (1) 병목 관리 (TOC: Theory of Constraints)

#### 5단계 집중 개선

```
1. 제약 식별: 작업 3 (400% 이용률)
2. 제약 활용: 작업 3 유휴 시간 최소화
3. 제약에 동조: 다른 작업을 작업 3에 맞춤
4. 제약 완화: 자원 증가 (1→4명)
5. 반복: 새 제약(작업 2) 개선
```

### (2) 프로세스 재설계

#### 병렬 처리
```
현재: 순차 처리
개선: 일부 작업 병렬화

예:
작업 2(주 요리) ─┐
                 ├─→ 작업 5(세팅)
작업 3(사이드) ──┘

효과: 전체 시간 단축
```

#### 작업 재분배
```
작업 3(12분) 분할:
→ 작업 3a(6분) + 작업 3b(6분)
→ 2명이 각각 담당
→ 이용률 200%로 감소 (여전히 높지만 개선)
```

### (3) 유연성 확보

#### 다기능 인력
```
셰프 교차 훈련:
- 주 요리 + 사이드 요리 가능
- 피크 시간대 유연한 배치
- 이용률 균등화
```

#### 동적 자원 배분
```
시간대별 수요 변동 대응:
- 점심 피크: 작업 3에 인력 집중
- 한가한 시간: 작업 1, 5로 인력 이동
```

```
1. 공식 명시

4. 최종 답 강조
```

### 시간 관리
```
문제 2 (30점) 권장 시간: 25~30분

배분:
(1) 이용률 5개: 12분
(2) 최소 자원: 5분
(3) 산출물 분석: 10분
(4) Little's Law: 3분

```

```
✓ 시간 단위 일치 (분 ↔ 시간)

✓ Little's Law 단위 통일
```

```
✓ 병목이 전체 성능 결정

✓ 균형잡힌 자원 배치 중요
✓ 이용률 80~90% 목표 적정
```
