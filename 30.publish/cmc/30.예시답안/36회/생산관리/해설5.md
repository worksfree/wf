# 제36회 경영지도사 생산관리 - 문제 5

## 생산능력 확장 시 유의사항

### 문제 요약
장기적 생산능력 계획 수립 시, 생산능력 확장 시 유의해야 할 사항을 세 가지 기술하시오.

---

## 📋 1. 생산능력의 기본 개념

### (1) 생산능력(Capacity) 정의

```
생산능력 = 주어진 시간 내 생산할 수 있는 최대 산출량
```

**구분**
- **설계 능력**: 이론적 최대 생산량
- **유효 능력**: 현실적 최대 생산량 (정비, 휴게 고려)
- **실제 능력**: 현재 달성 중인 생산량

### (2) 생산능력 계획의 중요성

```
특징:
✓ 장기적 의사결정 (5~10년)
✓ 막대한 자본 투자
✓ 되돌리기 어려움 (비가역성)
✓ 전사적 영향
✓ 전략적 중요성
```

**영향 범위**
- 시장 대응 능력
- 원가 구조
- 경쟁 우위
- 재무 안정성
- 조직 구조

### (3) 생산능력 확장의 배경

```
확장 필요 상황:
- 수요 지속 증가
- 신규 시장 진출
- 제품 라인 확대
- 경쟁사 견제
- 규모의 경제 추구
```

## 💡 2. 생산능력 확장 시 유의사항

### 유의사항 1: 수요예측의 정확성 확보

#### (1) 핵심 내용

**수요예측의 중요성**
```
생산능력 = 수요 충족을 위한 투자
→ 수요예측 오류 = 투자 실패
```

**과잉 투자 위험**
```
수요 과대 예측 시:
- 유휴 설비 발생
- 고정비 부담 증가
- 자본 회수 지연
- 재무 건전성 악화
```

**과소 투자 위험**
```
수요 과소 예측 시:
- 시장 기회 상실
- 경쟁사에 시장 점유율 양보
- 고객 이탈
- 추가 증설 비용 발생
```

#### (2) 구체적 유의사항

**다각도 수요 분석**
```
✓ 과거 추세 분석
  - 시계열 분석
  - 성장률 패턴 파악
  - 계절성 고려

✓ 시장 조사
  - 고객 니즈 변화
  - 시장 규모 전망
  - 경쟁 환경 분석

✓ 거시경제 요인
  - GDP 성장률
  - 인구 변화
  - 산업 트렌드

✓ 제품 수명주기
  - 도입기, 성장기, 성숙기, 쇠퇴기
  - 기술 변화 속도
  - 대체재 출현 가능성
```

**시나리오 분석**
```
다중 시나리오 수립:

낙관적 시나리오 (P=30%)
- 수요 연평균 15% 성장
- 필요 능력: 150%

기준 시나리오 (P=50%)
- 수요 연평균 8% 성장
- 필요 능력: 120%

비관적 시나리오 (P=20%)
- 수요 연평균 3% 성장
- 필요 능력: 105%

→ 기대값 계산 및 위험 평가
```

**단계적 검증**
```
1단계: 초기 시장 테스트
2단계: 시범 생산
3단계: 본격 확장
→ 각 단계에서 수요 재검증
```

#### (3) 실무 사례

```
사례: 반도체 업체 A사
- 2020년: 수요 급증 예측 → 대규모 증설
- 2022년: 수요 급감 → 가동률 50%
- 결과: 3조원 투자 회수 난항

교훈: 단기 호황을 장기 추세로 오판
     → 보수적 증설 + 단계적 확장 필요
```

### 유의사항 2: 적절한 확장 시기 및 규모 결정

#### (1) 핵심 내용

**타이밍의 중요성**
```
너무 빠른 확장:
- 수요 미달 → 유휴 설비
- 자금 회수 지연

너무 늦은 확장:
- 기회 상실
- 리드타임으로 시장 대응 실패
```

**규모의 딜레마**
```
대규모 확장:
- 장점: 규모의 경제, 단가 절감
- 단점: 리스크 집중, 유연성 부족

소규모 확장:
- 장점: 리스크 분산, 유연성
- 단점: 규모의 불경제, 높은 단가
```

#### (2) 구체적 유의사항

**확장 시기 결정 요소**
```
✓ 현재 가동률
  - 80% 이상: 확장 검토 시작
  - 90% 이상: 확장 필요
  - 95% 이상: 긴급 확장

✓ 수요 증가 추세
  - 지속성: 3년 이상 지속적 증가
  - 안정성: 일시적 급증 vs 구조적 성장
  - 예측 신뢰도: 예측 정확도 평가

✓ 건설 리드타임
  - 공장 건설: 2~3년
  - 설비 도입: 1~2년
  - 시운전 기간: 3~6개월
  → 수요 발생 이전 착수 필요

✓ 경쟁 상황
  - 경쟁사 증설 계획
  - 시장 선점 필요성
  - 과당 경쟁 위험
```

**확장 규모 결정 방법**

**방법 1: 단계적 확장(Incremental)**
```
특징:
- 소규모 능력을 순차적 증설
- 수요 변화에 탄력적 대응

장점:
✓ 리스크 분산
✓ 학습 효과
✓ 유연성 확보

단점:
✗ 규모의 경제 제한
✗ 잦은 증설 비용
✗ 운영 복잡성

적용:
- 수요 불확실성 높음
- 기술 변화 빠름
- 자금 여력 제한
```

**방법 2: 일괄 확장(Lumpy)**
```
특징:
- 대규모 능력을 한 번에 증설
- 장기 수요 예측 기반

장점:
✓ 규모의 경제
✓ 단가 절감
✓ 관리 단순화

단점:
✗ 초기 유휴 설비
✗ 높은 리스크
✗ 유연성 부족

적용:
- 수요 예측 신뢰도 높음
- 규모의 경제 중요
- 자금 여력 충분
```

**방법 3: 선도적 확장(Leading)**
```
전략: 수요보다 앞서 확장

목적:
- 시장 선점
- 경쟁사 진입 억제
- 성장 촉진

위험:
- 초기 과잉 투자
- 수요 미충족 시 손실
```

**방법 4: 추종적 확장(Lagging)**
```
전략: 수요 확인 후 확장

목적:
- 위험 최소화
- 확실한 수요 기반

위험:
- 기회 상실
- 시장점유율 감소
```

#### (3) 실무 사례

```
사례 1: 현대자동차 (단계적 확장)
- 해외 공장: 소규모로 시작
- 수요 확인 후 점진적 증설
- 결과: 리스크 최소화

사례 2: 삼성전자 반도체 (선도적 대규모 확장)
- 시장 예측 기반 대규모 투자
- 경쟁사 진입 장벽 구축
- 결과: 시장 지배력 확보 (단, 높은 리스크)
```

### 유의사항 3: 재무적 타당성 및 투자 회수 계획

#### (1) 핵심 내용

**막대한 자본 투자**
```
생산능력 확장 투자 규모:
- 토지 구입
- 건물 건설
- 설비 구매
- 운전자본
→ 수백억~수조원
```

**투자 회수 기간**
```
장기 투자:
- 회수 기간: 5~10년
- 고정비 부담 지속
- 재무 레버리지 증가
```

#### (2) 구체적 유의사항

**재무 타당성 분석**

**방법 1: NPV (순현재가치)**
```
NPV = Σ(현금유입 / (1+r)^t) - 초기 투자

판단:
NPV > 0: 투자 가치 있음
NPV < 0: 투자 부적절

예시:
초기 투자: 100억원
연간 현금유입: 20억원 (10년)
할인율: 8%

NPV = 20억 × 6.71 - 100억
    = 134.2억 - 100억
    = 34.2억원 > 0 ✓
```

**방법 2: IRR (내부수익률)**
```
IRR = NPV를 0으로 만드는 할인율

판단:
IRR > 자본비용: 투자 가치 있음

예시:
IRR = 15%
자본비용 = 8%
→ 15% > 8% → 투자 적합
```

**방법 3: 회수 기간법**
```
회수 기간 = 초기 투자 / 연간 현금유입

예시:
투자: 100억원
연간 현금유입: 20억원
회수 기간 = 100 / 20 = 5년

판단: 기준 기간(예: 7년) 이내 → 적합
```

**재무 리스크 관리**

```
✓ 자금 조달 계획
  - 자기자본 vs 타인자본 비율
  - 부채비율 적정성
  - 이자 부담 능력
  - 현금흐름 안정성

✓ 손익분기점 분석
  BEP = 고정비 / (단위당 가격 - 단위당 변동비)

  확장 후:
  - 고정비 증가
  - BEP 상승
  - 위험 증가
  → BEP 수요와 예상 수요 비교

✓ 민감도 분석
  주요 변수 변화 시 영향:
  - 수요 ±20%
  - 가격 ±10%
  - 변동비 ±15%
  → 각 시나리오별 수익성 평가

✓ 위험 대비책
  - 유휴 설비 활용 방안 (임대, 다각화)
  - 설비 유연성 (다품종 생산 가능)
  - 단계적 투자로 리스크 분산
```

**운전자본 고려**

```
생산능력 확장 시:
- 원자재 재고 증가
- 재공품 증가
- 완제품 재고 증가
- 매출채권 증가

운전자본 = 유동자산 - 유동부채
→ 추가 운전자본 필요

예시:
능력 2배 확장:
- 설비 투자: 200억원
- 운전자본 증가: 50억원
- 총 필요 자금: 250억원
```

#### (3) 실무 사례

```
사례: 제조업체 B사 확장 프로젝트

투자 계획:
- 공장 부지: 50억원
- 건물: 100억원
- 설비: 150억원
- 운전자본: 50억원
- 총 투자: 350억원

재무 분석:
- 연간 추가 매출: 200억원
- 증분 영업이익: 40억원
- NPV (할인율 10%): 96억원
- IRR: 14.5%
- 회수 기간: 8.75년

의사결정:
- NPV > 0 ✓
- IRR (14.5%) > WACC (10%) ✓
- 회수 기간 10년 이내 ✓
→ 투자 진행 결정

리스크 관리:
- 단계적 투자 (1차 60%, 2차 40%)
- 정부 보조금 활용
- 장기 차입 활용 (금리 고정)
```

## 🎯 5. 최종 답안 정리

### 생산능력 확장 시 유의사항 3가지

#### 1) 수요예측의 정확성 확보

**내용**
- 장기적 생산능력 투자는 수요예측에 기반하므로, 정확한 수요 분석이 필수적이다.
- 과대 예측 시 유휴 설비 발생으로 고정비 부담 증가, 과소 예측 시 시장 기회 상실의 위험이 있다.

**구체적 방안**
- 다각도 수요 분석: 과거 추세, 시장 조사, 거시경제 요인, 제품 수명주기 등 종합 검토
- 시나리오 분석: 낙관/기준/비관 시나리오 수립 및 기대값 계산
- 단계적 검증: 시장 테스트 → 시범 생산 → 본격 확장

#### 2) 적절한 확장 시기 및 규모 결정

**내용**
- 확장 시기가 너무 빠르면 유휴 설비, 너무 늦으면 시장 기회 상실이 발생한다.
- 확장 규모는 대규모(규모의 경제)와 소규모(유연성) 간 균형을 고려해야 한다.

**구체적 방안**
- 시기 결정: 현재 가동률(80% 이상 시 검토), 수요 증가 지속성, 건설 리드타임, 경쟁 상황 고려
- 규모 선택:
  * 단계적 확장: 수요 불확실 시, 리스크 분산
  * 일괄 확장: 수요 확실 시, 규모의 경제
- 전략 선택: 선도적(시장 선점) vs 추종적(위험 최소화)

#### 3) 재무적 타당성 및 투자 회수 계획

**내용**
- 생산능력 확장은 막대한 자본 투자를 수반하므로, 철저한 재무 분석과 회수 계획이 필요하다.
- 투자 회수 기간이 장기(5~10년)이므로, 재무 리스크를 면밀히 관리해야 한다.

**구체적 방안**
- 재무 타당성 분석: NPV, IRR, 회수기간법 등 다각도 평가
- 재무 리스크 관리:
  * 자금 조달 계획: 자기자본/타인자본 비율, 부채비율 적정성
  * 손익분기점 분석: 확장 후 BEP와 예상 수요 비교
  * 민감도 분석: 수요, 가격, 비용 변화 시 영향 평가
- 운전자본 고려: 설비 투자 외 재고, 매출채권 증가분 반영

## 📝 6. 답안 작성 팁

### 서술형 답안 구조
```
각 유의사항마다:
1. 제목 (핵심 키워드)
2. 중요성/배경 (2~3문장)
3. 구체적 내용 (3~5가지 세부사항)
4. 실무 적용 방안 또는 예시
```

### 시간 관리
```
문제 5 (10점) 권장 시간: 8~10분

배분:
- 유의사항 1: 3분
- 유의사항 2: 3분
- 유의사항 3: 4분
```

### 고득점 전략
```
✓ 3가지를 명확히 구분
✓ 각 유의사항의 중요성 설명
✓ 구체적 내용과 예시 제시
✓ 실무 적용 가능성 강조
✓ 논리적 체계성
```

### 주의사항
```
✓ 단순 나열 지양
✓ 중복 내용 회피
✓ 일반론보다 구체적 설명
✓ 생산관리 관점 유지
✓ 분량 배분 (각 3~4줄)
```

### 다른 답안 예시 (참고)

```
대안 1: 전략적 적합성 검토
대안 2: 대안 분석 (아웃소싱 등)
대안 3: 입지 선정
대안 4: 기술 및 설비 선택
대안 5: 유연성 확보
대안 6: 환경 및 규제 대응
대안 7: 리스크 관리 체계

→ 핵심 3가지 선택하여 심도있게 서술
```
