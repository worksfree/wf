# 제36회 경영지도사 생산관리 - 문제 1

## 수요예측 - 단순지수평활법과 계절지수

### 문제 요약
최근 6년간 제품 수요 데이터를 바탕으로:
- (1) 단순지수평활법으로 5~7년 수요 예측 (α=0.7)
- (2) 6년의 분기별 수요로 계절지수 계산
- (3) 7년의 분기별 예측수요 계산

---

## 📋 1. 수요예측 기법의 이해

### (1) 단순지수평활법 (Simple Exponential Smoothing)

#### 개념
```
Ft+1 = α × At + (1 - α) × Ft
     = Ft + α × (At - Ft)
```

**의미**
- Ft+1: t+1기의 예측값
- At: t기의 실제값
- Ft: t기의 예측값
- α: 평활상수 (0 < α < 1)

#### 특징
- **최근 데이터에 가중치 부여**: α가 클수록 최근 실제값 반영도 높음
- **추세나 계절성 미반영**: 단순한 수평 패턴에 적합
- **계산 간단**: 이전 예측값과 실제값만 필요
- **α 선택이 중요**: 0.1~0.3 (안정), 0.7~0.9 (반응적)

### (2) 계절지수 (Seasonal Index)

#### 개념
```
계절지수 = 해당 기간 실제값 / 평균값
```

**승법 모형 (Multiplicative Model)**
```
수요 = 기본 수요 × 계절지수
```

#### 특징
- **계절적 패턴 정량화**: 각 기간의 상대적 수요 수준
- **계절지수 합계**: 승법모형에서 = 기간 수
- **예측 조정**: 기본 예측치에 계절지수 곱하여 조정

## 🧮 2. 문제 (1) 풀이: 단순지수평활법

### 주어진 데이터

| 년(t) | 1년 | 2년 | 3년 | 4년 | 5년 | 6년 | 7년 |
|------|-----|-----|-----|-----|-----|-----|-----|
| 실제수요(At) | 1,028 | 1,002 | 1,063 | 1,037 | 1,041 | 1,040 | - |
| 예측수요(Ft) | 1,018 | 1,025 | 1,009 | 1,047 | ? | ? | ? |

**조건**: α = 0.7

### 계산 과정

#### F5 (5년 예측수요) 계산
```
F5 = α × A4 + (1 - α) × F4
   = 0.7 × 1,037 + 0.3 × 1,047
   = 725.9 + 314.1
   = 1,040.0
   ≈ 1,040개
```

**검증**
```
F5 = F4 + α × (A4 - F4)
   = 1,047 + 0.7 × (1,037 - 1,047)
   = 1,047 + 0.7 × (-10)
   = 1,047 - 7
   = 1,040개 ✓
```

#### F6 (6년 예측수요) 계산
```
F6 = α × A5 + (1 - α) × F5
   = 0.7 × 1,041 + 0.3 × 1,040
   = 728.7 + 312.0
   = 1,040.7
   ≈ 1,041개
```

#### F7 (7년 예측수요) 계산
```
F7 = α × A6 + (1 - α) × F6
   = 0.7 × 1,040 + 0.3 × 1,041
   = 728.0 + 312.3
   = 1,040.3
   ≈ 1,040개
```

### 결과 요약

| 년(t) | 실제수요(At) | 예측수요(Ft) | 오차(At-Ft) |
|------|------------|------------|-----------|
| 5년 | 1,041 | **1,040** | +1 |
| 6년 | 1,040 | **1,041** | -1 |
| 7년 | - | **1,040** | - |

## 📊 3. 문제 (2) 풀이: 계절지수 계산

### 주어진 데이터

| 분기 | 1분기 | 2분기 | 3분기 | 4분기 | 합계 |
|------|------|------|------|------|------|
| 6년 실제수요(A6) | 182 | 340 | 280 | 238 | 1,040 |

### 계산 과정

#### 1단계: 분기별 평균 수요 계산
```
분기당 평균 수요 = 연간 수요 / 4
                = 1,040 / 4
                = 260개
```

#### 2단계: 분기별 계절지수 계산

**1분기 계절지수**
```
SI1 = 1분기 수요 / 평균 수요
    = 182 / 260
    = 0.7000
```

**2분기 계절지수**
```
SI2 = 2분기 수요 / 평균 수요
    = 340 / 260
    = 1.3077
    ≈ 1.308
```

**3분기 계절지수**
```
SI3 = 3분기 수요 / 평균 수요
    = 280 / 260
    = 1.0769
    ≈ 1.077
```

**4분기 계절지수**
```
SI4 = 4분기 수요 / 평균 수요
    = 238 / 260
    = 0.9154
    ≈ 0.915
```

### 결과 및 검증

| 분기 | 실제수요 | 평균수요 | 계절지수 |
|------|---------|---------|---------|
| 1분기 | 182 | 260 | **0.700** |
| 2분기 | 340 | 260 | **1.308** |
| 3분기 | 280 | 260 | **1.077** |
| 4분기 | 238 | 260 | **0.915** |
| **합계** | 1,040 | 1,040 | **4.000** ✓ |

**검증**: 계절지수의 합 = 0.700 + 1.308 + 1.077 + 0.915 = 4.000 ✓

## 🎯 4. 문제 (3) 풀이: 분기별 예측수요

### 주어진 데이터
- 7년 예측수요(F7) = 1,040개
- 분기별 계절지수: 1분기(0.700), 2분기(1.308), 3분기(1.077), 4분기(0.915)

### 계산 과정

#### 분기당 기본 예측
```
분기당 기본 예측 = F7 / 4
                = 1,040 / 4
                = 260개
```

#### 분기별 예측수요 계산 (승법 모형)

**1분기 예측수요**
```
F7,Q1 = 분기 기본 예측 × 1분기 계절지수
      = 260 × 0.700
      = 182.0
      = 182개
```

**2분기 예측수요**
```
F7,Q2 = 260 × 1.308
      = 340.08
      ≈ 340개
```

**3분기 예측수요**
```
F7,Q3 = 260 × 1.077
      = 280.02
      ≈ 280개
```

**4분기 예측수요**
```
F7,Q4 = 260 × 0.915
      = 237.9
      ≈ 238개
```

### 결과 요약

| 분기 | 계절지수 | 기본예측 | 분기별 예측수요 |
|------|---------|---------|---------------|
| 1분기 | 0.700 | 260 | **182개** |
| 2분기 | 1.308 | 260 | **340개** |
| 3분기 | 1.077 | 260 | **280개** |
| 4분기 | 0.915 | 260 | **238개** |
| **합계** | 4.000 | 1,040 | **1,040개** ✓ |

**검증**: 182 + 340 + 280 + 238 = 1,040 ✓

## 📈 5. 종합 분석

### (1) 연간 수요 패턴 분석

```
연도별 실제수요 추이:
1년: 1,028 → 2년: 1,002 (-2.5%)
2년: 1,002 → 3년: 1,063 (+6.1%)
3년: 1,063 → 4년: 1,037 (-2.4%)
4년: 1,037 → 5년: 1,041 (+0.4%)
5년: 1,041 → 6년: 1,040 (-0.1%)
```

**특징**
- 평균 수요: 약 1,035개
- 변동 범위: 1,002 ~ 1,063 (약 ±3%)
- 추세: 큰 상승/하락 없이 안정적
- 패턴: **수평적 (Horizontal)** 수요 패턴

### (2) 계절적 패턴 분석

```
계절지수 비교:
2분기 (1.308) > 3분기 (1.077) > 4분기 (0.915) > 1분기 (0.700)
```

**해석**
- **2분기 (성수기)**: 평균 대비 +30.8% (최고 수요)
- **3분기 (성수기)**: 평균 대비 +7.7%
- **4분기 (평수기)**: 평균 대비 -8.5%
- **1분기 (비수기)**: 평균 대비 -30.0% (최저 수요)

**계절 변동 폭**
```
최대 변동 = (최고지수 - 최저지수) / 최저지수
         = (1.308 - 0.700) / 0.700
         = 86.9%
```

### (3) α=0.7의 의미

```
F(t+1) = 0.7 × A(t) + 0.3 × F(t)
```

**특성**
- **높은 반응성**: 최근 실제값에 70% 가중치
- **낮은 안정성**: 과거 예측값에 30% 가중치만 부여
- **적용 상황**: 수요 변동이 크거나 빠른 대응 필요 시

**본 문제에서**
- 실제 수요가 비교적 안정적 (변동계수 작음)
- α=0.7은 다소 높은 설정
- α=0.3~0.5 정도가 더 적합할 수 있음

## 💡 6. 경영 의사결정 시사점

### (1) 재고 관리 전략

#### 연간 계획
```
7년 예상 수요: 1,040개
안전재고 고려: 1,040 × 1.1 = 1,144개 (10% 여유)
```

#### 분기별 재고 계획

| 분기 | 예측수요 | 안전재고(10%) | 목표 재고 |
|------|---------|--------------|----------|
| 1분기 | 182 | 18 | 200 |
| 2분기 | 340 | 34 | 374 |
| 3분기 | 280 | 28 | 308 |
| 4분기 | 238 | 24 | 262 |

**전략**
- 1분기 말: 2분기 성수기 대비 재고 증량
- 2분기: 최대 재고 확보 (340개)
- 4분기 말: 재고 최소화하여 1분기 진입

### (2) 생산 계획

#### 균등 생산 vs 추종 생산

**균등 생산 전략**
```
분기당 균등 생산: 1,040 / 4 = 260개

재고 변동:
1분기 말: 260 - 182 = 78 (재고 증가)
2분기 말: 78 + 260 - 340 = -2 (재고 부족!)
→ 균등 생산은 부적합
```

**추종 생산 전략**
```
분기별 실제 예측량 생산:
1분기: 182개
2분기: 340개
3분기: 280개
4분기: 238개
→ 재고 최소화, 생산 변동성 증가
```

**절충 전략 (권장)**
```
기본 생산: 260개/분기
2분기 추가 생산: +80개
→ 생산 평준화 + 재고 최적화
```

### (3) 마케팅 전략

#### 비수기(1분기) 수요 확대
```
목표: 1분기 수요 182개 → 220개 (20% 증가)
수단:
- 프로모션 (할인, 사은품)
- 신제품 출시
- 대체 수요 창출
```

#### 성수기(2분기) 대응
```
대비책:
- 사전 재고 확보 (1분기 말까지 300개)
- 외주 생산 협력사 확보
- 고객 사전 예약제 운영
```

### (4) 수요예측 정확도 향상

#### 예측 오차 분석
```
MAPE (평균절대백분율오차) 계산:
|A5-F5|/A5 = |1,041-1,040|/1,041 = 0.10%
|A6-F6|/A6 = |1,040-1,041|/1,040 = 0.10%
평균 MAPE = 0.10% → 매우 우수
```

#### 개선 방안
```
1. 계절성 반영 예측법 적용
   - Holt-Winters 지수평활법
   - 계절 ARIMA 모형

2. 인과적 변수 추가
   - 경제 지표
   - 마케팅 활동
   - 경쟁사 동향

3. 단기 예측 정교화
   - 주간/월간 예측
   - 실시간 수요 모니터링
```

## 🔍 7. 심화 학습

### (1) 다른 평활상수의 영향

| α | 특성 | 적용 상황 |
|---|------|----------|
| 0.1~0.3 | 안정적, 변동 완화 | 안정적 수요, 장기 계획 |
| 0.4~0.6 | 균형적 | 일반적 상황 |
| 0.7~0.9 | 반응적, 민감 | 변동 큰 수요, 단기 대응 |

**α=0.3으로 재계산 시**
```
F5 = 0.3 × 1,037 + 0.7 × 1,047
   = 311.1 + 732.9 = 1,044개

차이: 1,044 - 1,040 = 4개
→ α가 낮을수록 변화에 덜 민감
```

### (2) 계절조정 예측법

**Winters의 지수평활법**
```
L(t) = α × (A(t) / S(t-s)) + (1-α) × L(t-1)  (수준)
S(t) = β × (A(t) / L(t)) + (1-β) × S(t-s)    (계절성)
F(t+k) = L(t) × S(t+k-s)                      (예측)
```

**본 문제 적용**
- 연간 수준: 약 1,040개 (안정적)
- 계절성: 4개 분기 패턴 명확
- 향후 예측: 수준 × 계절지수

### (3) 예측 구간

**점 예측의 한계**
```
F7 = 1,040개 (단일 값)
→ 불확실성 미반영
```

**구간 예측 (권장)**
```
표준편차(σ) 추정: √Σ(At-Ft)²/n
예측 구간: F7 ± 1.96σ (95% 신뢰구간)

예: 1,040 ± 30개
→ 1,010 ~ 1,070개 범위
```

## 🎯 9. 답안 작성 팁

1. **공식 명시**: 사용하는 공식 먼저 제시
2. **단계별 계산**: 중간 과정 모두 표기
3. **단위 표기**: 개, %, 등 단위 명확히
4. **반올림 표시**: 계산값 → 최종값 구분
5. **검증**: 가능한 경우 검산 수행

```

```
