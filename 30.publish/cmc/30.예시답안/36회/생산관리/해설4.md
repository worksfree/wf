# 제36회 경영지도사 생산관리 - 문제 4

## 경제적 주문량(EOQ) 모형

### 문제 요약
- (1) EOQ 계산 및 주문간격 산출
  - 연간 수요(D): 3,000개
  - 1회 주문비용(S): 1,000,000원
  - 단위당 연간재고유지비용(H): 6,000원
- (2) 파라미터 변화 시 EOQ 민감도 분석

---

## 📋 1. EOQ 모형의 기본 개념

### (1) EOQ (Economic Order Quantity)

#### 정의
```
경제적 주문량 = 총 재고비용을 최소화하는 1회 주문량
```

**의미**
- 주문비용과 재고유지비용의 균형점
- 연간 총비용(Total Cost)을 최소화
- 외부 구매 시 적용 (cf. EPQ는 자체 생산)

### (2) EOQ 모형의 가정

```
1. 수요율: 일정하고 확정적
2. 리드타임: 일정하고 알려짐
3. 입고: 즉시 전량 입고 (일시 입고)
4. 재고 부족: 허용 안 됨
5. 품목: 독립적 (상호 영향 없음)
6. 비용: 일정 (가격 할인 없음)
```

### (3) 비용 구조

#### 총 재고비용 구성
```
TC (Total Cost) = 주문비용 + 재고유지비용

주문비용 = (D/Q) × S
재고유지비용 = (Q/2) × H

여기서:
D: 연간 수요량
Q: 1회 주문량
S: 1회 주문비용 (Setup cost)
H: 단위당 연간재고유지비용 (Holding cost)
```

## 🧮 2. 문제 (1) 풀이: EOQ 계산

### 주어진 데이터
```
D (연간 수요량) = 3,000개
S (1회 주문비용) = 1,000,000원
H (단위당 연간재고유지비용) = 6,000원
```

### 1단계: EOQ 공식

```
EOQ = Q* = √[(2 × D × S) / H]
```

**공식 유도** (참고)
```
TC = (D/Q) × S + (Q/2) × H

dTC/dQ = 0 에서 최소점:
-D×S/Q² + H/2 = 0
D×S/Q² = H/2
Q² = 2×D×S/H
Q* = √(2DS/H)
```

### 2단계: EOQ 계산 과정

```
Q* = √[(2 × D × S) / H]
   = √[(2 × 3,000 × 1,000,000) / 6,000]
```

**분자 계산**
```
2 × D × S = 2 × 3,000 × 1,000,000
          = 6,000,000,000
```

**분수 계산**
```
(2 × D × S) / H = 6,000,000,000 / 6,000
                = 1,000,000
```

**제곱근 계산**
```
Q* = √1,000,000
   = 1,000개
```

**답**: EOQ = **1,000개**

### 3단계: 주문간격 계산

#### 연간 주문 횟수
```
N (연간 주문 횟수) = D / Q*
                   = 3,000 / 1,000
                   = 3회
```

#### 주문간격 (개월)
```
주문간격 = 12개월 / N
        = 12개월 / 3회
        = 4개월
```

**답**: 주문간격 = **4개월**

**의미**: 4개월마다 1,000개씩 주문

### 4단계: 검증 (최적 조건 확인)

#### EOQ에서 주문비용 = 재고유지비용

**주문비용**
```
연간 주문비용 = (D/Q*) × S
             = (3,000/1,000) × 1,000,000
             = 3 × 1,000,000
             = 3,000,000원
```

**재고유지비용**
```
평균 재고 = Q*/2 = 1,000/2 = 500개

연간 재고유지비용 = (Q*/2) × H
                 = 500 × 6,000
                 = 3,000,000원
```

**검증**
```
주문비용 = 재고유지비용
3,000,000원 = 3,000,000원 ✓

→ 최적 조건 충족
```

#### 연간 총비용
```
TC = 주문비용 + 재고유지비용
   = 3,000,000 + 3,000,000
   = 6,000,000원
```

## 📊 3. 문제 (2) 풀이: 민감도 분석

### EOQ 공식 재확인
```
Q* = √(2DS/H)
```

### 파라미터별 영향 분석

#### (1) 연간 수요량(D) 감소 → EOQ 변화?

**수학적 분석**
```
Q* ∝ √D  (D와 제곱근 비례)

D 감소 → √D 감소 → Q* 감소
```

**구체적 예시**
```
현재: D = 3,000 → Q* = 1,000

D를 50% 감소 (3,000 → 1,500):
Q*_new = √[(2 × 1,500 × 1,000,000) / 6,000]
       = √(500,000)
       = 707개

감소율: (1,000 - 707) / 1,000 = 29.3%
→ D가 50% 감소 시 Q*는 29.3% 감소
→ √0.5 = 0.707 (약 29.3% 감소)
```

**답**: **감소**

**경영 시사점**
- 수요 감소 시 주문량도 감소해야 함
- 단, 비례적 감소 아님 (제곱근 관계)
- 수요 1/4 감소 시 주문량 1/2 감소

#### (2) 1회 주문비용(S) 감소 → EOQ 변화?

**수학적 분석**
```
Q* ∝ √S  (S와 제곱근 비례)

S 감소 → √S 감소 → Q* 감소
```

**구체적 예시**
```
현재: S = 1,000,000 → Q* = 1,000

S를 36% 감소 (1,000,000 → 640,000):
Q*_new = √[(2 × 3,000 × 640,000) / 6,000]
       = √(640,000)
       = 800개

감소율: (1,000 - 800) / 1,000 = 20%
→ S가 36% 감소 시 Q*는 20% 감소
```

**답**: **감소**

**경영 시사점**
- 주문비용 절감 → 소량 다빈도 주문 가능
- EDI, 자동 발주 시스템 → S 감소 → Q* 감소
- JIT (Just-In-Time) 전략의 기반

#### (3) 단위당 연간재고유지비용(H) 증가 → EOQ 변화?

**수학적 분석**
```
Q* ∝ 1/√H  (H와 반비례의 제곱근)

H 증가 → √H 증가 → 1/√H 감소 → Q* 감소
```

**구체적 예시**
```
현재: H = 6,000 → Q* = 1,000

H를 44% 증가 (6,000 → 8,640):
Q*_new = √[(2 × 3,000 × 1,000,000) / 8,640]
       = √(694,444)
       = 833개

감소율: (1,000 - 833) / 1,000 = 16.7%
→ H가 44% 증가 시 Q*는 16.7% 감소
```

**답**: **감소**

**경영 시사점**
- 재고유지비용 증가 → 재고 최소화 전략
- 금리 상승, 창고료 인상 → 소량 주문 유리
- 부패성/계절성 제품 → H 높음 → Q* 작아짐

## 📈 4. 민감도 분석 종합

### (1) 파라미터별 영향 요약

| 파라미터 | 변화 방향 | EOQ 변화 | 관계 | 민감도 |
|---------|---------|---------|------|--------|
| **D (수요량)** | 감소 | **감소** | √D | 중간 |
| **S (주문비용)** | 감소 | **감소** | √S | 중간 |
| **H (재고유지비용)** | 증가 | **감소** | 1/√H | 중간 |

**공통점**: 모두 제곱근 관계 → 완만한 변화

### (2) 제곱근 관계의 의미

```
Q* = k × √(파라미터)

특징:
- 파라미터 4배 증가 → Q* 2배 증가
- 파라미터 1/4 감소 → Q* 1/2 감소
- 완충 효과(Cushioning effect)
```

**경영적 의미**
```
✓ 파라미터 추정 오차에 덜 민감
✓ 실무적으로 강건한(Robust) 모형
✓ 정확한 데이터 없어도 적용 가능
```

### (3) 시나리오 분석

#### 시나리오 1: 경기 침체
```
상황: D 30% 감소, H 20% 증가 (자금 부담)

D_new = 3,000 × 0.7 = 2,100
H_new = 6,000 × 1.2 = 7,200

Q*_new = √[(2 × 2,100 × 1,000,000) / 7,200]
       = √(583,333)
       = 764개

변화: 1,000 → 764 (23.6% 감소)
주문간격: 4개월 → 5.1개월
→ 주문 빈도 감소, 재고 감소
```

#### 시나리오 2: 프로세스 혁신
```
상황: S 60% 감소 (EDI 도입)

S_new = 1,000,000 × 0.4 = 400,000

Q*_new = √[(2 × 3,000 × 400,000) / 6,000]
       = √(400,000)
       = 632개

변화: 1,000 → 632 (36.8% 감소)
주문간격: 4개월 → 2.5개월
→ 소량 다빈도 주문 가능 (JIT 방향)
```

## 💡 5. 경영 의사결정 시사점

### (1) EOQ 활용 전략

#### 재고 정책 수립
```
기본 원칙:
- 1회 주문량: 1,000개
- 주문 시점: 4개월마다
- 평균 재고: 500개
- 최대 재고: 1,000개 (입고 직후)
- 최소 재고: 0개 (주문 직전)
```

#### 안전재고 추가 고려
```
EOQ는 확정적 수요 가정
→ 실제는 수요 변동 존재

안전재고 = Z × σ × √LT
(Z: 서비스수준, σ: 수요 표준편차, LT: 리드타임)

예: 안전재고 100개 추가
→ 재주문점 = LT 동안 수요 + 100개
```

### (2) 비용 절감 방안

#### 주문비용(S) 절감
```
방법:
✓ EDI/자동발주 시스템
✓ 거래선 통합
✓ 장기 계약
✓ 온라인 주문 플랫폼

효과:
S 감소 → Q* 감소 → 소량 다빈도
→ 재고 감소 → 재고유지비용 절감
```

#### 재고유지비용(H) 절감
```
방법:
✓ 창고 효율화
✓ 재고 회전율 향상
✓ 보험료 협상
✓ 재고 손실 감소

효과:
H 감소 → Q* 증가 → 대량 저빈도
→ 주문비용 절감
```

### (3) 파라미터 최적화

#### 균형점 찾기
```
목표: TC (총비용) 최소화

현재 TC = 6,000,000원

만약 S를 50% 절감 (500,000원):
Q*_new = √[(2 × 3,000 × 500,000) / 6,000]
       = 707개
TC_new = 2 × 주문비용 (또는 재고유지비용)
       = 2 × [(3,000/707) × 500,000]
       = 2 × 2,121,320
       = 4,242,640원

절감액: 6,000,000 - 4,242,640 = 1,757,360원 (29.3%)
```

### (4) 수요 변동 대응

#### 수요 증가 시
```
D 증가 → Q* 증가 필요

예: D가 3,000 → 4,800 (60% 증가)
Q*_new = √[(2 × 4,800 × 1,000,000) / 6,000]
       = √(1,600,000)
       = 1,265개 (26.5% 증가)

주문간격 = 12 / (4,800/1,265) = 3.2개월
→ 주문 빈도 증가 필요
```

## 🔍 6. EOQ 모형의 확장

### (1) 수량 할인 EOQ

```
상황: 대량 구매 시 단가 할인

예:
Q < 1,000: 단가 10,000원
Q ≥ 1,000: 단가 9,500원 (5% 할인)

분석:
- 기본 EOQ: 1,000개
- 할인 적용 시: 총비용 재계산 필요
  TC = 구매비용 + 주문비용 + 재고유지비용
```

### (2) 계획적 품절 허용 EOQ

```
상황: 품절 허용 시 품절 비용 발생

공식:
Q* = √[(2DS/H) × {(H + B) / B}]

B: 단위당 품절비용
→ B가 클수록 Q*는 일반 EOQ에 근접
```

### (3) 유한 보충률 모형 (EPQ)

```
생산 속도 > 수요 속도일 때

EPQ = √[(2DS/H) × {p / (p-d)}]

p: 생산율
d: 수요율
→ EOQ의 확장형 (40회 문제 2 참고)
```

## 📊 7. 실무 적용 가이드

### (1) EOQ 적용 체크리스트

```
✓ 수요 패턴: 비교적 안정적인가?
✓ 리드타임: 일정하고 예측 가능한가?
✓ 주문비용: 파악 가능한가?
✓ 재고유지비용: 산정 가능한가?
✓ 품목 특성: 독립 수요 품목인가?
```

### (2) 파라미터 추정 방법

#### 주문비용(S) 산정
```
포함 항목:
- 발주 업무 인건비
- 통신비 (전화, 팩스, 이메일)
- 검수 비용
- 시스템 처리 비용

예: 발주 1건당 평균 소요 시간 2시간
    시간당 인건비 25,000원
    기타 비용 10,000원
    → S = 50,000 + 10,000 = 60,000원
```

#### 재고유지비용(H) 산정
```
포함 항목:
- 자본비용 (기회비용): 단가 × 연이자율
- 창고 보관비: 단가 × 보관료율
- 보험료: 단가 × 보험료율
- 노후화/파손: 단가 × 손실율

예: 단가 10,000원, 연이자 5%, 기타 15%
    → H = 10,000 × (0.05 + 0.15) = 2,000원
```

### (3) 모니터링 및 조정

```
정기 검토 (분기별):
✓ 실제 수요 vs 예상 수요
✓ 파라미터 변화 (S, H)
✓ EOQ 재계산
✓ 정책 조정

이상 신호:
- 재고 회전율 급변
- 빈번한 품절
- 과다 재고 누적
→ EOQ 재검토 필요
```

## 📝 8. 최종 답안 정리

### (1) EOQ 및 주문간격

**경제적 주문량(EOQ)**
```
Q* = √[(2 × D × S) / H]
   = √[(2 × 3,000 × 1,000,000) / 6,000]
   = √1,000,000
   = 1,000개
```

**주문간격**
```
연간 주문 횟수 = D / Q* = 3,000 / 1,000 = 3회
주문간격 = 12개월 / 3회 = 4개월
```

**답**: EOQ = **1,000개**, 주문간격 = **4개월**

### (2) 파라미터 변화에 따른 EOQ 변화

| 파라미터 | 변화 | EOQ 변화 |
|---------|------|---------|
| 연간 수요량(D) | 감소 | **감소** |
| 1회 주문비용(S) | 감소 | **감소** |
| 단위당 연간재고유지비용(H) | 증가 | **감소** |
