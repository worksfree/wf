## 📋 문제 상황

### 주어진 정보

**투자금액**: 100억원

**투자안에 대한 성과표 (1년 후 잔존가치, 단위: 억원)**

| 경제상황<br>투자안 | 호황 | 보통 | 불황 |
|------|-----|-----|-----|
| 주식 | 200 | 130 | 50 |
| 부동산 | 150 | 100 | 80 |
| 금 | 100 | 120 | 150 |

---

## 🎯 (1) 후회의 미니맥스 기준 (10점)

### 후회(Regret) 개념

```
후회 = 각 상황에서의 최대 성과 - 선택한 대안의 성과

의미: "만약 그때 최선의 선택을 했다면..." 하는 아쉬움의 크기
```

---

### Step 1: 각 경제상황별 최대 성과 확인

```
호황 상황: max(200, 150, 100) = 200 (주식)
보통 상황: max(130, 100, 120) = 130 (주식)
불황 상황: max(50, 80, 150) = 150 (금)
```

---

### Step 2: 후회표(Regret Table) 작성

#### 계산 과정

**호황 상황의 후회**
```
주식: 200 - 200 = 0
부동산: 200 - 150 = 50
금: 200 - 100 = 100
```

**보통 상황의 후회**
```
주식: 130 - 130 = 0
부동산: 130 - 100 = 30
금: 130 - 120 = 10
```

**불황 상황의 후회**
```
주식: 150 - 50 = 100
부동산: 150 - 80 = 70
금: 150 - 150 = 0
```

#### 후회표

| 경제상황<br>투자안 | 호황 | 보통 | 불황 | **최대 후회** |
|------|-----|-----|-----|----------|
| 주식 | 0 | 0 | **100** | **100** |
| 부동산 | 50 | 30 | 70 | **70** |
| 금 | 100 | 10 | 0 | **100** |

---

### Step 3: 미니맥스 후회(Minimax Regret) 기준 적용

**미니맥스 후회 기준**
```
각 대안의 최대 후회 중에서 최소값을 선택
→ "최악의 경우 후회를 최소화"
```

**각 대안의 최대 후회**
```
주식: max(0, 0, 100) = 100
부동산: max(50, 30, 70) = 70  ← 최소
금: max(100, 10, 0) = 100
```

**최적 대안**
```
부동산 (최대 후회 = 70억원)
```

---

### 해석

```
부동산에 투자할 경우:
- 어떤 경제상황이 오더라도 후회는 최대 70억원
- 주식이나 금에 투자하면 최대 100억원까지 후회 가능
- 보수적 의사결정자에게 적합
```

## 💰 (2) 기대화폐가치 (EMV: Expected Monetary Value) (10점)

### 주어진 확률

```
P(호황) = 0.30
P(보통) = 0.50
P(불황) = 0.20
```

---

### 기대화폐가치(EMV) 공식

```
EMV = Σ [성과 × 확률]
    = (호황 성과 × 0.30) + (보통 성과 × 0.50) + (불황 성과 × 0.20)
```

---

### 계산

#### 주식의 EMV

```
EMV(주식) = 200 × 0.30 + 130 × 0.50 + 50 × 0.20
          = 60 + 65 + 10
          = 135 억원
```

#### 부동산의 EMV

```
EMV(부동산) = 150 × 0.30 + 100 × 0.50 + 80 × 0.20
            = 45 + 50 + 16
            = 111 억원
```

#### 금의 EMV

```
EMV(금) = 100 × 0.30 + 120 × 0.50 + 150 × 0.20
        = 30 + 60 + 30
        = 120 억원
```

---

### EMV 요약 및 최적 대안

| 투자안 | EMV (억원) | 순위 |
|--------|-----------|------|
| **주식** | **135** | **1위** ← 최대 |
| 금 | 120 | 2위 |
| 부동산 | 111 | 3위 |

**최적 대안 (EMV 기준)**
```
주식 (EMV = 135억원)
```

---

### 해석

```
확률을 고려한 기대수익:
- 주식이 가장 높은 기대수익 (135억원)
- 금은 중간 (120억원)
- 부동산은 가장 낮음 (111억원)

→ 위험 중립적 의사결정자는 주식 선택
```

---

## 📊 (3) 완전정보의 기대가치 (EVPI: Expected Value of Perfect Information) (10점)

### 완전정보의 기대가치(EVPI) 개념

```
EVPI = 완전정보 하의 기대가치(EVWPI) - 최선 대안의 EMV(EMV*)

의미: 미래를 완벽하게 예측할 수 있다면, 그 정보에 지불할 용의가 있는 최대 금액
```

---

### Step 1: 완전정보 하의 기대가치(EVWPI) 계산

**완전정보 하의 전략**
```
만약 미래를 알 수 있다면:
- 호황이 올 것을 안다면 → 주식 선택 (200억원)
- 보통이 올 것을 안다면 → 주식 선택 (130억원)
- 불황이 올 것을 안다면 → 금 선택 (150억원)
```

**EVWPI 계산**
```
EVWPI = (각 상황의 최대 성과) × (해당 상황의 확률)

EVWPI = 200 × 0.30 + 130 × 0.50 + 150 × 0.20
      = 60 + 65 + 30
      = 155 억원
```

---

### Step 2: 최선 대안의 EMV (EMV*) 확인

```
EMV* = max(EMV(주식), EMV(부동산), EMV(금))
     = max(135, 111, 120)
     = 135 억원 (주식)
```

---

### Step 3: EVPI 계산

```
EVPI = EVWPI - EMV*
     = 155 - 135
     = 20 억원
```

---

### 답

```
완전정보의 기대가치(EVPI) = 20억원
```

---

### 해석

```
완전정보의 가치 = 20억원

의미:
1. 미래 경제상황을 완벽히 예측할 수 있는 정보가 있다면,
   그 정보에 최대 20억원까지 지불할 가치가 있음

2. 만약 시장조사 비용이 20억원 이하라면 투자 가치 있음
   (예: 10억원 들여 정확한 예측 가능 → 순이익 10억원)

3. 20억원 초과 시 정보 구매 불필요
```
