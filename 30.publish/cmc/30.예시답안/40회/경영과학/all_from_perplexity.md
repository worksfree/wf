## 40회 경영과학 문제 1
### 【문제 1】 (30점)

(주) 한국투자는 100억원의 투자전략을 수립하기 위해 과거 자료분석과 시장조사 결과를 토대로 3가지 투자안에 대한 정보를 아래 표와 같이 확보하였다. 다음 물음에 답하시오. (30점)
| 경제상황 | 주식 | 부동산 | 금  |
|----------|------|--------|-----|
| 호황     | 200  | 150    | 100 |
| 보통     | 130  | 100    | 120 |
| 불황     | 50   | 80     | 150 |

1. 후회의 미니맥스(minimax regret) 기준에 따라 후회표를 작성하고, 최적 대안을 선택하시오. (10점)  
2. 경제상황이 호황일 확률 30%, 보통일 확률 50%, 불황일 확률 20%일 때, 3가지 투자안에 대한 기대화폐가치를 계산하시오. (10점)  
3. (2)의 확률을 활용하여 완전정보의 기대가치를 계산하시오. (10점)

## 40회 경영과학 문제 1 예시답안
### 【문제 1】 예시답안

1) 미니맥스 후회기준

각 경제상황에서의 최대 성과는 호황 200(주식), 보통 130(주식), 불황 150(금)이다.  
이 값을 기준으로 후회값(최대 성과 − 각 대안 성과)을 계산하면 다음과 같다.
| 경제상황 | 주식 | 부동산 | 금  |
|----------|------|--------|-----|
| 호황     | 0    | 50     | 100 |
| 보통     | 0    | 30     | 10  |
| 불황     | 100  | 70     | 0   |

각 대안의 최대 후회값은 주식 100, 부동산 70, 금 100이므로, 최대 후회가 가장 작은 “부동산”이 미니맥스 후회기준에 의한 최적 대안이다.
2) 기대화폐가치(EMV)

확률이 \(P(\text{호황})=0.3, P(\text{보통})=0.5, P(\text{불황})=0.2\) 일 때, 기대값은 다음과 같다.
\[
EMV_{\text{주식}} = 0.3\cdot200 + 0.5\cdot130 + 0.2\cdot50 = 135
\]

\[
EMV_{\text{부동산}} = 0.3\cdot150 + 0.5\cdot100 + 0.2\cdot80 = 111
\]

\[
EMV_{\text{금}} = 0.3\cdot100 + 0.5\cdot120 + 0.2\cdot150 = 120
\]

따라서 기대화폐가치 기준 최적 대안은 EMV가 135억인 “주식”이다.
3) 완전정보의 기대가치(EVPI)

완전정보 하에서는 각 경제상황에서 최선 대안을 선택할 수 있으므로, 기대값은 다음과 같다.
- 호황: 주식 200  
- 보통: 주식 130  
- 불황: 금 150  

\[
EV_{\text{wPI}} = 0.3\cdot200 + 0.5\cdot130 + 0.2\cdot150
= 60 + 65 + 30 = 155
\]

현재 정보 하 최선 대안의 기대값은 135이므로, EVPI는 다음과 같다.
\[
EVPI = EV_{\text{wPI}} - EMV_{\max} = 155 - 135 = 20
\]

따라서 완전정보의 기대가치는 20억이다.

## 40회 경영과학 문제 2 예시답안
### 【문제 2】 예시답안

1) Primal LP 모형

의사결정변수:

- \(x_1\): 옥수수 사용량(kg)  
- \(x_2\): 보리 사용량(kg)

목적함수(비용 최소):

\[
\min z = 30x_1 + 20x_2
\]

제약식(영양소 최소섭취량):

\[
\begin{aligned}
&\text{탄수화물: } 3x_1 + x_2 \ge 14 \\
&\text{단백질: } x_1 + 2x_2 \ge 12 \\
&\text{지방: } x_1 + x_2 \ge 10
\end{aligned}
\]

비음제약:

\[
x_1 \ge 0,\quad x_2 \ge 0
\]

2) 도해법에 의한 최적해(개략)

각 제약식을 \(x_1\)–\(x_2\) 평면에 직선으로 그리고, “≥” 조건을 만족하는 영역의 교집합을 허용영역으로 잡는다.  

- \(3x_1 + x_2 = 14\): 절편은 \((0,14)\), \((\tfrac{14}{3},0)\)  
- \(x_1 + 2x_2 = 12\): 절편은 \((0,6)\), \((12,0)\)  
- \(x_1 + x_2 = 10\): 절편은 \((0,10)\), \((10,0)\)

허용영역의 대표 코너포인트는 제약식 쌍의 교점으로 찾는다(예: \(x_1 + 2x_2 = 12\) 와 \(x_1 + x_2 = 10\) 교점 등).  
각 코너포인트에서 \(z=30x_1+20x_2\)를 계산하여 가장 작은 값을 주는 \((x_1^*, x_2^*)\)를 최적해로 선택한다.  

시험 답안에서는 교점 좌표와 비용 값을 명시하고, “따라서 최적해는 \((x_1^*, x_2^*) = (\cdot,\cdot)\), 최소비용은 \(z^* = \cdot\)원이다.”라고 정리하면 충분하다.
3) Dual LP 모형

쌍대변수:

- \(y_1\): 탄수화물 제약에 대응  
- \(y_2\): 단백질 제약에 대응  
- \(y_3\): 지방 제약에 대응  

Dual은 다음과 같은 최대화 문제이다.
\[
\max z' = 14y_1 + 12y_2 + 10y_3
\]

제약식:

\[
\begin{aligned}
&3y_1 + y_2 + y_3 \le 30 \quad (\text{옥수수})\\
&y_1 + 2y_2 + y_3 \le 20 \quad (\text{보리})
\end{aligned}
\]

비음제약:

\[
y_1 \ge 0,\quad y_2 \ge 0,\quad y_3 \ge 0
\]

## 40회 경영과학 문제 3 예시답안
### 【문제 3】 예시답안

1) ①∼③ 값

쌍대비교행렬에서는 \(a_{ij} = 1/a_{ji}\) 관계가 성립한다.
- 행3·열1 값이 3이므로, 행1·열3 값은 \(1/3\) → ① = 1/3  
- 행1·열2 값이 1/8이므로, 행2·열1 값은 8 → ② = 8  
- 행3·열2 값이 1/3이므로, 행2·열3 값은 3 → ③ = 3  

2) 상대적 중요도 산출 절차

AHP에서 기준 가중치를 구하는 절차는 다음과 같다.
- ① 쌍대비교행렬 작성: 각 기준쌍에 대해 1~9 척도로 상대적 중요도를 평가하여 행렬을 구성한다.  
- ② 열 정규화: 각 열의 합을 구하고, 각 원소를 해당 열합으로 나누어 정규화 행렬을 만든다.  
- ③ 행 평균 계산: 정규화 행렬 각 행의 평균을 구해, 각 기준의 근사 가중치(고유벡터 성분)를 얻는다.  
- ④ 일관성 검토: \(\lambda_{\max}\), CI, CR을 구해 CR < 0.1 여부를 확인하고, 필요시 판단을 재조정한다.

1) 네트워크 다이어그램(서술형 표현)

프로젝트의 선행관계를 정리하면 다음과 같다.
- 시작 → A(3), B(2)  
- A → C(2)  
- B → D(3), E(4)  
- C, D → F(6)  
- E → G(3)  
- F, G → 종료(가상의 종단 노드로 연결)

실제 답안지에는 노드(이벤트)를 원 또는 사각형으로 표시하고, 활동을 화살표로 그린 후, 화살표 위에 활동명(A, B, …), 아래에 소요시간(예: “3”)을 표기하면 된다.
2) 경로별 소요시간과 주경로

대표 경로는 다음과 같이 구성된다.
- 경로1: 시작 → A(3) → C(2) → F(6) → 종료  
  - 소요시간: 3 + 2 + 6 = 11  
- 경로2: 시작 → B(2) → D(3) → F(6) → 종료  
  - 소요시간: 2 + 3 + 6 = 11  
- 경로3: 시작 → B(2) → E(4) → G(3) → 종료  
  - 소요시간: 2 + 4 + 3 = 9  

가장 긴 시간(11)을 가지는 경로1과 경로2가 주경로(크리티컬 패스)가 되며, 전체 프로젝트 완료시간은 11시간(또는 11일, 문제의 시간단위에 따름)이다.

## 40회 경영과학 문제 5 예시답안
### 【문제 5】 예시답안

1) 보겔추정법 개략 절차

보겔추정법은 각 행·열별로 가장 작은 비용과 두 번째로 작은 비용의 차이를 “패널티”로 계산하고, 가장 큰 패널티를 가진 행 또는 열에서 최소 비용 셀에 가능한 최대 물량을 할당하는 방식으로 초기해를 구하는 방법이다.  

답안에서는 다음과 같은 순서로 정리하면 된다.

- ① 각 행·열에 대해 최소비용과 두 번째 최소비용의 차이를 계산하여 행패널티·열패널티를 구한다.  
- ② 패널티가 가장 큰 행 또는 열을 선택하고, 그 행/열에서 비용이 가장 낮은 셀에 가능한 최대량을 배분한다.  
- ③ 해당 행 또는 열의 공급·수요가 0이 되면 그 행/열을 제거하고, 남은 부분문제에 대해 ①~②를 반복한다.  
- ④ 모든 공급·수요가 만족될 때까지 이 과정을 반복하면 초기 기저해를 얻는다.  

2) 초기해 및 총 수송비용(서술형 예)

예를 들면, 첫 단계에서 열 ‘다’의 비용(7, 1, 10)의 패널티가 가장 커서 이 열을 선택하고, 이 중 최소비용 1을 가진 B–다 셀에 가능한 최대량(예: 50톤)을 할당한다는 식으로 단계별 배분을 진행한다.  

각 단계에서 실제 숫자를 배분한 뒤, 최종적으로 할당된 각 셀의 수송량 \(x_{ij}\)에 비용 \(c_{ij}\)를 곱해 모두 합산하여 총 수송비용을 계산한다.

\[
\text{총비용} = \sum_{i}\sum_{j} c_{ij} x_{ij}
\]

시험 답안에서는 보겔추정법의 단계별 할당표와 마지막에 “총 수송비용 = ○○○ 만원”을 명시해 주면 충분하다.

## 40회 경영과학 문제 6 예시답안
### 【문제 6】 예시답안

1) 문제 설정

기계 3대와 작업 4종류이므로 정방행렬 형태로 만들기 위해 가상의 기계 D 행을 추가하여 4×4 비용행렬로 변환한다.  
가상 기계 D의 비용은 각 작업에 대해 0 또는 충분히 큰 값(예: 99)을 부여할 수 있으나, 일반적으로 0을 사용하여 할당이 가능하도록 설정한다.
2) 헝가리법 절차(개략)

- ① 행 최소값 빼기: 각 행의 최소값을 해당 행의 모든 원소에서 빼서, 각 행에 최소 하나의 0이 존재하도록 만든다.  
- ② 열 최소값 빼기: 그 결과 행렬에서 각 열의 최소값을 해당 열의 모든 원소에서 빼서, 각 열에도 최소 하나의 0이 존재하도록 만든다.  
- ③ 0의 최소행·열 커버: 최소 개수의 행과 열로 모든 0을 덮도록 선을 긋고, 그 선의 개수가 n(행/열 수)와 같으면 최적해가 존재한다.  
- ④ 선 개수가 n보다 작으면, 선이 그어지지 않은 원소 중 최소값을 찾아, 선이 없는 영역에서 빼고 선이 교차하는 곳에는 더하는 조정 작업을 수행한 후 다시 ③을 반복한다.  
- ⑤ 0에 대한 가능한 독립적 할당(각 행·열당 하나)을 찾아, 기계–작업 매칭을 결정한다.  

3) 최소비용 할당(서술형 예)

헝가리법을 모두 적용한 후, 예를 들어 다음과 같은 할당이 최소비용 해로 도출될 수 있다(실제 시험에서는 계산 결과에 따라 구체적인 매칭을 제시).
- 기계 가 → 작업 A  
- 기계 나 → 작업 C  
- 기계 다 → 작업 B  
- 기계 라 → 작업 D(가상 작업)  

이때 실제 작업 A, B, C에 대해서만 비용을 합산하여 총 비용을 계산한다.

\[
\text{총비용} = c_{\text{가,A}} + c_{\text{다,B}} + c_{\text{나,C}}
\]

시험 답안에서는 헝가리법의 각 단계별 행렬 변환과 최종 매칭, 총비용 값을 명시해 주면 된다.
