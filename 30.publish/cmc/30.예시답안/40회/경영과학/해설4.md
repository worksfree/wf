# 제40회 경영지도사 경영과학 문제4 - 네트워크/PERT 답안

## 문제 분석

프로젝트 네트워크 문제로 7개의 작업으로 구성되어 있으며, 각 작업의 소요시간과 선행관계는 다음과 같습니다.

| 작업 | 선행작업 | 소요시간(일) |
|------|----------|--------------|
| A | - | 3 |
| B | - | 2 |
| C | A | 2 |
| D | B | 3 |
| E | B | 4 |
| F | C, D | 6 |
| G | E | 3 |

---

## (1) 네트워크 다이어그램

### AON (Activity-On-Node) 방식

```
시작점 (0)
    ├─→ A(3) ─→ C(2) ─┐
    │                   ├─→ F(6) ─→ 종료점
    └─→ B(2) ─┬─→ D(3) ─┘
              │
              └─→ E(4) ─→ G(3) ─→ 종료점
```

### AOA (Activity-On-Arrow) 방식 상세도

```
        A(3)         C(2)
    ① ─────→ ② ─────────→ ④
    │                       │
    │                       ↓ F(6)
    │       B(2)            ⑤ ─────→ ⑦ (종료)
    └─────→ ③ ─┬─→ D(3) ───┘         ↑
              │                      │
              └─→ E(4) ─→ ⑥ ─ G(3) ─┘
```

**노드(Node) 설명:**
- ① : 프로젝트 시작점 (노드 0)
- ② : 작업 A 완료 (노드 1)
- ③ : 작업 B 완료 (노드 2)
- ④ : 작업 C 완료 (노드 3)
- ⑤ : 작업 D, F의 병합점 (노드 4)
- ⑥ : 작업 E 완료 (노드 5)
- ⑦ : 프로젝트 종료점 (노드 6)

---

## (2) 모든 경로 및 임계경로 분석

### 1) 모든 가능한 경로 나열

프로젝트 시작점에서 종료점까지의 모든 경로를 파악합니다.

**경로 1: A → C → F**
- 작업 순서: 시작 → A → C → F → 종료
- 소요시간: 3 + 2 + 6 = **11일**

**경로 2: B → D → F**
- 작업 순서: 시작 → B → D → F → 종료
- 소요시간: 2 + 3 + 6 = **11일**

**경로 3: B → E → G**
- 작업 순서: 시작 → B → E → G → 종료
- 소요시간: 2 + 4 + 3 = **9일**

### 2) 임계경로(Critical Path) 결정

임계경로는 프로젝트 완료에 가장 긴 시간이 소요되는 경로입니다.

**분석 결과:**
- 경로 1 (A-C-F): 11일 ★
- 경로 2 (B-D-F): 11일 ★
- 경로 3 (B-E-G): 9일

**임계경로: 2개 존재**
1. **A → C → F** (11일)
2. **B → D → F** (11일)

### 3) 프로젝트 완료시간

**프로젝트 완료시간 = 11일**

임계경로가 2개 존재하므로, 두 경로 중 어느 하나라도 지연되면 전체 프로젝트가 지연됩니다.

## (3) 각 작업의 시간 분석 (최조시간, 최지시간, 여유시간)

### 최조시간(EST: Earliest Start Time)과 최조완료시간(EFT: Earliest Finish Time)

| 작업 | 선행작업 | 소요시간 | EST | EFT |
|------|----------|----------|-----|-----|
| A | - | 3 | 0 | 3 |
| B | - | 2 | 0 | 2 |
| C | A | 2 | 3 | 5 |
| D | B | 3 | 2 | 5 |
| E | B | 4 | 2 | 6 |
| F | C, D | 6 | 5 | 11 |
| G | E | 3 | 6 | 9 |

### 최지시간(LST: Latest Start Time)과 최지완료시간(LFT: Latest Finish Time)

프로젝트 완료시간이 11일이므로, 역산하여 계산합니다.

| 작업 | 소요시간 | LFT | LST | 여유시간 |
|------|----------|-----|-----|----------|
| F | 6 | 11 | 5 | 0 |
| G | 3 | 11 | 8 | 2 |
| C | 2 | 5 | 3 | 0 |
| D | 3 | 5 | 2 | 0 |
| E | 4 | 8 | 4 | 2 |
| A | 3 | 3 | 0 | 0 |
| B | 2 | 2 | 0 | 0 |

### 여유시간(Slack Time) 분석

**여유시간 = LST - EST (또는 LFT - EFT)**

- **작업 A**: 0 - 0 = 0일 (임계작업)
- **작업 B**: 0 - 0 = 0일 (임계작업)
- **작업 C**: 3 - 3 = 0일 (임계작업)
- **작업 D**: 2 - 2 = 0일 (임계작업)
- **작업 E**: 4 - 2 = 2일 (비임계작업)
- **작업 F**: 5 - 5 = 0일 (임계작업)
- **작업 G**: 8 - 6 = 2일 (비임계작업)

**임계작업(여유시간 0):** A, B, C, D, F
**비임계작업(여유시간 존재):** E(2일), G(2일)

## 결론 및 관리적 시사점

### 1) 프로젝트 특성
- 프로젝트 완료에는 최소 **11일**이 소요됩니다.
- **2개의 임계경로**가 존재하여 관리가 복잡합니다.
- 임계경로상의 작업들(A, B, C, D, F)은 어느 것도 지연되어서는 안 됩니다.

### 2) 관리 포인트
- **임계경로 1 (A-C-F)**: 작업 A, C, F에 대한 집중 관리 필요
- **임계경로 2 (B-D-F)**: 작업 B, D, F에 대한 집중 관리 필요
- **작업 B와 F**: 두 임계경로에 공통적으로 영향을 미치므로 특히 중요
- **작업 E와 G**: 각각 2일의 여유시간이 있어 일정 조정 가능

### 3) 프로젝트 단축 전략
프로젝트 기간을 단축하려면:
- 작업 F(6일)가 두 임계경로에 모두 포함되므로, F를 단축하면 효과적
- 작업 A 또는 C를 단축하면 경로 1만 단축
- 작업 D를 단축하면 경로 2만 단축
- 전체 프로젝트 단축을 위해서는 두 임계경로를 동시에 단축해야 함

## 답안 요약

**(1) 네트워크 다이어그램**
- AOA 또는 AON 방식으로 7개 작업의 선행관계를 도식화
- 작업 A, B는 선행작업 없음
- 작업 F는 C와 D가 모두 완료되어야 시작 가능

**(2) 임계경로 분석**
- 전체 경로: 3개 (A-C-F, B-D-F, B-E-G)
- 임계경로: A→C→F (11일), B→D→F (11일)
- 프로젝트 완료시간: **11일**
- 임계작업: A, B, C, D, F (여유시간 0일)
- 비임계작업: E, G (여유시간 2일)
