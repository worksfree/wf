# 제40회 경영지도사 경영과학 문제2 답안

## 문제: 사료 배합 문제 (선형계획법)

### 문제 요약
- 옥수수(x₁)와 보리(x₂)를 배합하여 사료를 제조
- 영양소 최소 요구량을 만족하면서 비용을 최소화
- 목적함수: min z = 30x₁ + 20x₂

---

## (1) LP 모형 작성

### 1) 목적함수 (Objective Function)
```
min z = 30x₁ + 20x₂
```
- x₁: 옥수수의 양 (kg)
- x₂: 보리의 양 (kg)
- 30: 옥수수 단위당 비용
- 20: 보리 단위당 비용

### 2) 제약조건 (Constraints)

**탄수화물 제약:**
```
3x₁ + x₂ ≥ 14
```
- 옥수수는 단위당 3단위, 보리는 단위당 1단위의 탄수화물 함유
- 최소 14단위 필요

**단백질 제약:**
```
x₁ + 2x₂ ≥ 12
```
- 옥수수는 단위당 1단위, 보리는 단위당 2단위의 단백질 함유
- 최소 12단위 필요

**지방 제약:**
```
x₁ + x₂ ≥ 10
```
- 옥수수와 보리 모두 단위당 1단위의 지방 함유
- 최소 10단위 필요

### 3) 비음조건 (Non-negativity Constraints)
```
x₁ ≥ 0, x₂ ≥ 0
```
- 음수의 사료는 존재할 수 없음

### 완성된 LP 모형
```
min z = 30x₁ + 20x₂

subject to:
    3x₁ + x₂ ≥ 14    (탄수화물)
    x₁ + 2x₂ ≥ 12    (단백질)
    x₁ + x₂ ≥ 10     (지방)
    x₁, x₂ ≥ 0       (비음조건)
```

---

## (2) 도해법으로 최적해 구하기

### 1) 제약조건을 등식으로 변환하여 경계선 그리기

**제약조건 1: 3x₁ + x₂ = 14**
- x₁ = 0일 때: x₂ = 14 → 점 (0, 14)
- x₂ = 0일 때: x₁ = 14/3 ≈ 4.67 → 점 (4.67, 0)

**제약조건 2: x₁ + 2x₂ = 12**
- x₁ = 0일 때: x₂ = 6 → 점 (0, 6)
- x₂ = 0일 때: x₁ = 12 → 점 (12, 0)

**제약조건 3: x₁ + x₂ = 10**
- x₁ = 0일 때: x₂ = 10 → 점 (0, 10)
- x₂ = 0일 때: x₁ = 10 → 점 (10, 0)

### 2) 실행가능영역 결정

최소화 문제에서 "≥" 제약조건이므로:
- 3x₁ + x₂ ≥ 14: 직선의 우상향 영역
- x₁ + 2x₂ ≥ 12: 직선의 우상향 영역
- x₁ + x₂ ≥ 10: 직선의 우상향 영역

실행가능영역은 세 제약조건을 모두 만족하는 영역입니다.

### 3) 꼭지점(Corner Points) 찾기

**꼭지점 A: 제약조건 1과 2의 교점**
```
3x₁ + x₂ = 14  ... ①
x₁ + 2x₂ = 12  ... ②

①에서: x₂ = 14 - 3x₁
②에 대입: x₁ + 2(14 - 3x₁) = 12
         x₁ + 28 - 6x₁ = 12
         -5x₁ = -16
         x₁ = 16/5 = 3.2

x₂ = 14 - 3(3.2) = 14 - 9.6 = 4.4
```
**점 A = (3.2, 4.4)**

검증:
- 제약 1: 3(3.2) + 4.4 = 9.6 + 4.4 = 14 ✓
- 제약 2: 3.2 + 2(4.4) = 3.2 + 8.8 = 12 ✓
- 제약 3: 3.2 + 4.4 = 7.6 < 10 ✗

**점 A는 제약조건 3을 만족하지 않으므로 실행가능영역에 속하지 않습니다.**

**꼭지점 B: 제약조건 1과 3의 교점**
```
3x₁ + x₂ = 14  ... ①
x₁ + x₂ = 10   ... ③

③에서: x₂ = 10 - x₁
①에 대입: 3x₁ + (10 - x₁) = 14
         2x₁ = 4
         x₁ = 2

x₂ = 10 - 2 = 8
```
**점 B = (2, 8)**

검증:
- 제약 1: 3(2) + 8 = 14 ✓
- 제약 2: 2 + 2(8) = 18 ≥ 12 ✓
- 제약 3: 2 + 8 = 10 ✓

**점 B는 실행가능영역에 속합니다.**

**꼭지점 C: 제약조건 2와 3의 교점**
```
x₁ + 2x₂ = 12  ... ②
x₁ + x₂ = 10   ... ③

②-③: x₂ = 2
③에 대입: x₁ + 2 = 10
         x₁ = 8
```
**점 C = (8, 2)**

검증:
- 제약 1: 3(8) + 2 = 26 ≥ 14 ✓
- 제약 2: 8 + 2(2) = 12 ✓
- 제약 3: 8 + 2 = 10 ✓

**점 C는 실행가능영역에 속합니다.**

### 4) 각 꼭지점에서 목적함수 값 계산

**점 B = (2, 8):**
```
z = 30(2) + 20(8) = 60 + 160 = 220
```

**점 C = (8, 2):**
```
z = 30(8) + 20(2) = 240 + 40 = 280
```

### 5) 최적해

**최적해: x₁* = 2, x₂* = 8**
**최소비용: z* = 220**

**해석:**
- 옥수수 2kg, 보리 8kg을 배합
- 최소 비용은 220원
- 이 배합은 모든 영양소 요구량을 만족함
  - 탄수화물: 3(2) + 8 = 14 (딱 맞음)
  - 단백질: 2 + 2(8) = 18 (여유 6)
  - 지방: 2 + 8 = 10 (딱 맞음)

## (3) 쌍대문제(Dual Problem) 작성

### 쌍대성 원리 (Duality Principle)

원문제(Primal)가 최소화 문제일 때, 쌍대문제(Dual)는 최대화 문제가 됩니다.

### 원문제 (Primal)
```
min z = 30x₁ + 20x₂

subject to:
    3x₁ + x₂ ≥ 14
    x₁ + 2x₂ ≥ 12
    x₁ + x₂ ≥ 10
    x₁, x₂ ≥ 0
```

### 쌍대변수 정의

- y₁: 탄수화물 제약에 대한 쌍대변수 (그림자 가격)
- y₂: 단백질 제약에 대한 쌍대변수
- y₃: 지방 제약에 대한 쌍대변수

### 쌍대문제 도출 과정

**1단계: 제약조건 행렬 전치**

원문제의 계수 행렬:
```
        x₁  x₂  RHS
탄수화물  3   1   14
단백질    1   2   12
지방      1   1   10
목적함수 30  20
```

**2단계: 쌍대문제 구성**

- 원문제의 제약조건 개수(3개) = 쌍대문제의 변수 개수
- 원문제의 변수 개수(2개) = 쌍대문제의 제약조건 개수
- 원문제의 RHS = 쌍대문제의 목적함수 계수
- 원문제의 목적함수 계수 = 쌍대문제의 RHS
- 원문제 "≥" → 쌍대문제 "≤"
- 원문제 "min" → 쌍대문제 "max"

### 쌍대문제 (Dual Problem)

```
max w = 14y₁ + 12y₂ + 10y₃

subject to:
    3y₁ + y₂ + y₃ ≤ 30    (x₁에 대응)
    y₁ + 2y₂ + y₃ ≤ 20    (x₂에 대응)
    y₁, y₂, y₃ ≥ 0
```

### 쌍대문제의 경제적 의미

- **목적함수**: 영양소의 총 가치를 최대화
- **y₁**: 탄수화물 1단위의 그림자 가격 (marginal value)
- **y₂**: 단백질 1단위의 그림자 가격
- **y₃**: 지방 1단위의 그림자 가격
- **제약조건 1**: 옥수수가 제공하는 영양소의 가치 ≤ 옥수수 비용(30)
- **제약조건 2**: 보리가 제공하는 영양소의 가치 ≤ 보리 비용(20)

### 강쌍대성 정리 (Strong Duality Theorem)

원문제와 쌍대문제가 모두 최적해를 가지면:
```
min z* = max w*
220 = 220
```

최적해에서 상보적 여유성(Complementary Slackness) 조건:
- 제약조건 1: 3(2) + 8 = 14 (binding) → y₁* > 0 가능
- 제약조건 2: 2 + 2(8) = 18 > 12 (slack = 6) → y₂* = 0
- 제약조건 3: 2 + 8 = 10 (binding) → y₃* > 0 가능

## 요약

### 최적해
- **옥수수(x₁)**: 2kg
- **보리(x₂)**: 8kg
- **최소비용**: 220원

### 제약조건 충족 상황
- 탄수화물: 14 (요구량 만족, 여유 없음)
- 단백질: 18 (요구량 12 초과, 여유 6)
- 지방: 10 (요구량 만족, 여유 없음)

### 경영학적 시사점
1. 단백질 제약이 느슨하므로(slack), 단백질 요구량을 줄여도 최적해는 변하지 않음
2. 탄수화물과 지방 제약이 binding이므로, 이들의 요구량 변화는 최적해에 직접 영향
3. 쌍대문제를 통해 각 영양소의 그림자 가격을 파악하여 자원 배분의 효율성 평가 가능
