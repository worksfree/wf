# 제40회 경영지도사 생산관리 - 문제 6

## 제약이론(TOC) 집중개선프로세스

### 문제 요약
제약이론(Theory of Constraints, TOC)의 집중개선 5단계 프로세스에서:
- (1) ①, ②, ③에 들어갈 용어
- (2) 5단계의 순서: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ

```
1단계: 시스템의 (①)을 식별한다
2단계: (①)의 (②)을 최대화하는 방법을 결정한다
3단계: (③)의 일정이 2단계의 결정에 종속되도록 한다
4단계: (①)을 개선한다
5단계: 1단계로 돌아간다

ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
ㄷ. 시스템의 제약자원을 식별
ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
ㅁ. 제약자원 자체를 개선
```

---

## 📋 1. 제약이론(TOC) 개념

### (1) TOC(Theory of Constraints)
```
정의: 시스템의 목표 달성을 가로막는 제약요인을 식별하고
      집중적으로 개선하여 전체 시스템 성과를 향상시키는 경영 기법
```

**창시자**: 엘리 골드랫(Eliyahu M. Goldratt)
**대표 저서**: 『The Goal』

### (2) 핵심 원리

#### ① 시스템 사고
```
"체인은 가장 약한 고리만큼만 강하다"

전체 시스템의 성과는 가장 취약한 제약자원에 의해 결정됨
```

#### ② 쓰루풋(Throughput) 중심
```
쓰루풋: 판매를 통해 돈을 버는 속도
제약자원: 쓰루풋을 제한하는 병목(Bottleneck)
```

#### ③ 집중의 원리
```
모든 자원을 골고루 개선 ✗
제약자원에 집중 개선 ✓
```

## 🧮 2. 정답 도출

### (1) 빈칸 ①, ②, ③

#### 문맥 분석
```
1단계: 시스템의 (①)을 식별한다
       → 가장 취약한 부분 찾기
       → 답: "제약자원" 또는 "쓰루풋"

2단계: (①)의 (②)을 최대화하는 방법을 결정한다
       → 제약자원의 무엇을 최대화?
       → 답: "쓰루풋"

3단계: (③)의 일정이 2단계의 결정에 종속되도록 한다
       → 제약자원이 아닌 다른 자원
       → 답: "비제약자원"
```

### 정답
```
① 제약자원 (Constraint) 또는 쓰루풋
② 쓰루풋 (Throughput)
③ 비제약자원 (Non-constraint)
```

**참고**: ①은 문맥상 "제약자원"이 더 적절하지만, "쓰루풋"도 가능

### (2) 5단계 순서

#### 논리적 순서 분석

```
ㄷ. 시스템의 제약자원을 식별
    ↓
    먼저 문제가 무엇인지 찾아야 함

ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
    ↓
    제약자원을 어떻게 활용할지 결정

ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
    ↓
    나머지 자원들을 제약자원에 맞춤

ㅁ. 제약자원 자체를 개선
    ↓
    제약자원의 능력 향상

ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
    ↓
    새로운 제약자원 찾아 반복
```

### 정답
```
순서: ㄷ → ㄱ → ㄴ → ㅁ → ㄹ
```

## 📊 3. TOC 집중개선 5단계 상세 설명

### 1단계: 제약자원 식별 (Identify)
```
ㄷ. 시스템의 제약자원을 식별
```

**방법**
- 작업장 관찰: 재공품(WIP)이 쌓인 곳
- 데이터 분석: 가동률이 100%인 자원
- 쓰루풋 분석: 시스템 전체 속도를 결정하는 공정

**예시**
```
공정: A(10분) → B(15분) → C(8분) → D(12분)

B 공정이 가장 느림(15분) → 제약자원
```

---

### 2단계: 제약자원 최대 활용 (Exploit)
```
ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
```

**방법**
- 제약자원의 유휴시간 제거
- 불량품이 제약자원에 도달하지 않도록 사전 검사
- 제약자원의 준비시간(Setup Time) 최소화
- 제약자원 앞에 완충재고(Buffer) 배치

**중요**: 추가 투자 없이 기존 자원 최대 활용

**예시**
```
✓ B 공정 앞에 항상 작업 대기
✓ B 공정의 휴식시간 재조정
✓ B 공정의 작업 전환 최소화
✓ B 공정에 불량품 투입 방지
```

---

### 3단계: 다른 자원 종속 (Subordinate)
```
ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
```

**방법**
- 비제약자원은 제약자원의 속도에 맞춤
- 비제약자원의 과잉 생산 방지
- DBR(Drum-Buffer-Rope) 스케줄링 적용

**DBR 시스템**
```
Drum (북): 제약자원이 전체 리듬 결정
Buffer (완충재고): 제약자원 앞 재공품 확보
Rope (밧줄): 최초 투입 속도를 제약자원에 맞춤
```

**예시**
```
A 공정은 B 공정 속도에 맞춰 10분당 1개만 투입
(A의 능력이 10분당 2개라도 1개만 생산)
→ 재공품 과다 축적 방지
```

---

### 4단계: 제약자원 개선 (Elevate)
```
ㅁ. 제약자원 자체를 개선
```

**방법**
- 설비 증설 (B 공정 기계 1대 추가)
- 작업자 추가 배치
- 기술 향상 (공정 개선, 자동화)
- 외주 활용

**주의**: 투자 필요 → 2단계 최대 활용 후 진행

**예시**
```
Before: B 공정 15분/개
After: B 공정 기계 1대 추가 → 7.5분/개

→ 이제 B는 더 이상 제약자원 아님
→ 새로운 제약자원 발생 (예: D 공정)
```

---

### 5단계: 타성 방지 및 반복 (Repeat)
```
ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
```

**의미**
- 제약자원은 계속 바뀜
- 한 제약 해결 → 다른 제약 발생
- 지속적 개선(Continuous Improvement)

**주의**: 관성(Inertia) 극복
```
잘못된 예:
"B 공정이 제약이었으니 계속 B에 투자"
→ ✗ 이미 B는 제약 아님

올바른 예:
"이제 D 공정이 제약이므로 D에 집중"
→ ✓ 새로운 제약 식별 및 대응
```

## 📈 4. TOC 5단계 흐름도

```
┌─────────────────────────────────┐
│  1단계: 제약자원 식별 (ㄷ)         │
│  "어디가 병목인가?"                │
└─────────────┬───────────────────┘
              ↓
┌─────────────────────────────────┐
│  2단계: 제약자원 최대 활용 (ㄱ)     │

└─────────────┬───────────────────┘
              ↓
┌─────────────────────────────────┐
│  3단계: 비제약자원 종속 (ㄴ)        │
│  "다른 자원은 제약에 맞춤"          │
└─────────────┬───────────────────┘
              ↓
┌─────────────────────────────────┐
│  4단계: 제약자원 개선 (ㅁ)          │

              ↓
┌─────────────────────────────────┐

└─────────────┬───────────────────┘
              ↓
              (무한 반복)
```

## 💡 5. TOC의 핵심 개념

### (1) 쓰루풋 회계(Throughput Accounting)

```
쓰루풋(T) = 판매를 통해 돈을 버는 속도
재고(I) = 판매할 제품에 투자한 모든 돈
운영비용(OE) = 재고를 쓰루풋으로 전환하는 데 드는 돈

목표: T 최대화, I와 OE 최소화
```

### (2) 제약자원의 1분 = 시스템 전체의 1분

```
일반 자원의 1분 손실: 단지 그 자원만 손실
제약자원의 1분 손실: 전체 시스템 쓰루풋 손실

→ 제약자원은 절대 놀려서는 안 됨
→ 제약자원 앞에 완충재고 필수
```

### (3) 시간 활용의 구분

| 자원 유형 | 유휴시간 허용? | 이유 |
|----------|-------------|------|
| 제약자원 | ✗ 불허 | 전체 쓰루풋 손실 |
| 비제약자원 | ✓ 허용 | 과잉 생산 방지 |

```
비제약자원의 100% 가동 = 재공품 과다 = 낭비
비제약자원은 제약자원 속도에 맞춰 "적절히" 가동
```

## 🎯 6. TOC 적용 사례

### 사례 1: 제조 공정

**문제**
```
공정: A(10분) → B(20분) → C(8분)
B가 제약자원
```

**적용**
```
1단계: B 식별
2단계: B 앞에 완충재고, 준비시간 최소화 → 12개/시간
3단계: A는 12개/시간만 생산, C는 B 속도에 맞춤
4단계: B에 설비 추가 → 10분/개로 단축
5단계: 이제 A가 제약 → 다시 1단계
```

### 사례 2: 프로젝트 관리 (CCPM)

```
TOC를 프로젝트에 적용 = Critical Chain Project Management

핵심:
- Critical Chain (제약) 식별
- 버퍼 관리
- 멀티태스킹 제거
```

## 📝 7. 결론

### 최종 답안

```
(1) 빈칸
   ① 제약자원 (또는 쓰루풋)
   ② 쓰루풋
   ③ 비제약자원

(2) 5단계 순서
   ㄷ → ㄱ → ㄴ → ㅁ → ㄹ

   1단계(ㄷ): 시스템의 제약자원 식별
   2단계(ㄱ): 제약자원의 쓰루풋 최대화
   3단계(ㄴ): 비제약자원을 제약자원에 종속
   4단계(ㅁ): 제약자원 자체 개선
   5단계(ㄹ): 1단계로 돌아가 지속 개선
```

### 핵심 메시지

> **"시스템 전체를 개선하려면 제약자원에 집중하라"**

### TOC의 철학

```
"Tell me how you measure me, and I will tell you how I will behave."
"나를 어떻게 측정하는지 말해주면, 내가 어떻게 행동할지 말해주겠다."

→ 전체 최적화(Global Optimization) 중시
→ 부분 최적화(Local Optimization) 경계
```

### 경영 시사점

```
✓ 모든 자원을 100% 활용 ≠ 효율적
✓ 제약자원에 집중 투자
✓ 비제약자원은 제약에 맞춤
✓ 지속적 개선으로 계속 성장
✓ 전체 시스템 관점에서 의사결정
```

## 🔍 8. TOC vs 기존 관리 기법

| 구분 | 전통적 접근 | TOC 접근 |
|------|-----------|----------|
| **초점** | 모든 자원 균등 개선 | 제약자원 집중 |
| **효율** | 개별 자원 효율 극대화 | 시스템 전체 효율 극대화 |
| **재고** | 최소화 | 제약자원 앞은 확보 |
| **가동률** | 모든 자원 100% 목표 | 제약자원만 100% |
| **성과지표** | 원가, 효율성 | 쓰루풋, 리드타임 |
| **사고** | 분석적 사고 | 시스템 사고 |
