# 제40회 경영지도사 생산관리 - 문제 1

## 물적 생산성과 가치 생산성

### 문제 요약
생산인력 5명이 각각 월 150시간 근무하며, 5월과 6월의 생산량과 판매액이 주어졌을 때:
- 5월: 제품 A 1,200개, 제품 B 600개, 판매액 200,000천원
- 6월: 제품 A 900개, 제품 B 1,200개, 판매액 196,000천원

물적 생산성과 가치 생산성을 계산하고 경영 시사점을 도출하시오.

---

## 📋 1. 개념 정의

### (1) 물적 생산성 (Physical Productivity)
```
물적 생산성 = 생산량(개) / 투입인시(인시)
```
- **의미**: 투입된 노동 시간당 생산된 제품의 수량
- **특징**: 물리적 수량 기준, 가격 변동 영향 없음
- **용도**: 생산 효율성의 기술적 지표

### (2) 가치 생산성 (Value Productivity)
```
가치 생산성 = 생산액(천원) / 투입인시(인시)
```
- **의미**: 투입된 노동 시간당 창출된 가치(금액)
- **특징**: 가격 반영, 경제적 성과 측정
- **용도**: 수익성 및 경제적 효율성 지표

---

## 🧮 2. 계산 과정

### (1) 투입 인시 계산
```
월간 투입 인시 = 인원 × 월 근무시간
             = 5명 × 150시간
             = 750 인시
```

### (2) 5월 생산성 계산

#### 물적 생산성
```
총 생산량 = 1,200개 + 600개 = 1,800개

물적 생산성 = 1,800개 / 750인시
           = 2.4 개/인시
```

#### 가치 생산성
```
생산액 = 200,000천원

가치 생산성 = 200,000천원 / 750인시
           = 266.7 천원/인시
```

### (3) 6월 생산성 계산

#### 물적 생산성
```
총 생산량 = 900개 + 1,200개 = 2,100개

물적 생산성 = 2,100개 / 750인시
           = 2.8 개/인시
```

#### 가치 생산성
```
생산액 = 196,000천원

가치 생산성 = 196,000천원 / 750인시
           = 261.3 천원/인시
```

---

## 📊 3. 변화율 분석

### (1) 물적 생산성 변화
```
변화율 = (6월 - 5월) / 5월 × 100
      = (2.8 - 2.4) / 2.4 × 100
      = 16.7% (증가)
```

**해석**: 6월에 단위 시간당 생산량이 16.7% 증가하여 생산 효율이 향상됨

### (2) 가치 생산성 변화
```
변화율 = (6월 - 5월) / 5월 × 100
      = (261.3 - 266.7) / 266.7 × 100
      = -2.0% (감소)
```

**해석**: 6월에 단위 시간당 생산액이 2.0% 감소하여 경제적 효율이 하락함

---

## 📈 4. 결과 요약표

| 구분 | 5월 | 6월 | 변화율 |
|------|-----|-----|--------|
| **총 생산량** | 1,800개 | 2,100개 | +16.7% |
| **생산액** | 200,000천원 | 196,000천원 | -2.0% |
| **투입인시** | 750인시 | 750인시 | 0% |
| **물적 생산성** | 2.4개/인시 | 2.8개/인시 | **+16.7%** |
| **가치 생산성** | 266.7천원/인시 | 261.3천원/인시 | **-2.0%** |

---

## 💡 5. 경영 시사점

### (1) 핵심 발견: 물적 생산성 증가 ≠ 경제성 향상

**현상 분석**
```
물적 생산성: 2.4 → 2.8 (16.7% ↑)
가치 생산성: 266.7 → 261.3 (2.0% ↓)
```

이는 **생산량은 늘었지만 수익성은 오히려 감소**한 상황을 의미합니다.

### (2) 원인 분석

#### 제품 믹스 변화
```
5월: A제품 1,200개 (66.7%), B제품 600개 (33.3%)
6월: A제품 900개 (42.9%), B제품 1,200개 (57.1%)
```

**추정**
- A제품: 고가 제품 (약 111천원/개)
- B제품: 저가 제품 (약 163천원/개로 추정되나 실제로는 더 낮을 가능성)

**실제 단가 계산**
```
5월 평균 단가 = 200,000천원 / 1,800개 = 111.1천원/개
6월 평균 단가 = 196,000천원 / 2,100개 = 93.3천원/개

평균 단가 감소율 = -16.0%
```

### (3) 경영진에 대한 제언

#### ① 제품 믹스 최적화
```
권장사항:
- 고부가가치 제품(A) 판매 비중 확대
- 저수익 제품(B) 생산량 조정
- 제품별 공헌이익률 분석 필요
```

#### ② 가격 전략 재검토
```
대안:
- B제품 가격 인상 검토
- 고객 세분화 및 차별적 가격 책정
- 프리미엄 제품 라인 강화
```

#### ③ 원가 관리 강화
```
점검사항:
- 제품별 원가 구조 분석
- 변동비/고정비 최적화
- 생산 효율성과 수익성의 균형
```

#### ④ 수요 예측 및 판매 전략
```
필요조치:
- 시장 수요 정확한 예측
- 고수익 제품 판매 촉진
- 영업팀과 생산팀 협업 강화
```

### (4) 전략적 의사결정 기준

```
물적 생산성 ↑ + 가치 생산성 ↑ → 최적 (생산성과 수익성 동시 향상)
물적 생산성 ↑ + 가치 생산성 ↓ → 문제 (본 사례, 제품믹스 재검토)
물적 생산성 ↓ + 가치 생산성 ↑ → 고려 (고부가가치 전략)
물적 생산성 ↓ + 가치 생산성 ↓ → 위험 (즉시 개선 필요)
```

## 🎯 6. 결론

### 핵심 메시지
> **"생산량 증가가 반드시 수익성 향상을 의미하지는 않는다."**

### 경영자의 의사결정
1. **단기**: B제품 생산량 조정, A제품 판매 확대
2. **중기**: 제품별 수익성 분석 및 포트폴리오 최적화
3. **장기**: 고부가가치 제품 개발 및 시장 포지셔닝 강화

### 모니터링 지표
```
✓ 월별 제품믹스 비율
✓ 제품별 평균 판매 단가
✓ 제품별 공헌이익률
✓ 물적 생산성과 가치 생산성의 동시 추이
```

---

**답안 작성 시 주의사항**
1. 계산 과정을 모두 명시
2. 단위를 정확히 표기
3. 변화율 계산 시 소수점 처리 명확히
4. 경영 시사점을 구체적으로 제시
5. 단순 계산이 아닌 의사결정 관점에서 접근
