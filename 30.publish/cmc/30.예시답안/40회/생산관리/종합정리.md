## 2. 문제별 요약

### 문제 1: 물적생산성과 가치생산성 (30점)

#### 핵심 개념
```
물적 생산성 = 생산량 / 투입인시 (수량 기준)
가치 생산성 = 생산액 / 투입인시 (가격 반영)
```

#### 핵심 계산
- 5월 물적생산성: 2.4개/인시 (+16.7%)
- 6월 물적생산성: 2.8개/인시
- 5월 가치생산성: 266.7천원/인시 (-2.0%)
- 6월 가치생산성: 261.3천원/인시

#### 경영 시사점
- 물적 생산성 증가 ≠ 수익성 향상
- 제품 믹스 최적화 중요
- 고부가가치 제품 판매 필요

---

### 문제 2: EPQ 모형 (30점)

#### 핵심 개념
```
EPQ: 자체 생산 시 최적 생산량
점진적 입고 vs 일시 입고 (EOQ와의 차이)
```

#### 핵심 공식
```
Q* = √[(2×D×Cs×p) / (Ch×(p-d))]
Imax = Q* × (1 - d/p)
```

#### 핵심 계산
- 최적 생산량: 2,828개
- 최대 재고: 1,414개
- 연간 총비용: 14,140,000원

#### 의사결정
- 약 14일마다 생산
- 생산준비비용 = 재고유지비용

#### 핵심 비교

|------|----------------|----------------|
| 수요예측 오차 | 작다 | 크다 |

| 공헌이익 | 작다 | 크다 |
| 제품다양성 | 작다 | 크다 |

---

### 문제 4: 물류창고 입지선정 (10점)

#### 핵심 공식
```
X* = Σ(Wi×Xi) / ΣWi
Y* = Σ(Wi×Yi) / ΣWi
```

#### 핵심 계산
- 동일 운송량: (7.0, 6.0)
- 가중 운송량: (7.2, 6.9)
- 물동량 많은 곳으로 이동

---

### 문제 5: 자체생산 vs 외주생산 (10점)

#### 핵심 공식
```
BEP = FC / (VC2 - VC1)
```

#### 핵심 계산
- 손익분기 생산량: 40,000개
- BEP를 20,000개로 낮추려면:
  - 변동비 1,250원 절감 (25%)
  - 목표 변동비: 3,750원/개

#### 의사결정
- Q ≥ 40,000개: 자체 생산
- Q < 40,000개: 외주 생산

## 3. 핵심 개념 총정리

### 생산성 관리

#### 물적 생산성
```
정의: 투입 대비 산출의 물리적 비율
특징: 가격 변동 영향 없음
한계: 경제적 가치 반영 안 됨
```

#### 가치 생산성
```
정의: 투입 대비 금액 기준 산출
특징: 실제 경제적 성과 반영
중요성: 수익성 측정
```

---

### 재고 관리

#### EOQ (Economic Order Quantity)
```
상황: 외부 구매
입고: 일시 입고
공식: Q* = √(2DCo/Ch)
최대재고: Q
```

#### EPQ (Economic Production Quantity)
```
상황: 자체 생산
입고: 점진적 입고
공식: Q* = √[(2Dsp)/(Ch(p-d))]
최대재고: Q×(1-d/p)
```

---

### 공급사슬 관리

#### 효율적 공급사슬
```
목표: 비용 최소화
제품: 기능성 제품
전략: JIT, 재고 최소화
사례: 월마트, 도요타
```

#### 반응적 공급사슬
```

제품: 혁신 제품
전략: 완충재고, 유연성

```

## 4. 계산 공식 모음

### 생산성
```
물적 생산성 = 생산량 / 투입인시
가치 생산성 = 생산액 / 투입인시
변화율 = (당기 - 전기) / 전기 × 100
```

### EPQ
```
Q* = √[(2×D×Cs×p) / (Ch×(p-d))]
Imax = Q* × (p-d) / p
평균재고 = Imax / 2
TC = √[2×D×Cs×Ch×(p-d)/p]
```

### 입지선정
```
X* = Σ(Wi×Xi) / ΣWi
Y* = Σ(Wi×Yi) / ΣWi
```

### 손익분기점
```
BEP = FC / (VC2 - VC1)
TC = FC + VC × Q
```
