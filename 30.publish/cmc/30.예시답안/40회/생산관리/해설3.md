# 제40회 경영지도사 생산관리 - 문제 3

## 공급사슬의 유형

### 문제 요약
효율적(Efficient) 공급사슬과 반응적(Responsive) 공급사슬의 특성을 비교하고, 10가지 항목에 대한 적절한 답을 선택하시오.

---

## 📋 1. 공급사슬 전략의 개념

### (1) 효율적(Efficient) 공급사슬
```
목표: 비용 최소화를 통한 효율성 극대화
```

**특징**
- 안정적이고 예측 가능한 수요
- 표준화된 제품
- 가격 경쟁 중심
- 재고 최소화 전략

**대표 산업**: 생필품, 범용 제품

### (2) 반응적(Responsive) 공급사슬
```
목표: 신속한 대응을 통한 고객 만족 극대화
```

**특징**
- 변동이 크고 불확실한 수요
- 차별화된 제품
- 유연성과 속도 중심
- 충분한 완충재고 보유

**대표 산업**: 패션, 전자제품, 신제품

---

## 🧮 2. 10가지 항목별 정답 및 해설

### ① 수요예측 오차

| 효율적 공급사슬 | 반응적 공급사슬 |
|---------------|----------------|
| **작다** | **크다** |

**해설**
- 효율적: 안정적 수요 → 예측 정확도 높음 (예: 생필품)
- 반응적: 변동성 큰 수요 → 예측 어려움 (예: 패션 의류)

---

### ② ③ 경쟁우선순위

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ③ | **원가(Cost)** | 유연성 |
| ④ | 원가 | **유연성(Flexibility)** |

**해설**
- 효율적: 낮은 가격으로 시장 점유 → 원가 최소화 중시
- 반응적: 빠른 시장 대응 → 유연성과 신속성 중시

**예시**
- 효율적: 월마트 - "Everyday Low Price"
- 반응적: ZARA - "Fast Fashion"

---

### ⑤ ⑥ 재고투자

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ⑤ | **재고 최소화** | 완충재고 유지 |
| ⑥ | 재고 최소화 | **완충재고 유지** |

**해설**
- 효율적: 재고비용 절감 위해 JIT(Just-In-Time) 전략
- 반응적: 신속 대응 위해 충분한 안전재고 확보

**전략**
```
효율적: 최소 재고 + 높은 회전율
반응적: 충분한 재고 + 빠른 대응
```

---

### ⑦ ⑧ 공헌이익

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ⑦ | **작다(낮다)** | 크다 |
| ⑧ | 작다 | **크다(높다)** |

**해설**
- 효율적: 낮은 마진, 높은 판매량으로 수익 창출
- 반응적: 높은 마진, 차별화 프리미엄

**수익 구조**
```
효율적: 낮은 이익률 × 높은 판매량 = 총이익
반응적: 높은 이익률 × 적정 판매량 = 총이익
```

---

### ⑨ ⑩ 제품다양성

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ⑨ | **작다(적다)** | 크다 |
| ⑩ | 작다 | **크다(많다)** |

**해설**
- 효율적: 소품종 대량생산, 표준화 제품
- 반응적: 다품종 소량생산, 맞춤형 제품

**전략**
```
효율적: 규모의 경제 추구
반응적: 범위의 경제 추구
```

## 💡 4. 두 전략의 종합 비교

### (1) 핵심 차이점

| 비교 기준 | 효율적 공급사슬 | 반응적 공급사슬 |
|----------|----------------|----------------|
| **목표** | 비용 최소화 | 신속 대응 |
| **제품** | 기능성 제품 | 혁신 제품 |
| **수요** | 안정적, 예측 가능 | 변동적, 불확실 |
| **제품 수명** | 장기 | 단기 |
| **리드타임** | 길어도 무방 | 최대한 짧게 |
| **재고 전략** | 최소화 (JIT) | 충분한 보유 |
| **생산 방식** | 소품종 대량 | 다품종 소량 |
| **원가 구조** | 낮은 마진 | 높은 마진 |
| **경쟁 요소** | 가격 | 속도, 다양성 |
| **사례** | 생필품, 원자재 | 패션, 전자기기 |

### (2) Fisher의 제품-공급사슬 매칭

```
제품 유형          추천 공급사슬
─────────────────────────────────
기능성 제품   →   효율적 공급사슬
(Functional)      (Efficient)
- 안정적 수요
- 긴 수명주기
- 낮은 마진

혁신 제품     →   반응적 공급사슬
(Innovative)      (Responsive)
- 불확실한 수요
- 짧은 수명주기
- 높은 마진
```

## 🎯 5. 실무 적용 사례

### (1) 효율적 공급사슬 사례

#### 월마트(Walmart)
```
전략: Everyday Low Price (EDLP)
방법:
- 대량 구매를 통한 원가 절감
- 효율적 물류 시스템
- 크로스도킹(Cross-docking)으로 재고 최소화
- 정보 시스템 통한 수요 예측
```

#### 도요타(Toyota)
```
전략: JIT(Just-In-Time) 생산
방법:
- 필요한 만큼만 생산
- 낭비 제거 (7대 낭비)
- 칸반(Kanban) 시스템
- 공급자와 긴밀한 협력
```

### (2) 반응적 공급사슬 사례

#### ZARA
```
전략: Fast Fashion
방법:
- 2주 내 신제품 출시
- 소량 생산으로 희소성 창출
- 재고 회전율 극대화
- 수직 계열화로 신속 대응
```

#### Apple
```
전략: 혁신과 프리미엄
방법:
- 신제품 출시 시 충분한 재고 확보
- 글로벌 공급망 다변화
- 고객 수요에 빠른 대응
- 높은 마진율 유지
```

## 📈 6. 하이브리드 전략

### (1) 실무에서의 혼합 전략

대부분의 기업은 두 전략을 적절히 혼합합니다.

```
예: 자동차 산업
- 표준 부품: 효율적 공급사슬
- 맞춤 옵션: 반응적 공급사슬
```

### (2) 지연(Postponement) 전략

```
개념: 제품 차별화 시점을 최대한 늦춤

방법:
1) 표준 제품을 효율적으로 대량 생산
2) 최종 단계에서 고객 주문에 따라 맞춤화
3) 효율성과 유연성의 동시 달성

사례: HP 프린터 - 표준 제품 생산 후 현지에서 전원장치 조립
```

## 🎯 7. 경영 의사결정 가이드

### 효율적 공급사슬을 선택해야 하는 경우
```
✓ 수요가 안정적이고 예측 가능
✓ 제품 수명주기가 길다
✓ 가격 경쟁이 치열하다
✓ 표준화된 제품
✓ 규모의 경제가 중요
```

### 반응적 공급사슬을 선택해야 하는 경우
```
✓ 수요가 불확실하고 변동성이 크다
✓ 제품 수명주기가 짧다
✓ 신속한 출시가 경쟁력
✓ 차별화된 제품
✓ 고객 맞춤이 중요
```

### 전환 전략
```
시장 성숙도에 따른 전략 전환:

신제품 출시 → 반응적 공급사슬
     ↓
시장 안정화 → 하이브리드 전략
     ↓
성숙 단계 → 효율적 공급사슬
```

## 📝 8. 결론

### 의사결정 원칙
```
1. 제품 특성 분석
   - 수요 패턴
   - 제품 수명주기
   - 고객 요구사항

2. 시장 환경 평가
   - 경쟁 강도
   - 불확실성 수준
   - 이익률

3. 공급사슬 전략 선택
   - 효율적 vs 반응적
   - 또는 하이브리드

4. 지속적 모니터링 및 조정
```

```
⑥ 반응적: 완충재고 유지
⑦ 효율적: 작다

```

**답안 작성 시 주의사항**
1. 각 특성의 대비 관계 명확히 이해
2. 단순 암기가 아닌 논리적 추론
3. 실무 사례로 이해도 입증
4. 효율적 = 원가/최소화, 반응적 = 유연성/충분함
