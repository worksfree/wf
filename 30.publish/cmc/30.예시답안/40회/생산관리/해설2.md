# 제40회 경영지도사 생산관리 - 문제 2

## 경제적 생산량(EPQ) 모형

### 문제 요약
- 연간 수요(D): 50,000개 (영업일 250일, 일일 수요 200개/일)
- 생산율(p): 400개/일
- 생산준비비용(Cs): 400,000원/회
- 재고유지비용(Ch): 10,000원/개·년

최적 생산량, 최대 재고수준, 연간 총비용을 계산하시오.

---

## 📋 1. EPQ 모형 개념

### (1) EPQ(Economic Production Quantity)
```
정의: 생산과 소비가 동시에 발생할 때의 최적 생산량
```

**특징**
- 자체 생산으로 재고 보충
- 생산 중에도 제품이 소비됨 (점진적 입고)
- 생산율(p) > 수요율(d)

### (2) EOQ와의 차이

| 구분 | EOQ | EPQ |
|------|-----|-----|
| **상황** | 외부 구매 | 자체 생산 |
| **입고 방식** | 일시 입고 | 점진적 입고 |
| **재고 증가** | 즉시 Q만큼 증가 | 생산 중 (p-d) 비율로 증가 |
| **최대 재고** | Q | Q × (1 - d/p) |
| **적용** | 구매 의사결정 | 생산 의사결정 |

---

## 🧮 2. 계산 과정

### (1) 기본 데이터 정리

```
D (연간 수요) = 50,000개/년
d (일일 수요율) = 200개/일
p (일일 생산율) = 400개/일
Cs (생산준비비용) = 400,000원/회
Ch (재고유지비용) = 10,000원/개·년
```

### (2) 최적 생산량(Q*) 계산

#### EPQ 공식
```
Q* = √[(2 × D × Cs × p) / (Ch × (p - d))]
```

#### 단계별 계산
```
1단계: 분자 계산
= 2 × D × Cs × p
= 2 × 50,000 × 400,000 × 400
= 16,000,000,000,000

2단계: 분모 계산
= Ch × (p - d)
= 10,000 × (400 - 200)
= 10,000 × 200
= 2,000,000

3단계: 분수 계산
= 16,000,000,000,000 / 2,000,000
= 8,000,000

4단계: 제곱근
Q* = √8,000,000
   = 2,828.4개
   ≈ 2,828개
```

**답**: Q* = **2,828개**

### (3) 최대 재고수준(Imax) 계산

#### 공식
```
Imax = Q* × (1 - d/p)
     = Q* × (p - d) / p
```

#### 계산
```
Imax = 2,828 × (1 - 200/400)
     = 2,828 × (1 - 0.5)
     = 2,828 × 0.5
     = 1,414개
```

**답**: Imax = **1,414개**

#### 의미
- 생산이 완료되는 시점의 재고량
- 생산 중 일부가 소비되므로 Q*보다 작음
- 평균 재고 = Imax / 2 = 707개

### (4) 연간 총비용(TC) 계산

#### 총비용 구성
```
TC = 생산준비비용 + 재고유지비용
```

#### 방법 1: 직접 계산
```
1) 연간 생산 횟수(N)
N = D / Q*
  = 50,000 / 2,828
  = 17.68회

2) 생산준비비용
= N × Cs
= 17.68 × 400,000
= 7,072,000원

3) 평균 재고
= Imax / 2
= 1,414 / 2
= 707개

4) 재고유지비용
= 평균재고 × Ch
= 707 × 10,000
= 7,070,000원

5) 총비용
TC = 7,072,000 + 7,070,000
   = 14,142,000원
   ≈ 14,140,000원
```

#### 방법 2: EPQ 총비용 공식
```
TC = √[2 × D × Cs × Ch × (p - d) / p]
```

```
TC = √[2 × 50,000 × 400,000 × 10,000 × (400-200) / 400]
   = √[2 × 50,000 × 400,000 × 10,000 × 0.5]
   = √[200,000,000,000,000]
   = 14,142,136원
   ≈ 14,140,000원
```

**답**: TC = **14,140,000원** (약 1,414만원)

## 📈 4. EPQ 모형의 특성 분석

### (1) 최적 조건
```
생산준비비용 = 재고유지비용
```

위 계산에서:
- 생산준비비용: 7,072,000원
- 재고유지비용: 7,070,000원
- **거의 동일** → 최적점 달성

### (2) 재고 변동 패턴

```
재고량
 ↑
1,414 |     /\      /\      /\
      |    /  \    /  \    /  \
  707 |---/----\--/----\--/----\--- (평균재고)
      |  /      \/      \/      \
    0 |_/_______________________\____→ 시간
         7.1일      14.1일
      [생산기간] [소비기간]
```

**특징**
- 생산 중(7.1일): 재고가 (p-d) 비율로 증가
- 생산 후(7.0일): 재고가 d 비율로 감소
- 주기적 반복

### (3) p와 d의 관계

```
p/d 비율 = 400/200 = 2

의미: 생산 속도가 수요 속도의 2배
→ 생산 기간 동안 순증가율 = 50%
→ 최대 재고 = Q* × 50%
```

## 💡 5. 경영 의사결정 시사점

### (1) 생산 계획 수립

```
권장 생산 전략:
- 1회 생산량: 2,828개
- 생산 빈도: 약 17~18회/년 (월 1.5회)
- 생산 주기: 약 14일마다
```

### (2) 재고 관리

```
✓ 최대 재고 1,414개 이하 유지
✓ 평균 재고 707개 목표
✓ 안전재고 추가 고려 (불확실성 대응)
```

### (3) 비용 최적화 방안

#### 생산준비비용 절감 시 효과
```
만약 Cs를 50% 절감 (400,000 → 200,000):
Q* = √(8,000,000 × 0.5) = 2,000개
→ 생산 횟수 증가, 재고 감소
→ TC 감소
```

#### 재고유지비용 절감 시 효과
```
만약 Ch를 50% 절감 (10,000 → 5,000):
Q* = √(8,000,000 × 2) = 4,000개
→ 생산 횟수 감소, 재고 증가
→ TC 감소
```

### (4) 생산 능력 고려

```
확인사항:
✓ 일일 생산능력 400개/일 충분한가?
✓ 2,828개 생산을 7일 내에 완료 가능한가?
✓ 생산 라인 가동률은 적정한가?
```

### (5) 수요 변동성 대응

```
리스크:
- 수요 변동 시 재고 부족 또는 과잉
- 생산능력 제약 발생 가능

대책:
- 수요 예측 정확도 향상
- 안전재고 설정 (예: 평균 재고의 20%)
- 유연한 생산 계획 수립
```

## 🎯 6. EOQ와 비교 분석

### 만약 외부 구매(EOQ)라면?

```
EOQ = √[(2 × D × Cs) / Ch]
    = √[(2 × 50,000 × 400,000) / 10,000]
    = √[4,000,000,000 / 10,000]
    = √400,000,000
    = 20,000개

최대 재고 = 20,000개 (일시 입고)
평균 재고 = 10,000개
```

### 비교

| 항목 | EOQ (외부구매) | EPQ (자체생산) |
|------|---------------|---------------|
| 최적 주문/생산량 | 20,000개 | 2,828개 |
| 최대 재고 | 20,000개 | 1,414개 |
| 평균 재고 | 10,000개 | 707개 |
| 재고 회전율 | 낮음 | 높음 |
| 재고 투자 | 큼 | 작음 |

**결론**: 자체 생산 시 재고 부담이 훨씬 적음
