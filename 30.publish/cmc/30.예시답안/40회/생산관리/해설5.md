# 제40회 경영지도사 생산관리 - 문제 5

## 자체생산 vs 외주생산 의사결정

### 문제 요약
- 자체생산: 고정비 50,000,000원, 변동비 5,000원/개
- 외주생산: 고정비 0원, 변동비 6,250원/개

(1) 자체생산과 외주생산의 손익분기 생산량은?
(2) 손익분기 생산량을 20,000개로 낮추려면 변동비를 얼마나 절감해야 하는가?

---

## 📋 1. 자체생산 vs 외주생산 의사결정 개념

### (1) Make-or-Buy 의사결정
```
정의: 제품이나 부품을 자체 생산할지, 외부에서 구매할지 결정하는 전략적 의사결정
```

**고려 요소**
- 비용 (고정비, 변동비)
- 품질 통제
- 생산 능력
- 핵심 역량
- 공급 안정성

### (2) 원가 구조

#### 자체생산
```
총비용(TC1) = 고정비(FC1) + 변동비(VC1) × 수량(Q)
```
- 고정비: 설비, 인건비 등
- 변동비: 재료비, 전력비 등

#### 외주생산
```
총비용(TC2) = 고정비(FC2) + 변동비(VC2) × 수량(Q)
```
- 고정비: 보통 0원 또는 매우 작음
- 변동비: 구매 단가

## 🧮 2. (1) 손익분기 생산량 계산

### 주어진 데이터
```
자체생산:
- FC1 = 50,000,000원
- VC1 = 5,000원/개

외주생산:
- FC2 = 0원
- VC2 = 6,250원/개
```

### 손익분기점(BEP) 개념
```
손익분기 생산량: 자체생산 총비용 = 외주생산 총비용이 되는 생산량
```

### 손익분기점 공식 유도

```
TC1 = TC2
FC1 + VC1 × Q = FC2 + VC2 × Q
50,000,000 + 5,000 × Q = 0 + 6,250 × Q
50,000,000 = 6,250Q - 5,000Q
50,000,000 = 1,250Q
Q = 50,000,000 / 1,250
Q = 40,000개
```

### 손익분기 생산량
```
Q* = 40,000개
```

**답**: 손익분기 생산량은 **40,000개**

## 📊 3. 손익분기점 분석

### (1) 비용 비교표

| 생산량(Q) | 자체생산 총비용 | 외주생산 총비용 | 차이 (자체-외주) |
|----------|----------------|----------------|-----------------|
| 0 | 50,000,000 | 0 | +50,000,000 |
| 10,000 | 100,000,000 | 62,500,000 | +37,500,000 |
| 20,000 | 150,000,000 | 125,000,000 | +25,000,000 |

| 50,000 | 300,000,000 | 312,500,000 | -12,500,000 |
| 60,000 | 350,000,000 | 375,000,000 | -25,000,000 |

### (2) 비용 그래프

```
비용(백만원)
  ↑
400│                          외주생산
   │                       ╱  (VC2=6,250)
350│                    ╱
   │                 ╱
300│              ╱   자체생산
   │           ╱    (FC1=50M, VC1=5,000)
250│        ╱ ×
   │     ╱   └─ BEP (40,000개)
200│  ╱
   │╱
150│
   │
100│━━━━━━━
 50│      FC1=50M
   └────────────────────────────→ 생산량(천개)
    0  10  20  30  40  50  60
```

### (3) 의사결정 기준

```
Q < 40,000개: 외주생산이 유리
Q = 40,000개: 동일 (무차별점)
Q > 40,000개: 자체생산이 유리
```

## 🧮 4. (2) 변동비 절감 목표 계산

### 목표
```
손익분기 생산량을 40,000개 → 20,000개로 낮추기
```

### 의미
```
더 낮은 생산량에서도 자체생산이 유리하게 만들기
→ 자체생산의 경쟁력 향상
```

### 새로운 손익분기점 공식

```
Q* = FC1 / (VC2 - VC1')

여기서:
- Q* = 20,000개 (목표)
- FC1 = 50,000,000원 (고정)
- VC2 = 6,250원/개 (고정)
- VC1' = 구하고자 하는 새로운 변동비
```

### 역산 계산

```
20,000 = 50,000,000 / (6,250 - VC1')
6,250 - VC1' = 50,000,000 / 20,000
6,250 - VC1' = 2,500
VC1' = 6,250 - 2,500
VC1' = 3,750원/개
```

### 변동비 절감액

```
현재 변동비: 5,000원/개
목표 변동비: 3,750원/개

절감액 = 5,000 - 3,750 = 1,250원/개
절감율 = 1,250 / 5,000 × 100 = 25%
```

**답**: 변동비를 개당 **1,250원 절감** (25% 감소)하여 **3,750원/개**로 낮춰야 함

## 💡 6. 경영 의사결정 시사점

### (1) 변동비 절감 방안

#### ① 재료비 절감
```
✓ 대량 구매를 통한 단가 인하
✓ 대체 재료 탐색
✓ 공급업체 다변화 및 경쟁 입찰
```

#### ② 공정 개선
```
✓ 자동화로 인건비 절감
✓ 불량률 감소
✓ 생산성 향상 (시간당 생산량 증가)
```

#### ③ 에너지 효율화
```
✓ 에너지 효율 높은 설비 도입
✓ 전력 사용 최적화
```

#### ④ 외주 협력
```
✓ 일부 공정 외주화
✓ 핵심 공정만 자체 수행
```

### (2) 고정비 관리

현재 문제는 변동비 절감이지만, 고정비 절감도 효과적:

```
만약 고정비를 50M → 25M로 절감:
Q* = 25,000,000 / 1,250 = 20,000개

→ 동일 효과
```

**고정비 절감 방법**
```
✓ 설비 리스 대신 임대
✓ 유휴 설비 매각 또는 임대
✓ 인력 효율화
```

### (3) 전략적 의사결정 기준

#### 자체생산을 선택해야 하는 경우
```
✓ 예상 생산량이 BEP보다 충분히 큼
✓ 품질 통제가 중요
✓ 핵심 역량에 해당
✓ 공급 안정성 확보 필요
✓ 기술 유출 방지
```

#### 외주생산을 선택해야 하는 경우
```
✓ 예상 생산량이 BEP보다 작음
✓ 자본 투자 부담
✓ 비핵심 영역
✓ 수요 불확실성 높음
✓ 유연성 필요
```

### (4) 리스크 고려

#### 수요 불확실성
```
시나리오 분석:
- 낙관: Q = 60,000개 → 자체생산
- 기본: Q = 40,000개 → 무차별
- 비관: Q = 20,000개 → 외주생산

→ 의사결정나무로 기댓값 계산
```

#### 고정비 회수 기간
```
회수 기간 = FC1 / [(VC2 - VC1) × Q]

예: Q = 50,000개/년
= 50,000,000 / [(6,250 - 5,000) × 50,000]
= 50,000,000 / 62,500,000
= 0.8년 (약 10개월)

→ 1년 내 회수 가능하면 긍정적
```
