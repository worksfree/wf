# 제40회 경영지도사 품질경영 - 문제 5

## 통계적 품질관리

---

## 📋 (1) 통계적 품질관리의 개념 (3점)

### 정의
```
통계적 품질관리(SQC: Statistical Quality Control):
통계적 기법과 원리를 활용하여 제품이나 서비스의 품질을
체계적으로 관리하고 개선하는 활동
```

### 상세 설명

#### 핵심 개념

**1. 통계적 접근**
```
- 전수검사가 아닌 샘플링 기반
- 확률 및 통계 이론 활용
- 데이터 기반 의사결정
```

**2. 변동의 이해**
```
품질 특성의 변동 = 우연 원인 + 이상 원인

- 우연 원인(Chance Cause / Common Cause):
  * 제거 불가능한 불가피한 변동
  * 시스템에 내재된 랜덤한 변동
  * 정규분포를 따름

- 이상 원인(Assignable Cause / Special Cause):
  * 식별 및 제거 가능한 변동
  * 특정할 수 있는 원인
  * 관리 이탈 신호
```

**3. 관리 상태 (State of Statistical Control)**
```
- 우연 원인만 존재하는 상태
- 예측 가능한 변동
- 공정이 안정적
```

---

### 목적

```
✓ 품질의 예측 및 통제
✓ 불량 발생 사전 예방
✓ 공정 능력 파악
✓ 검사 비용 절감
✓ 품질 개선의 과학적 근거 제공
```

---

### 특징

**1. 예방 중심**
```
사후 검사 → 사전 예방
불량 발견 → 불량 예방
```

**2. 데이터 기반**
```
주관적 판단 → 객관적 데이터
경험 의존 → 통계 분석
```

**3. 전수검사 대체**
```
전수검사: 시간·비용 과다
샘플링: 경제적·효율적
→ 통계 이론으로 모집단 추정
```

**4. 공정 중심**
```
제품 검사 → 공정 관리
결과 중심 → 프로세스 중심
```

---

### 주요 구성 요소

**1. 샘플링 검사 (Sampling Inspection)**
```
- 모집단에서 샘플 추출
- 샘플 검사 결과로 합격/불합격 판정
- 경제적이고 효율적
```

**2. 관리도 (Control Chart)**
```
- 공정의 시간 흐름에 따른 변동 관리
- 관리 한계선 설정
- 이상 원인 탐지
```

**3. 공정 능력 분석 (Process Capability Analysis)**
```
- 공정의 품질 생산 능력 평가
- Cp, Cpk 등 지수 산출
- 설계 규격과 실제 공정 비교
```

---

### 역사적 배경

```
1920년대: Shewhart의 관리도 개발
1930년대: Dodge & Romig의 샘플링 검사표
1950년대: 일본의 TQC 운동
1980년대: 6시그마 등장
```

---

### 효과

```
✓ 불량률 감소
✓ 생산성 향상
✓ 검사 비용 절감
✓ 고객 만족도 향상
✓ 경쟁력 강화
```

## 📊 (2) QC 7가지 도구 (7점)

### 개요
```
QC 7가지 도구: 품질 문제 해결을 위한 기본적인 통계적 도구
- 일본의 이시카와 카오루(Kaoru Ishikawa) 교수가 체계화
- "QC의 7가지 도구"로 통칭
- 현장에서 쉽게 활용 가능
```

---

### 1. 체크 시트 (Check Sheet / Tally Sheet)

#### 정의
```
데이터를 체계적이고 간편하게 수집·기록하기 위한 양식
```

#### 목적
```
✓ 데이터 수집의 표준화
✓ 기록의 용이성
✓ 데이터 분석 준비
```

#### 종류

**① 점검용 체크 시트**
```
- 작업 완료 여부 확인
- 체크리스트 형태
```

**② 기록용 체크 시트**
```
- 데이터 수치 기록
- 불량 발생 기록
```

**③ 위치 체크 시트**
```
- 불량 발생 위치 표시
- 도면이나 그림에 표시
```

#### 예시
```
[불량 유형별 체크 시트]

날짜: 2025-01-10

불량 유형     | 정(正) 표시  | 합계
─────────────┼─────────────┼─────
치수 불량     | 正正正       | 13
표면 흠집     | 正正         | 8
도장 불량     | 正           | 5
기타         | 正正         | 7
─────────────┼─────────────┼─────
합계         |              | 33
```

### 2. 히스토그램 (Histogram)

#### 정의
```
데이터의 분포 상태를 막대그래프 형태로 시각화한 도구
```

#### 목적
```
✓ 데이터의 분포 형태 파악
✓ 중심 경향 및 산포도 확인
✓ 규격과의 관계 분석
```

#### 구성 요소
```
- 계급(Class): 데이터 구간
- 도수(Frequency): 각 계급의 데이터 개수
- 계급 폭(Class Width): 각 구간의 너비
```

#### 예시
```
     도수
     ↑
  25 │
  20 │     ██
  15 │   ████
  10 │ ██████
   5 │████████
   0 └────────────→ 측정값
     LSL  μ  USL

LSL: 하한 규격
USL: 상한 규격
μ: 평균
```

#### 분석 포인트
```
✓ 분포의 중심 위치
✓ 분포의 폭(산포)
✓ 분포의 형태(정규분포 여부)
✓ 규격 한계와의 관계
✓ 이상 데이터 존재 여부
```

---

### 3. 파레토 차트 (Pareto Chart)

#### 정의
```
항목을 크기 순서로 나열한 막대그래프와 누적 비율 선그래프를 결합한 도구
```

#### 목적
```
✓ 중요 소수(Vital Few) 파악
✓ 개선 우선순위 결정
✓ 80/20 법칙 적용
```

#### 파레토 원리 (80/20 법칙)
```
"전체 결과의 80%는 전체 원인의 20%에서 발생한다"
```

#### 예시
```
불량건수                          누적비율(%)
   ↑                                    ↑
100│                              100%  │
 80│██              ─────────────  80%  │
 60│██                                  │
 40│██ ██           ─────────  60%      │
 20│██ ██ ██       ──────  40%          │
  0└─────────────────────────────→      │
    A   B  C  D  E                      │

A: 치수 불량 (50건)
B: 표면 흠집 (25건)
C: 도장 불량 (15건)
...
```

#### 활용
```
1. 불량 항목을 크기순 정렬
2. 누적 비율 계산
3. 상위 20% 항목이 80% 기여하는지 확인
4. 중요 항목부터 개선
```

---

### 4. 특성 요인도 (Cause and Effect Diagram / Fishbone Diagram / Ishikawa Diagram)

#### 정의
```
결과(특성)와 그 원인(요인)의 관계를 물고기 뼈 모양으로 체계화한 도구
```

#### 목적
```
✓ 문제의 원인 규명
✓ 체계적 원인 분석
✓ 팀원 간 아이디어 공유
```

#### 구조
```
          대분류 1          대분류 2
             │                │
        ─────┼────        ────┼─────
        │    │    │        │  │  │
       소분류들           소분류들
                  ╲        ╱
                   ╲      ╱
                    ╲    ╱
                     ───→  특성
                           (결과)
          대분류 3          대분류 4
             │                │
        ─────┼────        ────┼─────
```

#### 4M (제조업) / 5M / 6M
```
Man (사람): 기능, 훈련, 의식
Machine (설비): 정밀도, 보전, 노후화
Material (재료): 품질, 규격, 공급업체
Method (방법): 작업 순서, 조건, 표준

+ Measurement (측정): 정확도, 방법
+ Mother Nature (환경): 온도, 습도
```

#### 작성 방법
```
1. 특성(결과) 명확히 정의
2. 대분류 설정 (4M 등)
3. 중분류, 소분류 원인 도출 (Brainstorming)
4. 중요 원인 표시
5. 검증 및 대책 수립
```

---

### 5. 산점도 (Scatter Diagram)

#### 정의
```
두 변수 간의 상관관계를 점으로 표시하여 시각화한 도구
```

#### 목적
```
✓ 변수 간 상관관계 파악
✓ 원인-결과 관계 검증
✓ 회귀 분석 기초 자료
```

#### 상관관계 유형

```
(1) 강한 양의 상관          (2) 약한 양의 상관
     y                           y
     ↑  ●                        ↑   ●
        ●●                          ● ●
       ●●●                        ●  ●
      ●●●●                      ●    ●
     ●●●●●                    ●      ●
    ────────→ x               ──────────→ x

(3) 상관 없음                (4) 음의 상관
     y                           y
     ↑ ● ●●                      ↑ ●●●●●
       ● ● ●                        ●●●●
       ●  ● ●                       ●●●
       ● ●● ●                        ●●
       ●●  ●                          ●
    ────────→ x               ──────────→ x
```

#### 상관계수 (r)
```
r = +1.0 : 완전한 양의 상관
r = +0.7~+0.9 : 강한 양의 상관
r = +0.4~+0.6 : 중간 양의 상관
r = 0 : 상관 없음
r = -0.4~-0.6 : 중간 음의 상관
r = -0.7~-0.9 : 강한 음의 상관
r = -1.0 : 완전한 음의 상관
```

#### 활용 예시
```
- 온도 vs 불량률
- 작업 시간 vs 숙련도
- 재료 경도 vs 제품 강도
```

### 6. 관리도 (Control Chart)

#### 정의
```
공정의 시간적 변동을 관리하고 이상 원인을 탐지하기 위한 도구
```

#### 목적
```
✓ 공정의 관리 상태 확인
✓ 이상 원인 조기 발견
✓ 공정의 예측 가능성 확보
```

#### 구조
```
     측정값
        ↑
   UCL  │─────────────────────  상한 관리선
        │    ●    ●      ●
   CL   │──●───●───●─●────●──  중심선
        │●           ●
   LCL  │─────────────────────  하한 관리선
        │
        └────────────────────→ 시간(샘플 번호)

UCL: Upper Control Limit (상한 관리 한계선)
CL: Center Line (중심선)
LCL: Lower Control Limit (하한 관리 한계선)
```

#### 관리도 종류

**계량형 관리도**
```
- X̄-R 관리도: 평균과 범위
- X̄-s 관리도: 평균과 표준편차
- X-Rm 관리도: 개별값과 이동범위
```

**계수형 관리도**
```
- p 관리도: 불량률
- np 관리도: 불량 개수
- c 관리도: 결점 수
- u 관리도: 단위당 결점 수
```

#### 관리 이탈 판정 기준

**① 관리 한계선 이탈**
```
점이 UCL 또는 LCL 밖에 있음
```

**② 런(Run)**
```
중심선 위 또는 아래로 연속 7개 이상
```

**③ 경향(Trend)**
```
연속 7개 점이 상승 또는 하락
```

**④ 주기성(Cycle)**
```
일정한 주기로 상승/하락 반복
```

### 7. 층별 (Stratification)

#### 정의
```
데이터를 특정 기준(층)으로 분류하여 분석하는 기법
```

#### 목적
```
✓ 데이터 속 숨겨진 패턴 발견
✓ 문제 원인의 명확화
✓ 효과적인 대책 수립
```

#### 층별 기준 (4M 중심)

**Man (작업자)**
```
- 숙련도별 (신입/베테랑)
- 근무조별 (A조/B조)
- 개인별
```

**Machine (설비)**
```
- 기계별 (1호기/2호기)
- 신구 설비별
- 설비 유형별
```

**Material (재료)**
```
- 공급업체별
- 로트별
- 재질별
```

**Method (방법)**
```
- 작업 방법별
- 공정별
- 조건별
```

**기타**
```
- 시간대별 (오전/오후)
- 계절별
- 지역별
```

#### 활용 방법

**1. 층별 기준 선정**
```
문제와 관련 있는 요인 선택
```

**2. 데이터 분류**
```
선정된 기준으로 데이터 그룹화
```

**3. 층별 분석**
```
각 층의 특성 비교 분석
히스토그램, 관리도 등 활용
```

**4. 차이 원인 규명**
```
층 간 차이가 큰 경우 원인 조사
```

#### 예시
```
[작업조별 불량률 층별 분석]

A조: 불량률 2.5%
B조: 불량률 5.8%
C조: 불량률 2.3%

→ B조의 불량률이 높음
→ B조의 작업 방법, 숙련도, 설비 등 조사
→ 원인: B조는 신입이 많고 교육 부족
```

## 📊 QC 7가지 도구 활용 순서

### 문제 해결 프로세스

```
1. 문제 인식
   ↓
   [체크 시트] 데이터 수집
   ↓
2. 현상 파악
   ↓
   [히스토그램] 분포 확인
   [파레토 차트] 중요 항목 선정
   [층별] 차이 분석
   ↓
3. 원인 분석
   ↓
   [특성 요인도] 원인 도출
   [산점도] 상관관계 검증
   ↓
4. 대책 실시
   ↓
5. 효과 확인
   ↓
   [관리도] 공정 안정 확인
   [히스토그램] 개선 전후 비교
```

## 💡 QC 7가지 도구 vs 신 QC 7가지 도구

### 비교

| 구분 | QC 7가지 도구 | 신 QC 7가지 도구 |
|------|---------------|------------------|
| **대상** | 정량 데이터 | 정성 데이터, 언어 정보 |
| **목적** | 문제 해결, 데이터 분석 | 기획, 계획, 아이디어 정리 |
| **활용** | 제조 현장 | 개발, 기획, 관리 부서 |

### 신 QC 7가지 도구
```
1. 친화도법 (Affinity Diagram)
2. 연관도법 (Interrelationship Diagram)
3. 계통도법 (Tree Diagram)  ← 문제3에서 출제
4. 매트릭스도 (Matrix Diagram)  ← 문제3에서 출제
5. 매트릭스 데이터 해석법
6. PDPC법 (Process Decision Program Chart)
7. 애로우 다이어그램 (Arrow Diagram)
```
