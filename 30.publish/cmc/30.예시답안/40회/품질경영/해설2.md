# 제40회 경영지도사 품질경영 - 문제 2

## 품질경영 발전 및 개념

---

## 📋 (1) 파이겐바움(A.V. Feigenbaum)의 품질관리 발전 4단계 (8점)

### 개요
```
파이겐바움(Armand V. Feigenbaum, 1922-2014)
- 총체적 품질관리(TQC: Total Quality Control) 제창
- 품질관리의 발전 과정을 4단계로 체계화
```

---

### 1단계: 작업자 품질관리 (Operator Quality Control)

**시기**: 1900년대 초~1920년대

**특징**
```
- 개별 작업자가 자신의 작업 품질에 대해 책임
- 장인(Craftsman) 중심의 품질관리
- 수작업 중심 생산 시대
```

**주요 내용**
```
✓ 작업자가 직접 검사 및 품질 확인
✓ 기능과 검사의 비분리
✓ 작업자의 기술과 경험에 의존
✓ 소량 생산, 주문 생산 방식
```

**한계**
```
- 대량 생산 시대에 부적합
- 작업자마다 품질 편차 큼
- 체계적 품질관리 부재
```

---

### 2단계: 감독자 품질관리 (Foreman Quality Control)

**시기**: 1920년대~1940년대

**특징**
```
- 감독자(현장 관리자)가 품질관리 책임
- 대량 생산 시스템의 등장
- 분업과 전문화의 시작
```

**주요 내용**
```
✓ 생산 라인 감독자가 품질 검사 수행
✓ 작업 표준화 및 검사 기준 설정
✓ 불량품 선별 및 조치
✓ 테일러의 과학적 관리법 영향
```

**배경**
```
- 포드의 컨베이어 벨트 시스템
- 대량 생산으로 작업자 개별 검사 불가능
- 생산과 검사의 분리 시작
```

**한계**
```
- 사후 검사 중심 (예방 개념 미약)
- 감독자의 역량에 의존
- 전사적 품질 관점 부재
```

---

### 3단계: 검사 품질관리 (Inspection Quality Control)

**시기**: 1940년대~1960년대

**특징**
```
- 독립된 검사 부서 설치
- 통계적 품질관리(SQC)의 등장
- 과학적 품질관리 기법 도입
```

**주요 내용**
```
✓ 전문 검사부서 및 검사원 배치
✓ 샘플링 검사 기법 활용
✓ 관리도(Control Chart) 사용
✓ 수리통계학 기반 품질관리
```

**대표 기법**
```
- Shewhart의 관리도 (1924)
- Dodge & Romig의 샘플링 검사표
- 허용 품질 수준(AQL)
- 통계적 공정관리(SPC)
```

**의의**
```
✓ 품질관리의 과학화
✓ 전수검사에서 샘플링검사로 전환
✓ 품질의 예측 및 관리 가능
```

**한계**
```
- 여전히 사후 검사 중심
- 생산 부서와 검사 부서의 벽
- 품질은 검사부서의 책임이라는 인식
```

---

### 4단계: 총체적 품질관리 (Total Quality Control, TQC)

**시기**: 1960년대 이후

**특징**
```
- 전사적 품질관리 체계
- 예방 중심 품질관리
- 모든 부서와 구성원의 참여
```

**주요 내용**
```
✓ 전 부서(설계, 구매, 제조, 영업, A/S 등) 품질 책임
✓ 최고경영자의 품질 리더십
✓ 고객 중심의 품질 정의
✓ 지속적 개선(Continuous Improvement)
```

**핵심 원칙**
```
1. 품질은 전사적 책임
   - "Quality is everybody's job"
   - 모든 부서가 품질에 기여

2. 예방 중심
   - 불량 발생 후 검사 → 불량 예방
   - 공정 설계 단계부터 품질 확보

3. 시스템적 접근
   - 품질 시스템 구축
   - 프로세스 관점의 품질관리

4. 고객 만족
   - 고객 요구사항 중심
   - 내부 고객 + 외부 고객
```

**발전 양상**
```
TQC → TQM (Total Quality Management)
     → 6시그마
     → ISO 9000 시리즈
```

## 🎯 (2) 쥬란(J.M. Juran)의 품질 트릴러지 3단계 (12점)

### 개요
```
쥬란(Joseph M. Juran, 1904-2008)
- 품질의 구루(Guru) 중 한 명
- 품질 트릴러지(Quality Trilogy): 품질경영의 3대 과정
- "품질은 설계로 들어가고, 생산으로 나온다"
```

---

### 1단계: 품질계획 (Quality Planning)

#### 정의
```
고객의 요구사항을 파악하고, 이를 충족시킬 수 있는 제품과 프로세스를
설계하는 활동
```

#### 주요 활동

**① 고객 식별 (Identify Customers)**
```
- 외부 고객: 최종 사용자, 유통업자
- 내부 고객: 다음 공정 작업자, 타 부서
```

**② 고객 니즈 파악 (Determine Customer Needs)**
```
- 시장조사, VOC(Voice of Customer) 수집
- 고객 요구사항 명확화
- 명시적 요구 + 잠재적 요구
```

**③ 제품 특성 개발 (Develop Product Features)**
```
- 고객 요구를 제품 사양으로 전환
- 품질 기능 전개(QFD) 활용
- CTQ(Critical To Quality) 도출
```

**④ 프로세스 설계 (Develop Process)**
```
- 제품 생산을 위한 공정 설계
- 공정 능력 확보
- 작업 표준 설정
```

**⑤ 프로세스 이관 (Transfer to Operations)**
```
- 양산 부서로 이관
- 작업 매뉴얼 및 교육
- 초기 유동 관리
```

#### 결과물
```
✓ 제품 사양서
✓ 공정 흐름도
✓ 품질 계획서
✓ 작업 표준서
```

#### 중요성
```
"품질의 80%는 설계 단계에서 결정된다"
→ 계획 단계의 품질 확보가 가장 중요
```

---

### 2단계: 품질관리 (Quality Control)

#### 정의
```
제품이 계획된 품질 수준을 달성하고 유지하도록 공정을 관리·통제하는 활동
```

#### 주요 활동

**① 품질 측정 (Measure Performance)**
```
- 주요 품질 특성 측정
- 데이터 수집 및 기록
- 실시간 모니터링
```

**② 기준과 비교 (Compare to Standards)**
```
- 목표 vs 실제 성과 비교
- 관리 한계선 설정
- 이상 징후 탐지
```

**③ 이상 발생 시 조치 (Act on Difference)**
```
- 이상 원인 규명
- 시정 조치 실시
- 재발 방지 대책 수립
```

#### 주요 기법
```
✓ 통계적 공정관리(SPC)
✓ 관리도(Control Chart)
✓ 공정 능력 분석(Cp, Cpk)
✓ 샘플링 검사
```

#### 품질관리 사이클 (Control Loop)
```
    ┌──────────────┐
    │  목표 설정    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  실적 측정    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  비교 평가    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  시정 조치    │
    └──────┬───────┘
           │
           └──────→ (반복)
```

#### 목표
```
- 공정을 관리 상태로 유지
- 변동 최소화
- 안정적 품질 확보
```

---

### 3단계: 품질개선 (Quality Improvement)

#### 정의
```
현재의 품질 수준을 획기적으로 향상시키기 위한 프로젝트 중심의 활동
```

#### 주요 활동

**① 개선 인프라 구축 (Establish Infrastructure)**
```
- 품질협의회 설치
- 개선 팀 구성
- 자원 배분
```

**② 개선 프로젝트 선정 (Identify Projects)**
```
- 만성적 품질 문제 파악
- 파레토 분석으로 우선순위 결정
- 경영 목표와 연계
```

**③ 개선 팀 조직 (Organize Teams)**
```
- 프로젝트 팀 구성
- 역할 및 책임 부여
- 팀 리더 교육
```

**④ 근본 원인 분석 (Diagnose Causes)**
```
- 5 Why 분석
- 특성 요인도(Fishbone Diagram)
- 실험 계획법(DOE)
```

**⑤ 해결책 개발 및 실행 (Develop Remedies)**
```
- 개선 아이디어 도출
- 대책 수립 및 실행
- 효과 검증
```

**⑥ 효과 유지 (Hold Gains)**
```
- 표준화 및 문서화
- 교육 및 전파
- 지속적 모니터링
```

#### 주요 기법
```
✓ PDCA 사이클
✓ 6시그마 DMAIC
✓ QC 7가지 도구
✓ Kaizen (개선 활동)
```

#### 특징
```
- 혁신적 품질 향상
- 프로젝트 기반
- 팀 활동
- 지속적 개선(Continuous Improvement)
```

#### 쥬란의 품질개선 곡선

```
품질수준
   ↑
   │        개선 3
   │      ╱─────────  새로운 관리 수준
   │     ╱
   │    개선 2
   │   ╱─────────  새로운 관리 수준
   │  ╱
   │ 개선 1
   │╱─────────  초기 관리 수준
   │
   └──────────────────────────→ 시간

   단계적 개선 (Breakthrough Improvement)
```

---

### 품질 트릴러지의 통합 관계

```
┌──────────────┐
│ 품질 계획     │  → 새로운 제품/공정 설계
│(Planning)    │     고객 요구사항 반영
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 품질 관리     │  → 일상적 공정 관리
│(Control)     │     품질 유지 및 안정화
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 품질 개선     │  → 획기적 품질 향상
│(Improvement) │     만성 문제 해결
└──────┬───────┘
       │
       └──────→ 다시 계획 단계로
                (Spiral Up)
```

## 🎯 (3) 가빈(D.A. Garvin)의 5가지 품질 개념 (10점)

### 개요
```
가빈(David A. Garvin, 1955-2017)
- 하버드 경영대학원 교수
- "품질의 다차원적 접근"
- 품질을 5가지 관점에서 정의
```

---

### 1. 선험적(초월적) 품질 (Transcendent Quality)

#### 정의
```
품질은 절대적이고 보편적으로 인정되는 탁월함(Excellence)이며,
경험을 통해서만 인식할 수 있는 것
```

#### 특징
```
✓ 정의하거나 측정하기 어려움
✓ 직관적으로 인식 가능
✓ "알면 알 수 있다" (You know it when you see it)
✓ 예술적·철학적 개념
```

#### 장점
```
- 품질의 본질적 가치 강조
- 최고 수준 추구의 동기 부여
```

#### 단점
```
- 객관적 측정 불가
- 실무 적용 어려움
- 주관적 판단에 의존
```

#### 실무 적용
```
- 명품 브랜드: 롤스로이스, 에르메스
- "최고급", "프리미엄" 이미지
- 브랜드 가치
```

---

### 2. 제품 중심적 품질 (Product-Based Quality)

#### 정의
```
품질은 제품이 가지고 있는 측정 가능한 특성이나 속성의 양
```

#### 특징
```
✓ 객관적이고 정밀하게 측정 가능
✓ 수량화 가능
✓ 제품 사양(Specification) 중심
✓ 품질 = 특정 속성의 양
```

#### 예시
```
- 자동차: 마력, 연비, 최고속도
- 컴퓨터: CPU 속도, 메모리 용량, 저장공간
- 섬유: 실의 굵기, 밀도
```

#### 장점
```
- 명확한 측정 기준
- 제품 간 비교 용이
- 품질 등급 설정 가능
```

#### 단점
```
- 고객 니즈와 괴리 가능
- "많다 = 좋다"는 가정의 한계
- 과잉 품질(Over-Quality) 위험
```

#### 실무 적용
```
- 제품 사양서 작성
- 품질 등급 구분 (등급 A, B, C)
- 성능 테스트 기준
```

---

### 3. 사용자 중심적 품질 (User-Based Quality)

#### 정의
```
품질은 고객의 요구사항과 선호도를 충족시키는 정도
```

#### 특징
```
✓ 고객 관점의 품질
✓ 주관적이고 개인적
✓ "고객이 원하는 것 = 품질"
✓ 시장 중심적 접근
```

#### 핵심 개념
```
"Quality is fitness for use" (쥬란)
"고객이 만족하면 그것이 품질"
```

#### 장점
```
- 고객 만족 직결
- 시장 수요 반영
- 경쟁력 확보
```

#### 단점
```
- 고객마다 요구사항 상이
- 측정 및 표준화 어려움
- 비용 증가 가능성
```

#### 실무 적용
```
- 고객 만족도 조사
- VOC(Voice of Customer) 분석
- QFD(품질 기능 전개)
- 맞춤형 제품 개발
```

#### 예시
```
- 스마트폰: 사용 편의성, 디자인, 생태계
- 호텔: 서비스, 위치, 청결도
- 의류: 스타일, 편안함, 유행
```

---

### 4. 제조 중심적 품질 (Manufacturing-Based Quality)

#### 정의
```
품질은 설계 사양이나 표준에 대한 일치도(Conformance to Specifications)
```

#### 특징
```
✓ 생산 관점의 품질
✓ 규격 준수 여부
✓ "설계대로 만들었는가?"
✓ 변동 최소화 중요
```

#### 핵심 개념
```
품질 = 설계 사양과의 일치
불량 = 규격 이탈
```

#### 장점
```
- 명확한 기준
- 객관적 평가 가능
- 불량률 관리 용이
- 생산 효율성 향상
```

#### 단점
```
- 고객 관점 미흡
- 설계 사양 자체의 적절성 무시
- "규격 내 불량" 가능
```

#### 주요 기법
```
✓ 통계적 공정관리(SPC)
✓ 공정 능력 분석(Cp, Cpk)
✓ 6시그마
✓ 무결점 운동(ZD)
```

#### 실무 적용
```
- 도면과 실제 제품 비교
- 공차 관리
- 불량률 감소 활동
- ISO 9001 품질시스템
```

#### 예시
```
- 기계 부품: 치수 공차 ±0.01mm
- 전자 제품: 전압 220V ±10%
- 식품: 중량 100g ±5g
```

---

### 5. 가치 중심적 품질 (Value-Based Quality)

#### 정의
```
품질은 적절한 가격으로 제공되는 우수성 또는 성능
→ 품질 = 성능 / 가격
```

#### 특징
```
✓ 경제적 관점
✓ 비용 대비 성능
✓ "가성비(가격 대비 성능 비율)"
✓ 상대적 개념
```

#### 핵심 개념
```
"합리적 가격에 원하는 수준 충족"
고품질 ≠ 고가격
저품질 ≠ 저가격
```

#### 장점
```
- 경제적 합리성
- 시장 세분화 가능
- 가격 경쟁력 고려
```

#### 단점
```
- 품질과 가격의 교환(Trade-off)
- 저가 저품질의 정당화 위험
- 장기적 품질 저하 가능
```

#### 실무 적용
```
- 원가 절감 활동과 품질의 균형
- VE(Value Engineering)
- 목표 원가 설정
- 시장 세그먼트별 제품 전략
```

#### 예시
```
- 이코노미 항공사: 저가, 기본 서비스
- 패스트 패션: 빠른 유행 반영, 합리적 가격
- 제네릭 의약품: 동일 효과, 저가
```

## 💡 5가지 품질 개념의 종합 비교

| 품질 개념 | 관점 | 측정 가능성 | 주요 적용 분야 |
|-----------|------|-------------|----------------|
| **선험적** | 철학적 | 어려움 | 명품, 예술품 |
| **제품 중심** | 제품 속성 | 용이 | 기술 제품, 공산품 |
| **사용자 중심** | 고객 만족 | 중간 | 서비스, 소비재 |
| **제조 중심** | 규격 일치 | 용이 | 제조업, 생산 현장 |
| **가치 중심** | 가격 대비 성능 | 중간 | 대중 시장 제품 |

## 🎯 실무 통합 적용

### 균형잡힌 품질 전략

```
1. 고객 니즈 파악 (사용자 중심)
   ↓
2. 제품 사양 결정 (제품 중심)
   ↓
3. 제조 공정 관리 (제조 중심)
   ↓
4. 비용 효율성 검토 (가치 중심)
   ↓
5. 브랜드 이미지 구축 (선험적)
```

### 제품 수명주기별 강조점

```
- 설계 단계: 사용자 중심 + 제품 중심
- 생산 단계: 제조 중심
- 판매 단계: 가치 중심
- 브랜딩: 선험적 품질
```

## 📝 최종 정리

### 파이겐바움의 4단계
```
1. 작업자 품질관리 → 개인 책임
2. 감독자 품질관리 → 현장 관리자 책임
3. 검사 품질관리 → 전문 검사부서, 통계 기법
4. 총체적 품질관리 → 전사적 참여, 예방 중심
```

### 쥬란의 트릴러지
```
1. 품질계획 → 고객 요구를 제품/공정으로 전환
2. 품질관리 → 일상적 공정 관리 및 유지
3. 품질개선 → 획기적 품질 향상, 프로젝트 방식
```

### 가빈의 5가지 개념
```
1. 선험적 → 탁월함, 경험적 인식
2. 제품 중심 → 측정 가능한 속성
3. 사용자 중심 → 고객 요구사항 충족
4. 제조 중심 → 설계 사양 일치
5. 가치 중심 → 가격 대비 성능
```
