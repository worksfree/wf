## 이원배치 실험 및 분산분석

## 📋 문제 상황

### 실험 설계
```
- 인자 A: 반응 온도 (4수준) - A₁, A₂, A₃, A₄
- 인자 B: 원료 (3수준) - B₁, B₂, B₃
- 반응변수: 수율(%)
- 실험 방법: 반복 없는 이원배치 실험
```

### 실험 데이터

| 구분 | A₁ | A₂ | A₃ | A₄ | 계 |
|------|-----|-----|-----|-----|-------|
| B₁ | 97.6 | 98.6 | 99.0 | 98.0 | 393.2 |
| B₂ | 97.3 | 98.2 | 98.0 | 97.7 | 391.2 |
| B₃ | 96.7 | 96.9 | 97.9 | 96.5 | 388.0 |
| 계 | 291.6 | 293.7 | 294.9 | 292.2 | 1,172.4 |

## 🧮 (1) 분산분석표 완성 (5점)

### 주어진 분산분석표

| 요인 | SS | DF | MS | F₀ | F(0.95) | F(0.99) |
|------|-----|-----|-----|-----|---------|---------|
| A | 2.22 | 3 | 0.74 | 7.96* | 4.76 | 9.78 |
| B | ① | ② | ③ | ④ | 5.14 | 10.90 |
| E | 0.56 | 6 | 0.093 | - | - | - |
| T | 6.22 | 11 | - | - | - | - |

---

### 기본 공식 정리

#### 총 제곱합 (Total Sum of Squares, SST)
```
SST = ΣΣ(xᵢⱼ - x̄)² = ΣΣxᵢⱼ² - CT

CT (Correction Term) = T²/N
여기서 T: 총합, N: 총 관측값 개수
```

#### 제곱합 분해
```
SST = SSA + SSB + SSE

SSA: 인자 A의 제곱합
SSB: 인자 B의 제곱합
SSE: 오차 제곱합
```

---

### 계산 과정

#### Step 1: 기본 데이터 확인
```
총 관측값 수 N = 4 × 3 = 12
총합 T = 1,172.4

A₁ 합계 = 291.6
A₂ 합계 = 293.7
A₃ 합계 = 294.9
A₄ 합계 = 292.2

B₁ 합계 = 393.2
B₂ 합계 = 391.2
B₃ 합계 = 388.0
```

#### Step 2: ① SSB (인자 B의 제곱합) 계산

**공식**
```
SSB = Σ(Bⱼ²/nⱼ) - CT

여기서:
- Bⱼ: 각 B 수준의 합계
- nⱼ: 각 B 수준의 관측값 수 (= 4)
- CT: 보정항
```

**계산**
```
CT = T²/N = (1,172.4)²/12 = 1,374,521.76/12 = 114,543.48

SSB = (B₁²/4 + B₂²/4 + B₃²/4) - CT
    = (393.2²/4 + 391.2²/4 + 388.0²/4) - 114,543.48
    = (154,606.24/4 + 153,037.44/4 + 150,544.00/4) - 114,543.48
    = (38,651.56 + 38,259.36 + 37,636.00) - 114,543.48
    = 114,546.92 - 114,543.48
    = 3.44
```

**답**: ① SSB = **3.44**

---

#### Step 3: ② DFB (인자 B의 자유도) 계산

**공식**
```
DFB = b - 1

여기서 b: 인자 B의 수준 수 = 3
```

**계산**
```
DFB = 3 - 1 = 2
```

**답**: ② DFB = **2**

---

#### Step 4: ③ MSB (인자 B의 평균제곱) 계산

**공식**
```
MSB = SSB / DFB
```

**계산**
```
MSB = 3.44 / 2 = 1.72
```

**답**: ③ MSB = **1.72**

---

#### Step 5: ④ F₀ (F 통계량) 계산

**공식**
```
F₀ = MSB / MSE

여기서 MSE: 오차 평균제곱 = 0.093 (주어짐)
```

**계산**
```
F₀ = 1.72 / 0.093 = 18.49
```

**답**: ④ F₀ = **18.49**

---

### 검증: 제곱합 분해 확인

```
SST = SSA + SSB + SSE
6.22 = 2.22 + 3.44 + 0.56
6.22 = 6.22 ✓

→ 계산 정확함
```

---

### 완성된 분산분석표

| 요인 | SS | DF | MS | F₀ | F(0.95) | F(0.99) |
|------|-----|-----|-----|-----|---------|---------|
| A | 2.22 | 3 | 0.74 | 7.96* | 4.76 | 9.78 |
| B | **3.44** | **2** | **1.72** | **18.49*** | 5.14 | 10.90 |
| E | 0.56 | 6 | 0.093 | - | - | - |
| T | 6.22 | 11 | - | - | - | - |

---

### 통계적 검정 결과 해석

#### 인자 A (반응 온도) 검정
```
F₀ = 7.96
F(0.95) = 4.76
F(0.99) = 9.78

F₀(7.96) > F(0.95)(4.76) → 유의수준 5%에서 유의*
F₀(7.96) < F(0.99)(9.78) → 유의수준 1%에서 유의하지 않음

결론: 반응 온도는 수율에 유의한 영향을 미침 (α=0.05)
```

#### 인자 B (원료) 검정
```
F₀ = 18.49
F(0.95) = 5.14
F(0.99) = 10.90

F₀(18.49) > F(0.95)(5.14) → 유의수준 5%에서 유의**
F₀(18.49) > F(0.99)(10.90) → 유의수준 1%에서도 유의**

결론: 원료는 수율에 매우 유의한 영향을 미침 (α=0.01)
```

#### 종합 해석
```
✓ 인자 A (반응 온도): 유의함 (α=0.05)
✓ 인자 B (원료): 매우 유의함 (α=0.01)
✓ 원료가 온도보다 수율에 더 큰 영향을 미침
```

## 🎯 (2) 최적수준의 모평균 점추정값 (5점)

### 최적수준 결정

#### 각 수준별 평균 계산

**인자 A (반응 온도) 평균**
```
A₁ 평균 = 291.6 / 3 = 97.20%
A₂ 평균 = 293.7 / 3 = 97.90%
A₃ 평균 = 294.9 / 3 = 98.30%  ← 최대
A₄ 평균 = 292.2 / 3 = 97.40%
```

**인자 B (원료) 평균**
```
B₁ 평균 = 393.2 / 4 = 98.30%  ← 최대
B₂ 평균 = 391.2 / 4 = 97.80%
B₃ 평균 = 388.0 / 4 = 97.00%
```

**최적 조건**
```
최적 인자 조합: A₃B₁
- A₃ (반응 온도 3번 수준): 평균 98.30%
- B₁ (원료 1번): 평균 98.30%
```

---

### 모평균 점추정값 계산

#### 공식 (이원배치 실험)
```
μ̂(AᵢBⱼ) = x̄ + (x̄ᵢ. - x̄) + (x̄.ⱼ - x̄)
         = x̄ᵢ. + x̄.ⱼ - x̄

여기서:
- x̄: 전체 평균
- x̄ᵢ.: i번째 A 수준의 평균
- x̄.ⱼ: j번째 B 수준의 평균
```

#### 계산

**전체 평균**
```
x̄ = T / N = 1,172.4 / 12 = 97.70%
```

**A₃ 평균**
```
x̄₃. = 294.9 / 3 = 98.30%
```

**B₁ 평균**
```
x̄.₁ = 393.2 / 4 = 98.30%
```

**모평균 점추정값**
```
μ̂(A₃B₁) = x̄₃. + x̄.₁ - x̄
         = 98.30 + 98.30 - 97.70
         = 98.90%
```

---

### 검증: 실제 관측값과 비교

```
실제 관측값 x₃₁ = 99.0% (데이터표에서 A₃, B₁ 교차점)
추정값 μ̂(A₃B₁) = 98.90%

차이 = 99.0 - 98.90 = 0.10% (오차)

→ 추정값이 실제값과 매우 근사함
```

---

### 답안
```
최적수준의 모평균 점추정값: μ̂(A₃B₁) = 98.90%
```

```

```

**해석**
```
✓ 원료(B)의 효과가 약간 더 큼 (1.30% vs 1.10%)

```

---

### 기여율 (Contribution Ratio)

**공식**
```
기여율(%) = (각 요인의 SS / SST) × 100
```

**계산**
```
A의 기여율 = (2.22 / 6.22) × 100 = 35.7%
B의 기여율 = (3.44 / 6.22) × 100 = 55.3%
E의 기여율 = (0.56 / 6.22) × 100 = 9.0%

합계 = 100.0%
```

**해석**
```
원료(B)가 수율 변동의 55.3%를 설명
반응 온도(A)가 수율 변동의 35.7%를 설명
→ 원료 선택이 가장 중요
```
