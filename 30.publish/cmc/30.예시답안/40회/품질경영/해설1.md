# 제40회 경영지도사 품질경영 - 문제 1

## 품질비용(Quality Cost)

---

## 📋 (1) 품질비용의 정의 (5점)

### 정의
```
품질비용(Quality Cost): 제품이나 서비스의 품질을 확보하고 유지하기 위해
발생하는 모든 비용과 품질 미달로 인해 발생하는 손실비용의 총합
```

### 상세 설명

**1. 품질 확보 비용 (Cost of Quality Assurance)**
```
- 불량을 예방하고 품질을 평가하기 위해 적극적으로 투자하는 비용
- 예방비용 + 평가비용
```

**2. 품질 실패 비용 (Cost of Quality Failure)**
```
- 불량품이 발생하여 손실이 발생한 비용
- 사내실패비용 + 사외실패비용
```

### 품질비용의 중요성

```
✓ 품질 개선 활동의 경제적 정당성 제공
✓ 품질 관련 의사결정의 기준
✓ 품질비용 최소화를 통한 경쟁력 향상
✓ 예방 중심 품질경영 전환의 근거
```

---

## 📊 (2) 품질비용의 분류 및 내용 (9점)

### 1. 예방비용 (Prevention Cost)

**정의**: 불량이 발생하지 않도록 사전에 예방하는 활동에 소요되는 비용

#### 예방비용 항목 (3개)

**① 품질계획 비용**
```
- 품질 목표 수립 및 품질계획 수립
- 품질 매뉴얼 작성 및 품질 시스템 설계
- QC 공정도 작성
```

**② 교육훈련 비용**
```
- 품질 관련 교육 프로그램 운영
- 작업자 기능 향상 교육
- 품질 의식 고취 활동 비용
```

**③ 공정관리 비용**
```
- 통계적 공정관리(SPC) 시스템 운영
- 예방 보전 활동 비용
- 공정 능력 분석 비용
```

---

### 2. 평가비용 (Appraisal Cost)

**정의**: 제품이나 서비스가 품질 요구사항을 충족하는지 확인하고 측정하는 데 소요되는 비용

#### 평가비용 항목 (3개)

**① 검사비용**
```
- 수입검사, 공정검사, 최종검사 비용
- 검사원 인건비
- 검사 설비 및 기기 유지비
```

**② 시험비용**
```
- 제품 성능 시험 비용
- 파괴 시험 및 비파괴 시험
- 신뢰성 시험 비용
```

**③ 측정장비 관리비용**
```
- 측정기기 교정(Calibration) 비용
- 계측기 유지보수 비용
- 측정 시스템 분석(MSA) 비용
```

---

### 3. 실패비용 (Failure Cost)

**정의**: 품질 요구사항을 충족하지 못하여 발생하는 비용

#### 3-1. 사내실패비용 (Internal Failure Cost)

**정의**: 제품이 고객에게 인도되기 전에 발견된 불량으로 인한 비용

**① 재작업 비용 (Rework Cost)**
```
- 불량품을 정상품으로 만들기 위한 추가 작업 비용
- 재작업 인건비 및 재료비
- 재검사 비용
```

**② 폐기 비용 (Scrap Cost)**
```
- 수리 불가능한 불량품의 폐기 비용
- 불량품의 재료비 및 가공비 손실
- 폐기물 처리 비용
```

**③ 공정 중단 비용 (Downtime Cost)**
```
- 품질 문제로 인한 생산 중단 손실
- 기계 고장에 따른 가동 손실
- 납기 지연 비용
```

#### 3-2. 사외실패비용 (External Failure Cost)

**정의**: 제품이 고객에게 인도된 후 발견된 불량으로 인한 비용

**① 보증 비용 (Warranty Cost)**
```
- 무상 A/S 비용
- 제품 교환 및 환불 비용
- 보증 수리 인건비 및 부품비
```

**② 클레임 처리 비용 (Complaint Handling Cost)**
```
- 고객 불만 처리 비용
- 반품 물류 비용
- 배상 및 소송 비용
```

**③ 브랜드 이미지 손실**
```
- 신뢰도 하락에 따른 매출 감소
- 시장 점유율 하락
- 고객 이탈로 인한 장기적 손실
```

## 📈 (3) 품질비용 모델 (16점)

### 1. 전통적 품질비용 모델 (Traditional Quality Cost Model)

#### 그래프

```
비용
 ↑
 │
 │        총 품질비용
 │       ╱╲
 │      ╱  ╲
 │     ╱    ╲________
 │    ╱   ╱          ╲___
 │   ╱   ╱  실패비용      ╲____
 │  ╱___╱____________________╲______
 │ ╱
 │╱__________________________ 예방+평가비용
 │                 ×
 │                최적 품질수준
 └────────────────────────────────────→ 품질수준
  0%                                  100%
  (낮음)                              (높음)
```

#### 특징

**X축**: 품질수준 (0% ~ 100%)
- 0%: 품질이 매우 나쁨
- 100%: 완벽한 품질 (무결점)

**Y축**: 비용

**곡선 설명**

**① 예방+평가비용 (Prevention + Appraisal Cost)**
```
- 품질수준이 높아질수록 증가
- 우상향 곡선
- 100% 품질 추구 시 비용 급격히 증가
```

**② 실패비용 (Failure Cost)**
```
- 품질수준이 높아질수록 감소
- 우하향 곡선
- 낮은 품질수준에서 매우 높음
```

**③ 총 품질비용 (Total Quality Cost)**
```
- 예방+평가비용 + 실패비용
- U자형 곡선
- 최소점이 "최적 품질수준"
```

**최적 품질수준**
```
- 총 품질비용이 최소가 되는 지점
- 100%보다 낮은 수준 (예: 95~98%)
- "허용 가능한 품질수준(AQL)" 개념
```

### 2. 현대적 품질비용 모델 (Modern Quality Cost Model)

#### 그래프

```
비용
 ↑
 │
 │                      실패비용
 │                    ╱
 │                  ╱
 │                ╱
 │              ╱
 │            ╱
 │          ╱
 │        ╱
 │      ╱
 │____╱________________________ 예방+평가비용
 │                         ×
 │                    최적 품질수준
 │                    (100% 또는 무결점)
 └────────────────────────────────────→ 품질수준
  0%                                  100%
  (낮음)                              (높음)
```

#### 특징

**X축**: 품질수준 (0% ~ 100%)

**Y축**: 비용

**곡선 설명**

**① 예방+평가비용**
```
- 거의 일정하거나 완만하게 증가
- 품질 기술 발전으로 비용 증가율 낮음
- 품질 시스템 구축으로 예방 비용 일정 수준 유지
```

**② 실패비용**
```
- 품질수준이 낮을 때 매우 가파르게 증가
- 특히 사외실패비용은 기하급수적 증가
- 브랜드 이미지 손실, 소송 비용 등 숨겨진 비용 큼
```

**③ 총 품질비용**
```
- 지속적으로 감소
- U자형이 아닌 우하향
```

**최적 품질수준**
```
- 100% 품질 (무결점, Zero Defect)
- "완벽한 품질이 가장 경제적"
- 6시그마, TQM의 철학적 기반
```

---

## 💡 두 모델의 비교

| 구분 | 전통적 모델 | 현대적 모델 |
|------|------------|------------|
| **최적 품질수준** | 100% 미만 (95~98%) | 100% (무결점) |
| **철학** | 허용 가능한 불량률 존재 | 불량은 절대 허용 불가 |
| **총비용 곡선** | U자형 | 우하향 |
| **예방비용 관점** | 100% 품질은 비경제적 | 100% 품질이 가장 경제적 |
| **실패비용 추정** | 과소평가 경향 | 숨겨진 비용 포함 |
| **시대적 배경** | 1950~1970년대 | 1980년대 이후 |
| **대표 기법** | AQL, 샘플링검사 | TQM, 6시그마 |

## 🎯 경영 시사점

### 1. 예방 중심 품질경영

```
전통적: 검사로 불량 걸러내기
현대적: 불량이 발생하지 않도록 예방

→ 예방비용 투자 확대가 장기적으로 유리
```

### 2. 품질비용의 정확한 측정

```
✓ 사외실패비용의 숨겨진 비용 파악
✓ 브랜드 이미지 손실의 금액화
✓ 고객 이탈 비용의 장기적 영향 분석
```

### 3. 무결점 품질 추구

```
- 6시그마: 100만 개당 3.4개 불량
- Zero Defect 운동
- Poka-Yoke (실수 방지)
```

### 4. 품질비용 관리 체계

```
1단계: 품질비용 분류 체계 수립
2단계: 품질비용 데이터 수집 시스템 구축
3단계: 정기적 품질비용 분석 및 보고
4단계: 개선 활동 및 효과 측정
```

## 📝 답안 작성 시 주의사항

### (1) 정의 작성 시
```
✓ 품질 확보 비용 + 품질 실패 비용 구조 명확히
✓ 예방적 관점과 사후적 관점 모두 포함
✓ 경제적 개념임을 강조
```

### (2) 비용 분류 시
```
✓ 각 비용 항목을 정확히 3개씩
✓ 대표적이고 실무에서 중요한 항목 선택
✓ 구체적 예시로 이해도 증명
```

### (3) 그래프 작성 시
```
✓ X축, Y축 명확히 표시
✓ 각 비용 곡선의 형태 정확히
✓ 최적 품질수준 위치 표시
✓ 곡선 간 교차점 및 최소점 명확히
```

## 🔍 추가 학습 포인트

### PAF 모델 (Prevention-Appraisal-Failure)
```
- Crosby의 품질은 공짜다(Quality is Free)
- Juran의 품질비용 분석
- Feigenbaum의 총체적 품질비용
```

### 숨겨진 품질비용 (Hidden Quality Cost)
```
- 고객 이탈로 인한 기회비용
- 직원 사기 저하
- 재작업으로 인한 일정 지연
- 재고 과다 보유
```

### 품질비용 측정의 어려움
```
✓ 간접비용 배분의 정확성
✓ 무형 손실의 계량화
✓ 장기적 영향의 현재가치 환산
```

---

**최종 답안 요약**

```
(1) 품질비용: 품질 확보 및 유지 비용 + 품질 실패로 인한 손실 비용

(2) 비용 분류 (각 3개)
   - 예방비용: 품질계획, 교육훈련, 공정관리
   - 평가비용: 검사비용, 시험비용, 측정장비 관리
   - 실패비용:
     * 사내: 재작업, 폐기, 공정중단
     * 사외: 보증, 클레임, 브랜드 손실

(3) 그래프
   - 전통적: U자형, 최적 품질수준 < 100%
   - 현대적: 우하향, 최적 품질수준 = 100%
```
