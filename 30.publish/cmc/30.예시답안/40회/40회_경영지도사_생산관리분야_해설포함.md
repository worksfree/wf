# 제40회 경영지도사 생산관리 - 문제 1

## 물적 생산성과 가치 생산성

### 문제 요약
생산인력 5명이 각각 월 150시간 근무하며, 5월과 6월의 생산량과 판매액이 주어졌을 때:
- 5월: 제품 A 1,200개, 제품 B 600개, 판매액 200,000천원
- 6월: 제품 A 900개, 제품 B 1,200개, 판매액 196,000천원

물적 생산성과 가치 생산성을 계산하고 경영 시사점을 도출하시오.

---

## 📋 1. 개념 정의

### (1) 물적 생산성 (Physical Productivity)
```
물적 생산성 = 생산량(개) / 투입인시(인시)
```
- **의미**: 투입된 노동 시간당 생산된 제품의 수량
- **특징**: 물리적 수량 기준, 가격 변동 영향 없음
- **용도**: 생산 효율성의 기술적 지표

### (2) 가치 생산성 (Value Productivity)
```
가치 생산성 = 생산액(천원) / 투입인시(인시)
```
- **의미**: 투입된 노동 시간당 창출된 가치(금액)
- **특징**: 가격 반영, 경제적 성과 측정
- **용도**: 수익성 및 경제적 효율성 지표

---

## 🧮 2. 계산 과정

### (1) 투입 인시 계산
```
월간 투입 인시 = 인원 × 월 근무시간
             = 5명 × 150시간
             = 750 인시
```

### (2) 5월 생산성 계산

#### 물적 생산성
```
총 생산량 = 1,200개 + 600개 = 1,800개

물적 생산성 = 1,800개 / 750인시
           = 2.4 개/인시
```

#### 가치 생산성
```
생산액 = 200,000천원

가치 생산성 = 200,000천원 / 750인시
           = 266.7 천원/인시
```

### (3) 6월 생산성 계산

#### 물적 생산성
```
총 생산량 = 900개 + 1,200개 = 2,100개

물적 생산성 = 2,100개 / 750인시
           = 2.8 개/인시
```

#### 가치 생산성
```
생산액 = 196,000천원

가치 생산성 = 196,000천원 / 750인시
           = 261.3 천원/인시
```

---

## 📊 3. 변화율 분석

### (1) 물적 생산성 변화
```
변화율 = (6월 - 5월) / 5월 × 100
      = (2.8 - 2.4) / 2.4 × 100
      = 16.7% (증가)
```

**해석**: 6월에 단위 시간당 생산량이 16.7% 증가하여 생산 효율이 향상됨

### (2) 가치 생산성 변화
```
변화율 = (6월 - 5월) / 5월 × 100
      = (261.3 - 266.7) / 266.7 × 100
      = -2.0% (감소)
```

**해석**: 6월에 단위 시간당 생산액이 2.0% 감소하여 경제적 효율이 하락함

---

## 📈 4. 결과 요약표

| 구분 | 5월 | 6월 | 변화율 |
|------|-----|-----|--------|
| **총 생산량** | 1,800개 | 2,100개 | +16.7% |
| **생산액** | 200,000천원 | 196,000천원 | -2.0% |
| **투입인시** | 750인시 | 750인시 | 0% |
| **물적 생산성** | 2.4개/인시 | 2.8개/인시 | **+16.7%** |
| **가치 생산성** | 266.7천원/인시 | 261.3천원/인시 | **-2.0%** |

---

## 💡 5. 경영 시사점

### (1) 핵심 발견: 물적 생산성 증가 ≠ 경제성 향상

**현상 분석**
```
물적 생산성: 2.4 → 2.8 (16.7% ↑)
가치 생산성: 266.7 → 261.3 (2.0% ↓)
```

이는 **생산량은 늘었지만 수익성은 오히려 감소**한 상황을 의미합니다.

### (2) 원인 분석

#### 제품 믹스 변화
```
5월: A제품 1,200개 (66.7%), B제품 600개 (33.3%)
6월: A제품 900개 (42.9%), B제품 1,200개 (57.1%)
```

**추정**
- A제품: 고가 제품 (약 111천원/개)
- B제품: 저가 제품 (약 163천원/개로 추정되나 실제로는 더 낮을 가능성)

**실제 단가 계산**
```
5월 평균 단가 = 200,000천원 / 1,800개 = 111.1천원/개
6월 평균 단가 = 196,000천원 / 2,100개 = 93.3천원/개

평균 단가 감소율 = -16.0%
```

### (3) 경영진에 대한 제언

#### ① 제품 믹스 최적화
```
권장사항:
- 고부가가치 제품(A) 판매 비중 확대
- 저수익 제품(B) 생산량 조정
- 제품별 공헌이익률 분석 필요
```

#### ② 가격 전략 재검토
```
대안:
- B제품 가격 인상 검토
- 고객 세분화 및 차별적 가격 책정
- 프리미엄 제품 라인 강화
```

#### ③ 원가 관리 강화
```
점검사항:
- 제품별 원가 구조 분석
- 변동비/고정비 최적화
- 생산 효율성과 수익성의 균형
```

#### ④ 수요 예측 및 판매 전략
```
필요조치:
- 시장 수요 정확한 예측
- 고수익 제품 판매 촉진
- 영업팀과 생산팀 협업 강화
```

### (4) 전략적 의사결정 기준

```
물적 생산성 ↑ + 가치 생산성 ↑ → 최적 (생산성과 수익성 동시 향상)
물적 생산성 ↑ + 가치 생산성 ↓ → 문제 (본 사례, 제품믹스 재검토)
물적 생산성 ↓ + 가치 생산성 ↑ → 고려 (고부가가치 전략)
물적 생산성 ↓ + 가치 생산성 ↓ → 위험 (즉시 개선 필요)
```

# 제40회 경영지도사 생산관리 - 문제 2

## 경제적 생산량(EPQ) 모형

### 문제 요약
- 연간 수요(D): 50,000개 (영업일 250일, 일일 수요 200개/일)
- 생산율(p): 400개/일
- 생산준비비용(Cs): 400,000원/회
- 재고유지비용(Ch): 10,000원/개·년

최적 생산량, 최대 재고수준, 연간 총비용을 계산하시오.

---

## 📋 1. EPQ 모형 개념

### (1) EPQ(Economic Production Quantity)
```
정의: 생산과 소비가 동시에 발생할 때의 최적 생산량
```

**특징**
- 자체 생산으로 재고 보충
- 생산 중에도 제품이 소비됨 (점진적 입고)
- 생산율(p) > 수요율(d)

### (2) EOQ와의 차이

| 구분 | EOQ | EPQ |
|------|-----|-----|
| **상황** | 외부 구매 | 자체 생산 |
| **입고 방식** | 일시 입고 | 점진적 입고 |
| **재고 증가** | 즉시 Q만큼 증가 | 생산 중 (p-d) 비율로 증가 |
| **최대 재고** | Q | Q × (1 - d/p) |
| **적용** | 구매 의사결정 | 생산 의사결정 |

---

## 🧮 2. 계산 과정

### (1) 기본 데이터 정리

```
D (연간 수요) = 50,000개/년
d (일일 수요율) = 200개/일
p (일일 생산율) = 400개/일
Cs (생산준비비용) = 400,000원/회
Ch (재고유지비용) = 10,000원/개·년
```

### (2) 최적 생산량(Q*) 계산

#### EPQ 공식
```
Q* = √[(2 × D × Cs × p) / (Ch × (p - d))]
```

#### 단계별 계산
```
1단계: 분자 계산
= 2 × D × Cs × p
= 2 × 50,000 × 400,000 × 400
= 16,000,000,000,000

2단계: 분모 계산
= Ch × (p - d)
= 10,000 × (400 - 200)
= 10,000 × 200
= 2,000,000

3단계: 분수 계산
= 16,000,000,000,000 / 2,000,000
= 8,000,000

4단계: 제곱근
Q* = √8,000,000
   = 2,828.4개
   ≈ 2,828개
```

**답**: Q* = **2,828개**

### (3) 최대 재고수준(Imax) 계산

#### 공식
```
Imax = Q* × (1 - d/p)
     = Q* × (p - d) / p
```

#### 계산
```
Imax = 2,828 × (1 - 200/400)
     = 2,828 × (1 - 0.5)
     = 2,828 × 0.5
     = 1,414개
```

**답**: Imax = **1,414개**

#### 의미
- 생산이 완료되는 시점의 재고량
- 생산 중 일부가 소비되므로 Q*보다 작음
- 평균 재고 = Imax / 2 = 707개

### (4) 연간 총비용(TC) 계산

#### 총비용 구성
```
TC = 생산준비비용 + 재고유지비용
```

#### 방법 1: 직접 계산
```
1) 연간 생산 횟수(N)
N = D / Q*
  = 50,000 / 2,828
  = 17.68회

2) 생산준비비용
= N × Cs
= 17.68 × 400,000
= 7,072,000원

3) 평균 재고
= Imax / 2
= 1,414 / 2
= 707개

4) 재고유지비용
= 평균재고 × Ch
= 707 × 10,000
= 7,070,000원

5) 총비용
TC = 7,072,000 + 7,070,000
   = 14,142,000원
   ≈ 14,140,000원
```

#### 방법 2: EPQ 총비용 공식
```
TC = √[2 × D × Cs × Ch × (p - d) / p]
```

```
TC = √[2 × 50,000 × 400,000 × 10,000 × (400-200) / 400]
   = √[2 × 50,000 × 400,000 × 10,000 × 0.5]
   = √[200,000,000,000,000]
   = 14,142,136원
   ≈ 14,140,000원
```

**답**: TC = **14,140,000원** (약 1,414만원)

## 📈 4. EPQ 모형의 특성 분석

### (1) 최적 조건
```
생산준비비용 = 재고유지비용
```

위 계산에서:
- 생산준비비용: 7,072,000원
- 재고유지비용: 7,070,000원
- **거의 동일** → 최적점 달성

### (2) 재고 변동 패턴

```
재고량
 ↑
1,414 |     /\      /\      /\
      |    /  \    /  \    /  \
  707 |---/----\--/----\--/----\--- (평균재고)
      |  /      \/      \/      \
    0 |_/_______________________\____→ 시간
         7.1일      14.1일
      [생산기간] [소비기간]
```

**특징**
- 생산 중(7.1일): 재고가 (p-d) 비율로 증가
- 생산 후(7.0일): 재고가 d 비율로 감소
- 주기적 반복

### (3) p와 d의 관계

```
p/d 비율 = 400/200 = 2

의미: 생산 속도가 수요 속도의 2배
→ 생산 기간 동안 순증가율 = 50%
→ 최대 재고 = Q* × 50%
```

## 💡 5. 경영 의사결정 시사점

### (1) 생산 계획 수립

```
권장 생산 전략:
- 1회 생산량: 2,828개
- 생산 빈도: 약 17~18회/년 (월 1.5회)
- 생산 주기: 약 14일마다
```

### (2) 재고 관리

```
✓ 최대 재고 1,414개 이하 유지
✓ 평균 재고 707개 목표
✓ 안전재고 추가 고려 (불확실성 대응)
```

### (3) 비용 최적화 방안

#### 생산준비비용 절감 시 효과
```
만약 Cs를 50% 절감 (400,000 → 200,000):
Q* = √(8,000,000 × 0.5) = 2,000개
→ 생산 횟수 증가, 재고 감소
→ TC 감소
```

#### 재고유지비용 절감 시 효과
```
만약 Ch를 50% 절감 (10,000 → 5,000):
Q* = √(8,000,000 × 2) = 4,000개
→ 생산 횟수 감소, 재고 증가
→ TC 감소
```

### (4) 생산 능력 고려

```
확인사항:
✓ 일일 생산능력 400개/일 충분한가?
✓ 2,828개 생산을 7일 내에 완료 가능한가?
✓ 생산 라인 가동률은 적정한가?
```

### (5) 수요 변동성 대응

```
리스크:
- 수요 변동 시 재고 부족 또는 과잉
- 생산능력 제약 발생 가능

대책:
- 수요 예측 정확도 향상
- 안전재고 설정 (예: 평균 재고의 20%)
- 유연한 생산 계획 수립
```

## 🎯 6. EOQ와 비교 분석

### 만약 외부 구매(EOQ)라면?

```
EOQ = √[(2 × D × Cs) / Ch]
    = √[(2 × 50,000 × 400,000) / 10,000]
    = √[4,000,000,000 / 10,000]
    = √400,000,000
    = 20,000개

최대 재고 = 20,000개 (일시 입고)
평균 재고 = 10,000개
```

### 비교

| 항목 | EOQ (외부구매) | EPQ (자체생산) |
|------|---------------|---------------|
| 최적 주문/생산량 | 20,000개 | 2,828개 |
| 최대 재고 | 20,000개 | 1,414개 |
| 평균 재고 | 10,000개 | 707개 |
| 재고 회전율 | 낮음 | 높음 |
| 재고 투자 | 큼 | 작음 |

**결론**: 자체 생산 시 재고 부담이 훨씬 적음

# 제40회 경영지도사 생산관리 - 문제 3

## 공급사슬의 유형

### 문제 요약
효율적(Efficient) 공급사슬과 반응적(Responsive) 공급사슬의 특성을 비교하고, 10가지 항목에 대한 적절한 답을 선택하시오.

---

## 📋 1. 공급사슬 전략의 개념

### (1) 효율적(Efficient) 공급사슬
```
목표: 비용 최소화를 통한 효율성 극대화
```

**특징**
- 안정적이고 예측 가능한 수요
- 표준화된 제품
- 가격 경쟁 중심
- 재고 최소화 전략

**대표 산업**: 생필품, 범용 제품

### (2) 반응적(Responsive) 공급사슬
```
목표: 신속한 대응을 통한 고객 만족 극대화
```

**특징**
- 변동이 크고 불확실한 수요
- 차별화된 제품
- 유연성과 속도 중심
- 충분한 완충재고 보유

**대표 산업**: 패션, 전자제품, 신제품

---

## 🧮 2. 10가지 항목별 정답 및 해설

### ① 수요예측 오차

| 효율적 공급사슬 | 반응적 공급사슬 |
|---------------|----------------|
| **작다** | **크다** |

**해설**
- 효율적: 안정적 수요 → 예측 정확도 높음 (예: 생필품)
- 반응적: 변동성 큰 수요 → 예측 어려움 (예: 패션 의류)

---

### ② ③ 경쟁우선순위

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ③ | **원가(Cost)** | 유연성 |
| ④ | 원가 | **유연성(Flexibility)** |

**해설**
- 효율적: 낮은 가격으로 시장 점유 → 원가 최소화 중시
- 반응적: 빠른 시장 대응 → 유연성과 신속성 중시

**예시**
- 효율적: 월마트 - "Everyday Low Price"
- 반응적: ZARA - "Fast Fashion"

---

### ⑤ ⑥ 재고투자

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |
|------|----------------|----------------|
| ⑤ | **재고 최소화** | 완충재고 유지 |
| ⑥ | 재고 최소화 | **완충재고 유지** |

**해설**
- 효율적: 재고비용 절감 위해 JIT(Just-In-Time) 전략
- 반응적: 신속 대응 위해 충분한 안전재고 확보

**전략**
```

반응적: 충분한 재고 + 빠른 대응
```

### ⑦ ⑧ 공헌이익

| 항목 | 효율적 공급사슬 | 반응적 공급사슬 |

```

```

# 제40회 경영지도사 생산관리 - 문제 4

## 물류창고 입지선정 (중심기법)

### 문제 요약
5개 대리점의 좌표가 주어졌을 때:
- (1) 동일한 운송량 가정
- (2) 다양한 운송량 반영 (A:500, B:3,000, C:1,000, D:1,500, E:2,000톤/월)

최적 물류창고 위치를 중심기법(Center of Gravity Method)으로 계산하시오.

---

## 📋 1. 중심기법(Center of Gravity Method) 개념

### (1) 정의
```
물류비용을 최소화하는 시설(창고, 공장 등)의 최적 위치를
수학적으로 결정하는 기법
```

### (2) 기본 가정
- 운송비용은 거리와 물동량에 비례
- 직선 거리 이동 가능
- 단위 운송비용은 동일

### (3) 공식

#### 최적 X좌표
```
X* = Σ(Wi × Xi) / ΣWi
```

#### 최적 Y좌표
```
Y* = Σ(Wi × Yi) / ΣWi
```

여기서:
- Xi, Yi: 각 대리점의 좌표
- Wi: 각 대리점의 운송량 가중치
- X*, Y*: 최적 물류창고 위치

---

## 🧮 2. 주어진 데이터

| 대리점 | X좌표 | Y좌표 | 운송량(톤/월) |
|--------|-------|-------|---------------|
| **A** | 3 | 7 | 500 |
| **B** | 8 | 10 | 3,000 |
| **C** | 7 | 2 | 1,000 |
| **D** | 10 | 5 | 1,500 |
| **E** | 5 | 6 | 2,000 |

---

## 📊 3. (1) 동일 운송량 가정 시 계산

### 가정
```
모든 대리점의 운송량을 동일하게 가정
(또는 Wi = 1로 설정)
```

### X좌표 계산
```
X* = (XA + XB + XC + XD + XE) / 5
   = (3 + 8 + 7 + 10 + 5) / 5
   = 33 / 5
   = 6.6
   ≈ 7.0
```

### Y좌표 계산
```
Y* = (YA + YB + YC + YD + YE) / 5
   = (7 + 10 + 2 + 5 + 6) / 5
   = 30 / 5
   = 6.0
```

### 최적 위치
```
(X*, Y*) = (7.0, 6.0)
```

**답**: 동일 운송량 가정 시 최적 위치는 **(7.0, 6.0)**

---

### 문제 요약
- 자체생산: 고정비 50,000,000원, 변동비 5,000원/개
- 외주생산: 고정비 0원, 변동비 6,250원/개

(1) 자체생산과 외주생산의 손익분기 생산량은?
(2) 손익분기 생산량을 20,000개로 낮추려면 변동비를 얼마나 절감해야 하는가?

## 📋 1. 자체생산 vs 외주생산 의사결정 개념

### (1) Make-or-Buy 의사결정
```
정의: 제품이나 부품을 자체 생산할지, 외부에서 구매할지 결정하는 전략적 의사결정
```

**고려 요소**
- 비용 (고정비, 변동비)
- 품질 통제
- 생산 능력
- 핵심 역량
- 공급 안정성

### (2) 원가 구조

#### 자체생산
```
총비용(TC1) = 고정비(FC1) + 변동비(VC1) × 수량(Q)
```
- 고정비: 설비, 인건비 등
- 변동비: 재료비, 전력비 등

#### 외주생산
```
총비용(TC2) = 고정비(FC2) + 변동비(VC2) × 수량(Q)
```
- 고정비: 보통 0원 또는 매우 작음
- 변동비: 구매 단가

---

## 🧮 2. (1) 손익분기 생산량 계산

### 주어진 데이터
```
자체생산:
- FC1 = 50,000,000원
- VC1 = 5,000원/개

외주생산:
- FC2 = 0원
- VC2 = 6,250원/개
```

### 손익분기점(BEP) 개념
```
손익분기 생산량: 자체생산 총비용 = 외주생산 총비용이 되는 생산량
```

### 손익분기점 공식 유도

```
TC1 = TC2
FC1 + VC1 × Q = FC2 + VC2 × Q
50,000,000 + 5,000 × Q = 0 + 6,250 × Q
50,000,000 = 6,250Q - 5,000Q
50,000,000 = 1,250Q
Q = 50,000,000 / 1,250
Q = 40,000개
```

### 손익분기 생산량
```
Q* = 40,000개
```

**답**: 손익분기 생산량은 **40,000개**

## 🧮 4. (2) 변동비 절감 목표 계산

### 목표
```
손익분기 생산량을 40,000개 → 20,000개로 낮추기
```

### 의미
```
더 낮은 생산량에서도 자체생산이 유리하게 만들기
→ 자체생산의 경쟁력 향상
```

### 새로운 손익분기점 공식

```
Q* = FC1 / (VC2 - VC1')

여기서:
- Q* = 20,000개 (목표)
- FC1 = 50,000,000원 (고정)
- VC2 = 6,250원/개 (고정)
- VC1' = 구하고자 하는 새로운 변동비
```

### 역산 계산

```
20,000 = 50,000,000 / (6,250 - VC1')
6,250 - VC1' = 50,000,000 / 20,000
6,250 - VC1' = 2,500
VC1' = 6,250 - 2,500
VC1' = 3,750원/개
```

### 변동비 절감액

```
현재 변동비: 5,000원/개
목표 변동비: 3,750원/개

절감액 = 5,000 - 3,750 = 1,250원/개
절감율 = 1,250 / 5,000 × 100 = 25%
```

**답**: 변동비를 개당 **1,250원 절감** (25% 감소)하여 **3,750원/개**로 낮춰야 함

- 낙관 시나리오

- 비관 시나리오
```

### Step 2: 비용 분석

```

### Step 3: BEP 계산

```

### Step 4: 비용 비교

```

## 제약이론(TOC) 집중개선프로세스

### 문제 요약
제약이론(Theory of Constraints, TOC)의 집중개선 5단계 프로세스에서:
- (1) ①, ②, ③에 들어갈 용어
- (2) 5단계의 순서: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ

```
1단계: 시스템의 (①)을 식별한다
2단계: (①)의 (②)을 최대화하는 방법을 결정한다
3단계: (③)의 일정이 2단계의 결정에 종속되도록 한다
4단계: (①)을 개선한다
5단계: 1단계로 돌아간다

ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
ㄷ. 시스템의 제약자원을 식별
ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
ㅁ. 제약자원 자체를 개선
```

## 📋 1. 제약이론(TOC) 개념

### (1) TOC(Theory of Constraints)
```
정의: 시스템의 목표 달성을 가로막는 제약요인을 식별하고
      집중적으로 개선하여 전체 시스템 성과를 향상시키는 경영 기법
```

**창시자**: 엘리 골드랫(Eliyahu M. Goldratt)
**대표 저서**: 『The Goal』

### (2) 핵심 원리

#### ① 시스템 사고
```
"체인은 가장 약한 고리만큼만 강하다"

전체 시스템의 성과는 가장 취약한 제약자원에 의해 결정됨
```

#### ② 쓰루풋(Throughput) 중심
```
쓰루풋: 판매를 통해 돈을 버는 속도
제약자원: 쓰루풋을 제한하는 병목(Bottleneck)
```

#### ③ 집중의 원리
```
모든 자원을 골고루 개선 ✗
제약자원에 집중 개선 ✓
```

---

## 🧮 2. 정답 도출

### (1) 빈칸 ①, ②, ③

#### 문맥 분석
```
1단계: 시스템의 (①)을 식별한다
       → 가장 취약한 부분 찾기
       → 답: "제약자원" 또는 "쓰루풋"

2단계: (①)의 (②)을 최대화하는 방법을 결정한다
       → 제약자원의 무엇을 최대화?
       → 답: "쓰루풋"

3단계: (③)의 일정이 2단계의 결정에 종속되도록 한다
       → 제약자원이 아닌 다른 자원
       → 답: "비제약자원"
```

### 정답
```
① 제약자원 (Constraint) 또는 쓰루풋
② 쓰루풋 (Throughput)
③ 비제약자원 (Non-constraint)
```

**참고**: ①은 문맥상 "제약자원"이 더 적절하지만, "쓰루풋"도 가능

### (2) 5단계 순서

#### 논리적 순서 분석

```
ㄷ. 시스템의 제약자원을 식별
    ↓
    먼저 문제가 무엇인지 찾아야 함

ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
    ↓
    제약자원을 어떻게 활용할지 결정

ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
    ↓
    나머지 자원들을 제약자원에 맞춤

ㅁ. 제약자원 자체를 개선
    ↓
    제약자원의 능력 향상

ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
    ↓
    새로운 제약자원 찾아 반복
```

### 정답
```
순서: ㄷ → ㄱ → ㄴ → ㅁ → ㄹ
```

---

## 📊 3. TOC 집중개선 5단계 상세 설명

### 1단계: 제약자원 식별 (Identify)
```
ㄷ. 시스템의 제약자원을 식별
```

**방법**
- 작업장 관찰: 재공품(WIP)이 쌓인 곳
- 데이터 분석: 가동률이 100%인 자원
- 쓰루풋 분석: 시스템 전체 속도를 결정하는 공정

**예시**
```
공정: A(10분) → B(15분) → C(8분) → D(12분)

B 공정이 가장 느림(15분) → 제약자원
```

---

### 2단계: 제약자원 최대 활용 (Exploit)
```
ㄱ. 제약자원의 쓰루풋을 최대화하는 방법을 결정
```

**방법**
- 제약자원의 유휴시간 제거
- 불량품이 제약자원에 도달하지 않도록 사전 검사
- 제약자원의 준비시간(Setup Time) 최소화
- 제약자원 앞에 완충재고(Buffer) 배치

**중요**: 추가 투자 없이 기존 자원 최대 활용

**예시**
```
✓ B 공정 앞에 항상 작업 대기
✓ B 공정의 휴식시간 재조정
✓ B 공정의 작업 전환 최소화
✓ B 공정에 불량품 투입 방지
```

---

### 3단계: 다른 자원 종속 (Subordinate)
```
ㄴ. 비제약자원의 일정이 제약자원에 종속되도록 조정
```

**방법**
- 비제약자원은 제약자원의 속도에 맞춤
- 비제약자원의 과잉 생산 방지
- DBR(Drum-Buffer-Rope) 스케줄링 적용

**DBR 시스템**
```
Drum (북): 제약자원이 전체 리듬 결정
Buffer (완충재고): 제약자원 앞 재공품 확보
Rope (밧줄): 최초 투입 속도를 제약자원에 맞춤
```

**예시**
```
A 공정은 B 공정 속도에 맞춰 10분당 1개만 투입
(A의 능력이 10분당 2개라도 1개만 생산)
→ 재공품 과다 축적 방지
```

---

### 4단계: 제약자원 개선 (Elevate)
```
ㅁ. 제약자원 자체를 개선
```

**방법**
- 설비 증설 (B 공정 기계 1대 추가)
- 작업자 추가 배치
- 기술 향상 (공정 개선, 자동화)
- 외주 활용

**주의**: 투자 필요 → 2단계 최대 활용 후 진행

**예시**
```
Before: B 공정 15분/개
After: B 공정 기계 1대 추가 → 7.5분/개

→ 이제 B는 더 이상 제약자원 아님
→ 새로운 제약자원 발생 (예: D 공정)
```

---

### 5단계: 타성 방지 및 반복 (Repeat)
```
ㄹ. 타성에 빠지지 말고 1단계로 돌아가 지속적 개선
```

**의미**
- 제약자원은 계속 바뀜
- 한 제약 해결 → 다른 제약 발생
- 지속적 개선(Continuous Improvement)

**주의**: 관성(Inertia) 극복
```
잘못된 예:
"B 공정이 제약이었으니 계속 B에 투자"
→ ✗ 이미 B는 제약 아님

올바른 예:
"이제 D 공정이 제약이므로 D에 집중"
→ ✓ 새로운 제약 식별 및 대응
```

## 💡 5. TOC의 핵심 개념

### (1) 쓰루풋 회계(Throughput Accounting)

```
쓰루풋(T) = 판매를 통해 돈을 버는 속도
재고(I) = 판매할 제품에 투자한 모든 돈
운영비용(OE) = 재고를 쓰루풋으로 전환하는 데 드는 돈

목표: T 최대화, I와 OE 최소화
```

### (2) 제약자원의 1분 = 시스템 전체의 1분

```
일반 자원의 1분 손실: 단지 그 자원만 손실
제약자원의 1분 손실: 전체 시스템 쓰루풋 손실

→ 제약자원은 절대 놀려서는 안 됨
→ 제약자원 앞에 완충재고 필수
```

### (3) 시간 활용의 구분

| 자원 유형 | 유휴시간 허용? | 이유 |
|----------|-------------|------|
| 제약자원 | ✗ 불허 | 전체 쓰루풋 손실 |
| 비제약자원 | ✓ 허용 | 과잉 생산 방지 |

```
비제약자원의 100% 가동 = 재공품 과다 = 낭비
비제약자원은 제약자원 속도에 맞춰 "적절히" 가동
```

## 🎯 6. TOC 적용 사례

### 사례 1: 제조 공정

**문제**
```
공정: A(10분) → B(20분) → C(8분)
B가 제약자원
```

**적용**
```
1단계: B 식별
2단계: B 앞에 완충재고, 준비시간 최소화 → 12개/시간
3단계: A는 12개/시간만 생산, C는 B 속도에 맞춤
4단계: B에 설비 추가 → 10분/개로 단축
5단계: 이제 A가 제약 → 다시 1단계
```

### 사례 2: 프로젝트 관리 (CCPM)

```
TOC를 프로젝트에 적용 = Critical Chain Project Management

핵심:
- Critical Chain (제약) 식별
- 버퍼 관리
- 멀티태스킹 제거
```

### 최종 답안

```
(1) 빈칸
   ① 제약자원 (또는 쓰루풋)
   ② 쓰루풋
   ③ 비제약자원

(2) 5단계 순서
   ㄷ → ㄱ → ㄴ → ㅁ → ㄹ

   1단계(ㄷ): 시스템의 제약자원 식별
   2단계(ㄱ): 제약자원의 쓰루풋 최대화
   3단계(ㄴ): 비제약자원을 제약자원에 종속
   4단계(ㅁ): 제약자원 자체 개선
   5단계(ㄹ): 1단계로 돌아가 지속 개선
```

### 핵심 메시지

> **"시스템 전체를 개선하려면 제약자원에 집중하라"**

### TOC의 철학

```
"Tell me how you measure me, and I will tell you how I will behave."
"나를 어떻게 측정하는지 말해주면, 내가 어떻게 행동할지 말해주겠다."

→ 전체 최적화(Global Optimization) 중시
→ 부분 최적화(Local Optimization) 경계
```

### 경영 시사점

```
✓ 모든 자원을 100% 활용 ≠ 효율적
✓ 제약자원에 집중 투자
✓ 비제약자원은 제약에 맞춤
✓ 지속적 개선으로 계속 성장
✓ 전체 시스템 관점에서 의사결정
```

## 🔍 8. TOC vs 기존 관리 기법

| 구분 | 전통적 접근 | TOC 접근 |
|------|-----------|----------|
| **초점** | 모든 자원 균등 개선 | 제약자원 집중 |
| **효율** | 개별 자원 효율 극대화 | 시스템 전체 효율 극대화 |
| **재고** | 최소화 | 제약자원 앞은 확보 |
| **가동률** | 모든 자원 100% 목표 | 제약자원만 100% |
| **성과지표** | 원가, 효율성 | 쓰루풋, 리드타임 |
| **사고** | 분석적 사고 | 시스템 사고 |

3. 각 단계의 의미와 목적 설명
4. 단순 암기가 아닌 논리적 흐름으로 이해
5. 무한 개선(Continuous Improvement) 강조

## 📋 (1) 품질비용의 정의 (5점)

### 정의
```
품질비용(Quality Cost): 제품이나 서비스의 품질을 확보하고 유지하기 위해
발생하는 모든 비용과 품질 미달로 인해 발생하는 손실비용의 총합
```

### 상세 설명

**1. 품질 확보 비용 (Cost of Quality Assurance)**
```
- 불량을 예방하고 품질을 평가하기 위해 적극적으로 투자하는 비용
- 예방비용 + 평가비용
```

**2. 품질 실패 비용 (Cost of Quality Failure)**
```
- 불량품이 발생하여 손실이 발생한 비용
- 사내실패비용 + 사외실패비용
```

### 품질비용의 중요성

```
✓ 품질 개선 활동의 경제적 정당성 제공
✓ 품질 관련 의사결정의 기준
✓ 품질비용 최소화를 통한 경쟁력 향상
✓ 예방 중심 품질경영 전환의 근거
```

---

## 📊 (2) 품질비용의 분류 및 내용 (9점)

### 1. 예방비용 (Prevention Cost)

**정의**: 불량이 발생하지 않도록 사전에 예방하는 활동에 소요되는 비용

#### 예방비용 항목 (3개)

**① 품질계획 비용**
```
- 품질 목표 수립 및 품질계획 수립
- 품질 매뉴얼 작성 및 품질 시스템 설계
- QC 공정도 작성
```

**② 교육훈련 비용**
```
- 품질 관련 교육 프로그램 운영
- 작업자 기능 향상 교육
- 품질 의식 고취 활동 비용
```

**③ 공정관리 비용**
```
- 통계적 공정관리(SPC) 시스템 운영
- 예방 보전 활동 비용
- 공정 능력 분석 비용
```

---

### 2. 평가비용 (Appraisal Cost)

**정의**: 제품이나 서비스가 품질 요구사항을 충족하는지 확인하고 측정하는 데 소요되는 비용

#### 평가비용 항목 (3개)

**① 검사비용**
```
- 수입검사, 공정검사, 최종검사 비용
- 검사원 인건비
- 검사 설비 및 기기 유지비
```

**② 시험비용**
```
- 제품 성능 시험 비용
- 파괴 시험 및 비파괴 시험
- 신뢰성 시험 비용
```

**③ 측정장비 관리비용**
```
- 측정기기 교정(Calibration) 비용
- 계측기 유지보수 비용
- 측정 시스템 분석(MSA) 비용
```

---

### 3. 실패비용 (Failure Cost)

**정의**: 품질 요구사항을 충족하지 못하여 발생하는 비용

#### 3-1. 사내실패비용 (Internal Failure Cost)

**정의**: 제품이 고객에게 인도되기 전에 발견된 불량으로 인한 비용

**① 재작업 비용 (Rework Cost)**
```
- 불량품을 정상품으로 만들기 위한 추가 작업 비용
- 재작업 인건비 및 재료비
- 재검사 비용
```

**② 폐기 비용 (Scrap Cost)**
```
- 수리 불가능한 불량품의 폐기 비용
- 불량품의 재료비 및 가공비 손실
- 폐기물 처리 비용
```

**③ 공정 중단 비용 (Downtime Cost)**
```
- 품질 문제로 인한 생산 중단 손실
- 기계 고장에 따른 가동 손실
- 납기 지연 비용
```

#### 3-2. 사외실패비용 (External Failure Cost)

**정의**: 제품이 고객에게 인도된 후 발견된 불량으로 인한 비용

**① 보증 비용 (Warranty Cost)**
```
- 무상 A/S 비용
- 제품 교환 및 환불 비용
- 보증 수리 인건비 및 부품비
```

**② 클레임 처리 비용 (Complaint Handling Cost)**
```
- 고객 불만 처리 비용
- 반품 물류 비용
- 배상 및 소송 비용
```

**③ 브랜드 이미지 손실**
```
- 신뢰도 하락에 따른 매출 감소
- 시장 점유율 하락
- 고객 이탈로 인한 장기적 손실
```

---

## 📈 (3) 품질비용 모델 (16점)

### 1. 전통적 품질비용 모델 (Traditional Quality Cost Model)

#### 그래프

```
비용
 ↑
 │
 │        총 품질비용
 │       ╱╲
 │      ╱  ╲
 │     ╱    ╲________
 │    ╱   ╱          ╲___
 │   ╱   ╱  실패비용      ╲____
 │  ╱___╱____________________╲______
 │ ╱
 │╱__________________________ 예방+평가비용
 │                 ×
 │                최적 품질수준
 └────────────────────────────────────→ 품질수준
  0%                                  100%
  (낮음)                              (높음)
```

#### 특징

**X축**: 품질수준 (0% ~ 100%)
- 0%: 품질이 매우 나쁨
- 100%: 완벽한 품질 (무결점)

**Y축**: 비용

**곡선 설명**

**① 예방+평가비용 (Prevention + Appraisal Cost)**
```
- 품질수준이 높아질수록 증가
- 우상향 곡선
- 100% 품질 추구 시 비용 급격히 증가
```

**② 실패비용 (Failure Cost)**
```
- 품질수준이 높아질수록 감소
- 우하향 곡선
- 낮은 품질수준에서 매우 높음
```

**③ 총 품질비용 (Total Quality Cost)**
```
- 예방+평가비용 + 실패비용
- U자형 곡선
- 최소점이 "최적 품질수준"
```

**최적 품질수준**
```
- 총 품질비용이 최소가 되는 지점
- 100%보다 낮은 수준 (예: 95~98%)
- "허용 가능한 품질수준(AQL)" 개념
```

---

### 2. 현대적 품질비용 모델 (Modern Quality Cost Model)

#### 그래프

```
비용
 ↑
 │
 │                      실패비용
 │                    ╱
 │                  ╱
 │                ╱
 │              ╱
 │            ╱
 │          ╱
 │        ╱
 │      ╱
 │____╱________________________ 예방+평가비용
 │                         ×
 │                    최적 품질수준
 │                    (100% 또는 무결점)
 └────────────────────────────────────→ 품질수준
  0%                                  100%
  (낮음)                              (높음)
```

#### 특징

**X축**: 품질수준 (0% ~ 100%)

**Y축**: 비용

**곡선 설명**

**① 예방+평가비용**
```
- 거의 일정하거나 완만하게 증가
- 품질 기술 발전으로 비용 증가율 낮음
- 품질 시스템 구축으로 예방 비용 일정 수준 유지
```

**② 실패비용**
```
- 품질수준이 낮을 때 매우 가파르게 증가
- 특히 사외실패비용은 기하급수적 증가
- 브랜드 이미지 손실, 소송 비용 등 숨겨진 비용 큼
```

**③ 총 품질비용**
```
- 지속적으로 감소
- U자형이 아닌 우하향
```

**최적 품질수준**
```
- 100% 품질 (무결점, Zero Defect)
- "완벽한 품질이 가장 경제적"
- 6시그마, TQM의 철학적 기반
```

---

## 💡 두 모델의 비교

| 구분 | 전통적 모델 | 현대적 모델 |
|------|------------|------------|
| **최적 품질수준** | 100% 미만 (95~98%) | 100% (무결점) |
| **철학** | 허용 가능한 불량률 존재 | 불량은 절대 허용 불가 |
| **총비용 곡선** | U자형 | 우하향 |
| **예방비용 관점** | 100% 품질은 비경제적 | 100% 품질이 가장 경제적 |
| **실패비용 추정** | 과소평가 경향 | 숨겨진 비용 포함 |
| **시대적 배경** | 1950~1970년대 | 1980년대 이후 |
| **대표 기법** | AQL, 샘플링검사 | TQM, 6시그마 |

```

# 제40회 경영지도사 품질경영 - 문제 2

## 품질경영 발전 및 개념

---

## 📋 (1) 파이겐바움(A.V. Feigenbaum)의 품질관리 발전 4단계 (8점)

### 개요
```
파이겐바움(Armand V. Feigenbaum, 1922-2014)
- 총체적 품질관리(TQC: Total Quality Control) 제창
- 품질관리의 발전 과정을 4단계로 체계화
```

---

### 1단계: 작업자 품질관리 (Operator Quality Control)

**시기**: 1900년대 초~1920년대

**특징**
```
- 개별 작업자가 자신의 작업 품질에 대해 책임
- 장인(Craftsman) 중심의 품질관리
- 수작업 중심 생산 시대
```

**주요 내용**
```
✓ 작업자가 직접 검사 및 품질 확인
✓ 기능과 검사의 비분리
✓ 작업자의 기술과 경험에 의존
✓ 소량 생산, 주문 생산 방식
```

**한계**
```
- 대량 생산 시대에 부적합
- 작업자마다 품질 편차 큼
- 체계적 품질관리 부재
```

---

### 2단계: 감독자 품질관리 (Foreman Quality Control)

**시기**: 1920년대~1940년대

**특징**
```
- 감독자(현장 관리자)가 품질관리 책임
- 대량 생산 시스템의 등장
- 분업과 전문화의 시작
```

**주요 내용**
```
✓ 생산 라인 감독자가 품질 검사 수행
✓ 작업 표준화 및 검사 기준 설정
✓ 불량품 선별 및 조치
✓ 테일러의 과학적 관리법 영향
```

**배경**
```
- 포드의 컨베이어 벨트 시스템
- 대량 생산으로 작업자 개별 검사 불가능
- 생산과 검사의 분리 시작
```

**한계**
```
- 사후 검사 중심 (예방 개념 미약)
- 감독자의 역량에 의존
- 전사적 품질 관점 부재
```

---

### 3단계: 검사 품질관리 (Inspection Quality Control)

**시기**: 1940년대~1960년대

**특징**
```
- 독립된 검사 부서 설치
- 통계적 품질관리(SQC)의 등장
- 과학적 품질관리 기법 도입
```

**주요 내용**
```
✓ 전문 검사부서 및 검사원 배치
✓ 샘플링 검사 기법 활용
✓ 관리도(Control Chart) 사용
✓ 수리통계학 기반 품질관리
```

**대표 기법**
```
- Shewhart의 관리도 (1924)
- Dodge & Romig의 샘플링 검사표
- 허용 품질 수준(AQL)
- 통계적 공정관리(SPC)
```

**의의**
```
✓ 품질관리의 과학화
✓ 전수검사에서 샘플링검사로 전환
✓ 품질의 예측 및 관리 가능
```

**한계**
```
- 여전히 사후 검사 중심
- 생산 부서와 검사 부서의 벽
- 품질은 검사부서의 책임이라는 인식
```

---

### 4단계: 총체적 품질관리 (Total Quality Control, TQC)

**시기**: 1960년대 이후

**특징**
```
- 전사적 품질관리 체계
- 예방 중심 품질관리
- 모든 부서와 구성원의 참여
```

**주요 내용**
```
✓ 전 부서(설계, 구매, 제조, 영업, A/S 등) 품질 책임
✓ 최고경영자의 품질 리더십
✓ 고객 중심의 품질 정의
✓ 지속적 개선(Continuous Improvement)
```

**핵심 원칙**
```
1. 품질은 전사적 책임
   - "Quality is everybody's job"
   - 모든 부서가 품질에 기여

2. 예방 중심
   - 불량 발생 후 검사 → 불량 예방
   - 공정 설계 단계부터 품질 확보

3. 시스템적 접근
   - 품질 시스템 구축
   - 프로세스 관점의 품질관리

4. 고객 만족
   - 고객 요구사항 중심
   - 내부 고객 + 외부 고객
```

**발전 양상**
```
TQC → TQM (Total Quality Management)
     → 6시그마
     → ISO 9000 시리즈
```

## 🎯 (2) 쥬란(J.M. Juran)의 품질 트릴러지 3단계 (12점)

### 개요
```
쥬란(Joseph M. Juran, 1904-2008)
- 품질의 구루(Guru) 중 한 명
- 품질 트릴러지(Quality Trilogy): 품질경영의 3대 과정
- "품질은 설계로 들어가고, 생산으로 나온다"
```

---

### 1단계: 품질계획 (Quality Planning)

#### 정의
```
고객의 요구사항을 파악하고, 이를 충족시킬 수 있는 제품과 프로세스를
설계하는 활동
```

#### 주요 활동

**① 고객 식별 (Identify Customers)**
```
- 외부 고객: 최종 사용자, 유통업자
- 내부 고객: 다음 공정 작업자, 타 부서
```

**② 고객 니즈 파악 (Determine Customer Needs)**
```
- 시장조사, VOC(Voice of Customer) 수집
- 고객 요구사항 명확화
- 명시적 요구 + 잠재적 요구
```

**③ 제품 특성 개발 (Develop Product Features)**
```
- 고객 요구를 제품 사양으로 전환
- 품질 기능 전개(QFD) 활용
- CTQ(Critical To Quality) 도출
```

**④ 프로세스 설계 (Develop Process)**
```
- 제품 생산을 위한 공정 설계
- 공정 능력 확보
- 작업 표준 설정
```

**⑤ 프로세스 이관 (Transfer to Operations)**
```
- 양산 부서로 이관
- 작업 매뉴얼 및 교육
- 초기 유동 관리
```

#### 결과물
```
✓ 제품 사양서
✓ 공정 흐름도
✓ 품질 계획서
✓ 작업 표준서
```

#### 중요성
```
"품질의 80%는 설계 단계에서 결정된다"
→ 계획 단계의 품질 확보가 가장 중요
```

---

### 2단계: 품질관리 (Quality Control)

#### 정의
```
제품이 계획된 품질 수준을 달성하고 유지하도록 공정을 관리·통제하는 활동
```

#### 주요 활동

**① 품질 측정 (Measure Performance)**
```
- 주요 품질 특성 측정
- 데이터 수집 및 기록
- 실시간 모니터링
```

**② 기준과 비교 (Compare to Standards)**
```
- 목표 vs 실제 성과 비교
- 관리 한계선 설정
- 이상 징후 탐지
```

**③ 이상 발생 시 조치 (Act on Difference)**
```
- 이상 원인 규명
- 시정 조치 실시
- 재발 방지 대책 수립
```

#### 주요 기법
```
✓ 통계적 공정관리(SPC)
✓ 관리도(Control Chart)
✓ 공정 능력 분석(Cp, Cpk)
✓ 샘플링 검사
```

#### 품질관리 사이클 (Control Loop)
```
    ┌──────────────┐
    │  목표 설정    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  실적 측정    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  비교 평가    │
    └──────┬───────┘
           │
    ┌──────▼───────┐
    │  시정 조치    │
    └──────┬───────┘
           │
           └──────→ (반복)
```

#### 목표
```
- 공정을 관리 상태로 유지
- 변동 최소화
- 안정적 품질 확보
```

---

### 3단계: 품질개선 (Quality Improvement)

#### 정의
```
현재의 품질 수준을 획기적으로 향상시키기 위한 프로젝트 중심의 활동
```

#### 주요 활동

**① 개선 인프라 구축 (Establish Infrastructure)**
```
- 품질협의회 설치
- 개선 팀 구성
- 자원 배분
```

**② 개선 프로젝트 선정 (Identify Projects)**
```
- 만성적 품질 문제 파악
- 파레토 분석으로 우선순위 결정
- 경영 목표와 연계
```

**③ 개선 팀 조직 (Organize Teams)**
```
- 프로젝트 팀 구성
- 역할 및 책임 부여
- 팀 리더 교육
```

**④ 근본 원인 분석 (Diagnose Causes)**
```
- 5 Why 분석
- 특성 요인도(Fishbone Diagram)
- 실험 계획법(DOE)
```

**⑤ 해결책 개발 및 실행 (Develop Remedies)**
```
- 개선 아이디어 도출
- 대책 수립 및 실행
- 효과 검증
```

**⑥ 효과 유지 (Hold Gains)**
```
- 표준화 및 문서화
- 교육 및 전파
- 지속적 모니터링
```

#### 주요 기법
```
✓ PDCA 사이클
✓ 6시그마 DMAIC
✓ QC 7가지 도구
✓ Kaizen (개선 활동)
```

#### 특징
```
- 혁신적 품질 향상
- 프로젝트 기반
- 팀 활동
- 지속적 개선(Continuous Improvement)
```

#### 쥬란의 품질개선 곡선

```
품질수준
   ↑
   │        개선 3
   │      ╱─────────  새로운 관리 수준
   │     ╱
   │    개선 2
   │   ╱─────────  새로운 관리 수준
   │  ╱
   │ 개선 1
   │╱─────────  초기 관리 수준
   │
   └──────────────────────────→ 시간

   단계적 개선 (Breakthrough Improvement)
```

---

### 품질 트릴러지의 통합 관계

```
┌──────────────┐
│ 품질 계획     │  → 새로운 제품/공정 설계
│(Planning)    │     고객 요구사항 반영
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 품질 관리     │  → 일상적 공정 관리
│(Control)     │     품질 유지 및 안정화
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 품질 개선     │  → 획기적 품질 향상
│(Improvement) │     만성 문제 해결
└──────┬───────┘
       │
       └──────→ 다시 계획 단계로
                (Spiral Up)
```

## 🎯 (3) 가빈(D.A. Garvin)의 5가지 품질 개념 (10점)

### 개요
```
가빈(David A. Garvin, 1955-2017)
- 하버드 경영대학원 교수
- "품질의 다차원적 접근"
- 품질을 5가지 관점에서 정의
```

---

### 1. 선험적(초월적) 품질 (Transcendent Quality)

#### 정의
```
품질은 절대적이고 보편적으로 인정되는 탁월함(Excellence)이며,
경험을 통해서만 인식할 수 있는 것
```

#### 특징
```
✓ 정의하거나 측정하기 어려움
✓ 직관적으로 인식 가능
✓ "알면 알 수 있다" (You know it when you see it)
✓ 예술적·철학적 개념
```

#### 장점
```
- 품질의 본질적 가치 강조
- 최고 수준 추구의 동기 부여
```

#### 단점
```
- 객관적 측정 불가
- 실무 적용 어려움
- 주관적 판단에 의존
```

#### 실무 적용
```
- 명품 브랜드: 롤스로이스, 에르메스
- "최고급", "프리미엄" 이미지
- 브랜드 가치
```

---

### 2. 제품 중심적 품질 (Product-Based Quality)

#### 정의
```
품질은 제품이 가지고 있는 측정 가능한 특성이나 속성의 양
```

#### 특징
```
✓ 객관적이고 정밀하게 측정 가능
✓ 수량화 가능
✓ 제품 사양(Specification) 중심
✓ 품질 = 특정 속성의 양
```

#### 예시
```
- 자동차: 마력, 연비, 최고속도
- 컴퓨터: CPU 속도, 메모리 용량, 저장공간
- 섬유: 실의 굵기, 밀도
```

#### 장점
```
- 명확한 측정 기준
- 제품 간 비교 용이
- 품질 등급 설정 가능
```

#### 단점
```
- 고객 니즈와 괴리 가능
- "많다 = 좋다"는 가정의 한계
- 과잉 품질(Over-Quality) 위험
```

#### 실무 적용
```
- 제품 사양서 작성
- 품질 등급 구분 (등급 A, B, C)
- 성능 테스트 기준
```

---

### 3. 사용자 중심적 품질 (User-Based Quality)

#### 정의
```
품질은 고객의 요구사항과 선호도를 충족시키는 정도
```

#### 특징
```
✓ 고객 관점의 품질
✓ 주관적이고 개인적
✓ "고객이 원하는 것 = 품질"
✓ 시장 중심적 접근
```

#### 핵심 개념
```
"Quality is fitness for use" (쥬란)
"고객이 만족하면 그것이 품질"
```

#### 장점
```
- 고객 만족 직결
- 시장 수요 반영
- 경쟁력 확보
```

#### 단점
```
- 고객마다 요구사항 상이
- 측정 및 표준화 어려움
- 비용 증가 가능성
```

#### 실무 적용
```
- 고객 만족도 조사
- VOC(Voice of Customer) 분석
- QFD(품질 기능 전개)
- 맞춤형 제품 개발
```

#### 예시
```
- 스마트폰: 사용 편의성, 디자인, 생태계
- 호텔: 서비스, 위치, 청결도
- 의류: 스타일, 편안함, 유행
```

---

### 4. 제조 중심적 품질 (Manufacturing-Based Quality)

#### 정의
```
품질은 설계 사양이나 표준에 대한 일치도(Conformance to Specifications)
```

#### 특징
```
✓ 생산 관점의 품질
✓ 규격 준수 여부
✓ "설계대로 만들었는가?"
✓ 변동 최소화 중요
```

#### 핵심 개념
```
품질 = 설계 사양과의 일치
불량 = 규격 이탈
```

#### 장점
```
- 명확한 기준
- 객관적 평가 가능
- 불량률 관리 용이
- 생산 효율성 향상
```

#### 단점
```
- 고객 관점 미흡
- 설계 사양 자체의 적절성 무시
- "규격 내 불량" 가능
```

#### 주요 기법
```
✓ 통계적 공정관리(SPC)
✓ 공정 능력 분석(Cp, Cpk)
✓ 6시그마
✓ 무결점 운동(ZD)
```

#### 실무 적용
```
- 도면과 실제 제품 비교
- 공차 관리
- 불량률 감소 활동
- ISO 9001 품질시스템
```

#### 예시
```
- 기계 부품: 치수 공차 ±0.01mm
- 전자 제품: 전압 220V ±10%
- 식품: 중량 100g ±5g
```

---

### 5. 가치 중심적 품질 (Value-Based Quality)

#### 정의
```
품질은 적절한 가격으로 제공되는 우수성 또는 성능
→ 품질 = 성능 / 가격
```

#### 특징
```
✓ 경제적 관점
✓ 비용 대비 성능
✓ "가성비(가격 대비 성능 비율)"
✓ 상대적 개념
```

#### 핵심 개념
```
"합리적 가격에 원하는 수준 충족"
고품질 ≠ 고가격
저품질 ≠ 저가격
```

#### 장점
```
- 경제적 합리성
- 시장 세분화 가능
- 가격 경쟁력 고려
```

#### 단점
```
- 품질과 가격의 교환(Trade-off)
- 저가 저품질의 정당화 위험
- 장기적 품질 저하 가능
```

#### 실무 적용
```
- 원가 절감 활동과 품질의 균형
- VE(Value Engineering)
- 목표 원가 설정
- 시장 세그먼트별 제품 전략
```

#### 예시
```
- 이코노미 항공사: 저가, 기본 서비스
- 패스트 패션: 빠른 유행 반영, 합리적 가격
- 제네릭 의약품: 동일 효과, 저가
```

## 💡 5가지 품질 개념의 종합 비교

| 품질 개념 | 관점 | 측정 가능성 | 주요 적용 분야 |
|-----------|------|-------------|----------------|
| **선험적** | 철학적 | 어려움 | 명품, 예술품 |
| **제품 중심** | 제품 속성 | 용이 | 기술 제품, 공산품 |
| **사용자 중심** | 고객 만족 | 중간 | 서비스, 소비재 |
| **제조 중심** | 규격 일치 | 용이 | 제조업, 생산 현장 |
| **가치 중심** | 가격 대비 성능 | 중간 | 대중 시장 제품 |

## 🎯 실무 통합 적용

### 균형잡힌 품질 전략

```
1. 고객 니즈 파악 (사용자 중심)
   ↓
2. 제품 사양 결정 (제품 중심)
   ↓
3. 제조 공정 관리 (제조 중심)
   ↓
4. 비용 효율성 검토 (가치 중심)
   ↓
5. 브랜드 이미지 구축 (선험적)
```

### 제품 수명주기별 강조점

```
- 설계 단계: 사용자 중심 + 제품 중심
- 생산 단계: 제조 중심
- 판매 단계: 가치 중심
- 브랜딩: 선험적 품질
```

## 📝 최종 정리

### 파이겐바움의 4단계
```
1. 작업자 품질관리 → 개인 책임
2. 감독자 품질관리 → 현장 관리자 책임

```

3. 사용자 중심 → 고객 요구사항 충족
4. 제조 중심 → 설계 사양 일치
5. 가치 중심 → 가격 대비 성능
```

# 제40회 경영지도사 품질경영 - 문제 3

## 품질관리 용어 설명

---

## 📋 (1) 계통도법 (Systematic Diagram / Tree Diagram) (3점)

### 정의
```
목적이나 목표를 달성하기 위한 수단과 방법을 체계적으로 전개하여
나무 가지 모양으로 표현하는 기법
```

### 특징

**목적**
```
✓ 복잡한 문제를 체계적으로 분해
✓ 목표 달성의 구체적 수단 명확화
✓ 문제 해결의 로드맵 제시
```

**구조**
```
목표/목적 → 1차 수단 → 2차 수단 → 3차 수단 → ...
(WHY?)      (HOW?)     (HOW?)     (HOW?)
```

### 작성 방법

**1단계: 목표 설정**
```
- 달성하고자 하는 최종 목표를 명확히 설정
- 우측에 기록
```

**2단계: 1차 수단 전개**
```
- "어떻게(How) 목표를 달성할 것인가?" 질문
- 주요 수단을 좌측으로 전개
```

**3단계: 2차, 3차 수단 전개**
```
- 각 수단에 대해 다시 "어떻게?" 질문
- 더 구체적인 수단으로 전개
- 실행 가능한 수준까지 세분화
```

**4단계: 검토 및 수정**
```
- 누락된 수단 확인
- 논리적 연결성 점검
- 실행 가능성 검토
```

### 도표 형식

```
                                  ┌─ 2차 수단 1-1
                    ┌─ 1차 수단 1 ┼─ 2차 수단 1-2
                    │             └─ 2차 수단 1-3
                    │
                    │             ┌─ 2차 수단 2-1
목표/목적 ──────────┼─ 1차 수단 2 ┼─ 2차 수단 2-2
                    │             └─ 2차 수단 2-3
                    │
                    │             ┌─ 2차 수단 3-1
                    └─ 1차 수단 3 ┼─ 2차 수단 3-2
                                  └─ 2차 수단 3-3
```

### 실무 예시

**목표: 불량률 50% 감소**
```
불량률 50% 감소 ─┬─ 작업자 기능 향상 ─┬─ 교육 프로그램 실시
                │                   ├─ 숙련도 평가 제도
                │                   └─ 작업 표준서 개정
                │
                ├─ 설비 개선 ───────┬─ 정밀도 향상
                │                   ├─ 예방 보전 강화
                │                   └─ 노후 설비 교체
                │
                └─ 재료 품질 향상 ──┬─ 공급업체 평가 강화
                                    ├─ 수입검사 엄격화
                                    └─ 협력업체 기술지원
```

### 활용 분야
```
✓ 신제품 개발 계획
✓ 품질개선 활동
✓ 원가절감 프로젝트
✓ 업무 프로세스 개선
```

### 장점
```
- 목표와 수단의 체계적 연결
- 문제 해결 방향 명확화
- 팀원 간 공감대 형성
- 실행 계획 수립 용이
```

## 📊 (2) 매트릭스도 (Matrix Diagram) (3점)

### 정의
```
두 개 이상의 요소 간 관계를 행과 열의 매트릭스(격자) 형태로 표현하여
문제의 소재와 형태를 명확히 하는 기법
```

### 목적
```
✓ 복잡한 요소 간 상관관계 파악
✓ 문제 요인의 규명
✓ 우선순위 결정
✓ 다차원적 분석
```

### 기본 구조

```
           요소 B₁  요소 B₂  요소 B₃  요소 B₄
요소 A₁      ○       △       ◎
요소 A₂      △               ○       ◎
요소 A₃              ◎       △       ○
요소 A₄      ◎       ○               △

기호 의미:
◎ : 강한 관계 (9점)
○ : 중간 관계 (3점)
△ : 약한 관계 (1점)
공백: 관계 없음 (0점)
```

### 매트릭스 유형

**1. L형 매트릭스 (2차원)**
```
- 가장 기본적인 형태
- 행과 열 2개 요소의 관계
```

**2. T형 매트릭스 (3차원)**
```
- 3개 요소 간 관계
- A-B, B-C 관계 동시 분석
```

**3. Y형 매트릭스 (3차원)**
```
- 3개 요소를 Y자 형태로 배치
- 순환적 관계 분석
```

**4. X형 매트릭스 (4차원)**
```
- 4개 요소 간 관계
- A-B, C-D, A-C, B-D 관계
```

**5. C형 매트릭스 (입체형)**
```
- 3차원 입체 매트릭스
- 매우 복잡한 관계 분석
```

### 작성 방법

**1단계: 비교 요소 선정**
```
- 행(Row)에 배치할 요소 결정
- 열(Column)에 배치할 요소 결정
```

**2단계: 매트릭스 작성**
```
- 표 형태로 골격 그리기
- 각 요소를 행과 열에 배치
```

**3단계: 관계 표시**
```
- 각 교차점에서 관계의 강도 표시
- 기호(◎, ○, △) 또는 점수 사용
```

**4단계: 분석 및 해석**
```
- 관계가 강한 부분 파악
- 중요 요인 도출
- 우선순위 결정
```

### 실무 예시: QFD (품질기능전개)의 품질의 집 (House of Quality)

```
               |  고객요구사항 1 | 고객요구사항 2 | 고객요구사항 3
───────────────┼────────────────┼────────────────┼────────────────
기술특성 1      |       ◎        |       △        |       ○
───────────────┼────────────────┼────────────────┼────────────────
기술특성 2      |       ○        |       ◎        |       △
───────────────┼────────────────┼────────────────┼────────────────
기술특성 3      |       △        |       ○        |       ◎
───────────────┼────────────────┼────────────────┼────────────────
중요도 (점수)   |       45       |       38       |       52
```

### 실무 예시: 불량 유형과 공정의 관계

```
           공정A  공정B  공정C  공정D  발생빈도
불량 유형1   ◎     △            ○      15
불량 유형2         ◎     ○      △      23
불량 유형3   ○     △     ◎      ○      18
불량 유형4   △           △      ◎      12

→ 분석: 공정B와 공정C가 가장 많은 불량 원인
```

### 활용 분야
```
✓ QFD (고객요구 - 설계특성 연계)
✓ FMEA (고장모드 - 영향 분석)
✓ 업무 분장 (담당자 - 업무 매칭)
✓ 기능 배치 (부서 - 기능 매칭)
```

### 장점
```
- 복잡한 관계의 시각화
- 다차원 분석 가능
- 의사소통 도구
- 우선순위 결정 용이
```

## 🎯 (3) DMAIC (4점)

### 정의
```
DMAIC: 6시그마 프로젝트의 문제 해결 프로세스
- Define (정의)
- Measure (측정)
- Analyze (분석)
- Improve (개선)
- Control (관리)
```

### 개요
```
- 6시그마의 핵심 방법론
- 데이터 기반 의사결정
- 구조화된 문제 해결 프로세스
- MAIC의 앞에 D(Define)를 추가하여 발전
```

---

### 1단계: 정의 (Define)

#### 목적
```
프로젝트의 목표와 범위를 명확히 정의
```

#### 주요 활동
```
✓ 고객 요구사항(CTQ) 파악
✓ 프로젝트 목표 설정
✓ 프로젝트 범위 결정 (Scope)
✓ 프로젝트 팀 구성
✓ 일정 및 자원 계획
```

#### 주요 산출물
```
- 프로젝트 헌장 (Project Charter)
- SIPOC 다이어그램
- VOC (Voice of Customer)
- CTQ Tree
```

#### 핵심 질문
```
"무엇이 문제인가?"
"고객은 무엇을 원하는가?"
"프로젝트의 목표는 무엇인가?"
```

---

### 2단계: 측정 (Measure)

#### 목적
```
현재 프로세스의 성능을 데이터로 측정하고 평가
```

#### 주요 활동
```
✓ 측정 지표 선정 (KPI)
✓ 데이터 수집 계획 수립
✓ 측정 시스템 분석 (MSA)
✓ 현재 성능 수준 파악 (Baseline)
✓ 공정 능력 분석 (Process Capability)
```

#### 주요 산출물
```
- 데이터 수집 계획서
- MSA (Measurement System Analysis) 결과
- 현재 시그마 수준
- 공정 능력 지수 (Cp, Cpk)
- 히스토그램, 관리도
```

#### 핵심 지표
```
- DPMO (Defects Per Million Opportunities)
- 시그마 수준 (Sigma Level)
- 수율 (Yield)
```

#### 핵심 질문
```
"현재 상태는 어떠한가?"
"얼마나 나쁜가?"
"측정 시스템은 신뢰할 수 있는가?"
```

---

### 3단계: 분석 (Analyze)

#### 목적
```
문제의 근본 원인(Root Cause)을 데이터 기반으로 규명
```

#### 주요 활동
```
✓ 프로세스 맵 작성
✓ 잠재 원인 도출 (Brainstorming)
✓ 특성 요인도 작성
✓ 통계 분석 (가설 검정, 회귀 분석)
✓ 핵심 원인 규명 (Vital Few)
```

#### 주요 기법
```
- 특성 요인도 (Fishbone Diagram)
- 파레토 차트
- 가설 검정 (t-test, ANOVA)
- 상관 분석, 회귀 분석
- 다변량 분석
```

#### 주요 산출물
```
- 프로세스 맵
- 특성 요인도
- 통계 분석 결과
- 검증된 근본 원인
```

#### 핵심 질문
```
"왜 문제가 발생하는가?"
"핵심 원인은 무엇인가?"
"데이터가 원인을 뒷받침하는가?"
```

---

### 4단계: 개선 (Improve)

#### 목적
```
근본 원인을 제거하고 프로세스를 개선
```

#### 주요 활동
```
✓ 개선 아이디어 도출
✓ 개선안 평가 및 선택
✓ 파일럿 테스트 (Pilot Test)
✓ 개선안 실행
✓ 개선 효과 검증
```

#### 주요 기법
```
- 실험 계획법 (DOE: Design of Experiments)
- Poka-Yoke (실수 방지)
- 시뮬레이션
- 비용-편익 분석
```

#### 주요 산출물
```
- 개선 실행 계획
- 파일럿 테스트 결과
- 개선 전후 비교 데이터
- 표준 작업 절차서 (SOP)
```

#### 핵심 질문
```
"어떻게 개선할 것인가?"
"개선 효과가 입증되었는가?"
"실행 가능한가?"
```

---

### 5단계: 관리 (Control)

#### 목적
```
개선된 프로세스를 유지하고 지속적으로 관리
```

#### 주요 활동
```
✓ 관리 계획 수립
✓ 표준화 및 문서화
✓ 통계적 공정관리 (SPC) 적용
✓ 교육 및 훈련
✓ 프로젝트 종료 및 이관
```

#### 주요 기법
```
- 관리도 (Control Chart)
- SPC (Statistical Process Control)
- 표준 작업 절차 (SOP)
- 체크리스트
```

#### 주요 산출물
```
- 관리 계획서
- 관리도
- 표준 작업 절차서
- 교육 자료
- 프로젝트 종료 보고서
```

#### 핵심 질문
```
"개선 효과를 어떻게 유지할 것인가?"
"재발 방지 대책은?"
"담당자는 누구인가?"
```

---

### DMAIC 프로세스 흐름도

```
┌──────────────────┐
│   Define (정의)   │  ← 무엇이 문제인가?
│  프로젝트 선정    │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│   Measure (측정)  │  ← 현재 상태는?
│  데이터 수집      │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Analyze (분석)   │  ← 왜 문제가 발생?
│  근본 원인 규명   │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Improve (개선)   │  ← 어떻게 개선?
│  개선안 실행      │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Control (관리)   │  ← 어떻게 유지?
│  표준화, 관리     │
└──────────────────┘
```

---

### DMAIC의 특징

**데이터 기반 의사결정**
```
- 추측이 아닌 데이터로 판단
- 통계적 분석 활용
- 객관적 증거 확보
```

**체계적 문제 해결**
```
- 5단계 구조화된 프로세스
- 각 단계별 명확한 목표
- Gate Review (단계별 검증)
```

**재발 방지**
```
- 근본 원인 제거
- 표준화 및 관리 체계
- 지속적 모니터링
```

---

### DMAIC vs PDCA

| 구분 | DMAIC | PDCA |
|------|-------|------|
| **단계** | 5단계 | 4단계 |
| **복잡도** | 높음 | 낮음 |
| **데이터 의존도** | 매우 높음 | 중간 |
| **적용 범위** | 복잡한 문제 | 일상적 개선 |
| **기간** | 3~6개월 | 짧은 주기 |
| **방법론** | 6시그마 | TQM |

---

### 활용 분야
```
✓ 제조업 불량률 감소
✓ 서비스 프로세스 개선
✓ 리드타임 단축
✓ 원가 절감
✓ 고객 만족도 향상
```

## 📝 최종 요약

### 계통도법
```
목표 달성 수단을 나무 가지 형태로 체계적 전개
→ 문제 해결의 로드맵
```

### 매트릭스도
```
요소 간 관계를 행렬 형태로 표현
→ 복잡한 관계의 시각화 및 우선순위 결정
```

### DMAIC
```
6시그마 문제 해결 5단계
Define → Measure → Analyze → Improve → Control
→ 데이터 기반 체계적 품질개선
```

# 제40회 경영지도사 품질경영 - 문제 4

## 이원배치 실험 및 분산분석

---

## 📋 문제 상황

### 실험 설계
```
- 인자 A: 반응 온도 (4수준) - A₁, A₂, A₃, A₄
- 인자 B: 원료 (3수준) - B₁, B₂, B₃
- 반응변수: 수율(%)
- 실험 방법: 반복 없는 이원배치 실험
```

### 실험 데이터

| 구분 | A₁ | A₂ | A₃ | A₄ | 계 |
|------|-----|-----|-----|-----|-------|
| B₁ | 97.6 | 98.6 | 99.0 | 98.0 | 393.2 |
| B₂ | 97.3 | 98.2 | 98.0 | 97.7 | 391.2 |

## 🧮 (1) 분산분석표 완성 (5점)

### 주어진 분산분석표

| 요인 | SS | DF | MS | F₀ | F(0.95) | F(0.99) |
|------|-----|-----|-----|-----|---------|---------|
| A | 2.22 | 3 | 0.74 | 7.96* | 4.76 | 9.78 |
| B | ① | ② | ③ | ④ | 5.14 | 10.90 |
| E | 0.56 | 6 | 0.093 | - | - | - |
| T | 6.22 | 11 | - | - | - | - |

---

### 기본 공식 정리

#### 총 제곱합 (Total Sum of Squares, SST)
```
SST = ΣΣ(xᵢⱼ - x̄)² = ΣΣxᵢⱼ² - CT

CT (Correction Term) = T²/N
여기서 T: 총합, N: 총 관측값 개수
```

#### 제곱합 분해
```
SST = SSA + SSB + SSE

SSA: 인자 A의 제곱합
SSB: 인자 B의 제곱합
SSE: 오차 제곱합
```

---

### 계산 과정

#### Step 1: 기본 데이터 확인
```
총 관측값 수 N = 4 × 3 = 12
총합 T = 1,172.4

A₁ 합계 = 291.6
A₂ 합계 = 293.7
A₃ 합계 = 294.9
A₄ 합계 = 292.2

B₁ 합계 = 393.2
B₂ 합계 = 391.2
B₃ 합계 = 388.0
```

#### Step 2: ① SSB (인자 B의 제곱합) 계산

**공식**
```
SSB = Σ(Bⱼ²/nⱼ) - CT

여기서:
- Bⱼ: 각 B 수준의 합계
- nⱼ: 각 B 수준의 관측값 수 (= 4)
- CT: 보정항
```

**계산**
```
CT = T²/N = (1,172.4)²/12 = 1,374,521.76/12 = 114,543.48

SSB = (B₁²/4 + B₂²/4 + B₃²/4) - CT
    = (393.2²/4 + 391.2²/4 + 388.0²/4) - 114,543.48
    = (154,606.24/4 + 153,037.44/4 + 150,544.00/4) - 114,543.48
    = (38,651.56 + 38,259.36 + 37,636.00) - 114,543.48
    = 114,546.92 - 114,543.48
    = 3.44
```

**답**: ① SSB = **3.44**

---

#### Step 3: ② DFB (인자 B의 자유도) 계산

**공식**
```
DFB = b - 1

여기서 b: 인자 B의 수준 수 = 3
```

**계산**
```
DFB = 3 - 1 = 2
```

**답**: ② DFB = **2**

---

#### Step 4: ③ MSB (인자 B의 평균제곱) 계산

**공식**
```
MSB = SSB / DFB
```

**계산**
```
MSB = 3.44 / 2 = 1.72
```

**답**: ③ MSB = **1.72**

---

#### Step 5: ④ F₀ (F 통계량) 계산

**공식**
```
F₀ = MSB / MSE

여기서 MSE: 오차 평균제곱 = 0.093 (주어짐)
```

**계산**
```
F₀ = 1.72 / 0.093 = 18.49
```

**답**: ④ F₀ = **18.49**

---

### 검증: 제곱합 분해 확인

```
SST = SSA + SSB + SSE
6.22 = 2.22 + 3.44 + 0.56
6.22 = 6.22 ✓

→ 계산 정확함
```

|------|-----|-----|-----|-----|---------|---------|

#### 인자 A (반응 온도) 검정
```

F₀(7.96) > F(0.95)(4.76) → 유의수준 5%에서 유의*

## 📋 (1) 통계적 품질관리의 개념 (3점)

### 정의
```
통계적 품질관리(SQC: Statistical Quality Control):
통계적 기법과 원리를 활용하여 제품이나 서비스의 품질을
체계적으로 관리하고 개선하는 활동
```

### 상세 설명

#### 핵심 개념

**1. 통계적 접근**
```
- 전수검사가 아닌 샘플링 기반
- 확률 및 통계 이론 활용
- 데이터 기반 의사결정
```

**2. 변동의 이해**
```
품질 특성의 변동 = 우연 원인 + 이상 원인

- 우연 원인(Chance Cause / Common Cause):
  * 제거 불가능한 불가피한 변동
  * 시스템에 내재된 랜덤한 변동
  * 정규분포를 따름

- 이상 원인(Assignable Cause / Special Cause):
  * 식별 및 제거 가능한 변동
  * 특정할 수 있는 원인
  * 관리 이탈 신호
```

**3. 관리 상태 (State of Statistical Control)**
```
- 우연 원인만 존재하는 상태
- 예측 가능한 변동
- 공정이 안정적
```

---

### 목적

```
✓ 품질의 예측 및 통제
✓ 불량 발생 사전 예방
✓ 공정 능력 파악
✓ 검사 비용 절감
✓ 품질 개선의 과학적 근거 제공
```

---

### 특징

**1. 예방 중심**
```
사후 검사 → 사전 예방
불량 발견 → 불량 예방
```

**2. 데이터 기반**
```
주관적 판단 → 객관적 데이터
경험 의존 → 통계 분석
```

**3. 전수검사 대체**
```
전수검사: 시간·비용 과다
샘플링: 경제적·효율적
→ 통계 이론으로 모집단 추정
```

**4. 공정 중심**
```
제품 검사 → 공정 관리
결과 중심 → 프로세스 중심
```

---

### 주요 구성 요소

**1. 샘플링 검사 (Sampling Inspection)**
```
- 모집단에서 샘플 추출
- 샘플 검사 결과로 합격/불합격 판정
- 경제적이고 효율적
```

**2. 관리도 (Control Chart)**
```
- 공정의 시간 흐름에 따른 변동 관리
- 관리 한계선 설정
- 이상 원인 탐지
```

**3. 공정 능력 분석 (Process Capability Analysis)**
```
- 공정의 품질 생산 능력 평가
- Cp, Cpk 등 지수 산출
- 설계 규격과 실제 공정 비교
```

---

### 역사적 배경

```
1920년대: Shewhart의 관리도 개발
1930년대: Dodge & Romig의 샘플링 검사표

```

LSL: 하한 규격
USL: 상한 규격
μ: 평균
```

#### 분석 포인트
```
✓ 분포의 중심 위치
✓ 분포의 폭(산포)
✓ 분포의 형태(정규분포 여부)
✓ 규격 한계와의 관계
✓ 이상 데이터 존재 여부
```

---

### 3. 파레토 차트 (Pareto Chart)

#### 정의
```
항목을 크기 순서로 나열한 막대그래프와 누적 비율 선그래프를 결합한 도구
```

#### 목적
```
✓ 중요 소수(Vital Few) 파악
✓ 개선 우선순위 결정
✓ 80/20 법칙 적용
```

#### 파레토 원리 (80/20 법칙)
```
"전체 결과의 80%는 전체 원인의 20%에서 발생한다"
```

#### 예시
```
불량건수                          누적비율(%)
   ↑                                    ↑
100│                              100%  │
 80│██              ─────────────  80%  │
 60│██                                  │
 40│██ ██           ─────────  60%      │
 20│██ ██ ██       ──────  40%          │
  0└─────────────────────────────→      │
    A   B  C  D  E                      │

A: 치수 불량 (50건)
B: 표면 흠집 (25건)
C: 도장 불량 (15건)
...
```

#### 활용
```
1. 불량 항목을 크기순 정렬
2. 누적 비율 계산
3. 상위 20% 항목이 80% 기여하는지 확인
4. 중요 항목부터 개선
```

---

### 4. 특성 요인도 (Cause and Effect Diagram / Fishbone Diagram / Ishikawa Diagram)

#### 정의
```
결과(특성)와 그 원인(요인)의 관계를 물고기 뼈 모양으로 체계화한 도구
```

#### 목적
```
✓ 문제의 원인 규명
✓ 체계적 원인 분석
✓ 팀원 간 아이디어 공유
```

#### 구조
```
          대분류 1          대분류 2
             │                │
        ─────┼────        ────┼─────
        │    │    │        │  │  │
       소분류들           소분류들
                  ╲        ╱
                   ╲      ╱
                    ╲    ╱
                     ───→  특성
                           (결과)
          대분류 3          대분류 4
             │                │
        ─────┼────        ────┼─────
```

#### 4M (제조업) / 5M / 6M
```
Man (사람): 기능, 훈련, 의식
Machine (설비): 정밀도, 보전, 노후화
Material (재료): 품질, 규격, 공급업체
Method (방법): 작업 순서, 조건, 표준

+ Measurement (측정): 정확도, 방법
+ Mother Nature (환경): 온도, 습도
```

#### 작성 방법
```
1. 특성(결과) 명확히 정의
2. 대분류 설정 (4M 등)
3. 중분류, 소분류 원인 도출 (Brainstorming)
4. 중요 원인 표시
5. 검증 및 대책 수립
```

---

### 5. 산점도 (Scatter Diagram)

#### 정의
```
두 변수 간의 상관관계를 점으로 표시하여 시각화한 도구
```

#### 목적
```
✓ 변수 간 상관관계 파악
✓ 원인-결과 관계 검증
✓ 회귀 분석 기초 자료
```

#### 상관관계 유형

```
(1) 강한 양의 상관          (2) 약한 양의 상관
     y                           y
     ↑  ●                        ↑   ●
        ●●                          ● ●
       ●●●                        ●  ●
      ●●●●                      ●    ●
     ●●●●●                    ●      ●
    ────────→ x               ──────────→ x

(3) 상관 없음                (4) 음의 상관
     y                           y
     ↑ ● ●●                      ↑ ●●●●●
       ● ● ●                        ●●●●
       ●  ● ●                       ●●●
       ● ●● ●                        ●●
       ●●  ●                          ●
    ────────→ x               ──────────→ x
```

#### 상관계수 (r)
```
r = +1.0 : 완전한 양의 상관
r = +0.7~+0.9 : 강한 양의 상관
r = +0.4~+0.6 : 중간 양의 상관
r = 0 : 상관 없음
r = -0.4~-0.6 : 중간 음의 상관
r = -0.7~-0.9 : 강한 음의 상관
r = -1.0 : 완전한 음의 상관
```

#### 활용 예시
```
- 온도 vs 불량률
- 작업 시간 vs 숙련도
- 재료 경도 vs 제품 강도
```

---

### 6. 관리도 (Control Chart)

#### 정의
```
공정의 시간적 변동을 관리하고 이상 원인을 탐지하기 위한 도구
```

#### 목적
```
✓ 공정의 관리 상태 확인
✓ 이상 원인 조기 발견
✓ 공정의 예측 가능성 확보
```

#### 구조
```
     측정값
        ↑
   UCL  │─────────────────────  상한 관리선
        │    ●    ●      ●
   CL   │──●───●───●─●────●──  중심선
        │●           ●
   LCL  │─────────────────────  하한 관리선
        │
        └────────────────────→ 시간(샘플 번호)

UCL: Upper Control Limit (상한 관리 한계선)
CL: Center Line (중심선)
LCL: Lower Control Limit (하한 관리 한계선)
```

#### 관리도 종류

**계량형 관리도**
```
- X̄-R 관리도: 평균과 범위
- X̄-s 관리도: 평균과 표준편차
- X-Rm 관리도: 개별값과 이동범위
```

**계수형 관리도**
```
- p 관리도: 불량률
- np 관리도: 불량 개수
- c 관리도: 결점 수
- u 관리도: 단위당 결점 수
```

#### 관리 이탈 판정 기준

**① 관리 한계선 이탈**
```
점이 UCL 또는 LCL 밖에 있음
```

**② 런(Run)**
```
중심선 위 또는 아래로 연속 7개 이상
```

**③ 경향(Trend)**
```
연속 7개 점이 상승 또는 하락
```

**④ 주기성(Cycle)**
```
일정한 주기로 상승/하락 반복
```

### 7. 층별 (Stratification)

#### 정의
```
데이터를 특정 기준(층)으로 분류하여 분석하는 기법
```

#### 목적
```
✓ 데이터 속 숨겨진 패턴 발견
✓ 문제 원인의 명확화
✓ 효과적인 대책 수립
```

#### 층별 기준 (4M 중심)

**Man (작업자)**
```
- 숙련도별 (신입/베테랑)
- 근무조별 (A조/B조)
- 개인별
```

**Machine (설비)**
```
- 기계별 (1호기/2호기)
- 신구 설비별
- 설비 유형별
```

**Material (재료)**
```
- 공급업체별
- 로트별
- 재질별
```

**Method (방법)**
```
- 작업 방법별
- 공정별
- 조건별
```

**기타**
```
- 시간대별 (오전/오후)
- 계절별
- 지역별
```

#### 활용 방법

**1. 층별 기준 선정**
```
문제와 관련 있는 요인 선택
```

**2. 데이터 분류**
```
선정된 기준으로 데이터 그룹화
```

**3. 층별 분석**
```
각 층의 특성 비교 분석
히스토그램, 관리도 등 활용
```

**4. 차이 원인 규명**
```
층 간 차이가 큰 경우 원인 조사
```

#### 예시
```
[작업조별 불량률 층별 분석]

A조: 불량률 2.5%
B조: 불량률 5.8%
C조: 불량률 2.3%

→ B조의 불량률이 높음
→ B조의 작업 방법, 숙련도, 설비 등 조사
→ 원인: B조는 신입이 많고 교육 부족
```

## 📋 (1) 고장나무 분석 (FTA: Fault Tree Analysis) (5점)

### 정의
```
FTA (Fault Tree Analysis):
시스템의 바람직하지 않은 사건(고장)을 최상위에 놓고,
그 원인을 논리 기호를 사용하여 나무(Tree) 형태로
연역적(Top-Down)으로 분석하는 기법
```

---

### 목적

```
✓ 시스템 고장의 원인 규명
✓ 고장 발생 확률 계산
✓ 취약점 파악 및 개선
✓ 안전성 평가
✓ 설계 단계에서의 신뢰성 확보
```

---

### 특징

**1. 연역적 분석 (Deductive Analysis)**
```
Top-Down 방식:
최상위 고장 사건 → 중간 사건 → 기본 사건

정해진 고장부터 원인을 찾아 내려감
```

**2. 논리 기호 사용**
```
AND 게이트, OR 게이트 등 논리 게이트로 인과관계 표현
```

**3. 정량적 분석 가능**
```
각 사건의 확률을 이용하여 최상위 사건의 발생 확률 계산
```

**4. 시각적 표현**
```
복잡한 인과관계를 나무 구조로 명확히 표현
```

---

### 주요 용어

#### 사건 (Event)

**① 최상위 사건 (Top Event)**
```
- 분석 대상이 되는 바람직하지 않은 사건
- FT 다이어그램의 최상단
- 예: 시스템 고장, 사고 발생
```

**② 중간 사건 (Intermediate Event)**
```
- 최상위 사건과 기본 사건 사이의 사건
- 논리 게이트의 출력
```

**③ 기본 사건 (Basic Event)**
```
- 더 이상 분해할 수 없는 최하위 사건
- FT의 말단 사건
- 고장률, 고장 확률이 알려진 사건
```

**④ 미전개 사건 (Undeveloped Event)**
```
- 더 분해 가능하나 정보 부족 등으로 전개하지 않은 사건
```

---

### 논리 게이트 (Logic Gate)

#### AND 게이트 (∩)
```
기호: ∩ 또는 ⌒

의미: 모든 입력 사건이 동시에 발생해야 출력 사건 발생

        출력
         │
      ┌──∩──┐
      │     │
    입력1  입력2

예: 두 개의 안전장치가 모두 고장나야 사고 발생
P(출력) = P(입력1) × P(입력2)
```

#### OR 게이트 (∪)
```
기호: ∪ 또는 ⌣

의미: 입력 사건 중 하나만 발생해도 출력 사건 발생

        출력
         │
      ┌──∪──┐
      │     │
    입력1  입력2

예: 두 개의 부품 중 하나만 고장나도 시스템 고장
P(출력) = 1 - (1-P(입력1)) × (1-P(입력2))
        ≈ P(입력1) + P(입력2)  (확률이 작을 때)
```

#### 기타 게이트
```
- 배타적 OR 게이트 (XOR): 하나만 발생
- 우선 AND 게이트: 특정 순서로 발생
- 금지 게이트 (Inhibit): 조건부 발생
```

---

### 사건 기호

```
┌─────┐
│     │  기본 사건 (Basic Event)
└──┬──┘  - 원으로 표시
   │     - 더 이상 분해 안 함

   ◇     미전개 사건 (Undeveloped Event)
   │     - 마름모로 표시
   │     - 정보 부족으로 미전개

┌─────┐
│     │  중간 사건 (Intermediate Event)
└──┬──┘  - 사각형으로 표시
   │     - 게이트의 출력
```

---

### FTA 작성 절차

**1단계: 최상위 사건 정의**
```
- 분석 대상이 되는 바람직하지 않은 사건 명확히 정의
- 예: "자동차 브레이크 고장"
```

**2단계: 시스템 경계 설정**
```
- 분석 범위 결정
- 시스템 구조 및 기능 파악
```

**3단계: 고장나무 전개**
```
- 최상위 사건의 직접 원인 찾기
- 논리 게이트(AND/OR)로 연결
- 기본 사건까지 반복 전개
```

**4단계: 정성적 분석**
```
- 최소 컷 셋(Minimal Cut Set) 도출
- 취약 경로 파악
```

**5단계: 정량적 분석**
```
- 각 기본 사건의 확률 할당
- 최상위 사건의 발생 확률 계산
```

**6단계: 개선 대책 수립**
```
- 고위험 경로 개선
- 중복성(Redundancy) 추가
- 예방 보전 강화
```

---

### FTA 예시

```
                    ┌──────────────┐
                    │ 자동차 사고   │  최상위 사건
                    │  발생        │
                    └──────┬───────┘
                           │
                      ┌────∪────┐     OR 게이트
                      │         │
          ┌───────────┴─┐   ┌───┴──────────┐
          │브레이크 고장 │   │ 조향장치 고장│  중간 사건
          └──────┬───────┘   └───┬──────────┘
                 │               │
            ┌────∩────┐     ┌────∩────┐     AND 게이트
            │         │     │         │
        ┌───┴───┐ ┌───┴───┐ ┌───┴───┐ ┌───┴───┐
        │브레이크│ │유압계통│ │핸들   │ │조향축 │  기본 사건
        │패드마모│ │누유   │ │파손   │ │파손   │
        └───○───┘ └───○───┘ └───○───┘ └───○───┘
```

---

### 최소 컷 셋 (Minimal Cut Set)

#### 정의
```
최상위 사건을 발생시키는 기본 사건의 최소 조합
```

#### 의미
```
- 컷 셋: 최상위 사건을 발생시키는 기본 사건 집합
- 최소 컷 셋: 더 이상 줄일 수 없는 최소 조합
- 시스템의 취약 경로
```

#### 예시
```
위 FTA에서 최소 컷 셋:
1. {브레이크 패드 마모, 유압계통 누유}
2. {핸들 파손, 조향축 파손}

→ 이 조합들이 발생하면 사고 발생
→ 우선 개선 대상
```

---

### 정량적 분석 예시

```
가정:
P(브레이크 패드 마모) = 0.01
P(유압계통 누유) = 0.02
P(핸들 파손) = 0.005
P(조향축 파손) = 0.008

계산:
P(브레이크 고장) = 0.01 × 0.02 = 0.0002  (AND)
P(조향장치 고장) = 0.005 × 0.008 = 0.00004  (AND)
P(자동차 사고) ≈ 0.0002 + 0.00004 = 0.00024  (OR)
             = 0.024% = 240 ppm
```

---

### 장점

```
✓ 복잡한 시스템 분석 가능
✓ 체계적이고 논리적
✓ 정량적 평가 가능
✓ 개선 우선순위 결정 용이
✓ 설계 단계부터 적용 가능
```

### 단점

```
- 시간과 비용 소요
- 전문 지식 필요
- 모든 고장 모드 파악 어려움
- 확률 데이터 확보 어려움
```

---

### 활용 분야

```
✓ 항공우주: 비행기 안전 분석
✓ 원자력: 원전 안전성 평가
✓ 화학: 폭발 사고 위험 분석
✓ 자동차: 안전 시스템 설계
✓ 전자: 회로 신뢰성 분석
```

---

## 🔍 (2) 고장증상과 영향분석 (FMEA: Failure Mode and Effect Analysis) (5점)

### 정의
```
FMEA (Failure Mode and Effect Analysis):
시스템, 제품, 공정에서 발생 가능한 고장 모드(Failure Mode)를
사전에 파악하고, 그 영향을 분석하여 우선순위를 정하고
예방 조치를 취하는 귀납적(Bottom-Up) 분석 기법
```

---

### 목적

```
✓ 잠재적 고장 사전 파악
✓ 고장의 영향 평가
✓ 고장 예방 조치 수립
✓ 설계 및 공정 개선
✓ 고객 만족도 향상
✓ 보증 비용 절감
```

---

### 특징

**1. 귀납적 분석 (Inductive Analysis)**
```
Bottom-Up 방식:
개별 부품/공정 → 시스템 전체 영향

작은 고장부터 시작하여 전체 영향 추적
```

**2. 사전 예방적**
```
- 설계/개발 단계에서 수행
- 문제 발생 전 예방
- "실패로부터 학습"
```

**3. 체계적 문서화**
```
- FMEA 양식에 체계적 기록
- 지식 축적 및 공유
```

**4. 정량적 평가**
```
- RPN (Risk Priority Number) 계산
- 우선순위 결정
```

---

### FMEA 유형

#### 1. 설계 FMEA (Design FMEA, DFMEA)
```
대상: 제품 설계
시기: 설계 단계
목적: 설계 결함 사전 발견
담당: 설계 부서
```

#### 2. 공정 FMEA (Process FMEA, PFMEA)
```
대상: 제조 공정
시기: 공정 설계 단계
목적: 공정 문제 사전 발견
담당: 제조 부서
```

#### 3. 시스템 FMEA (System FMEA)
```
대상: 전체 시스템
범위: 시스템 수준
목적: 시스템 간 상호작용 분석
```

---

### FMEA 주요 개념

#### 고장 모드 (Failure Mode)
```
정의: 부품, 서브시스템, 시스템이 기능을 수행하지 못하는 방식

예시:
- 파손, 변형, 균열
- 단선, 단락, 누전
- 마모, 부식
- 작동 불량, 기능 정지
```

#### 고장 영향 (Effect of Failure)
```
정의: 고장 모드가 발생했을 때 시스템, 고객, 작업자에게 미치는 결과

예시:
- 시스템 정지
- 성능 저하
- 안전사고
- 고객 불만
```

#### 고장 원인 (Cause of Failure)
```
정의: 고장 모드를 유발하는 설계상, 공정상 결함

예시:
- 재료 불량
- 설계 오류
- 가공 불량
- 조립 실수
```

---

### FMEA 양식 및 평가 항목

#### 표준 FMEA 양식

| 항목 | 고장모드 | 고장영향 | 심각도(S) | 고장원인 | 발생도(O) | 현재관리 | 검출도(D) | RPN | 조치사항 | 책임자 | 완료일 |
|------|----------|----------|-----------|----------|-----------|----------|-----------|-----|----------|--------|--------|
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

---

### 평가 지수

#### 1. 심각도 (Severity, S)

**정의**: 고장이 발생했을 때 영향의 심각한 정도

**평가 척도** (1~10점)

| 점수 | 등급 | 설명 |
|------|------|------|
| 10 | 매우 심각 | 안전 문제, 법규 위반 |
| 9 | 심각 | 시스템 기능 상실 |
| 7~8 | 높음 | 주요 기능 저하 |
| 4~6 | 중간 | 부분 기능 저하 |
| 2~3 | 낮음 | 경미한 불편 |
| 1 | 매우 낮음 | 영향 없음 |

---

#### 2. 발생도 (Occurrence, O)

**정의**: 고장 원인이 발생할 가능성

**평가 척도** (1~10점)

| 점수 | 발생 확률 | 설명 |
|------|-----------|------|
| 10 | ≥ 100 ppm | 거의 확실히 발생 |
| 9 | 50 ppm | 매우 높음 |
| 7~8 | 20 ppm | 높음 |
| 4~6 | 2~10 ppm | 중간 |
| 2~3 | 0.1~1 ppm | 낮음 |
| 1 | < 0.01 ppm | 거의 불가능 |

---

#### 3. 검출도 (Detection, D)

**정의**: 현재의 관리 방법으로 고장을 검출할 수 없는 정도
(높을수록 검출 어려움)

**평가 척도** (1~10점)

| 점수 | 검출 능력 | 설명 |
|------|-----------|------|
| 10 | 불가능 | 검출 수단 없음 |
| 9 | 매우 낮음 | 간헐적 검사 |
| 7~8 | 낮음 | 샘플 검사 |
| 4~6 | 중간 | 통계적 검사 |
| 2~3 | 높음 | 자동 검출 |
| 1 | 매우 높음 | 오류 방지 설계 |

---

### RPN (Risk Priority Number)

#### 정의
```
RPN = S × O × D

위험 우선순위 지수
고장 모드의 위험도를 정량화한 값
```

#### 범위
```
최소: 1 × 1 × 1 = 1
최대: 10 × 10 × 10 = 1,000
```

#### 활용
```
RPN이 높을수록 우선 개선 대상
보통 RPN ≥ 100 이상을 개선 대상으로 선정
```

---

### FMEA 수행 절차

**1단계: 준비**
```
- FMEA 팀 구성 (다기능 팀)
- 분석 대상 선정
- 시스템 구조 파악
```

**2단계: 고장 모드 파악**
```
- 각 항목별 가능한 고장 모드 나열
- 브레인스토밍, 과거 데이터 활용
```

**3단계: 고장 영향 분석**
```
- 각 고장 모드의 영향 기술
- 심각도(S) 평가
```

**4단계: 고장 원인 분석**
```
- 각 고장 모드의 원인 파악
- 발생도(O) 평가
```

**5단계: 현재 관리 방법 확인**
```
- 현재의 예방/검출 수단 파악
- 검출도(D) 평가
```

**6단계: RPN 계산**
```
- RPN = S × O × D 계산
- 우선순위 결정
```

**7단계: 개선 조치 수립**
```
- 고 RPN 항목에 대한 개선 대책
- 담당자 및 완료 기한 설정
```

**8단계: 조치 후 재평가**
```
- 개선 조치 실시 후 S, O, D 재평가
- 새로운 RPN 계산
- 효과 확인
```

**9단계: 문서화 및 지속 관리**
```
- FMEA 결과 문서화
- 정기적 갱신
```

---

### FMEA 예시

**제품**: 자동차 브레이크 시스템
**부품**: 브레이크 패드

| 항목 | 고장모드 | 고장영향 | S | 고장원인 | O | 현재관리 | D | RPN | 조치사항 |
|------|----------|----------|---|----------|---|----------|---|-----|----------|
| 브레이크 패드 | 마모 | 제동력 저하 | 9 | 저품질 재료 | 4 | 정기점검 | 3 | 108 | 재료 규격 강화 |
| 브레이크 패드 | 균열 | 제동 불능 | 10 | 과열 | 3 | 육안 검사 | 5 | 150 | 냉각 시스템 개선 |
| 브레이크 패드 | 이탈 | 제동 불능 | 10 | 잘못된 조립 | 2 | Poka-Yoke | 1 | 20 | 현재 관리 유지 |

**분석 결과**
```
- 균열 (RPN=150): 최우선 개선 대상 → 냉각 시스템 개선
- 마모 (RPN=108): 차순위 개선 → 재료 규격 강화
- 이탈 (RPN=20): 현재 관리 양호 → 유지
```

---

### 개선 전략

#### 심각도(S) 저감
```
- 설계 변경
- 여유도(Margin) 증가
- 중복 설계(Redundancy)
→ 가장 어려움, 근본적 해결
```

#### 발생도(O) 저감
```
- 공정 개선
- 작업 표준화
- 예방 보전
- 재료 품질 향상
→ 가장 효과적
```

#### 검출도(D) 저감 (검출 능력 향상)
```
- 검사 강화
- 자동화 검사
- Poka-Yoke (실수 방지)
- 센서 추가
→ 비교적 용이
```

---

### 장점

```
✓ 사전 예방적
✓ 체계적 분석
✓ 팀 접근 (지식 공유)
✓ 우선순위 명확
✓ 문서화로 지식 축적
✓ 지속적 개선 도구
```

### 단점

```
- 시간 소요
- 주관적 평가 가능성
- 복잡한 상호작용 파악 어려움
- 정기적 갱신 필요
```

---

### 활용 분야

```
✓ 자동차: 설계/제조 FMEA
✓ 항공: 안전 중시 산업
✓ 의료기기: FDA 요구사항
✓ 전자: 신뢰성 확보
✓ 식품: HACCP 연계
```

## 💡 FTA vs FMEA 비교

| 구분 | FTA | FMEA |
|------|-----|------|
| **방향** | 연역적 (Top-Down) | 귀납적 (Bottom-Up) |
| **시작점** | 특정 고장 사건 | 개별 부품/공정 |
| **초점** | 특정 사건의 원인 | 모든 고장 모드 |
| **표현** | 나무 구조 (그래프) | 표 (Table) |
| **정량화** | 확률 계산 | RPN 계산 |
| **장점** | 복잡한 인과관계 명확 | 포괄적, 체계적 |
| **단점** | 특정 사건만 분석 | 복잡한 상호작용 한계 |
| **시기** | 주로 설계 완료 후 | 설계/개발 초기 |
| **활용** | 치명적 고장 분석 | 전반적 개선 |

---

### 상호 보완적 활용

```
FMEA로 잠재 고장 모드 파악
     ↓
치명적 고장 모드 선정
     ↓
FTA로 상세 원인 분석
     ↓
종합 개선 대책 수립
```

---

## 📝 최종 정리

### (1) FTA
```
- 연역적(Top-Down) 분석

```

```

```

# 제40회 경영지도사 경영과학 - 문제 1

## 의사결정론 (Decision Theory)

---

## 📋 문제 상황

### 주어진 정보

**투자금액**: 100억원

**투자안에 대한 성과표 (1년 후 잔존가치, 단위: 억원)**

| 경제상황<br>투자안 | 호황 | 보통 | 불황 |
|------|-----|-----|-----|
| 주식 | 200 | 130 | 50 |
| 부동산 | 150 | 100 | 80 |
| 금 | 100 | 120 | 150 |

---

## 🎯 (1) 후회의 미니맥스 기준 (10점)

### 후회(Regret) 개념

```
후회 = 각 상황에서의 최대 성과 - 선택한 대안의 성과

의미: "만약 그때 최선의 선택을 했다면..." 하는 아쉬움의 크기
```

---

### Step 1: 각 경제상황별 최대 성과 확인

```
호황 상황: max(200, 150, 100) = 200 (주식)
보통 상황: max(130, 100, 120) = 130 (주식)
불황 상황: max(50, 80, 150) = 150 (금)
```

---

### Step 2: 후회표(Regret Table) 작성

#### 계산 과정

**호황 상황의 후회**
```
주식: 200 - 200 = 0
부동산: 200 - 150 = 50
금: 200 - 100 = 100
```

**보통 상황의 후회**
```
주식: 130 - 130 = 0
부동산: 130 - 100 = 30
금: 130 - 120 = 10
```

**불황 상황의 후회**
```
주식: 150 - 50 = 100
부동산: 150 - 80 = 70
금: 150 - 150 = 0
```

#### 후회표

| 경제상황<br>투자안 | 호황 | 보통 | 불황 | **최대 후회** |
|------|-----|-----|-----|----------|
| 주식 | 0 | 0 | **100** | **100** |
| 부동산 | 50 | 30 | 70 | **70** |
| 금 | 100 | 10 | 0 | **100** |

---

### Step 3: 미니맥스 후회(Minimax Regret) 기준 적용

**미니맥스 후회 기준**
```
각 대안의 최대 후회 중에서 최소값을 선택
→ "최악의 경우 후회를 최소화"
```

**각 대안의 최대 후회**
```
주식: max(0, 0, 100) = 100
부동산: max(50, 30, 70) = 70  ← 최소
금: max(100, 10, 0) = 100
```

**최적 대안**
```
부동산 (최대 후회 = 70억원)
```

---

### 해석

```
부동산에 투자할 경우:
- 어떤 경제상황이 오더라도 후회는 최대 70억원
- 주식이나 금에 투자하면 최대 100억원까지 후회 가능
- 보수적 의사결정자에게 적합
```

---

## 💰 (2) 기대화폐가치 (EMV: Expected Monetary Value) (10점)

### 주어진 확률

```
P(호황) = 0.30
P(보통) = 0.50
P(불황) = 0.20
```

---

### 기대화폐가치(EMV) 공식

```
EMV = Σ [성과 × 확률]
    = (호황 성과 × 0.30) + (보통 성과 × 0.50) + (불황 성과 × 0.20)
```

---

### 계산

#### 주식의 EMV

```
EMV(주식) = 200 × 0.30 + 130 × 0.50 + 50 × 0.20
          = 60 + 65 + 10
          = 135 억원
```

#### 부동산의 EMV

```
EMV(부동산) = 150 × 0.30 + 100 × 0.50 + 80 × 0.20
            = 45 + 50 + 16
            = 111 억원
```

#### 금의 EMV

```
EMV(금) = 100 × 0.30 + 120 × 0.50 + 150 × 0.20
        = 30 + 60 + 30
        = 120 억원
```

---

### EMV 요약 및 최적 대안

| 투자안 | EMV (억원) | 순위 |
|--------|-----------|------|
| **주식** | **135** | **1위** ← 최대 |
| 금 | 120 | 2위 |
| 부동산 | 111 | 3위 |

**최적 대안 (EMV 기준)**
```
주식 (EMV = 135억원)
```

---

### 해석

```
확률을 고려한 기대수익:
- 주식이 가장 높은 기대수익 (135억원)
- 금은 중간 (120억원)
- 부동산은 가장 낮음 (111억원)

→ 위험 중립적 의사결정자는 주식 선택
```

---

## 📊 (3) 완전정보의 기대가치 (EVPI: Expected Value of Perfect Information) (10점)

### 완전정보의 기대가치(EVPI) 개념

```
EVPI = 완전정보 하의 기대가치(EVWPI) - 최선 대안의 EMV(EMV*)

의미: 미래를 완벽하게 예측할 수 있다면, 그 정보에 지불할 용의가 있는 최대 금액
```

---

### Step 1: 완전정보 하의 기대가치(EVWPI) 계산

**완전정보 하의 전략**
```
만약 미래를 알 수 있다면:
- 호황이 올 것을 안다면 → 주식 선택 (200억원)
- 보통이 올 것을 안다면 → 주식 선택 (130억원)
- 불황이 올 것을 안다면 → 금 선택 (150억원)
```

**EVWPI 계산**
```
EVWPI = (각 상황의 최대 성과) × (해당 상황의 확률)

EVWPI = 200 × 0.30 + 130 × 0.50 + 150 × 0.20
      = 60 + 65 + 30
      = 155 억원
```

---

### Step 2: 최선 대안의 EMV (EMV*) 확인

```
EMV* = max(EMV(주식), EMV(부동산), EMV(금))
     = max(135, 111, 120)
     = 135 억원 (주식)
```

---

### Step 3: EVPI 계산

```
EVPI = EVWPI - EMV*
     = 155 - 135
     = 20 억원
```

---

### 답

```
완전정보의 기대가치(EVPI) = 20억원
```

---

### 해석

```
완전정보의 가치 = 20억원

의미:
1. 미래 경제상황을 완벽히 예측할 수 있는 정보가 있다면,
   그 정보에 최대 20억원까지 지불할 가치가 있음

2. 만약 시장조사 비용이 20억원 이하라면 투자 가치 있음
   (예: 10억원 들여 정확한 예측 가능 → 순이익 10억원)

3. 20억원 초과 시 정보 구매 불필요
```

# 제40회 경영지도사 경영과학 문제2 답안

## 문제: 사료 배합 문제 (선형계획법)

### 문제 요약
- 옥수수(x₁)와 보리(x₂)를 배합하여 사료를 제조
- 영양소 최소 요구량을 만족하면서 비용을 최소화
- 목적함수: min z = 30x₁ + 20x₂

---

## (1) LP 모형 작성

### 1) 목적함수 (Objective Function)
```
min z = 30x₁ + 20x₂
```
- x₁: 옥수수의 양 (kg)
- x₂: 보리의 양 (kg)
- 30: 옥수수 단위당 비용
- 20: 보리 단위당 비용

### 2) 제약조건 (Constraints)

**탄수화물 제약:**
```
3x₁ + x₂ ≥ 14
```
- 옥수수는 단위당 3단위, 보리는 단위당 1단위의 탄수화물 함유
- 최소 14단위 필요

**단백질 제약:**
```
x₁ + 2x₂ ≥ 12
```
- 옥수수는 단위당 1단위, 보리는 단위당 2단위의 단백질 함유
- 최소 12단위 필요

**지방 제약:**
```
x₁ + x₂ ≥ 10
```
- 옥수수와 보리 모두 단위당 1단위의 지방 함유
- 최소 10단위 필요

### 3) 비음조건 (Non-negativity Constraints)
```
x₁ ≥ 0, x₂ ≥ 0
```
- 음수의 사료는 존재할 수 없음

### 완성된 LP 모형
```
min z = 30x₁ + 20x₂

subject to:
    3x₁ + x₂ ≥ 14    (탄수화물)
    x₁ + 2x₂ ≥ 12    (단백질)
    x₁ + x₂ ≥ 10     (지방)
    x₁, x₂ ≥ 0       (비음조건)
```

---

## (2) 도해법으로 최적해 구하기

### 1) 제약조건을 등식으로 변환하여 경계선 그리기

**제약조건 1: 3x₁ + x₂ = 14**
- x₁ = 0일 때: x₂ = 14 → 점 (0, 14)
- x₂ = 0일 때: x₁ = 14/3 ≈ 4.67 → 점 (4.67, 0)

**제약조건 2: x₁ + 2x₂ = 12**
- x₁ = 0일 때: x₂ = 6 → 점 (0, 6)
- x₂ = 0일 때: x₁ = 12 → 점 (12, 0)

**제약조건 3: x₁ + x₂ = 10**
- x₁ = 0일 때: x₂ = 10 → 점 (0, 10)
- x₂ = 0일 때: x₁ = 10 → 점 (10, 0)

### 2) 실행가능영역 결정

최소화 문제에서 "≥" 제약조건이므로:
- 3x₁ + x₂ ≥ 14: 직선의 우상향 영역
- x₁ + 2x₂ ≥ 12: 직선의 우상향 영역
- x₁ + x₂ ≥ 10: 직선의 우상향 영역

실행가능영역은 세 제약조건을 모두 만족하는 영역입니다.

### 3) 꼭지점(Corner Points) 찾기

**꼭지점 A: 제약조건 1과 2의 교점**
```
3x₁ + x₂ = 14  ... ①
x₁ + 2x₂ = 12  ... ②

①에서: x₂ = 14 - 3x₁
②에 대입: x₁ + 2(14 - 3x₁) = 12
         x₁ + 28 - 6x₁ = 12
         -5x₁ = -16
         x₁ = 16/5 = 3.2

x₂ = 14 - 3(3.2) = 14 - 9.6 = 4.4
```
**점 A = (3.2, 4.4)**

검증:
- 제약 1: 3(3.2) + 4.4 = 9.6 + 4.4 = 14 ✓
- 제약 2: 3.2 + 2(4.4) = 3.2 + 8.8 = 12 ✓
- 제약 3: 3.2 + 4.4 = 7.6 < 10 ✗

**점 A는 제약조건 3을 만족하지 않으므로 실행가능영역에 속하지 않습니다.**

**꼭지점 B: 제약조건 1과 3의 교점**
```
3x₁ + x₂ = 14  ... ①
x₁ + x₂ = 10   ... ③

③에서: x₂ = 10 - x₁
①에 대입: 3x₁ + (10 - x₁) = 14
         2x₁ = 4
         x₁ = 2

x₂ = 10 - 2 = 8
```
**점 B = (2, 8)**

검증:
- 제약 1: 3(2) + 8 = 14 ✓
- 제약 2: 2 + 2(8) = 18 ≥ 12 ✓
- 제약 3: 2 + 8 = 10 ✓

**점 B는 실행가능영역에 속합니다.**

**꼭지점 C: 제약조건 2와 3의 교점**
```
x₁ + 2x₂ = 12  ... ②
x₁ + x₂ = 10   ... ③

②-③: x₂ = 2
③에 대입: x₁ + 2 = 10
         x₁ = 8
```
**점 C = (8, 2)**

검증:
- 제약 1: 3(8) + 2 = 26 ≥ 14 ✓
- 제약 2: 8 + 2(2) = 12 ✓
- 제약 3: 8 + 2 = 10 ✓

**점 C는 실행가능영역에 속합니다.**

### 4) 각 꼭지점에서 목적함수 값 계산

**점 B = (2, 8):**
```
z = 30(2) + 20(8) = 60 + 160 = 220
```

**점 C = (8, 2):**
```
z = 30(8) + 20(2) = 240 + 40 = 280
```

### 5) 최적해

**최적해: x₁* = 2, x₂* = 8**
**최소비용: z* = 220**

**해석:**
- 옥수수 2kg, 보리 8kg을 배합
- 최소 비용은 220원
- 이 배합은 모든 영양소 요구량을 만족함
  - 탄수화물: 3(2) + 8 = 14 (딱 맞음)
  - 단백질: 2 + 2(8) = 18 (여유 6)
  - 지방: 2 + 8 = 10 (딱 맞음)

## (3) 쌍대문제(Dual Problem) 작성

### 쌍대성 원리 (Duality Principle)

원문제(Primal)가 최소화 문제일 때, 쌍대문제(Dual)는 최대화 문제가 됩니다.

### 원문제 (Primal)
```
min z = 30x₁ + 20x₂

subject to:
    3x₁ + x₂ ≥ 14
    x₁ + 2x₂ ≥ 12
    x₁ + x₂ ≥ 10
    x₁, x₂ ≥ 0
```

### 쌍대변수 정의

- y₁: 탄수화물 제약에 대한 쌍대변수 (그림자 가격)
- y₂: 단백질 제약에 대한 쌍대변수
- y₃: 지방 제약에 대한 쌍대변수

### 쌍대문제 도출 과정

**1단계: 제약조건 행렬 전치**

원문제의 계수 행렬:
```
        x₁  x₂  RHS
탄수화물  3   1   14
단백질    1   2   12
지방      1   1   10
목적함수 30  20
```

**2단계: 쌍대문제 구성**

- 원문제의 제약조건 개수(3개) = 쌍대문제의 변수 개수
- 원문제의 변수 개수(2개) = 쌍대문제의 제약조건 개수
- 원문제의 RHS = 쌍대문제의 목적함수 계수
- 원문제의 목적함수 계수 = 쌍대문제의 RHS
- 원문제 "≥" → 쌍대문제 "≤"
- 원문제 "min" → 쌍대문제 "max"

### 쌍대문제 (Dual Problem)

```
max w = 14y₁ + 12y₂ + 10y₃

subject to:
    3y₁ + y₂ + y₃ ≤ 30    (x₁에 대응)
    y₁ + 2y₂ + y₃ ≤ 20    (x₂에 대응)
    y₁, y₂, y₃ ≥ 0
```

### 쌍대문제의 경제적 의미

- **목적함수**: 영양소의 총 가치를 최대화
- **y₁**: 탄수화물 1단위의 그림자 가격 (marginal value)
- **y₂**: 단백질 1단위의 그림자 가격
- **y₃**: 지방 1단위의 그림자 가격
- **제약조건 1**: 옥수수가 제공하는 영양소의 가치 ≤ 옥수수 비용(30)
- **제약조건 2**: 보리가 제공하는 영양소의 가치 ≤ 보리 비용(20)

### 강쌍대성 정리 (Strong Duality Theorem)

원문제와 쌍대문제가 모두 최적해를 가지면:
```
min z* = max w*
220 = 220
```

최적해에서 상보적 여유성(Complementary Slackness) 조건:
- 제약조건 1: 3(2) + 8 = 14 (binding) → y₁* > 0 가능
- 제약조건 2: 2 + 2(8) = 18 > 12 (slack = 6) → y₂* = 0
- 제약조건 3: 2 + 8 = 10 (binding) → y₃* > 0 가능

---

## 요약

### 최적해
- **옥수수(x₁)**: 2kg
- **보리(x₂)**: 8kg
- **최소비용**: 220원

### 제약조건 충족 상황
- 탄수화물: 14 (요구량 만족, 여유 없음)
- 단백질: 18 (요구량 12 초과, 여유 6)
- 지방: 10 (요구량 만족, 여유 없음)

### 경영학적 시사점
1. 단백질 제약이 느슨하므로(slack), 단백질 요구량을 줄여도 최적해는 변하지 않음
2. 탄수화물과 지방 제약이 binding이므로, 이들의 요구량 변화는 최적해에 직접 영향
3. 쌍대문제를 통해 각 영양소의 그림자 가격을 파악하여 자원 배분의 효율성 평가 가능

# 제40회 경영지도사 경영과학 문제3 답안 (AHP)

## 문제 개요
계층분석법(AHP, Analytic Hierarchy Process)에서 3개 평가기준(경제적 보상, 성장 가능성, 적성 적합도)에 대한 쌍대비교행렬이 주어지고, 빈칸 ①②③을 채우고 상대적 중요도 가중치를 계산하는 문제입니다.

---

## (1) 쌍대비교행렬의 빈칸 채우기

### 1.1 쌍대비교행렬의 기본 원리

쌍대비교행렬은 다음과 같은 특성을 가집니다:

**1) 대각선 원소는 1**
- 자기 자신과의 비교이므로 모든 대각선 원소는 1입니다
- a₁₁ = a₂₂ = a₃₃ = 1

**2) 역수 관계 (대칭성)**
- aᵢⱼ = 1/aⱼᵢ
- 만약 A가 B보다 3배 중요하면, B는 A보다 1/3배 중요합니다

**3) 정성적 척도**
- AHP에서는 일반적으로 1~9 척도를 사용합니다
- 1: 동등하게 중요, 3: 약간 더 중요, 5: 강하게 더 중요, 7: 매우 강하게 더 중요, 9: 극단적으로 더 중요

### 1.2 쌍대비교행렬 구조 (일반적인 형태)

일반적으로 문제에서 제시되는 쌍대비교행렬의 형태는 다음과 같습니다:

```
           경제적보상  성장가능성  적성적합도
경제적보상     1         a₁₂        a₁₃
성장가능성    a₂₁        1         a₂₃
적성적합도    a₃₁        a₃₂        1
```

### 1.3 빈칸 채우기 절차

**단계 1: 주어진 값 확인**
문제에서 일부 비교값이 주어집니다. 예를 들어:
- 경제적 보상 vs 성장 가능성 = 2 (경제적 보상이 2배 더 중요)
- 경제적 보상 vs 적성 적합도 = ① (빈칸)
- 성장 가능성 vs 적성 적합도 = 3 (성장 가능성이 3배 더 중요)

**단계 2: 역수 관계를 이용하여 빈칸 계산**

빈칸 ①:
- 만약 적성 적합도 vs 경제적 보상 = 1/4 가 주어졌다면
- 역수 관계에 의해 ① = 1/(1/4) = **4**

빈칸 ②:
- 성장 가능성 vs 경제적 보상 관계 이용
- 경제적 보상 vs 성장 가능성 = 2 가 주어졌다면
- ② = 1/2 = **0.5 또는 1/2**

빈칸 ③:
- 적성 적합도 vs 성장 가능성 관계 이용
- 성장 가능성 vs 적성 적합도 = 3 이 주어졌다면
- ③ = 1/3 = **0.333... 또는 1/3**

### 1.4 완성된 쌍대비교행렬 (예시)

```
           경제적보상  성장가능성  적성적합도
경제적보상     1         2          4
성장가능성    1/2        1          3
적성적합도    1/4       1/3         1
```

또는 소수로 표현:

```
           경제적보상  성장가능성  적성적합도
경제적보상    1.000     2.000      4.000
성장가능성    0.500     1.000      3.000
적성적합도    0.250     0.333      1.000
```

**검증**:
- a₁₂ × a₂₁ = 2 × 0.5 = 1 ✓
- a₁₃ × a₃₁ = 4 × 0.25 = 1 ✓
- a₂₃ × a₃₂ = 3 × 0.333 ≈ 1 ✓

---

## (2) 상대적 중요도 가중치 계산

AHP에서 가중치를 계산하는 방법은 여러 가지가 있으나, 가장 일반적인 **고유벡터법(Eigenvector Method)**과 간편한 **열 정규화 평균법**을 설명합니다.

### 2.1 열 정규화 평균법 (Column Normalization Method)

이 방법은 계산이 간편하고 실무에서 많이 사용됩니다.

#### 단계 1: 각 열의 합 계산

```
           경제적보상  성장가능성  적성적합도
경제적보상    1.000     2.000      4.000
성장가능성    0.500     1.000      3.000
적성적합도    0.250     0.333      1.000
─────────────────────────────────────────
열 합계       1.750     3.333      8.000
```

**계산:**
- 열1 합: 1.000 + 0.500 + 0.250 = 1.750
- 열2 합: 2.000 + 1.000 + 0.333 = 3.333
- 열3 합: 4.000 + 3.000 + 1.000 = 8.000

#### 단계 2: 각 원소를 열 합으로 나누어 정규화

**정규화된 행렬:**

```
           경제적보상      성장가능성      적성적합도      행 평균
경제적보상  1.000/1.750   2.000/3.333    4.000/8.000
           = 0.571       = 0.600        = 0.500       = 0.557

성장가능성  0.500/1.750   1.000/3.333    3.000/8.000
           = 0.286       = 0.300        = 0.375       = 0.320

적성적합도  0.250/1.750   0.333/3.333    1.000/8.000
           = 0.143       = 0.100        = 0.125       = 0.123
```

#### 단계 3: 각 행의 평균 계산 (최종 가중치)

**최종 가중치:**
- **경제적 보상**: (0.571 + 0.600 + 0.500) / 3 = **0.557 (55.7%)**
- **성장 가능성**: (0.286 + 0.300 + 0.375) / 3 = **0.320 (32.0%)**
- **적성 적합도**: (0.143 + 0.100 + 0.125) / 3 = **0.123 (12.3%)**

**검증**: 0.557 + 0.320 + 0.123 = 1.000 ✓ (합이 1이 되어야 함)

### 2.2 가중치 계산의 의미

위 결과는 다음을 의미합니다:
- 경제적 보상이 **55.7%**로 가장 중요한 기준
- 성장 가능성이 **32.0%**로 두 번째로 중요
- 적성 적합도가 **12.3%**로 상대적으로 덜 중요

### 2.3 고유벡터법 (참고)

더 정확한 방법으로 고유벡터법이 있습니다:

#### 단계 1: 각 행의 기하평균 계산

- 경제적 보상: (1 × 2 × 4)^(1/3) = 8^(1/3) = 2.000
- 성장 가능성: (0.5 × 1 × 3)^(1/3) = 1.5^(1/3) = 1.145
- 적성 적합도: (0.25 × 0.333 × 1)^(1/3) = 0.083^(1/3) = 0.436

#### 단계 2: 정규화 (합이 1이 되도록)

기하평균 합: 2.000 + 1.145 + 0.436 = 3.581

**최종 가중치:**
- **경제적 보상**: 2.000 / 3.581 = **0.559 (55.9%)**
- **성장 가능성**: 1.145 / 3.581 = **0.320 (32.0%)**
- **적성 적합도**: 0.436 / 3.581 = **0.122 (12.2%)**

## (3) 일관성 검증 (추가 설명)

AHP에서는 판단의 일관성을 검증하는 것이 중요합니다.

### 3.1 일관성 지수 (CI: Consistency Index)

**공식:**
```
CI = (λmax - n) / (n - 1)
```

여기서:
- λmax: 최대 고유치 (principal eigenvalue)
- n: 평가기준의 개수 (여기서는 3)

### 3.2 일관성 비율 (CR: Consistency Ratio)

**공식:**
```
CR = CI / RI
```

여기서 RI(Random Index)는 행렬 크기에 따른 무작위 지수:
- n=3: RI = 0.58
- n=4: RI = 0.90
- n=5: RI = 1.12

**판단 기준:**
- CR < 0.1 (10%): 일관성 있음 (acceptable)
- CR ≥ 0.1 (10%): 재평가 필요

### 3.3 λmax 계산 방법 (간편법)

#### 단계 1: 가중합 벡터 계산

쌍대비교행렬과 가중치 벡터를 곱합니다:

```
[1.000  2.000  4.000]   [0.557]   [1.000×0.557 + 2.000×0.320 + 4.000×0.123]   [1.689]
[0.500  1.000  3.000] × [0.320] = [0.500×0.557 + 1.000×0.320 + 3.000×0.123] = [0.967]
[0.250  0.333  1.000]   [0.123]   [0.250×0.557 + 0.333×0.320 + 1.000×0.123]   [0.372]
```

#### 단계 2: λ 값 계산

각 원소를 대응하는 가중치로 나눕니다:

```
λ₁ = 1.689 / 0.557 = 3.032
λ₂ = 0.967 / 0.320 = 3.022
λ₃ = 0.372 / 0.123 = 3.024
```

#### 단계 3: 평균값이 λmax

```
λmax = (3.032 + 3.022 + 3.024) / 3 = 3.026
```

#### 단계 4: CI 및 CR 계산

```
CI = (3.026 - 3) / (3 - 1) = 0.026 / 2 = 0.013

CR = 0.013 / 0.58 = 0.022 = 2.2%
```

**결론**: CR = 2.2% < 10% 이므로 일관성이 있습니다.

## 정리

### 핵심 요약

**1. 쌍대비교행렬 작성**
- 대각선은 모두 1
- 역수 관계: aᵢⱼ = 1/aⱼᵢ
- 1~9 척도 사용

**2. 가중치 계산 (열 정규화 평균법)**
- ① 각 열의 합 계산
- ② 각 원소를 열 합으로 나누어 정규화
- ③ 각 행의 평균 계산 → 최종 가중치

**3. 일관성 검증**
- CR < 0.1 이면 일관성 있음
- 일관성이 없으면 재평가 필요

### 답안 작성 시 주의사항

1. **계산 과정을 명확히**: 단계별로 계산 과정을 보여주어야 합니다
2. **검증 포함**: 가중치 합이 1인지 확인
3. **단위 표시**: 백분율(%)로도 표시하면 이해가 쉽습니다
4. **일관성 언급**: 시간이 허락하면 일관성 검증까지 언급하면 좋습니다

# 제40회 경영지도사 경영과학 문제4 - 네트워크/PERT 답안

## 문제 분석

프로젝트 네트워크 문제로 7개의 작업으로 구성되어 있으며, 각 작업의 소요시간과 선행관계는 다음과 같습니다.

| 작업 | 선행작업 | 소요시간(일) |
|------|----------|--------------|
| A | - | 3 |
| B | - | 2 |
| C | A | 2 |
| D | B | 3 |
| E | B | 4 |
| F | C, D | 6 |
| G | E | 3 |

---

## (1) 네트워크 다이어그램

### AON (Activity-On-Node) 방식

```
시작점 (0)
    ├─→ A(3) ─→ C(2) ─┐
    │                   ├─→ F(6) ─→ 종료점
    └─→ B(2) ─┬─→ D(3) ─┘
              │
              └─→ E(4) ─→ G(3) ─→ 종료점
```

### AOA (Activity-On-Arrow) 방식 상세도

```
        A(3)         C(2)
    ① ─────→ ② ─────────→ ④
    │                       │
    │                       ↓ F(6)
    │       B(2)            ⑤ ─────→ ⑦ (종료)
    └─────→ ③ ─┬─→ D(3) ───┘         ↑
              │                      │
              └─→ E(4) ─→ ⑥ ─ G(3) ─┘
```

**노드(Node) 설명:**
- ① : 프로젝트 시작점 (노드 0)
- ② : 작업 A 완료 (노드 1)
- ③ : 작업 B 완료 (노드 2)
- ④ : 작업 C 완료 (노드 3)
- ⑤ : 작업 D, F의 병합점 (노드 4)
- ⑥ : 작업 E 완료 (노드 5)
- ⑦ : 프로젝트 종료점 (노드 6)

---

## (2) 모든 경로 및 임계경로 분석

### 1) 모든 가능한 경로 나열

프로젝트 시작점에서 종료점까지의 모든 경로를 파악합니다.

**경로 1: A → C → F**
- 작업 순서: 시작 → A → C → F → 종료
- 소요시간: 3 + 2 + 6 = **11일**

**경로 2: B → D → F**
- 작업 순서: 시작 → B → D → F → 종료
- 소요시간: 2 + 3 + 6 = **11일**

**경로 3: B → E → G**
- 작업 순서: 시작 → B → E → G → 종료
- 소요시간: 2 + 4 + 3 = **9일**

### 2) 임계경로(Critical Path) 결정

임계경로는 프로젝트 완료에 가장 긴 시간이 소요되는 경로입니다.

**분석 결과:**
- 경로 1 (A-C-F): 11일 ★
- 경로 2 (B-D-F): 11일 ★
- 경로 3 (B-E-G): 9일

**임계경로: 2개 존재**
1. **A → C → F** (11일)
2. **B → D → F** (11일)

### 3) 프로젝트 완료시간

**프로젝트 완료시간 = 11일**

임계경로가 2개 존재하므로, 두 경로 중 어느 하나라도 지연되면 전체 프로젝트가 지연됩니다.

---

## (3) 각 작업의 시간 분석 (최조시간, 최지시간, 여유시간)

### 최조시간(EST: Earliest Start Time)과 최조완료시간(EFT: Earliest Finish Time)

| 작업 | 선행작업 | 소요시간 | EST | EFT |
|------|----------|----------|-----|-----|
| A | - | 3 | 0 | 3 |
| B | - | 2 | 0 | 2 |
| C | A | 2 | 3 | 5 |

## (1) 보겔근사법(VAM) 적용 과정

보겔근사법은 각 행과 열에서 최소 비용과 차순위 비용의 차이(패널티)를 계산하여, 패널티가 가장 큰 행 또는 열에서 최소 비용 셀에 가능한 최대량을 할당하는 방법입니다.

  - 가: |1 - 2| = 1
  - 나: |3 - 4| = 1

- **B → 다: 50톤 할당**

#### 갱신된 공급/수요:

# 제40회 경영지도사 경영과학 문제6 답안

## 문제: 할당문제 - 헝가리법(Hungarian Method)

### 문제 상황
- 3대의 기계(A, B, C)에 4개의 작업(가, 나, 다, 라)을 할당
- 기계 수(m=3) < 작업 수(n=4)이므로 더미(dummy) 행 추가 필요
- 최소 비용으로 할당하는 문제

### 초기 비용행렬

|기계\작업|가|나|다|라|
|---|---|---|---|---|
|A|6|9|4|5|
|B|4|7|5|3|
|C|6|2|4|6|

---

## 풀이과정

### (1) 더미 행 추가

기계 수가 작업 수보다 적으므로, 더미 기계 D를 추가합니다.
더미 행의 모든 비용은 0으로 설정합니다.

**확장된 비용행렬:**

|기계\작업|가|나|다|라|
|---|---|---|---|---|
|A|6|9|4|5|
|B|4|7|5|3|
|C|6|2|4|6|
|D|0|0|0|0|

---

### (2) 행 감소(Row Reduction)

각 행에서 최소값을 찾아 해당 행의 모든 원소에서 뺍니다.

**행별 최소값:**
- A행: min = 4
- B행: min = 3
- C행: min = 2
- D행: min = 0

**행 감소 후 행렬:**

|기계\작업|가|나|다|라|
|---|---|---|---|---|
|A|2|5|0|1|
|B|1|4|2|0|
|C|4|0|2|4|
|D|0|0|0|0|

---

### (3) 열 감소(Column Reduction)

각 열에서 최소값을 찾아 해당 열의 모든 원소에서 뺍니다.

**열별 최소값:**
- 가열: min = 0
- 나열: min = 0
- 다열: min = 0
- 라열: min = 0

모든 열의 최소값이 0이므로 추가 감소 불필요합니다.

**열 감소 후 행렬 (변화 없음):**

|기계\작업|가|나|다|라|
|---|---|---|---|---|
|A|2|5|0|1|
|B|1|4|2|0|
|C|4|0|2|4|
|D|0|0|0|0|

---

### (4) 최소선 긋기 및 최적성 검사

#### 4-1단계: 초기 0 커버링

모든 0을 최소 개수의 선으로 커버합니다.

**0의 위치:**
- A행: 다(A,다)
- B행: 라(B,라)
- C행: 나(C,나)
- D행: 가, 나, 다, 라(D,가), (D,나), (D,다), (D,라)

**최소선 긋기:**
- D행 전체에 가로선 1개
- 다열 전체에 세로선 1개
- 나열 전체에 세로선 1개

총 3개의 선으로 모든 0을 커버할 수 있습니다.

선의 개수(3) < 행렬 크기(4) → **최적해가 아님**

#### 4-2단계: 행렬 조정

선으로 커버되지 않은 원소 중 최소값을 찾습니다.

**커버되지 않은 원소:**
- A행의 가(2), 라(1)
- B행의 가(1), 라(0) → 라는 선과 교차점
- C행의 다(2), 라(4)

선으로 커버되지 않은 최소값 = **1**

**조정 규칙:**
1. 선으로 커버되지 않은 원소: -1
2. 선의 교차점: +1
3. 한 개의 선으로만 커버된 원소: 변화 없음

**조정 후 행렬:**

|기계\작업|가|나|다|라|
|---|---|---|---|---|
|A|1|5|0|0|
|B|0|4|2|0|
|C|3|0|2|3|
|D|0|0|1|1|

#### 4-3단계: 재검사

**새로운 0의 위치:**
- A행: 다(A,다), 라(A,라)
- B행: 가(B,가), 라(B,라)
- C행: 나(C,나)
- D행: 가(D,가), 나(D,나)

**최소선 긋기:**
- 가열에 세로선
- 나열에 세로선
- 다열에 세로선
- 라열에 세로선

총 4개의 선으로 모든 0을 커버할 수 있습니다.

선의 개수(4) = 행렬 크기(4) → **최적해 발견!**

---

### (5) 최적 할당 및 최소 비용 계산

#### 할당 찾기

0이 있는 위치에서 각 행과 각 열에 정확히 하나씩만 선택:

1. **C행**: 나열에만 0 → **(C, 나) 할당**
2. **A행**: 다, 라에 0 있음 → 라는 다른 선택 가능성 있으므로 **(A, 다) 할당**
3. **B행**: 가, 라에 0 있음 → 가는 다른 선택 가능성 있으므로 **(B, 라) 할당**
4. **D행**: 가에 0 → **(D, 가) 할당**

#### 최적 할당 결과

|기계|작업|원래 비용|
|---|---|---|
|A|다|4|
|B|라|3|
|C|나|2|
|D(더미)|가|0|

**작업 가는 할당되지 않음** (더미 기계에 할당됨)

---

### 최종 답안

#### 최적 할당:
- **기계 A → 작업 다 (비용: 4)**
- **기계 B → 작업 라 (비용: 3)**
- **기계 C → 작업 나 (비용: 2)**
- **작업 가는 수행하지 않음**

#### 최소 총 비용:
**4 + 3 + 2 = 9**

## 해설

### 핵심 포인트

1. **더미 추가**: m < n인 경우 더미 행을 추가하여 정방행렬을 만듭니다. 더미의 비용은 모두 0입니다.

2. **행/열 감소**: 각 행과 열에서 최소값을 빼서 각 행과 열에 최소한 하나의 0을 만듭니다.

3. **최적성 검사**: 최소 개수의 선으로 모든 0을 커버했을 때, 선의 개수가 행렬 크기와 같으면 최적해입니다.

4. **행렬 조정**: 최적해가 아닌 경우, 커버되지 않은 최소값을 이용하여 행렬을 조정하고 다시 검사합니다.

5. **할당 결정**: 최적 조건이 만족되면, 0의 위치에서 각 행/열에 하나씩 할당을 결정합니다.

### 경영적 의미

- 3대의 기계로 4개 작업 중 3개만 수행 가능
- 작업 가는 외주 처리하거나 다른 방법으로 처리 필요
- 최소 비용 9로 나, 다, 라 작업을 효율적으로 배분 가능
