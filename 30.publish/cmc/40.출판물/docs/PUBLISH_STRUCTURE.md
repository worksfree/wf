# 출판물 관리 구조

## 폴더 용도
- `개별회차/`
  - 최신 작업본 MD/PDF
- `5개년통합/`
  - 최신 5개년 통합본 MD/PDF
- `archives/`
  - 과거 실제 판매본 보존
- `releases/`
  - 새로 배포할 최종본 PDF 모음
- `docs/`
  - 변경 이력, 배포 메모, 운영 기준 문서

## 현재 기준
- `archives/2025-05_37-39_first-release/`
  - 2025년 5월 판매본 37~39회 보존본
- `releases/2026-03_revision_37-39/`
  - 37~39회 개정판 배포 대상 폴더
- `releases/2026-03_release_36-40_and_5years/`
  - 최종 출판 대상 6종 배포 폴더

## 운영 규칙
- 기존 판매본 MD/PDF는 삭제하지 않고 `archives/`에 보존한다.
- 내부 작업용 MD는 저장소에 유지한다.
- 외부 배포 폴더에는 PDF 중심으로 관리한다.
- 회차별 변경사항은 `docs/CHANGELOG_37-39.md`에 먼저 기록한 뒤 배포한다.

## 페이지 구분 검토 기준
- 개별회차 PDF에서 확인한 본문 내부 페이지 구분 의도는 5개년통합본에도 유지되어야 한다.
- 5개년통합본은 회차와 회차 사이에 통합본 편집용 페이지 구분이 추가될 수 있다.
- 따라서 소스상 페이지 구분 마커 수가 개별회차와 5개년통합본 사이에 완전히 같지 않아도 된다.
- 최종 판단 기준은 소스 마커 개수의 1:1 일치 여부가 아니라, 사람이 PDF를 보았을 때 문제, 예시답안, 표, 그림, 풀이 흐름이 개별회차와 동일하게 자연스럽게 보이는지 여부로 한다.
