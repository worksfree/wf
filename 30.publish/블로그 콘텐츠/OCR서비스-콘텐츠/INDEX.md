# OCR 서비스 구축기 시리즈 INDEX
## 클라우드 Vision API 없이 — 집 PC 한 대로 OCR 서비스 만들기

**시리즈 포지셔닝**: RTX 5090 로컬 PC + Ollama + Cloudflare Worker로 월 구독료 0원 OCR 서비스를 만들고, 실측으로 모델을 비교하고, 실전에서 터진 버그를 해결해 나간 기록
**타깃**: 오픈소스 VLM으로 직접 OCR을 붙여보려는 개발자, 클라우드 Vision API 비용이 부담스러운 1인 개발자·스타트업
**파일 형식**: 블로그 본문 + `📱 30초 쇼츠 스크립트` 섹션 통합 (NAS 인프라구축 시리즈와 동일 포맷)

## 핵심 수치 요약 (전 편 공통 인용용)

- **손글씨 인식**: 97.4~99.8% (전처리 없이 목표 90% 초과 달성)
- **스캔 문서(정부 서식, 표 포함)**: 80.5% (표 전체 인식 성공, 헤더·푸터 잔글씨만 일부 누락 — 해당 영역만 잘라 재인식하면 94.5%까지 확인)
- **영수증(사진)**: 78~83% (핵심 데이터—상호·사업자번호·승인번호·금액—는 매번 정확히 추출)
- **채택 모델**: olmOCR-2-7B (Qwen2.5-VL 기반, Ollama `richardyoung/olmocr2:7b-q8`)
- **탈락 모델**: glm-ocr(표 섹션 통째 누락), dots.ocr(CLIP 로드 실패), PaddleOCR-VL(mmproj 누락으로 텍스트 전용), Baidu Unlimited-OCR(공식 프롬프트로도 성능 낮음)
- **그리드서치 최적값(로컬 6종 표본)**: 손글씨 대비-20%/샤프니스73% CER 0.0204, 긴문서 대비-10%/샤프니스0% CER 0.1326, 영수증 대비-20%/샤프니스8% CER 0.1885
- **AI-Hub 재검증(1212회 호출)**: 요식업 CER 0.2877, 제조업 CER 0.2835 — 유통업은 라벨링 스키마 문제로 무효 판정
- **카메라 버그**: 3개 원인 순차 발견(새로고침 홈 이동 → 계정전환 오판 → 탭 자체 재시작) → getUserMedia 전면 교체로 근본 해결
- **정밀교정 오버레이(1차, EP12)**: EasyOCR(위치 탐지 전용, CPU) + olmOCR-2(크롭 재인식) 하이브리드 — PaddleOCR·Tesseract.js 둘 다 배제
- **정밀교정 오버레이(재설계, EP13)**: 크롭 재인식을 폐기하고 내용 비교 없이 순서·글자수 누적(스케일 보정 포함)만으로 위치 계산 — "내용이 일치해야 찾아진다"는 순환논리를 근본적으로 제거
