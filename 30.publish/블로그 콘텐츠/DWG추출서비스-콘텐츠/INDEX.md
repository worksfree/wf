## 핵심 수치 요약 (전 편 공통 인용용)

- **채택 도구**: GNU LibreDWG(GPL, 완전 오픈소스) `dwgread.exe -O JSON` — ODA File Converter는 라이선스 불명확, DXF 변환 경로는 데이터 유실 확인으로 배제
- **DXF 변환 데이터 유실**: MTEXT 374개 → minimal 모드 87개(77% 유실), INSERT(블록 참조) 32개 → 0개
- **표제란 정확도**: 실제 도면 3건, 필드 12/12(또는 9/9·13/13) 100% 일치
- **BOM 정확도**: 실제 도면 6건 대조 검증(그 중 3건 정답 엑셀 대조), 실질적으로 100% 일치(잔여 불일치는 표기 방식 차이·데이터 드리프트, 코드 버그 아님)
- **실제 발견·수정한 버그**: 라벨-값 방향 가정 오류, 유클리드거리 미적용, 도면 테두리 그리드 오탐, DXF 데이터 유실, BOM 블록 modelspace 오인, 열 오배정(빈 열 스킵), BOM/홀치수표 오판정 — 총 7건
- **텍스트 없는 썸네일**: LibreDWG JSON의 LINE/ARC/CIRCLE/LWPOLYLINE 좌표만 추출해 SVG 렌더링(MTEXT 완전 배제), 대형 조립도(LINE 71,951개)는 4000개로 균등 샘플링, 이상치 좌표는 상하위 1% 퍼센타일 트림으로 제거
- **프라이버시 조치**: 표제란(DESIGN/CHECK/APPROVE/PART NAME/DWG NO.)·BOM(품명/설명) 블러(샘플 결과만, CSS) + 샘플 결과 엑셀 다운로드 버튼 숨김(블러가 못 막는 다운로드 유출 경로 차단) + O&M(admin/dwg-samples)에서 코드 배포 없이 샘플 6슬롯 교체 가능
